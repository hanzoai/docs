새 Hanzo 문서 사이트에 오신 것을 환영합니다. Hanzo AI Cloud 서비스, SDK, API 레퍼런스가 한곳에 있습니다.

## 여기 있는 것

- **33개 클라우드 서비스** — 모델 추론부터 오브젝트 스토리지까지 모두 `api.hanzo.ai`에 있습니다
- **SDK 레퍼런스** — Python, TypeScript, Go, Rust, C 클라이언트 라이브러리
- **API 문서** — 모든 엔드포인트의 OpenAPI 명세
- **제품 깊이 보기** — Commerce, Chat, Dev 도구 등

## 시작하기

가장 빠른 길은 [API 키를 받아](https://console.hanzo.ai) 요청을 보내는 것입니다.

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-sonnet-4-20250514", "messages": [{"role": "user", "content": "Hello!"}]}'
```

Hanzo가 제공하는 것은 [서비스 문서](/docs/services)에서 볼 수 있습니다.
