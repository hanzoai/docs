Chào mừng đến trang tài liệu mới của Hanzo. Đây là nơi thống nhất cho dịch vụ Hanzo AI Cloud, SDK và tài liệu API.

## Có gì ở đây

- **33 dịch vụ đám mây** — Từ suy luận mô hình đến lưu trữ đối tượng, tất cả tại `api.hanzo.ai`
- **Tham chiếu SDK** — Thư viện máy khách Python, TypeScript, Go, Rust và C
- **Tài liệu API** — Đặc tả OpenAPI cho mọi endpoint
- **Đi sâu sản phẩm** — Commerce, Chat, công cụ Dev và hơn thế

## Bắt đầu

Cách nhanh nhất là [lấy khóa API](https://console.hanzo.ai) rồi gửi yêu cầu:

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-sonnet-4-20250514", "messages": [{"role": "user", "content": "Hello!"}]}'
```

Xem [tài liệu dịch vụ](/docs/services) để biết Hanzo cung cấp những gì.
