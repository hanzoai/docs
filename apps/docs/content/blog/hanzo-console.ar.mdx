# تقديم Hanzo Console: مراقبة موحّدة لتطبيقات LLM

بناء تطبيقات LLM على نطاق واسع يعني أنك تعمل بلا رؤية. ترسل الطلبات إلى النماذج، وتتلقى الردود، وتأمل أن تسير الأمور. وحين لا تسير — مخرجات خاطئة، قفزات في زمن الاستجابة، تكاليف تنفجر — لا ترى السبب.

نطلق اليوم Hanzo Console: منصة مراقبة موحّدة لتطبيقات LLM.

## ماذا يفعل Console

يمنحك Console صورة كاملة لاستخدام LLM لدى كل المزوّدين:

**التتبّع**: كل استدعاء LLM يُسجَّل مع الطلب والرد كاملين، وزمن الاستجابة، وعدد الرموز، والتكلفة. اعرض الموجهات كما هي، والإكمالات كما هي، والتوقيت على مستوى الرمز.

**تتبّع التكلفة**: تكلفة آنية حسب النموذج والمشروع والمستخدم ومفتاح API. انظر إلى أين تذهب الميزانية، وحسّن على هذا الأساس.

**مراقبة الجودة**: تتبّع جودة المخرجات عبر الزمن. التقط الانحدارات قبل أن تصل إلى المستخدمين. اختبر الموجهات اختبار A/B بدلالة إحصائية.

**تعدد المزوّدين**: لوحة واحدة لـ OpenAI وAnthropic وTogether AI وكل مزوّد آخر تستخدمه. كفّ عن تجميع التقارير من خمس بوابات فوترة مختلفة.

## ضريبة التكامل

كل مزوّد LLM يقدّم شكلًا من لوحة الاستخدام. لكن إن كنت تستخدم عدة مزوّدين — وهو ما تفعله معظم تطبيقات الإنتاج — فأنت تطابق تقارير من خمسة أنظمة بخمسة مخططات مختلفة.

Console لا يرتبط بمزوّد. جهّز القياس مرة واحدة، وشاهد كل شيء.

```python
from hanzo import Console

console = Console(api_key="your-key")

# Automatic tracing with context manager
with console.trace("user_query"):
    response = openai.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": user_input}]
    )
```

## إدارة الموجهات

يتضمن Console سجلًا للموجهات. ضع إصدارات لموجهاتك، وتابع أي الإصدارات منشورة، وقارن الأداء بين الإصدارات.

مشكلة الموجهات داخل الشيفرة: تتقادم، وتتفرع، ولا أحد يعرف أي إصدار يعمل في الإنتاج. يجعل Console الموجهات مصنوعات مُدارة من الدرجة الأولى.

## تنسيق مجموعات البيانات

حوّل آثار الإنتاج إلى مجموعات بيانات للتقييم. علّم المخرجات الجيدة، وأشّر على السيئة، وابنِ مجموعة حقيقة مرجعية مباشرة من الاستخدام الفعلي.

حين تكون جاهزًا للضبط الدقيق أو لتبديل المزوّد، تكون لديك مجموعة بيانات تعكس حركة الإنتاج الحقيقية — لا أمثلة اصطناعية.

## متاح الآن

Console متاح على [console.hanzo.ai](https://console.hanzo.ai). الطبقة المجانية تشمل 50 ألف أثر في الشهر. النشر المستضاف ذاتيًا مدعوم للمؤسسات.
