# Hanzo Cloud: управляемая инфраструктура для коммерции

Шесть лет эксплуатации коммерческой инфраструктуры научили нас тому, что нужно предприятиям. Сегодня мы запускаем Hanzo Cloud: полностью управляемую коммерческую инфраструктуру с надёжностью корпоративного уровня.

## Зачем Hanzo Cloud

Растущий бизнес стоит перед выбором:

**SaaS-платформы**: Легко начать, но кастомизация ограничена. Вы подстраиваетесь под платформу.

**Своё размещение**: Полный контроль, но операционная нагрузка. Вы становитесь инфраструктурной компанией.

Hanzo Cloud даёт третий путь: возможности платформы и гибкость инфраструктуры.

## Что входит

### Выделенная инфраструктура

Ваш экземпляр Hanzo работает на изолированной инфраструктуре:

- Выделенные вычислительные ресурсы
- Изолированные кластеры баз данных
- Частная сеть
- Свои домены с автоматическим TLS

Без шумных соседей. Предсказуемая производительность.

### Глобальная периферийная сеть

Контент доставляется из более чем 200 периферийных точек:

- Статические ресурсы кэшируются на периферии
- Динамические запросы маршрутизируются оптимально
- Автоматическое переключение при сбое
- Защита от DDoS включена

Клиенты по всему миру получают локальную производительность.

### Управляемые базы данных

Полностью управляемый уровень данных:

- Автоматические резервные копии (восстановление на момент времени)
- Реплики для чтения ради масштабирования
- Автоматическое переключение при сбое
- Шифрование при хранении и при передаче

### Наблюдаемость

Полная видимость вашей инфраструктуры:

- Панели метрик в реальном времени
- Агрегация и поиск журналов
- Распределённая трассировка
- Свои оповещения

### Соответствие требованиям

Контроли, на которых строится корпоративное соответствие:

- Контроли SOC 2 Type II
- Контроли GDPR
- Контроли PCI DSS
- Контроли HIPAA

Сертификация ограничивается рамками конкретного проекта.

## Варианты развёртывания

### Один регион

Оптимизировано по стоимости, подходит региональному бизнесу:

- Выбор основного региона
- Автоматическое резервное копирование во вторичный регион
- SLA доступности 99,9%

### Несколько регионов

Глобальное присутствие с региональным размещением данных:

- Развёртывание в нескольких регионах
- Данные остаются в регионе
- Active-active для высокой доступности
- SLA доступности 99,99%

### Гибрид

Подключение к вашей существующей инфраструктуре:

- Связность через VPN
- Поддержка Private Link
- Репликация локальных баз данных
- Свои средства контроля безопасности
