Benvenuto nel nuovo sito di documentazione di Hanzo. È la casa unica dei servizi Hanzo AI Cloud, degli SDK e dei riferimenti API.

## Cosa c’è qui

- **33 servizi cloud** — Dall’inferenza dei modelli all’object storage, tutto su `api.hanzo.ai`
- **Riferimenti SDK** — Librerie client Python, TypeScript, Go, Rust e C
- **Documentazione API** — Specifiche OpenAPI per ogni endpoint
- **Approfondimenti di prodotto** — Commerce, Chat, strumenti Dev e altro

## Per iniziare

Il modo più rapido è [ottenere una chiave API](https://console.hanzo.ai) e iniziare a inviare richieste:

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-sonnet-4-20250514", "messages": [{"role": "user", "content": "Hello!"}]}'
```

Esplora la [documentazione dei servizi](/docs/services) per vedere tutto ciò che offre Hanzo.
