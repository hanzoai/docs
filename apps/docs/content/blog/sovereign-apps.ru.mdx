Base владеет состоянием. Lux владеет доверием. Семь лет коммитов, каждая часть прослеживается до первого хеша.

**Каждое приложение, которым вы пользуетесь сегодня, сдаёт вам в аренду доступ к вашим же данным. Мы построили замену. Это заняло семь лет.**

## Архитектура

Base (2022) — зашифрованное хранилище, синхронизация CRDT, API реального времени, Base Functions. Плоскость данных.

Lux (2020) — 15 цепей на каждом валидаторе. Идентичность, ключи, пороговое FHE, подпись MPC, EVM, DEX, мост, ZK, квантовый консенсус, инференс ИИ. Ядро доверия.

Три уровня: AES-256-GCM + ML-KEM (по умолчанию), пороговое раскрытие TFHE (высокая ценность), конфиденциальные вычисления CKKS (новые продукты).
