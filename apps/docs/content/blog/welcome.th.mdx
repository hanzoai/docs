ยินดีต้อนรับสู่ไซต์เอกสารใหม่ของ Hanzo ที่รวมบริการ Hanzo AI Cloud, SDK และเอกสาร API ไว้ที่เดียว

## มีอะไรที่นี่

- **33 บริการคลาวด์** — ตั้งแต่การอนุมานโมเดลถึงที่เก็บอ็อบเจกต์ ทั้งหมดอยู่ที่ `api.hanzo.ai`
- **เอกสาร SDK** — ไลบรารีไคลเอนต์ Python, TypeScript, Go, Rust และ C
- **เอกสาร API** — ข้อกำหนด OpenAPI ของทุกเอนด์พอยต์
- **เจาะผลิตภัณฑ์** — Commerce, Chat, เครื่องมือ Dev และอื่น ๆ

## เริ่มต้น

ทางที่เร็วที่สุดคือ [ขอคีย์ API](https://console.hanzo.ai) แล้วเริ่มส่งคำขอ:

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-sonnet-4-20250514", "messages": [{"role": "user", "content": "Hello!"}]}'
```

ดู [เอกสารบริการ](/docs/services) เพื่อเห็นทุกอย่างที่ Hanzo มี
