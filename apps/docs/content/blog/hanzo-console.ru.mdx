# Представляем Hanzo Console: единая наблюдаемость LLM

Строить LLM-приложения в масштабе — значит лететь вслепую. Вы отправляете запросы моделям, получаете ответы и надеетесь, что всё работает. Когда нет — неверные выводы, скачки задержки, взрыв затрат — не видно, почему.

Сегодня мы запускаем Hanzo Console: единую платформу наблюдаемости для LLM-приложений.

## Что делает Console

Console даёт полную картину использования LLM у всех провайдеров:

**Трассировка**: Каждый вызов LLM записывается с полным запросом и ответом, задержкой, числом токенов и стоимостью. Смотрите точные промпты, точные завершения и тайминг на уровне токена.

**Учёт стоимости**: Стоимость в реальном времени по модели, проекту, пользователю и ключу API. Видно, куда уходит бюджет, и можно оптимизировать.

**Контроль качества**: Следите за качеством выводов во времени. Ловите регрессии до того, как они дойдут до пользователей. Проводите A/B-тесты промптов со статистической значимостью.

**Несколько провайдеров**: Одна панель для OpenAI, Anthropic, Together AI и любого другого провайдера. Хватит сшивать отчёты из пяти разных биллинговых кабинетов.

## Налог на интеграцию

У каждого провайдера LLM есть какая-то панель использования. Но если провайдеров несколько — а у большинства продакшен-приложений так и есть — вы сверяете отчёты пяти систем с пятью разными схемами.

Console не зависит от провайдера. Инструментируйте один раз и видьте всё.

```python
from hanzo import Console

console = Console(api_key="your-key")

# Automatic tracing with context manager
with console.trace("user_query"):
    response = openai.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": user_input}]
    )
```

## Управление промптами

В Console есть реестр промптов. Версионируйте промпты, отслеживайте, какие версии развёрнуты, сравнивайте производительность версий.

Проблема промптов в коде: они устаревают, расходятся в ветки, и никто не знает, какая версия работает в продакшене. Console делает промпты управляемыми артефактами первого класса.

## Сбор наборов данных

Превращайте продакшен-трассы в наборы для оценки. Отмечайте удачные выводы, помечайте неудачные и собирайте набор эталонных данных прямо из реального использования.

Когда вы готовы к дообучению или смене провайдера, у вас есть набор, который отражает реальный продакшен-трафик, а не синтетические примеры.

## Уже доступно

Console доступен на [console.hanzo.ai](https://console.hanzo.ai). Бесплатный уровень включает 50 000 трасс в месяц. Для предприятий поддерживается самостоятельное развёртывание.
