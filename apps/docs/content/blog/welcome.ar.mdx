مرحبًا بك في موقع التوثيق الجديد. إنه الموطن الموحّد لخدمات Hanzo AI Cloud وحزم SDK ومراجع API.

## ماذا ستجد هنا

- **33 خدمة سحابية** — من استدلال النماذج إلى تخزين الكائنات، كل شيء على `api.hanzo.ai`
- **مراجع SDK** — مكتبات عميل لـ Python وTypeScript وGo وRust وC
- **توثيق API** — مواصفات OpenAPI لكل نقطة نهاية
- **شروح المنتجات** — Commerce وChat وأدوات Dev والمزيد

## البداية

أسرع طريق هو [الحصول على مفتاح API](https://console.hanzo.ai) ثم إرسال الطلبات:

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-sonnet-4-20250514", "messages": [{"role": "user", "content": "Hello!"}]}'
```

استعرض [توثيق الخدمات](/docs/services) لترى كل ما تقدمه Hanzo.
