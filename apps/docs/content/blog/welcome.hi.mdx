Hanzo के नए दस्तावेज़ साइट पर स्वागत है. यह Hanzo AI Cloud सेवाओं, SDK और API संदर्भों का एक घर है.

## यहाँ क्या है

- **33 क्लाउड सेवाएँ** — मॉडल इन्फ़रेंस से ऑब्जेक्ट स्टोरेज तक, सब कुछ `api.hanzo.ai` पर
- **SDK संदर्भ** — Python, TypeScript, Go, Rust और C क्लाइंट लाइब्रेरी
- **API दस्तावेज़** — हर एंडपॉइंट की OpenAPI विशिष्टताएँ
- **उत्पाद की गहराई** — Commerce, Chat, Dev उपकरण और अधिक

## शुरुआत

सबसे तेज़ रास्ता है [API कुंजी लें](https://console.hanzo.ai) और अनुरोध भेजना शुरू करें:

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-sonnet-4-20250514", "messages": [{"role": "user", "content": "Hello!"}]}'
```

Hanzo क्या देता है, यह [सेवा दस्तावेज़](/docs/services) में देखें.
