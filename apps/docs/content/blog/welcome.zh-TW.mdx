歡迎來到新的 Hanzo 文件站。這裡集中了 Hanzo AI Cloud 的服務、SDK 和 API 參考。

## 這裡有什麼

- **33 項雲端服務** — 從模型推論到物件儲存，都在 `api.hanzo.ai`
- **SDK 參考** — Python、TypeScript、Go、Rust 和 C 用戶端程式庫
- **API 文件** — 每個端點的 OpenAPI 規格
- **產品深入介紹** — Commerce、Chat、Dev 工具等

## 開始使用

最快的方式是[取得 API 金鑰](https://console.hanzo.ai)，然後送出請求：

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-sonnet-4-20250514", "messages": [{"role": "user", "content": "Hello!"}]}'
```

瀏覽[服務文件](/docs/services)，看 Hanzo 提供的一切。
