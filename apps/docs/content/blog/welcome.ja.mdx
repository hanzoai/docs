新しい Hanzo ドキュメントサイトへようこそ。Hanzo AI Cloud のサービス、SDK、API リファレンスがここに揃います。

## ここにあるもの

- **33 のクラウドサービス** — モデル推論からオブジェクトストレージまで、すべては `api.hanzo.ai`
- **SDK リファレンス** — Python、TypeScript、Go、Rust、C のクライアントライブラリ
- **API ドキュメント** — すべてのエンドポイントの OpenAPI 仕様
- **プロダクト解説** — Commerce、Chat、Dev ツールなど

## はじめに

いちばん速いのは [API キーを取得](https://console.hanzo.ai)してリクエストを送ることです。

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-sonnet-4-20250514", "messages": [{"role": "user", "content": "Hello!"}]}'
```

Hanzo が提供するものは [サービスドキュメント](/docs/services) にまとまっています。
