# Hanzo Cloud: 상거래를 위한 관리형 인프라

상거래 인프라를 여섯 해 운영하며 기업이 무엇을 필요로 하는지 배웠다. 오늘 Hanzo Cloud를 낸다. 기업급 신뢰성을 갖춘, 완전히 관리되는 상거래 인프라다.

## 왜 Hanzo Cloud인가

자라는 사업은 선택을 만난다.

**SaaS 플랫폼**: 시작은 쉽다. 맞춤은 제한된다. 플랫폼에 맞추게 된다.

**자체 호스팅**: 통제는 완전하다. 운영 부담이 남는다. 인프라 회사가 된다.

Hanzo Cloud는 세 번째 길이다. 플랫폼의 능력과 인프라의 유연성.

## 포함되는 것

### 전용 인프라

Hanzo 인스턴스는 격리된 인프라에서 돈다.

- 전용 컴퓨트 자원
- 격리된 데이터베이스 클러스터
- 사설 네트워킹
- 자동 TLS가 붙은 자체 도메인

시끄러운 이웃이 없다. 성능은 예측된다.

### 전역 엣지 망

콘텐츠는 200곳이 넘는 엣지 위치에서 전달된다.

- 정적 자산은 엣지에 캐시
- 동적 요청은 최적으로 라우팅
- 자동 장애 조치
- DDoS 보호 포함

전 세계 고객이 현지 성능을 본다.

### 관리형 데이터베이스

데이터 계층은 완전히 관리된다.

- 자동 백업(특정 시점으로 복구)
- 확장을 위한 읽기 복제본
- 자동 장애 조치
- 저장 시와 전송 시의 암호화

### 관측

인프라에 대한 완전한 가시성.

- 실시간 지표 대시보드
- 로그 수집과 검색
- 분산 추적
- 맞춤 경보

### 컴플라이언스

기업 컴플라이언스가 올라가는 통제.

- SOC 2 Type II 통제
- GDPR 통제
- PCI DSS 통제
- HIPAA 통제

인증 범위는 계약마다 자른다.

## 배포 선택

### 단일 리전

비용에 맞춘다. 지역 사업에 맞다.

- 기본 리전 선택
- 보조 리전으로의 자동 백업
- 가동률 99.9% SLA

### 다중 리전

전역 존재와 리전 안의 데이터 거주.

- 여러 리전에 배포
- 데이터는 리전에 남는다
- 고가용을 위한 액티브-액티브
- 가동률 99.99% SLA

### 하이브리드

이미 있는 인프라에 붙인다.

- VPN 연결
- Private Link 지원
- 온프레미스 데이터베이스 복제
- 맞춤 보안 통제

## 이전

Hanzo Cloud로 옮기는 일은 직선적이다.

1. **평가**: 현재 구성을 분석한다
2. **계획**: 맞춤 이전 계획
3. **실행**: 중단 없는 이전
4. **검증**: 포괄적 시험
5. **전환**: DNS를 바꾸고, 가동한다

이전 지원은 추가 비용 없이 포함된다.

## 가격

투명하고 예측되는 가격.

- **플랫폼 기본 요금**: 월 고정
- **컴퓨트**: 인스턴스 크기에 따라
- **스토리지**: 저장한 GB마다
- **전송**: 전송한 GB마다

숨은 요금이 없다. 청구서 기습도 없다.

## 지원

Hanzo Cloud에는 프리미엄 지원이 들어 있다.

- 24시간 기술 지원
- 응답 15분(심각)
- 전담 계정 관리자
- 분기별 사업 검토

## 뒤의 팀

인프라 팀은 다음을 다루는 상거래 시스템을 운영해 왔다.

- 연 5,000만 건이 넘는 트랜잭션
- 가동률 99.99%
- 100 ms 미만의 응답
- 블랙 프라이데이 규모의 이벤트

고용하지 않고 그 전문성을 얻는다.

## 시작

상담을 연락하라. 필요를 보고 제안서를 낸다.

Hanzo Cloud. 사업에 집중하고, 인프라는 우리가 맡는다.
