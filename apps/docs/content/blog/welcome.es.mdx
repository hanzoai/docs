Bienvenido al nuevo sitio de documentación de Hanzo. Es el hogar unificado de los servicios de Hanzo AI Cloud, los SDK y las referencias de API.

## Qué hay aquí

- **33 servicios en la nube** — De la inferencia de modelos al almacenamiento de objetos, todo en `api.hanzo.ai`
- **Referencias de SDK** — Bibliotecas cliente en Python, TypeScript, Go, Rust y C
- **Documentación de API** — Especificaciones OpenAPI de cada endpoint
- **Recorridos de producto** — Commerce, Chat, herramientas de Dev y más

## Primeros pasos

La forma más rápida es [obtener una clave de API](https://console.hanzo.ai) y empezar a hacer peticiones:

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-sonnet-4-20250514", "messages": [{"role": "user", "content": "Hello!"}]}'
```

Explora la [documentación de servicios](/docs/services) para ver todo lo que ofrece Hanzo.
