# Hanzo Cloud: verwaltete Infrastruktur für den Handel

Sechs Jahre Betrieb von Handelsinfrastruktur haben uns gezeigt, was Unternehmen brauchen. Heute starten wir Hanzo Cloud: vollständig verwaltete Handelsinfrastruktur mit Zuverlässigkeit auf Unternehmensniveau.

## Warum Hanzo Cloud

Wachsende Unternehmen stehen vor einer Wahl:

**SaaS-Plattformen**: Leicht zu starten, aber eingeschränkte Anpassung. Sie passen sich der Plattform an.

**Selbst gehostet**: Volle Kontrolle, aber operative Last. Sie werden zum Infrastrukturunternehmen.

Hanzo Cloud bietet einen dritten Weg: Plattformfähigkeiten mit Infrastrukturflexibilität.

## Was enthalten ist

### Dedizierte Infrastruktur

Ihre Hanzo-Instanz läuft auf isolierter Infrastruktur:

- Dedizierte Rechenressourcen
- Isolierte Datenbankcluster
- Private Vernetzung
- Eigene Domains mit automatischem TLS

Keine lauten Nachbarn. Vorhersehbare Leistung.

### Globales Edge-Netz

Inhalte werden von über 200 Edge-Standorten ausgeliefert:

- Statische Assets am Edge zwischengespeichert
- Dynamische Anfragen optimal geroutet
- Automatisches Failover
- DDoS-Schutz inklusive

Kunden weltweit erleben lokale Leistung.

### Verwaltete Datenbanken

Vollständig verwaltete Datenebene:

- Automatische Sicherungen (Wiederherstellung auf einen Zeitpunkt)
- Lesereplikate für die Skalierung
- Automatisches Failover
- Verschlüsselung im Ruhezustand und bei der Übertragung

### Observability

Vollständige Sicht auf Ihre Infrastruktur:

- Metrik-Dashboards in Echtzeit
- Log-Aggregation und Suche
- Verteiltes Tracing
- Eigene Alarme

### Compliance

Die Kontrollen, auf denen Unternehmens-Compliance aufbaut:

- SOC 2 Type II-Kontrollen
- GDPR-Kontrollen
- PCI DSS-Kontrollen
- HIPAA-Kontrollen

Die Zertifizierung wird je Auftrag abgegrenzt.

## Bereitstellungsoptionen

Auf Kosten optimiert, geeignet für regionale Unternehmen:

- 99,9 % Verfügbarkeits-SLA

### Mehrere Regionen

Globale Präsenz mit regionaler Datenresidenz:

- Bereitstellung in mehreren Regionen
- Daten bleiben in der Region
- Aktiv-aktiv für hohe Verfügbarkeit
- 99,99 % Verfügbarkeits-SLA

### Hybrid

Anbindung an Ihre bestehende Infrastruktur:

- VPN-Konnektivität
- Private Link-Unterstützung

- Eigene Sicherheitskontrollen
