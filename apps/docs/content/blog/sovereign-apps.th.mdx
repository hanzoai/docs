## สถาปัตยกรรม

Base (2022) — ห้องนิรภัยเข้ารหัส ซิงก์ CRDT API เรียลไทม์ Base Functions ระนาบข้อมูล

Lux (2020) — 15 เชนบนทุกตัวตรวจสอบ ตัวตน กุญแจ FHE ขีดแบ่ง ลายเซ็น MPC, EVM, DEX, สะพาน, ZK, ฉันทามติควอนตัม, การอนุมาน AI เคอร์เนลความไว้ใจ

สามชั้น: AES-256-GCM + ML-KEM (ค่าเริ่มต้น), การเปิดเผยขีดแบ่ง TFHE (มูลค่าสูง), การคำนวณลับ CKKS (ผลิตภัณฑ์ใหม่)

บทพิสูจน์ Lean 4 จำนวน 86 ไม่มี sorry มากกว่า 80 บทความ ทีมแดง ส่งแล้ว

**ระบบปฏิบัติการสำหรับแอปอธิปไตย Base เป็นเจ้าของสถานะ Lux เป็นเจ้าของความไว้ใจ ผู้ใช้เป็นเจ้าของทุกสิ่งที่สำคัญ**
