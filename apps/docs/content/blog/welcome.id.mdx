Selamat datang di situs dokumentasi Hanzo yang baru. Ini rumah terpadu untuk layanan Hanzo AI Cloud, SDK, dan referensi API.

## Apa yang ada di sini

- **33 layanan cloud** — Dari inferensi model sampai penyimpanan objek, semuanya di `api.hanzo.ai`
- **Referensi SDK** — Pustaka klien Python, TypeScript, Go, Rust, dan C
- **Dokumentasi API** — Spesifikasi OpenAPI untuk setiap endpoint
- **Ulasan produk** — Commerce, Chat, perkakas Dev, dan lainnya

## Memulai

Cara tercepat adalah [mengambil kunci API](https://console.hanzo.ai) lalu mengirim permintaan:

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-sonnet-4-20250514", "messages": [{"role": "user", "content": "Hello!"}]}'
```

Jelajahi [dokumentasi layanan](/docs/services) untuk melihat semua yang ditawarkan Hanzo.
