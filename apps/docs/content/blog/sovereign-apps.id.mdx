## Arsitektur

Base (2022) — brankas terenkripsi, sinkronisasi CRDT, API waktu nyata, Base Functions. Bidang data.

Lux (2020) — 15 rantai di setiap validator. Identitas, kunci, FHE ambang, penandatanganan MPC, EVM, DEX, jembatan, ZK, konsensus kuantum, inferensi AI. Kernel kepercayaan.

Tiga tingkat: AES-256-GCM + ML-KEM (bawaan), pengungkapan ambang TFHE (nilai tinggi), komputasi rahasia CKKS (produk baru).
