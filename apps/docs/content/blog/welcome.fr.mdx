Bienvenue sur le nouveau site de documentation Hanzo. C’est le foyer unique des services Hanzo AI Cloud, des SDK et des références d’API.

## Ce qui s’y trouve

- **33 services cloud** — De l’inférence de modèles au stockage d’objets, tout est sur `api.hanzo.ai`
- **Références SDK** — Bibliothèques clientes Python, TypeScript, Go, Rust et C
- **Documentation API** — Spécifications OpenAPI de chaque point de terminaison
- **Visites de produit** — Commerce, Chat, outils Dev, et plus

## Pour commencer

Le plus rapide est d’[obtenir une clé d’API](https://console.hanzo.ai) puis d’envoyer des requêtes :

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-sonnet-4-20250514", "messages": [{"role": "user", "content": "Hello!"}]}'
```

Parcourez la [documentation des services](/docs/services) pour voir tout ce que Hanzo propose.
