Добро пожаловать на новый сайт документации Hanzo. Это единый дом сервисов Hanzo AI Cloud, SDK и справочников API.

## Что здесь есть

- **33 облачных сервиса** — От инференса моделей до объектного хранилища — всё на `api.hanzo.ai`
- **Справочники SDK** — Клиентские библиотеки Python, TypeScript, Go, Rust и C
- **Документация API** — Спецификации OpenAPI для каждой конечной точки
- **Разборы продуктов** — Commerce, Chat, инструменты Dev и другое

## С чего начать

Быстрее всего [получить ключ API](https://console.hanzo.ai) и отправить первые запросы:

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-sonnet-4-20250514", "messages": [{"role": "user", "content": "Hello!"}]}'
```

В [документации сервисов](/docs/services) — всё, что предлагает Hanzo.
