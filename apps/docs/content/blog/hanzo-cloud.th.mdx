# Hanzo Cloud: โครงสร้างที่จัดการให้สำหรับงานพาณิชย์

หกปีที่เดินระบบโครงสร้างพาณิชย์สอนเราว่าองค์กรต้องการอะไร วันนี้เราเปิด Hanzo Cloud: โครงสร้างพาณิชย์ที่จัดการให้ทั้งชุด ด้วยความเชื่อถือได้ระดับองค์กร

## ทำไมต้อง Hanzo Cloud

ธุรกิจที่กำลังโตเจอทางเลือก:

**แพลตฟอร์ม SaaS**: เริ่มง่าย แต่ปรับแต่งได้จำกัด คุณต้องปรับตัวเข้ากับแพลตฟอร์ม

**โฮสต์เอง**: ควบคุมเต็ม แต่แบกภาระเดินระบบ คุณกลายเป็นบริษัทโครงสร้างพื้นฐาน

Hanzo Cloud ให้ทางที่สาม: ความสามารถของแพลตฟอร์ม พร้อมความยืดหยุ่นของโครงสร้าง

## มีอะไรบ้าง

### โครงสร้างเฉพาะ

อินสแตนซ์ Hanzo ของคุณรันบนโครงสร้างที่แยกออกมา:

- ทรัพยากรคอมพิวต์เฉพาะ
- คลัสเตอร์ฐานข้อมูลที่แยก
- เครือข่ายส่วนตัว
- โดเมนของคุณเองพร้อม TLS อัตโนมัติ

ไม่มีเพื่อนบ้านเสียงดัง ประสิทธิภาพคาดเดาได้

### เครือข่ายขอบทั่วโลก

เนื้อหาส่งจากจุดขอบกว่า 200 แห่ง:

- สินทรัพย์คงที่แคชที่ขอบ
- คำขอแบบไดนามิกถูกจัดเส้นทางอย่างเหมาะ
- สลับเมื่อล้มเหลวอัตโนมัติ
- การป้องกัน DDoS รวมอยู่แล้ว

ลูกค้าทั่วโลกได้ประสิทธิภาพแบบท้องถิ่น

### ฐานข้อมูลที่จัดการให้

ชั้นข้อมูลที่จัดการให้ทั้งชุด:

- สำรองอัตโนมัติ (กู้คืนถึงจุดเวลา)
- สำเนาอ่านเพื่อขยาย
- สลับเมื่อล้มเหลวอัตโนมัติ
- เข้ารหัสทั้งตอนเก็บและตอนส่ง

### การสังเกต

เห็นโครงสร้างของคุณครบ:

- แผงเมตริกตามเวลาจริง
- รวมและค้นบันทึก
- ตามรอยแบบกระจาย
- การแจ้งเตือนที่กำหนดเอง

### การปฏิบัติตาม

ตัวควบคุมที่การปฏิบัติตามขององค์กรสร้างบนนั้น:

- ตัวควบคุม SOC 2 Type II
- ตัวควบคุม GDPR
- ตัวควบคุม PCI DSS
- ตัวควบคุม HIPAA

การรับรองกำหนดขอบเขตต่องาน

## ทางเลือกในการติดตั้ง

### ภูมิภาคเดียว

ปรับให้ต้นทุนต่ำ เหมาะกับธุรกิจระดับภูมิภาค:

- เลือกภูมิภาคหลัก
- สำรองอัตโนมัติไปภูมิภาครอง
- SLA เวลาให้บริการ 99.9%

### หลายภูมิภาค

อยู่ทั่วโลก โดยข้อมูลอยู่ประจำภูมิภาค:

- ติดตั้งหลายภูมิภาค
- ข้อมูลอยู่ในภูมิภาคนั้น
- แอคทีฟ-แอคทีฟเพื่อความพร้อมสูง
- SLA เวลาให้บริการ 99.99%

### ไฮบริด

ต่อกับโครงสร้างที่คุณมีอยู่:

- การเชื่อม VPN
- รองรับ Private Link
- ทำซ้ำฐานข้อมูลในสถานที่ของคุณ
- ตัวควบคุมความปลอดภัยที่กำหนดเอง

## การย้าย

ย้ายมา Hanzo Cloud ตรงไปตรงมา:

1. **ประเมิน**: เราดูการจัดวางปัจจุบันของคุณ
2. **วางแผน**: แผนย้ายเฉพาะคุณ
3. **ลงมือ**: ย้ายโดยไม่หยุดระบบ
4. **ตรวจ**: ทดสอบครบ
5. **สลับ**: เปลี่ยน DNS แล้วคุณออนไลน์

การสนับสนุนการย้ายรวมอยู่แล้ว ไม่มีค่าเพิ่ม

## ราคา

ราคาโปร่งใส คาดเดาได้:

- **ค่าแพลตฟอร์มฐาน**: คงที่รายเดือน
- **คอมพิวต์**: ตามขนาดอินสแตนซ์
- **ที่เก็บ**: ต่อ GB ที่เก็บ
- **การส่ง**: ต่อ GB ที่ส่ง

ไม่มีค่าซ่อน ไม่มีบิลเซอร์ไพรส์

## การสนับสนุน

Hanzo Cloud รวมการสนับสนุนระดับพรีเมียม:

- สนับสนุนทางเทคนิค 24/7
- เวลาตอบ 15 นาที (วิกฤต)
- ผู้จัดการบัญชีเฉพาะ
- ทบทวนธุรกิจรายไตรมาส
