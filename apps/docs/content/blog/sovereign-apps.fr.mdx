**Chaque app que vous utilisez aujourd'hui vous loue l'accès à vos propres données. Nous avons construit le remplacement. Cela a pris sept ans.**

## Architecture

Base (2022) — coffre chiffré, synchro CRDT, API temps réel, Base Functions. Le plan de données.

Lux (2020) — 15 chaînes sur chaque validateur. Identité, clés, FHE à seuil, signature MPC, EVM, DEX, pont, ZK, consensus quantique, inférence d'IA. Le noyau de confiance.

Trois niveaux : AES-256-GCM + ML-KEM (par défaut), révélation à seuil TFHE (haute valeur), calcul confidentiel CKKS (nouveaux produits).

86 preuves Lean 4. Zéro sorry. Plus de 80 articles. Red team. Livré.
