# Hanzo Cloud: infraestrutura gerenciada para comércio

Seis anos operando infraestrutura de comércio nos ensinaram o que as empresas precisam. Hoje lançamos o Hanzo Cloud: infraestrutura de comércio totalmente gerenciada, com confiabilidade de nível empresarial.

## Por que o Hanzo Cloud

Negócios em crescimento enfrentam uma escolha:

**Plataformas SaaS**: Fáceis de começar, mas com personalização limitada. Você se adapta à plataforma.

**Auto-hospedado**: Controle total, mas carga operacional. Você vira uma empresa de infraestrutura.

O Hanzo Cloud oferece um terceiro caminho: capacidades de plataforma com flexibilidade de infraestrutura.

## O que está incluído

### Infraestrutura dedicada

Sua instância Hanzo roda em infraestrutura isolada:

- Recursos de computação dedicados
- Clusters de banco de dados isolados
- Rede privada
- Domínios próprios com TLS automático

Sem vizinhos barulhentos. Desempenho previsível.

### Rede de borda global

O conteúdo é entregue a partir de mais de 200 locais de borda:

- Ativos estáticos em cache na borda
- Requisições dinâmicas roteadas de forma ótima
- Failover automático
- Proteção contra DDoS incluída

Clientes no mundo todo têm desempenho local.

### Bancos de dados gerenciados

Camada de dados totalmente gerenciada:

- Backups automáticos (recuperação a um ponto no tempo)
- Réplicas de leitura para escalar
- Failover automático
- Criptografia em repouso e em trânsito

### Observabilidade

Visibilidade completa da sua infraestrutura:

- Painéis de métricas em tempo real
- Agregação e busca de logs
- Rastreamento distribuído
- Alertas sob medida

### Conformidade

Os controles sobre os quais a conformidade empresarial se apoia:

- Controles SOC 2 Type II
- Controles GDPR
- Controles PCI DSS
- Controles HIPAA

A certificação é delimitada por contrato.
