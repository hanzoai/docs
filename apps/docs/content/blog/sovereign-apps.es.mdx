## Arquitectura

Base (2022) — bóveda cifrada, sincronización CRDT, API en tiempo real, Base Functions. El plano de datos.

Lux (2020) — 15 cadenas en cada validador. Identidad, claves, FHE umbral, firma MPC, EVM, DEX, puente, ZK, consenso cuántico, inferencia de IA. El núcleo de confianza.

Tres niveles: AES-256-GCM + ML-KEM (predeterminado), revelación umbral TFHE (alto valor), cómputo confidencial CKKS (productos nuevos).
