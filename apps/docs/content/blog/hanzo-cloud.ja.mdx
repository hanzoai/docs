# Hanzo Cloud: 商取引のためのマネージド基盤

商取引の基盤を六年運用して、企業が何を必要とするかを学んだ。今日、Hanzo Cloud を出す。企業級の信頼性を持つ、完全マネージドの商取引基盤だ。

## なぜ Hanzo Cloud か

伸びている事業は選択を迫られる。

**SaaS プラットフォーム**: 始めやすい。しかしカスタマイズは限られる。プラットフォームに合わせる側になる。

**自前ホスティング**: 制御は完全だ。しかし運用負荷が残る。インフラ企業になる。

Hanzo Cloud は第三の道だ。プラットフォームの能力と、基盤の柔軟さ。

## 含まれるもの

### 専用基盤

Hanzo のインスタンスは隔離された基盤の上で動く。

- 専用の計算資源
- 隔離されたデータベースクラスタ
- プライベートネットワーク
- 自動 TLS つきの独自ドメイン

うるさい隣人はいない。性能は読める。

### グローバルなエッジ網

コンテンツは 200 を超えるエッジ拠点から届く。

- 静的アセットはエッジでキャッシュ
- 動的リクエストは最適にルーティング
- 自動フェイルオーバー
- DDoS 防御を含む

世界中の顧客が、現地の性能を得る。

### マネージドデータベース

データ層は完全に管理される。

- 自動バックアップ（時点復旧）
- スケールのための読み取りレプリカ
- 自動フェイルオーバー
- 保管時と転送時の暗号化

### オブザーバビリティ

基盤への完全な可視性。

- リアルタイムのメトリクスダッシュボード
- ログの集約と検索
- 分散トレース
- 独自のアラート

### コンプライアンス

企業コンプライアンスが乗る制御。

- SOC 2 Type II の制御
- GDPR の制御
- PCI DSS の制御
- HIPAA の制御

認証の範囲は契約ごとに切る。

## 配備の選択肢

### 単一リージョン

コスト優先。地域事業に向く。

- プライマリリージョンの選択
- セカンダリリージョンへの自動バックアップ
- 稼働率 99.9% の SLA

### 複数リージョン

グローバルな存在と、リージョン内のデータ所在。

- 複数リージョンへ配備
- データはリージョンに残る
- 高可用のためのアクティブ-アクティブ
- 稼働率 99.99% の SLA

### ハイブリッド

既存の基盤につなぐ。

- VPN 接続
- Private Link 対応
- オンプレミスのデータベース複製
- 独自のセキュリティ制御

## 移行

Hanzo Cloud への移動は直線的だ。

1. **評価**: いまの構成を分析する
2. **計画**: 個別の移行計画
3. **実行**: 停止なしの移行
4. **検証**: 包括的な試験
5. **切り替え**: DNS を切り替え、稼働する

移行支援は追加費用なしで含まれる。

## 価格

透明で、読める価格。

- **基盤の基本料金**: 月額固定
- **計算**: インスタンスサイズに応じて
- **ストレージ**: 保管した GB ごと
- **転送**: 転送した GB ごと

隠れた料金はない。請求の不意打ちもない。

## サポート

Hanzo Cloud にはプレミアムサポートが含まれる。

- 24 時間の技術サポート
- 応答 15 分（重大）
- 専任のアカウントマネージャ
- 四半期ごとの事業レビュー

## 背後のチーム

インフラチームは、次を扱う商取引システムを運用してきた。

- 年間 5,000 万件超のトランザクション
- 稼働率 99.99%
- 100 ms 未満の応答

雇わずに、その専門性を得られる。
