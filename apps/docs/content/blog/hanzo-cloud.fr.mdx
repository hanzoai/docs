# Hanzo Cloud : infrastructure gérée pour le commerce

Six ans à exploiter de l'infrastructure de commerce nous ont appris ce dont les entreprises ont besoin. Aujourd'hui nous lançons Hanzo Cloud : une infrastructure de commerce entièrement gérée, avec une fiabilité de niveau entreprise.

## Pourquoi Hanzo Cloud

Les entreprises en croissance font face à un choix :

**Plateformes SaaS** : Faciles à démarrer, mais personnalisation limitée. Vous vous adaptez à la plateforme.

**Auto-hébergé** : Contrôle total, mais charge opérationnelle. Vous devenez une société d'infrastructure.

Hanzo Cloud offre une troisième voie : les capacités d'une plateforme, avec la souplesse de l'infrastructure.

## Ce qui est inclus

### Infrastructure dédiée

Votre instance Hanzo tourne sur une infrastructure isolée :

- Ressources de calcul dédiées
- Clusters de bases de données isolés
