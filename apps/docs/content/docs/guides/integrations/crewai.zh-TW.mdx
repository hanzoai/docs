`LLM` 接受 **`base_url`**。給模型加上 `openai/` 前綴，LiteLLM 就會把它走 OpenAI 相容路徑。

```bash
pip install crewai
```

```python
from crewai import LLM, Agent

llm = LLM(
    model="openai/zen5",
    base_url="https://api.hanzo.ai/v1",
    api_key="sk-...",
)

agent = Agent(
    role="Researcher",
    goal="Answer precisely",
    backstory="You check before you answer.",
    llm=llm,
)
```

會打到 `POST /v1/chat/completions`。

對於 CrewAI 認不出是 OpenAI 名稱的模型 id，加上 **`custom_openai=True`**——這個旗標讓閘道模型 id 原樣通過、不被改寫：

```python
llm = LLM(
    model="anthropic/claude-sonnet-4-6",
    custom_openai=True,
    base_url="https://api.hanzo.ai/v1",
    api_key="sk-...",
)
```

環境變數對應項是 `OPENAI_API_KEY` 與 `OPENAI_BASE_URL`。

## MCP

MCP 伺服器在 Agent 上是一等公民，放在 `mcps` 清單裡。URL 是 `url` 參數。

```python
from crewai import Agent
from crewai.mcp import MCPServerHTTP

server = MCPServerHTTP(
    url="https://api.hanzo.ai/v1/mcp",
    headers={"Authorization": "Bearer sk-..."},
    streamable=True,
    cache_tools_list=True,
)

agent = Agent(role="Researcher", goal="Answer precisely", backstory="", llm=llm, mcps=[server])
```

要手動管生命週期，用 `crewai_tools` 裡的 `MCPServerAdapter`，以 `pip install 'crewai-tools[mcp]'` 安裝，它接受含 `url` 與 `transport` 的 dict。
