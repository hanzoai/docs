Cloudflare Agents hat keinen eigenen Basis-URL-Parameter. Die dokumentierte Konstruktion ist der schlichte `openai`-Client, gebaut im Agent, mit gesetztem **`baseURL`**.

```bash
npm i agents openai
```

```ts
import { Agent } from "agents";
import { OpenAI } from "openai";

export class Researcher extends Agent {
  async onRequest(request: Request): Promise<Response> {
    const client = new OpenAI({
      apiKey: this.env.HANZO_API_KEY,
      baseURL: "https://api.hanzo.ai/v1",
    });

    const { readable, writable } = new TransformStream();
    const writer = writable.getWriter();
    const encoder = new TextEncoder();

    this.ctx.waitUntil(
      (async () => {
        const stream = await client.chat.completions.create({
          model: "zen5",
          messages: [{ role: "user", content: await request.text() }],
          stream: true,
        });
        for await (const part of stream) {
          writer.write(encoder.encode(part.choices[0]?.delta?.content || ""));
        }
        writer.close();
      })(),
    );

    return new Response(readable);
  }
}
```

Landet auf `POST /v1/chat/completions`.

Legen Sie den Schlüssel in ein Worker-Secret — `wrangler secret put HANZO_API_KEY` — und er kommt auf `this.env` an. Streaming läuft in `ctx.waitUntil`, damit der Worker nicht abgebaut wird, solange die Antwort noch geschrieben wird.

Der andere dokumentierte Weg ist das AI SDK, das `AIChatAgent` und die Startvorlage schon nutzen. Alles auf der [Vercel-AI-SDK-Seite](/docs/guides/integrations/vercel-ai-sdk) gilt unverändert innerhalb eines Cloudflare Agent.

## MCP

MCP ist eine Methode auf dem Agent und keine Client-Bibliothek. `addMcpServer` gibt eine id und eine `authUrl` zurück; eine nicht-null `authUrl` heißt, dass dieser Server einen OAuth-Hin-und-Rückweg will, unserer nicht.

```ts
export class Researcher extends Agent {
  async onStart() {
    await this.addMcpServer("hanzo", "https://api.hanzo.ai/v1/mcp");
  }
}
```

Verbundene Server und ihre Werkzeuge lassen sich aus dem MCP-Zustand des Agenten lesen.
