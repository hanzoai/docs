Cloudflare Agents n'a pas de paramètre d'URL de base propre. La construction documentée est le client `openai` simple, construit à l'intérieur de l'Agent, avec **`baseURL`** fixé dessus.

```bash
npm i agents openai
```

```ts
import { Agent } from "agents";
import { OpenAI } from "openai";

export class Researcher extends Agent {
  async onRequest(request: Request): Promise<Response> {
    const client = new OpenAI({
      apiKey: this.env.HANZO_API_KEY,
      baseURL: "https://api.hanzo.ai/v1",
    });

    const { readable, writable } = new TransformStream();
    const writer = writable.getWriter();
    const encoder = new TextEncoder();

    this.ctx.waitUntil(
      (async () => {
        const stream = await client.chat.completions.create({
          model: "zen5",
          messages: [{ role: "user", content: await request.text() }],
          stream: true,
        });
        for await (const part of stream) {
          writer.write(encoder.encode(part.choices[0]?.delta?.content || ""));
        }
        writer.close();
      })(),
    );

    return new Response(readable);
  }
}
```

Atterrit sur `POST /v1/chat/completions`.

Mettez la clé dans un secret de Worker — `wrangler secret put HANZO_API_KEY` — et elle arrive sur `this.env`. Le streaming tourne dans `ctx.waitUntil` pour que le Worker ne soit pas démonté tant que la réponse s'écrit encore.

L'autre chemin documenté est l'AI SDK, que `AIChatAgent` et le modèle de départ utilisent déjà. Tout ce qui est sur la [page Vercel AI SDK](/docs/guides/integrations/vercel-ai-sdk) s'applique inchangé à l'intérieur d'un Cloudflare Agent.

## MCP

MCP est une méthode de l'Agent plutôt qu'une bibliothèque cliente. `addMcpServer` renvoie un id et un `authUrl` ; un `authUrl` non nul signifie que ce serveur veut un aller-retour OAuth, ce que le nôtre ne veut pas.

```ts
export class Researcher extends Agent {
  async onStart() {
    await this.addMcpServer("hanzo", "https://api.hanzo.ai/v1/mcp");
  }
}
```

Les serveurs connectés et leurs outils se lisent depuis l'état MCP de l'Agent.
