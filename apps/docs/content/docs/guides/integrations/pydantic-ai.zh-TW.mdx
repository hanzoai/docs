`OpenAIProvider` 接受 **`base_url`** 與 `api_key`，再以 `provider=` 交給一個模型類別。

```bash
pip install pydantic-ai
```

```python
from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider

model = OpenAIChatModel(
    'zen5',
    provider=OpenAIProvider(base_url='https://api.hanzo.ai/v1', api_key='sk-...'),
)

agent = Agent(model)
print(agent.run_sync('Hello').output)
```

會打到 `POST /v1/chat/completions`。

要有意地選模型類別，因為兩者打到不同位址。`OpenAIChatModel`，前綴 `openai-chat:`，支撐每一個 OpenAI 相容提供者，抵達 `POST /v1/chat/completions`。`OpenAIResponsesModel`，裸前綴 `openai:`，也是現代預設，抵達 `POST /v1/responses`。兩者都提供；面對相容端點時，聊天類別是較穩妥的預設。

`OPENAI_BASE_URL` 與 `OPENAI_API_KEY` 是環境變數對應項，`OpenAIProvider` 也接受一個事先建好的用戶端，作為 `openai_client`。

## MCP

`MCPToolset` 把伺服器 URL 當作第一個位置參數。普通 URL 當作 streamable HTTP；只有路徑以 `/sse` 結尾才是 SSE。

```python
from pydantic_ai import Agent
from pydantic_ai.mcp import MCPToolset

toolset = MCPToolset('https://api.hanzo.ai/v1/mcp')
agent = Agent(model, toolsets=[toolset])
```

它也會讀取一份帶 `mcpServers` 物件的 JSON 設定檔。
