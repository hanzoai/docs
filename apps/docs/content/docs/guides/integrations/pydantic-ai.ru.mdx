`OpenAIProvider` принимает **`base_url`** и `api_key` и передаётся классу модели как `provider=`.

```bash
pip install pydantic-ai
```

```python
from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider

model = OpenAIChatModel(
    'zen5',
    provider=OpenAIProvider(base_url='https://api.hanzo.ai/v1', api_key='sk-...'),
)

agent = Agent(model)
print(agent.run_sync('Hello').output)
```

Попадает на `POST /v1/chat/completions`.

Выбирайте класс модели сознательно, потому что два класса попадают на разные адреса. `OpenAIChatModel`, префикс `openai-chat:`, стоит за каждым OpenAI-совместимым провайдером и достигает `POST /v1/chat/completions`. `OpenAIResponsesModel`, голый префикс `openai:` и современное значение по умолчанию, достигает `POST /v1/responses`. Обслуживаются оба; класс чата — более безопасное значение по умолчанию против совместимой конечной точки.

`OPENAI_BASE_URL` и `OPENAI_API_KEY` — эквиваленты в окружении, и `OpenAIProvider` также принимает готовый клиент как `openai_client`.

## MCP

`MCPToolset` принимает URL сервера первым позиционным аргументом. Простой URL считается streamable HTTP; SSE только если путь заканчивается на `/sse`.

```python
from pydantic_ai import Agent
from pydantic_ai.mcp import MCPToolset

toolset = MCPToolset('https://api.hanzo.ai/v1/mcp')
agent = Agent(model, toolsets=[toolset])
```

Он также читает JSON-файл конфигурации с объектом `mcpServers`.
