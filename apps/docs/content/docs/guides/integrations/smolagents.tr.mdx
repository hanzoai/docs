`OpenAIModel` **`api_base`** alır; OpenAI ile uyumlu API sunucusunun taban URL'si olarak belgelenmiştir. Yazıma dikkat edin — bu `base_url` değildir — ve sınıf adına dikkat edin: başvuru `OpenAIModel` belgeler ve `OpenAIServerModel` artık onda görünmez.

```bash
pip install smolagents
```

```python
import os
from smolagents import OpenAIModel, CodeAgent

model = OpenAIModel(
    model_id="zen5",
    api_base="https://api.hanzo.ai/v1",
    api_key=os.environ["HANZO_API_KEY"],
)

agent = CodeAgent(tools=[], model=model)
agent.run("How many seconds in a fortnight?")
```

`POST /v1/chat/completions` adresine düşer.

Tam imza `OpenAIModel(model_id, api_base=None, api_key=None, organization=None, project=None, client_kwargs=None, custom_role_conversions=None, flatten_messages_as_text=False, **kwargs)` şeklindedir. Üretim argümanları — `temperature`, `max_tokens`, `top_p` — kurulumda kabul edilir ve her çağrıda iletilir. `LiteLLMModel` kardeştir ve o da `api_base` alır.

## MCP

`MCPClient` `url` ve `transport` alır ve araçları veren bir bağlam yöneticisidir.

```python
from smolagents import MCPClient, CodeAgent

with MCPClient({"url": "https://api.hanzo.ai/v1/mcp", "transport": "streamable-http"}) as tools:
    agent = CodeAgent(tools=tools, model=model)
    agent.run("What is my account balance?")
```

`ToolCollection.from_mcp` aynı dict üzerindeki diğer giriş noktasıdır; `trust_remote_code=True` ister. `streamable-http` varsayılan taşımadır.
