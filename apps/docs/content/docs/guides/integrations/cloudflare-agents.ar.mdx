ليس لدى Cloudflare Agents معامل عنوان URL أساسي خاص به. البناء الموثّق هو عميل `openai` العادي، يُبنى داخل Agent، مع ضبط **`baseURL`** عليه.

```bash
npm i agents openai
```

```ts
import { Agent } from "agents";
import { OpenAI } from "openai";

export class Researcher extends Agent {
  async onRequest(request: Request): Promise<Response> {
    const client = new OpenAI({
      apiKey: this.env.HANZO_API_KEY,
      baseURL: "https://api.hanzo.ai/v1",
    });

    const { readable, writable } = new TransformStream();
    const writer = writable.getWriter();
    const encoder = new TextEncoder();

    this.ctx.waitUntil(
      (async () => {
        const stream = await client.chat.completions.create({
          model: "zen5",
          messages: [{ role: "user", content: await request.text() }],
          stream: true,
        });
        for await (const part of stream) {
          writer.write(encoder.encode(part.choices[0]?.delta?.content || ""));
        }
        writer.close();
      })(),
    );

    return new Response(readable);
  }
}
```

يصل إلى `POST /v1/chat/completions`.

ضع المفتاح في سر Worker — `wrangler secret put HANZO_API_KEY` — فيصل على `this.env`. يجري البث داخل `ctx.waitUntil` كي لا يُفك Worker بينما لا تزال الاستجابة تُكتب.

المسار الموثّق الآخر هو AI SDK، الذي يستخدمه `AIChatAgent` وقالب البداية أصلًا. كل ما في [صفحة Vercel AI SDK](/docs/guides/integrations/vercel-ai-sdk) ينطبق من غير تغيير داخل Cloudflare Agent.

## MCP

MCP أسلوب على Agent لا مكتبة عميل. تُرجع `addMcpServer` معرّفًا و`authUrl`؛ و`authUrl` غير الصفري يعني أن ذلك الخادم يريد جولة OAuth، وخادمنا لا يريدها.

```ts
export class Researcher extends Agent {
  async onStart() {
    await this.addMcpServer("hanzo", "https://api.hanzo.ai/v1/mcp");
  }
}
```

الخوادم المتصلة وأدواتها تُقرأ من حالة MCP لدى Agent.
