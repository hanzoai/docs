Cloudflare Agents'ın kendine ait bir taban URL parametresi yoktur. Belgelenmiş kurulum, Agent içinde kurulan düz `openai` istemcisidir ve üzerinde **`baseURL`** ayarlanır.

```bash
npm i agents openai
```

```ts
import { Agent } from "agents";
import { OpenAI } from "openai";

export class Researcher extends Agent {
  async onRequest(request: Request): Promise<Response> {
    const client = new OpenAI({
      apiKey: this.env.HANZO_API_KEY,
      baseURL: "https://api.hanzo.ai/v1",
    });

    const { readable, writable } = new TransformStream();
    const writer = writable.getWriter();
    const encoder = new TextEncoder();

    this.ctx.waitUntil(
      (async () => {
        const stream = await client.chat.completions.create({
          model: "zen5",
          messages: [{ role: "user", content: await request.text() }],
          stream: true,
        });
        for await (const part of stream) {
          writer.write(encoder.encode(part.choices[0]?.delta?.content || ""));
        }
        writer.close();
      })(),
    );

    return new Response(readable);
  }
}
```

`POST /v1/chat/completions` adresine düşer.

Anahtarı bir Worker sırrına koyun — `wrangler secret put HANZO_API_KEY` — ve `this.env` üzerinde gelir. Akış `ctx.waitUntil` içinde çalışır ki yanıt hâlâ yazılırken Worker sökülmesin.

Belgelenmiş diğer yol AI SDK'dır; `AIChatAgent` ve başlangıç şablonu onu zaten kullanır. [Vercel AI SDK sayfasındaki](/docs/guides/integrations/vercel-ai-sdk) her şey bir Cloudflare Agent içinde değişmeden geçerlidir.

## MCP

MCP bir istemci kitaplığı değil, Agent üzerindeki bir yöntemdir. `addMcpServer` bir id ve bir `authUrl` döndürür; null olmayan bir `authUrl`, o sunucunun bir OAuth gidiş dönüşü istediği anlamına gelir, bizimki istemez.

```ts
export class Researcher extends Agent {
  async onStart() {
    await this.addMcpServer("hanzo", "https://api.hanzo.ai/v1/mcp");
  }
}
```

Bağlı sunucular ve araçları Agent'ın MCP durumundan okunabilir.
