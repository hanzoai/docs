Cloudflare Agents ไม่มีพารามิเตอร์ URL ฐานของตัวเอง โครงสร้างที่เอกสารระบุคือไคลเอนต์ `openai` ธรรมดา สร้างภายใน Agent พร้อมตั้ง **`baseURL`** บนมัน

```bash
npm i agents openai
```

```ts
import { Agent } from "agents";
import { OpenAI } from "openai";

export class Researcher extends Agent {
  async onRequest(request: Request): Promise<Response> {
    const client = new OpenAI({
      apiKey: this.env.HANZO_API_KEY,
      baseURL: "https://api.hanzo.ai/v1",
    });

    const { readable, writable } = new TransformStream();
    const writer = writable.getWriter();
    const encoder = new TextEncoder();

    this.ctx.waitUntil(
      (async () => {
        const stream = await client.chat.completions.create({
          model: "zen5",
          messages: [{ role: "user", content: await request.text() }],
          stream: true,
        });
        for await (const part of stream) {
          writer.write(encoder.encode(part.choices[0]?.delta?.content || ""));
        }
        writer.close();
      })(),
    );

    return new Response(readable);
  }
}
```

ลงที่ `POST /v1/chat/completions`

ใส่คีย์ในความลับของ Worker — `wrangler secret put HANZO_API_KEY` — แล้วมันมาถึงที่ `this.env` การสตรีมทำงานภายใน `ctx.waitUntil` เพื่อไม่ให้ Worker ถูกถอดขณะที่การตอบยังถูกเขียนอยู่

ทางที่เอกสารระบุอีกทางคือ AI SDK ซึ่ง `AIChatAgent` และเทมเพลตเริ่มต้นใช้อยู่แล้ว ทุกอย่างใน[หน้า Vercel AI SDK](/docs/guides/integrations/vercel-ai-sdk) ใช้ได้ไม่เปลี่ยนแปลงภายใน Cloudflare Agent

## MCP

MCP เป็นเมธอดบน Agent ไม่ใช่ไลบรารีไคลเอนต์ `addMcpServer` คืน id และ `authUrl` `authUrl` ที่ไม่เป็น null หมายความว่าเซิร์ฟเวอร์นั้นต้องการเที่ยวไปกลับ OAuth ซึ่งของเราไม่ต้องการ

```ts
export class Researcher extends Agent {
  async onStart() {
    await this.addMcpServer("hanzo", "https://api.hanzo.ai/v1/mcp");
  }
}
```

เซิร์ฟเวอร์ที่เชื่อมแล้วและเครื่องมือของมันอ่านได้จากสถานะ MCP ของ Agent
