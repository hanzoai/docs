`OpenAILike` 接受 **`api_base`**。注意拼法——它不是 `base_url`。這個類別裝在自己的套件裡，是 OpenAI 模型上的一層薄封裝，用來相容第三方端點。

```bash
pip install llama-index-llms-openai-like
```

```python
from llama_index.llms.openai_like import OpenAILike

llm = OpenAILike(
    model="zen5",
    api_base="https://api.hanzo.ai/v1",
    api_key="sk-...",
    context_window=1000000,
    is_chat_model=True,
    is_function_calling_model=True,
)

print(llm.complete("Hello"))
```

會打到 `POST /v1/chat/completions`。

三個預設值必須改掉，否則封裝會對模型判斷錯誤。**`is_chat_model` 預設為 `False`**，這會把 `complete()` 發到 completions 端點而不是聊天。`is_function_calling_model` 預設為 `False`，所以建在這個模型上的代理會在你期待工具呼叫的地方寫出散文。而 `context_window` 預設用的是 OpenAI 的值，不是這個模型的——真正的值從該模型在 `GET /v1/models` 裡的紀錄取。

`llama-index-embeddings-openai-like` 是檢索一側對應的套件，會抵達 `POST /v1/embeddings`。

## MCP

`BasicMCPClient` 把伺服器 URL 當作第一個位置參數，並從它推斷傳輸方式。

```bash
pip install llama-index-tools-mcp
```

```python
from llama_index.tools.mcp import BasicMCPClient, McpToolSpec

client = BasicMCPClient("https://api.hanzo.ai/v1/mcp")
tools = await McpToolSpec(client=client).to_tool_list_async()
```

以 `/mcp` 結尾的 URL 是 streamable HTTP，以 `/sse` 結尾的是 SSE，而第一個參數若是帶 `args` 的命令，那就是本機行程。
