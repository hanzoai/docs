`OpenAIModel` は **`api_base`** を取ります。OpenAI 互換 API サーバーのベース URL として文書化されています。綴りに注意 — `base_url` ではありません — そしてクラス名にも注意です。リファレンスが記すのは `OpenAIModel` で、`OpenAIServerModel` はもう出てきません。

```bash
pip install smolagents
```

```python
import os
from smolagents import OpenAIModel, CodeAgent

model = OpenAIModel(
    model_id="zen5",
    api_base="https://api.hanzo.ai/v1",
    api_key=os.environ["HANZO_API_KEY"],
)

agent = CodeAgent(tools=[], model=model)
agent.run("How many seconds in a fortnight?")
```

`POST /v1/chat/completions` に着地します。

完全なシグネチャは `OpenAIModel(model_id, api_base=None, api_key=None, organization=None, project=None, client_kwargs=None, custom_role_conversions=None, flatten_messages_as_text=False, **kwargs)` です。生成引数 — `temperature`、`max_tokens`、`top_p` — は構築時に受け取り、呼び出しのたびに転送されます。`LiteLLMModel` は兄弟で、こちらも `api_base` を取ります。

## MCP

`MCPClient` は `url` と `transport` を取り、ツールを生み出すコンテキストマネージャです。

```python
from smolagents import MCPClient, CodeAgent

with MCPClient({"url": "https://api.hanzo.ai/v1/mcp", "transport": "streamable-http"}) as tools:
    agent = CodeAgent(tools=tools, model=model)
    agent.run("What is my account balance?")
```

`ToolCollection.from_mcp` がもう一つの入り口で、同じ dict を使います。`trust_remote_code=True` が必要です。`streamable-http` が既定のトランスポートです。
