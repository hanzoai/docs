[hanzoskills.com](https://hanzoskills.com) publishes **1,477+ plain-markdown skills** across 14 categories and a progressive index of **2,832+ public open-source repositories** hosted on [forge.hanzo.ai](https://forge.hanzo.ai) — over plain HTTPS, with zero authentication required.

Everything uses **3-tier progressive disclosure**: an agent loads a compact Tier-0 index (~7–8 KB) up front, drills into a single category or organization at Tier 1 only when needed, and fetches one `SKILL.md` or clones one repository at Tier 2 on demand.

## 4. Install the Hanzo Browser Extension (Chrome, Firefox, Safari, Edge)

Download and unpack the latest Chrome/Chromium extension in one command:

```bash
mkdir -p ~/.hanzo/browser-extension && cd ~/.hanzo/browser-extension
URL=$(curl -fsSL https://api.github.com/repos/hanzoai/extension/releases/latest \
  | grep -oE 'https://[^"]*hanzo-ai-chrome[^"]*\.zip' | head -1)
curl -fsSL "$URL" -o ext.zip && unzip -oq ext.zip && rm ext.zip
```

1. Open `chrome://extensions` in Chrome, Brave, Arc, or Edge.
2. Enable **Developer mode** → click **Load unpacked** → select `~/.hanzo/browser-extension`.
3. Click the Hanzo extension icon and sign in via **[hanzo.id](https://hanzo.id)**. Once connected, Hanzo MCP's `computer`/browser tools bridge directly to live tabs over ZAP/CDP.
4. Firefox, Safari, Edge zips and VS Code / Cursor / Windsurf / Antigravity `.vsix` plugins are all at **[hanzo.ai/extension](https://hanzo.ai/extension)** and **[hanzo.ai/download](https://hanzo.ai/download)**.

## 5. Hanzo Desktop, CLI, Hanzo Dev, Hanzo Bot & Unified Usage Visibility

Install the native CLI + Dev agent + MCP + Engine, and install **Hanzo Desktop** so every local and cloud agent, session, bot run, and usage metric appears in one place:

```bash
curl -fsSL https://hanzo.sh | sh     # or: npm i -g hanzo
hanzo login                           # or headless wallet signup: https://hanzoskills.com/hanzo.md
```

- **Download Hanzo Desktop** (macOS / Windows / Linux): **[hanzo.ai/download](https://hanzo.ai/download)** (or **[hanzo.ai/desktop](https://hanzo.ai/desktop)**) and sign in with the same Hanzo ID.
- **Launch any coding agent via Hanzo CLI** so sessions, tool calls, and spend register automatically in Hanzo Desktop & CLI:
  ```bash
  hanzo dev                   # native Rust coding agent
  hanzo --claude              # Claude Code (keeps your Claude plan + attaches Hanzo MCP & session tracking)
  hanzo --claude --cloud      # Claude Code running model calls on your Hanzo plan
  hanzo --codex               # Codex (or add --cloud)
  hanzo --cursor              # Cursor
  hanzo --agy                 # Antigravity
  hanzo --gemini              # Gemini CLI
  hanzo engine serve <model>  # local open-weight inference
  hanzo up                    # run Hanzo Cloud locally
  ```
- **Live usage, plan & balance**:
  ```bash
  hanzo usage summary         # token & request usage across agents and models
  hanzo billing tier          # active plan & remaining allowance
  hanzo billing balance       # prepaid balance
  hanzo billing topup         # add credit (card or USDC/USDT)
  ```
- **Hanzo Bot (always-on autonomous resident agents)**:
  - Cloud: **[hanzo.bot](https://hanzo.bot)** (`hanzo bot runs list`) — dedicated sandbox Chromium, terminal, filesystem, memory, cron, and Slack/Discord/Telegram/WhatsApp/iMessage.
  - Local open-source daemon: `npm install -g @hanzo/bot && hanzo-bot onboard --install-daemon` ([docs.hanzo.bot](https://docs.hanzo.bot)).
