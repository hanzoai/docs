[hanzoskills.com](https://hanzoskills.com) publishes **1,477+ plain-markdown skills** across 14 categories and a progressive index of **2,800+ public open-source repositories** hosted on [forge.hanzo.ai](https://forge.hanzo.ai) — over plain HTTPS, with zero authentication required.

Everything uses **3-tier progressive disclosure**: an agent loads a compact Tier-0 index (~6–8 KB) up front, drills into a single category or organization at Tier 1 only when needed, and fetches one `SKILL.md` or clones one repository at Tier 2 on demand.

## 3. Hanzo MCP (Unified Local & Hosted Server)

Add the native Rust Hanzo MCP server over stdio with one command (no pre-install required):

```bash
# Claude Code (user scope — available in every repo)
claude mcp add --scope user hanzo -- npx -y hanzo mcp

# Codex
codex mcp add hanzo -- npx -y hanzo mcp
```

For JSON-configured MCP clients (**Cursor**, **Claude Desktop**, **Windsurf**, **Gemini CLI**, **Antigravity**, **VS Code**):

```json
{
  "mcpServers": {
    "hanzo": {
      "command": "npx",
      "args": ["-y", "hanzo", "mcp"]
    }
  }
}
```

- **Hosted Cloud MCP (Streamable HTTP, zero local setup)**: `https://api.hanzo.ai/v1/mcp` with `Authorization: Bearer $HANZO_API_KEY`.
- **13 HIP-0300 unified tools**: `fs`, `exec`, `code`, `git`, `fetch`, `workspace`, `computer`, `think`, `memory`, `hanzo`, `plan`, `tasks`, `ui` plus linked cloud connectors (GitHub, Slack, Google, Discord, X).
- **Progressive MCP schemas**: [`hanzoskills.com/mcp/index.json`](https://hanzoskills.com/mcp/index.json) → `/mcp/<tool>.json`. See [MCP](/docs/mcp).

## 4. Hanzo Browser Extension (Chrome, Firefox, Safari, Edge)

Install the Hanzo Browser Extension so your agent can inspect, navigate, snapshot, click, type, screenshot, and automate live browser tabs over the ZAP/MCP bridge:

1. Download or install from **[hanzo.ai/extension](https://hanzo.ai/extension)**, **[hanzo.ai/chrome](https://hanzo.ai/chrome)**, or the latest release zips at **[github.com/hanzoai/extension/releases/latest](https://github.com/hanzoai/extension/releases/latest)**.
2. **Unpacked Chrome / Chromium load**: download `hanzo-ai-chrome-*.zip`, unzip it, open `chrome://extensions`, enable **Developer mode**, click **Load unpacked**, and select the unzipped folder.
3. Click the Hanzo extension icon and sign in with **Hanzo ID** (`https://hanzo.id`). Once connected, Hanzo MCP's `computer` / browser tools automatically control tabs through the ZAP bridge.

## 6. Full Platform Fluency (`https://api.hanzo.ai/v1`)

Every Hanzo service shares one OpenAI-compatible API, one key, and the same `/v1/<capability>` route contract in the cloud and locally:

- **Zero-auth discovery**: `GET https://api.hanzo.ai/v1`, `GET /v1/<capability>`, `GET /v1/openapi.json`
- **AI & Decisions**: `/v1/chat/completions` (`enso-auto`, `zen-free`, `zen-*`, 500+ models), **Kai** typed calibrated decisions (`POST /v1/decisions`), embeddings, audio/image/video
- **Cloud & Data**: IAM (`hanzo.id`), KMS (`/v1/kms`), Base realtime DB (`/v1/base`), SQL (`/v1/sql`), KV (`/v1/kv`), Vector (`/v1/vector`), Storage/S3 (`/v1/storage`), PubSub, Tasks, Pipelines, Sandboxes, Deploy, Billing/USDC top-up, CRM, CMS, and Post/Social
