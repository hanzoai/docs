## 샌드박스와 승인

Hanzo Dev는 에이전트가 명령을 실행할 때 의도하지 않은 부작용을 막으려고 샌드박스를 강제합니다.

### 샌드박스 모드

| 모드 | 설명 |
| --- | --- |
| `off` | 샌드박스 없음(명령이 직접 실행됨) |
| `workspace-read` | 작업 공간에 읽기 전용 접근 |
| `workspace-write` | 작업 공간에 읽기 및 쓰기 접근(full-auto의 기본값) |
| `network-off` | 네트워크 접근을 끕니다 |
| `danger-full-access` | 전체 접근(주의해서 사용) |

### 승인 정책

| 정책 | 설명 |
| --- | --- |
| `always` | 항상 승인을 요청합니다 |
| `on-failure` | 명령이 실패할 때만 요청합니다 |
| `on-request` | 모델이 승인을 요청할 때 요청합니다 |
| `never` | 승인을 요청하지 않습니다 |

### 사용법

```bash
# Read-only mode (safest)
dev --sandbox workspace-read "analyze this codebase"

# Write mode with approval on failure
dev --sandbox workspace-write --ask-for-approval on-failure "refactor"

# Full auto (sandboxed writes, auto-approve)
dev --full-auto "fix all linting errors"

# Bypass all safety (DANGEROUS)
dev --dangerously-bypass-approvals-and-sandbox "your prompt"
```

### 세션 중간의 변경

대화 중에 승인 수준을 바꾸려면 TUI에서 `/approvals`를 씁니다.
