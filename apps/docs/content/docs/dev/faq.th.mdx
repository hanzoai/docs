## รองรับโมเดลใดบ้าง?

เราแนะนำพรีเซ็ตในตัวที่ห่อ GPT-5.2 (เช่น `code-gpt-5.2-codex`) ระดับการให้เหตุผลเริ่มต้นคือ medium — ยกเป็น high สำหรับงานซับซ้อนด้วย `/model`

คุณยังใช้โมเดลอื่นได้ผ่านการยืนยันตัวตนแบบ API ด้วยแฟล็ก `--model`

## จะหยุด Hanzo Dev ไม่ให้แก้ไฟล์ของฉันได้อย่างไร?

โดยค่าเริ่มต้น Hanzo Dev แก้ไฟล์ในไดเรกทอรีทำงานได้ (โหมด Auto) หากต้องการกันการแก้ ให้รันแบบอ่านอย่างเดียว:

```bash
dev --sandbox read-only
```

หรือเปลี่ยนระดับการอนุมัติระหว่างการสนทนาด้วย `/approvals`

## ใช้บน Windows ได้ไหม?

การรันตรงบน Windows อาจได้ แต่ไม่มีการรองรับอย่างเป็นทางการ เราแนะนำ [Windows Subsystem for Linux (WSL2)](https://learn.microsoft.com/en-us/windows/wsl/install)

## ทำไม Hanzo Dev หาเอเจนต์ของฉันบน Windows ไม่เจอ?

การค้นหาเอเจนต์บน Windows อาจได้รับผลจาก PATH และนามสกุลไฟล์ ทางแก้:

### ใช้พาธสัมบูรณ์ (แนะนำ)

```toml
[[agents]]
name = "claude"
command = "C:\\Users\\YourUser\\AppData\\Roaming\\npm\\claude.cmd"
enabled = true
```

### หาตำแหน่งติดตั้ง npm แบบโกลบอล

```cmd
npm config get prefix
```

### ตรวจว่า PATH มีไดเรกทอรี npm

```powershell
$env:PATH -split ';' | Select-String "npm"
```

### ตรวจนามสกุลไฟล์

บน Windows Hanzo Dev มองหาไฟล์ปฏิบัติการที่ลงท้าย `.exe`, `.cmd`, `.bat` และ `.com` ใส่สกุลที่ถูกต้องเมื่อใช้พาธสัมบูรณ์

## เกี่ยวข้องกับ OpenAI Codex อย่างไร?

Hanzo Dev เป็น CLI พัฒนาแบบเอเจนต์ที่เขียนด้วย Rust: ประสานหลายเอเจนต์, ไคลเอนต์และเซิร์ฟเวอร์ MCP, นโยบายการทำงานในแซนด์บ็อกซ์, และการเชื่อมกับโครงสร้าง Hanzo AI โดยตรง ชื่อนี้ไม่เกี่ยวกับโมเดล Codex ปี 2021 ของ OpenAI ที่เลิกใช้ในเดือนมีนาคม 2023
