## Perjanjian lisensi kontributor (CLA)

Semua kontributor **wajib** menerima CLA. Prosesnya ringan:

1. Buka pull request Anda
2. Tempel komentar berikut (atau balas `recheck` jika sudah pernah menandatangani):

```text
I have read the CLA Document and I hereby sign the CLA
```

3. Bot CLA-Assistant mencatat tanda tangan Anda dan menandai pemeriksaan status sebagai lulus

Tidak perlu perintah Git khusus, lampiran surel, atau catatan kaki commit.

## Keamanan dan AI yang bertanggung jawab

Menemukan kerentanan atau punya kekhawatiran tentang keluaran model? Kirim surel ke **security@hanzo.ai** dan kami akan menjawab segera.
