Hanzo Dev is developed at [github.com/hanzoai/dev](https://github.com/hanzoai/dev). Report bugs and request features in its [issues](https://github.com/hanzoai/dev/issues).

## Build from source

```bash
git clone --recurse-submodules https://github.com/hanzoai/dev.git
cd dev
make build
```

The binary is `target/debug/dev`. `make release` builds an optimized one in `target/release/dev`, and `make install` installs it with Cargo. The Rust toolchain is pinned in `rust-toolchain.toml`.

## Send a change

1. Branch from `main`.
2. Make the change in a `hanzo-*` crate under `crates/`. Do not edit `upstream/` by hand — `make bump` overwrites it; an edit that must reach upstream code goes in `patches/upstream.json`.
3. Run `make build` and `make test`. `make build` must pass with no warnings.
4. Open a pull request.

`make help` lists every target. The repository's `LLM.md` describes the workspace layout and its rules.
