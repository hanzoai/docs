## ข้อตกลงใบอนุญาตผู้ร่วมพัฒนา (CLA)

ผู้ร่วมพัฒนาทุกคน **ต้อง**ยอมรับ CLA ขั้นตอนเบา:

1. เปิด pull request ของคุณ
2. วางความคิดเห็นต่อไปนี้ (หรือตอบ `recheck` หากเคยลงนามแล้ว):

```text
I have read the CLA Document and I hereby sign the CLA
```

3. บอต CLA-Assistant บันทึกลายเซ็นของคุณและทำเครื่องหมายการตรวจสถานะว่าผ่าน

ไม่ต้องใช้คำสั่ง Git พิเศษ ไฟล์แนบอีเมล หรือท้าย commit

## ความปลอดภัยและ AI อย่างรับผิดชอบ

พบช่องโหว่หรือกังวลเกี่ยวกับผลลัพธ์ของโมเดล? ส่งอีเมลถึง **security@hanzo.ai** แล้วเราจะตอบโดยเร็ว
