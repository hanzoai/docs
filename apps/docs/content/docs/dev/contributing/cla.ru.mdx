## Лицензионное соглашение участника (CLA)

Все участники **обязаны** принять CLA. Процедура лёгкая:

1. Откройте свой pull request
2. Вставьте следующий комментарий (или ответьте `recheck`, если уже подписывали):

```text
I have read the CLA Document and I hereby sign the CLA
```

3. Бот CLA-Assistant фиксирует вашу подпись и отмечает проверку статуса как пройденную

Особые команды Git, вложения в письмах и нижние колонтитулы коммитов не нужны.

## Безопасность и ответственная ИИ

Нашли уязвимость или есть сомнения в выводе модели? Напишите на **security@hanzo.ai**, мы ответим быстро.
