## اتفاقية ترخيص المساهم (CLA)

يجب على كل المساهمين قبول CLA. العملية خفيفة:

1. افتح طلب السحب
2. الصق التعليق التالي (أو أجب `recheck` إذا وقّعت من قبل):

```text
I have read the CLA Document and I hereby sign the CLA
```

3. يسجّل بوت CLA-Assistant توقيعك ويعلّم فحص الحالة ناجحًا

لا حاجة إلى أوامر Git خاصة، ولا مرفقات بريد، ولا تذييلات commit.

## الأمن والذكاء الاصطناعي المسؤول

اكتشفت ثغرة أو لديك قلق بشأن مخرجات نموذج؟ راسل **security@hanzo.ai** وسنرد سريعًا.
