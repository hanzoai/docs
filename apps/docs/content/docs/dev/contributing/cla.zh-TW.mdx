## 貢獻者授權協議（CLA）

所有貢獻者 **必須** 接受 CLA。過程很輕：

1. 開啟你的拉取請求
2. 貼上下面的留言（如果以前簽過，回覆 `recheck`）：

```text
I have read the CLA Document and I hereby sign the CLA
```

3. CLA-Assistant 機器人記錄你的簽名，並把狀態檢查標為通過

不需要特殊的 Git 指令、郵件附件或提交頁尾。

## 安全與負責任的 AI

發現了漏洞，或對模型輸出有顧慮？請寫信到 **security@hanzo.ai**，我們會盡快回覆。
