## Katkıda bulunan lisans sözleşmesi (CLA)

Tüm katkıda bulunanlar CLA'yı **kabul etmek zorundadır**. Süreç hafiftir:

1. Pull request'inizi açın
2. Aşağıdaki yorumu yapıştırın (daha önce imzaladıysanız `recheck` yanıtını verin):

```text
I have read the CLA Document and I hereby sign the CLA
```

3. CLA-Assistant botu imzanızı kaydeder ve durum denetimini geçmiş olarak işaretler

Özel Git komutları, e-posta ekleri veya commit altbilgileri gerekmez.

## Güvenlik ve sorumlu yapay zekâ

Bir güvenlik açığı mı buldunuz ya da model çıktısı hakkında kaygınız mı var? **security@hanzo.ai** adresine yazın, hemen yanıtlarız.
