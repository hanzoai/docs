## 貢献者ライセンス契約（CLA）

貢献者は全員、CLA を **受け入れなければなりません**。手続きは軽いものです。

1. プルリクエストを開きます
2. 次のコメントを貼ります（以前に署名済みなら `recheck` と返信します）:

```text
I have read the CLA Document and I hereby sign the CLA
```

3. CLA-Assistant ボットが署名を記録し、ステータスチェックを合格にします

特別な Git コマンド、メールの添付、コミットのフッタは不要です。

## セキュリティと責任ある AI

脆弱性を見つけた、またはモデルの出力が気になる場合は **security@hanzo.ai** にメールしてください。速やかに返信します。
