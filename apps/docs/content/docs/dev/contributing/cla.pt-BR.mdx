## Acordo de licença de colaborador (CLA)

Todos os colaboradores **precisam** aceitar o CLA. O processo é leve:

1. Abra seu pull request
2. Cole o comentário a seguir (ou responda `recheck` se já tiver assinado):

```text
I have read the CLA Document and I hereby sign the CLA
```

3. O bot CLA-Assistant registra sua assinatura e marca a verificação de status como aprovada

Não é preciso comando especial do Git, anexo de e-mail nem rodapé de commit.

## Segurança e IA responsável

Encontrou uma vulnerabilidade ou tem dúvidas sobre a saída de um modelo? Escreva para **security@hanzo.ai** e responderemos rápido.
