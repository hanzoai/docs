## Acuerdo de licencia de colaborador (CLA)

Todos los colaboradores **deben** aceptar el CLA. El proceso es ligero:

1. Abre tu pull request
2. Pega el comentario siguiente (o responde `recheck` si ya firmaste antes):

```text
I have read the CLA Document and I hereby sign the CLA
```

3. El bot CLA-Assistant registra tu firma y marca la comprobación de estado como superada

No hacen falta comandos especiales de Git, adjuntos de correo ni pies de commit.

## Seguridad e IA responsable

¿Has encontrado una vulnerabilidad o te preocupa la salida de un modelo? Escribe a **security@hanzo.ai** y responderemos pronto.
