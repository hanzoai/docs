## 贡献者许可协议（CLA）

所有贡献者 **必须** 接受 CLA。过程很轻：

1. 打开你的拉取请求
2. 粘贴下面的评论（如果以前签过，回复 `recheck`）：

```text
I have read the CLA Document and I hereby sign the CLA
```

3. CLA-Assistant 机器人记录你的签名，并把状态检查标为通过

不需要特殊的 Git 命令、邮件附件或提交页脚。
