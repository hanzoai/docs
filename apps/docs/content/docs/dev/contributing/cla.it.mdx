## Accordo di licenza del collaboratore (CLA)

Tutti i collaboratori **devono** accettare il CLA. La procedura è leggera:

1. Apri la tua pull request
2. Incolla il commento seguente (oppure rispondi `recheck` se hai già firmato):

```text
I have read the CLA Document and I hereby sign the CLA
```

3. Il bot CLA-Assistant registra la tua firma e segna il controllo di stato come superato

Non servono comandi Git speciali, allegati di posta né piè di commit.

## Sicurezza e IA responsabile

Hai trovato una vulnerabilità o hai dubbi sull'output di un modello? Scrivi a **security@hanzo.ai** e risponderemo presto.
