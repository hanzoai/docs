## योगदानकर्ता लाइसेंस समझौता (CLA)

सभी योगदानकर्ताओं को CLA **स्वीकार करना होगा**। प्रक्रिया हल्की है:

1. अपना pull request खोलें
2. यह टिप्पणी चिपकाएँ (या पहले हस्ताक्षर कर चुके हों तो `recheck` उत्तर दें):

```text
I have read the CLA Document and I hereby sign the CLA
```

3. CLA-Assistant बॉट आपका हस्ताक्षर दर्ज करता है और स्थिति जाँच को उत्तीर्ण चिह्नित करता है

विशेष Git कमांड, ईमेल अनुलग्नक या commit पादलेख की ज़रूरत नहीं।

## सुरक्षा और ज़िम्मेदार एआई

कोई कमज़ोरी मिली या मॉडल आउटपुट को लेकर चिंता है? **security@hanzo.ai** पर लिखें, हम जल्दी उत्तर देंगे।
