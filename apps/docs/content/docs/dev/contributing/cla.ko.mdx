## 기여자 라이선스 계약(CLA)

모든 기여자는 CLA를 **받아들여야 합니다**. 절차는 가볍습니다.

1. 풀 리퀘스트를 엽니다
2. 다음 댓글을 붙입니다(전에 서명했다면 `recheck`로 답합니다):

```text
I have read the CLA Document and I hereby sign the CLA
```

3. CLA-Assistant 봇이 서명을 기록하고 상태 검사를 통과로 표시합니다

특별한 Git 명령, 메일 첨부, 커밋 바닥글은 필요 없습니다.

## 보안과 책임 있는 AI

취약점을 찾았거나 모델 출력이 걱정되면 **security@hanzo.ai**로 메일을 보내 주세요. 곧 답합니다.
