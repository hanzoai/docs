## Accord de licence de contributeur (CLA)

Tous les contributeurs **doivent** accepter le CLA. La procédure est légère :

1. Ouvrez votre pull request
2. Collez le commentaire suivant (ou répondez `recheck` si vous avez déjà signé) :

```text
I have read the CLA Document and I hereby sign the CLA
```

3. Le bot CLA-Assistant enregistre votre signature et marque le contrôle d'état comme réussi

Aucun ordre Git particulier, aucune pièce jointe, aucun pied de commit n'est requis.

## Sécurité et IA responsable

Vous avez découvert une vulnérabilité ou vous vous inquiétez d'une sortie de modèle ? Écrivez à **security@hanzo.ai** et nous répondrons rapidement.
