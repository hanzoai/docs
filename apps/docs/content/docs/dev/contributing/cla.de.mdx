## Mitwirkenden-Lizenzvereinbarung (CLA)

Alle Mitwirkenden **müssen** das CLA annehmen. Der Ablauf ist schlank:

1. Öffnen Sie Ihren Pull Request
2. Fügen Sie den folgenden Kommentar ein (oder antworten Sie `recheck`, wenn Sie schon unterschrieben haben):

```text
I have read the CLA Document and I hereby sign the CLA
```

3. Der Bot CLA-Assistant zeichnet Ihre Unterschrift auf und markiert die Statusprüfung als bestanden

Keine besonderen Git-Befehle, keine E-Mail-Anhänge und keine Commit-Fußzeilen nötig.

## Sicherheit und verantwortungsvolle KI

Eine Schwachstelle gefunden oder Bedenken zur Modellausgabe? Schreiben Sie an **security@hanzo.ai**, wir antworten zeitnah.
