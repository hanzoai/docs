## Какие модели поддерживаются?

Мы рекомендуем встроенные пресеты вокруг GPT-5.2 (например, `code-gpt-5.2-codex`). Уровень рассуждения по умолчанию — medium; для сложных задач поднимите его до high командой `/model`.

Другие модели доступны через аутентификацию по API с флагом `--model`.

## Как запретить Hanzo Dev править мои файлы?

По умолчанию Hanzo Dev может менять файлы в рабочем каталоге (режим Auto). Чтобы запретить правки, запустите режим только для чтения:

```bash
dev --sandbox read-only
```

Или смените уровень подтверждения по ходу разговора командой `/approvals`.

## Работает ли это в Windows?

Прямой запуск в Windows может сработать, но официально не поддерживается. Мы рекомендуем [Windows Subsystem for Linux (WSL2)](https://learn.microsoft.com/en-us/windows/wsl/install).

## Почему Hanzo Dev не находит моих агентов в Windows?

Поиск агентов в Windows зависит от PATH и расширений файлов. Решения:

### Используйте абсолютные пути (рекомендуется)

```toml
[[agents]]
name = "claude"
command = "C:\\Users\\YourUser\\AppData\\Roaming\\npm\\claude.cmd"
enabled = true
```

### Найдите каталог глобальной установки npm

```cmd
npm config get prefix
```

### Проверьте, что PATH содержит каталог npm

```powershell
$env:PATH -split ';' | Select-String "npm"
```

### Проверьте расширения файлов

В Windows Hanzo Dev ищет исполняемые файлы с расширениями `.exe`, `.cmd`, `.bat` и `.com`. Указывайте верное расширение в абсолютных путях.

## Какое отношение к OpenAI Codex?

Hanzo Dev — агентная CLI для разработки на Rust: оркестрация нескольких агентов, клиент и сервер MCP, политика выполнения в песочнице и прямая интеграция с инфраструктурой Hanzo AI. Имя не связано с моделью Codex от OpenAI 2021 года, снятой с поддержки в марте 2023.
