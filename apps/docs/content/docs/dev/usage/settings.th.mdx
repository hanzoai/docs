แผงการตั้งค่าเปลี่ยนโมเดล ธีม ค่าเริ่มต้นของ Auto Drive เอเจนต์ การแจ้งเตือน และอื่น ๆ โดยไม่ต้องออกจากแชท

## เปิดและนำทาง

- `/settings` เปิดภาพรวม
- `/settings <section>` กระโดดไปยังส่วนโดยตรง
- `/auto settings` และ `/update` เข้าสู่ส่วนของตน

### แป้นพิมพ์

| แป้น | การกระทำ |
| --- | --- |
| `↑/↓` หรือ `j/k` | เลื่อนตัวเลือก |
| `Tab/Shift+Tab` | วนส่วน |
| `Home/End` | ไปปลายรายการ |
| `Enter` | เปิดหรือเปิดใช้ |
| `Esc` | ปิดส่วน (สองครั้งปิดแผง) |
| `?` | สลับความช่วยเหลือในบรรทัด |

## ส่วน

| ส่วน | คำอธิบาย |
| --- | --- |
| **Model** | เลือกโมเดลแชทเริ่มต้นและความพยายามในการให้เหตุผล |
| **Theme** | เลือกธีมและตัวหมุน |
| **Updates** | ดูช่องทางอัปเกรดและสถานะ |
| **Agents** | ดูเอเจนต์ในตัวและที่กำหนดเอง เปิดปิด บังคับอ่านอย่างเดียว |
| **Prompts** | แก้ชิ้นพรอมต์ที่บันทึก |
| **Auto Drive** | สวิตช์รีวิว เอเจนต์ และ QA โหมดทำต่อ โมเดลแทน |
| **Review** | เลือกโมเดลรีวิว สลับการแก้ให้อัตโนมัติ |
| **Planning** | เลือกโมเดลและความพยายามสำหรับรอบวางแผน |
| **Validation** | สลับกลุ่มและเครื่องมือตรวจสอบ |
| **Limits** | มุมมองอ่านอย่างเดียวของขีดอัตราและการใช้บริบท |
| **Chrome** | ตัวเลือกการเชื่อมเบราว์เซอร์ |
| **MCP** | เปิดหรือปิดเซิร์ฟเวอร์ MCP |
| **Notifications** | สลับและกรองการแจ้งเตือน |

## ความคงอยู่

การเปลี่ยนแปลงเขียนลง `~/.code/config.toml` เมื่อมีไฟล์ โหมดการเข้าถึงเก็บได้ต่อเวิร์กสเปซ ที่เหลือใช้ทั้งระบบเว้นแต่โปรเจกต์จะทับ

## คำสั่ง

```bash
/settings [section]
/auto settings
/update
/notifications [on|off|status]
```
