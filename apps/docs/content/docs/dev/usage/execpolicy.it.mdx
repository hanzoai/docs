## Politica di esecuzione

Hanzo Dev usa politiche di esecuzione per decidere quali comandi l'agente può lanciare e quando serve un'approvazione.

### Modalità di sandbox

| Modalità | Descrizione |
| --- | --- |
| `off` | Nessuna sandbox (i comandi girano direttamente) |
| `workspace-read` | Accesso in sola lettura allo spazio di lavoro |
| `workspace-write` | Accesso in lettura e scrittura allo spazio di lavoro (predefinito per full-auto) |
| `network-off` | Disattiva l'accesso alla rete |

### Politiche di approvazione

| Politica | Descrizione |
| --- | --- |
| `always` | Chiede sempre l'approvazione prima di eseguire |
| `on-failure` | Chiede solo quando un comando fallisce (predefinito per full-auto) |
| `on-request` | Chiede quando il modello richiede esplicitamente l'approvazione |
| `never` | Non chiede mai l'approvazione |

### Uso

```bash
# Set sandbox mode
dev --sandbox workspace-write "your prompt"

# Set approval policy
dev --ask-for-approval on-failure "your prompt"

# Full auto (sandboxed + auto-approve)
dev --full-auto "your prompt"
```
