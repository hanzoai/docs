---
title: Slash Commands
description: Every slash command in the Hanzo Dev session, in the order the menu shows them.
---

Type `/` in the composer to open the menu. Commands that take an argument accept it after the name, e.g. `/rename auth-refactor`. Some commands cannot run while a turn is in progress.

## Model and permissions

| Command | What it does |
| --- | --- |
| `/model` | Choose the model and reasoning effort. |
| `/permissions` | Choose what the agent is allowed to do. |
| `/experimental` | Turn experimental features on or off. |
| `/approve` | Approve one retry of a command that automatic review refused. |
| `/memories` | Configure memory use and generation. |
| `/personality` | Choose a communication style. |

## Extending the agent

| Command | What it does |
| --- | --- |
| `/skills` | Browse and use [skills](/docs/dev/usage/skills). |
| `/hooks` | View and manage lifecycle hooks. |
| `/mcp` | List the configured [MCP](/docs/dev/usage/mcp) tools; `/mcp verbose` for details. |
| `/plugins` | Browse [plugins](/docs/dev/usage/mcp#plugins). |
| `/import` | Import setup, this project and recent chats from Claude Code. |
| `/ide` | Include the current selection, open files and other context from your IDE. |

## Sessions

| Command | What it does |
| --- | --- |
| `/new` | Start a new chat. |
| `/clear` | Clear the terminal and start a new chat. |
| `/resume` | Resume a saved chat. |
| `/fork` | Fork the current chat. |
| `/rename <name>` | Rename the current session. |
| `/archive` | Archive this session and exit. |
| `/delete` | Permanently delete this session and exit. |
| `/side <message>` | Start a side conversation in a throwaway fork. |
| `/agents` | View and switch between all active sessions. |
| `/subagents` | Switch between this session's [subagents](/docs/dev/usage/agents). |

## Working on the code

| Command | What it does |
| --- | --- |
| `/init` | Write an `AGENTS.md` for this repository. |
| `/review` | Review your current changes and find issues. |
| `/diff` | Show `git diff`, including untracked files. |
| `/mention` | Mention a file. |
| `/plan` | Switch to Plan mode. |
| `/goal [<objective>\|clear\|edit\|pause\|resume]` | Set, view or manage the goal of a long-running task. |
| `/compact` | Summarize the conversation to stay within the context limit. |
| `/recap` | Summarize the conversation now. |
| `/cd <dir>` | Change the working directory. |
| `/pwd` | Show the working directory. |
| `/ps` | List background terminals. |
| `/stop` | Stop all background terminals. |

## Output

| Command | What it does |
| --- | --- |
| `/copy` | Copy the last response, or part of it. |
| `/export` | Export the conversation as Markdown. |
| `/raw [on\|off]` | Toggle raw scrollback for copy-friendly selection. |

## Status and appearance

| Command | What it does |
| --- | --- |
| `/status` | Show the session configuration and token usage. |
| `/usage` | View account usage. |
| `/debug-config` | Show the configuration layers and where each setting came from. |
| `/statusline` | Choose what the status line shows. |
| `/title` | Choose what the terminal title shows. |
| `/theme` | Choose a syntax-highlighting theme. |
| `/keymap` | Remap shortcuts. |
| `/vim` | Toggle Vim mode in the composer. |
| `/pets` | Choose or hide the terminal pet. |

## Account and exit

| Command | What it does |
| --- | --- |
| `/feedback` | Send logs to the maintainers. |
| `/logout` | Sign out. |
| `/quit` | Exit. |

## Platform-specific

| Command | Where | What it does |
| --- | --- | --- |
| `/app` | macOS, Windows | Continue this session in the desktop app. |
| `/setup-default-sandbox` | Windows | Set up the elevated sandbox (shown only while the restricted sandbox is in use). |
| `/sandbox-add-read-dir <path>` | Windows | Let the sandbox read a directory. |
| `/worktree` | With `features.worktrees` on | Continue in a new Git worktree. |
| `/voice` | When voice is available | Start or stop a live voice conversation. |
