設定覆層讓你不離開對話就能改模型、主題、Auto Drive 預設值、代理、通知等。

## 開啟與導覽

- `/settings` 開啟概覽
- `/settings <section>` 直接跳到某一節
- `/auto settings` 和 `/update` 進入各自的節

### 鍵盤

| 鍵 | 動作 |
| --- | --- |
| `↑/↓` 或 `j/k` | 移動選擇 |
| `Tab/Shift+Tab` | 循環各節 |
| `Home/End` | 跳到清單兩端 |
| `Enter` | 開啟或啟用 |
| `Esc` | 關閉本節（兩次關閉覆層） |
| `?` | 切換行內說明 |

## 各節

| 節 | 說明 |
| --- | --- |
| **Model** | 選擇預設聊天模型和推理強度 |
| **Theme** | 選擇主題和旋轉指示 |
| **Updates** | 查看升級通道和狀態 |
| **Agents** | 查看內建和自訂代理，啟用、強制唯讀 |
| **Prompts** | 編輯已儲存的提示片段 |
| **Auto Drive** | 審查、代理和 QA 開關，繼續模式，替換模型 |
| **Review** | 選擇審查模型，切換自動解決 |
| **Planning** | 為規劃回合選擇模型和強度 |
| **Validation** | 切換驗證組和工具 |
| **Limits** | 速率限制和上下文用量的唯讀檢視 |
| **Chrome** | 瀏覽器連線選項 |
| **MCP** | 啟用或停用 MCP 伺服器 |
| **Notifications** | 開關並過濾通知 |

## 持久化

有檔案時，變更寫入 `~/.code/config.toml`。存取模式可以按工作區儲存；其餘設定全域生效，除非專案覆寫。

## 命令

```bash
/settings [section]
/auto settings
/update
/notifications [on|off|status]
```
