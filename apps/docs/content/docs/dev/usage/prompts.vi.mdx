## Prompt tùy chỉnh

Hanzo Dev cho phép lưu và quản lý các đoạn prompt tùy chỉnh để dùng lại.

### Quản lý prompt

- Mở trình quản lý prompt bằng `/prompts` trong TUI
- Tạo, sửa và xóa các đoạn prompt
- Prompt được lưu trong `~/.code/config.toml`

### Cách dùng

Mở prompt đã lưu qua:
- Lệnh gạch chéo `/prompts`
- Lớp Cài đặt (mục Prompt)

Prompt tùy chỉnh được đưa vào ngữ cảnh hội thoại khi được chọn, nên dễ dùng lại các chỉ dẫn thường gặp giữa các phiên.
