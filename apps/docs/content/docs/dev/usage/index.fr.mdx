Hanzo Dev propose plusieurs modes de fonctionnement pour l'assistance au développement par l'IA.

## Mode interactif

Lancez la TUI pour programmer en conversation :

```bash
dev "Help me refactor this function"
```

## Mode non interactif

Exécutez des tâches isolées sans interface :

```bash
dev exec "Add error handling to main.py"
```

## Conduite automatique

Exécution de tâches sur plusieurs tours, entièrement automatisée :

```bash
dev auto "Refactor the database module"
```

## Orchestration multi-agents

Répartissez le travail entre plusieurs agents d'IA :

```bash
/plan <task>    # Create a comprehensive plan
/solve <problem> # Solve challenging problems
/code <task>    # Perform coding tasks
```
