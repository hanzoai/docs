طبقة الإعدادات تغيّر النماذج والسمات وقيم Auto Drive الافتراضية والوكلاء والإشعارات وغيرها دون مغادرة المحادثة.

## الفتح والتنقل

- `/settings` يفتح النظرة العامة
- `/settings <section>` يقفز مباشرة إلى قسم
- `/auto settings` و`/update` يدخلان قسميهما

### لوحة المفاتيح

| المفتاح | الفعل |
| --- | --- |
| `↑/↓` أو `j/k` | تحريك التحديد |
| `Tab/Shift+Tab` | التنقل بين الأقسام |
| `Home/End` | القفز إلى طرفي القائمة |
| `Enter` | فتح أو تفعيل |
| `Esc` | إغلاق القسم (مرتان تغلقان الطبقة) |
| `?` | إظهار المساعدة المضمّنة أو إخفاؤها |

## الأقسام

| القسم | الوصف |
| --- | --- |
| **Model** | اختيار نموذج الدردشة الافتراضي وجهد الاستدلال |
| **Theme** | اختيار السمة ومؤشر النشاط |
| **Updates** | عرض قناة الترقية والحالة |
| **Agents** | رؤية الوكلاء المدمجين والمخصصين، تفعيلهم، فرض القراءة فقط |
| **Prompts** | تحرير مقتطفات المطالبات المحفوظة |
| **Auto Drive** | مفاتيح المراجعة والوكلاء وضمان الجودة، وضع المتابعة، استبدال النموذج |
| **Review** | اختيار نموذج المراجعة وتبديل الحل التلقائي |
| **Planning** | اختيار النموذج والجهد لجولات التخطيط |
| **Validation** | تبديل مجموعات التحقق وأدواته |
| **Limits** | عرض للقراءة فقط لحدود المعدل واستخدام السياق |
| **Chrome** | خيارات اتصال المتصفح |
| **MCP** | تفعيل خوادم MCP أو تعطيلها |
| **Notifications** | تبديل الإشعارات وتصفيتها |

## الاستمرارية

تُكتب التغييرات في `~/.code/config.toml` حين يتوفر. يمكن حفظ وضع الوصول لكل مساحة عمل؛ وبقية الإعدادات عامة ما لم يُلغِها مشروع.

## الأوامر

```bash
/settings [section]
/auto settings
/update
/notifications [on|off|status]
```
