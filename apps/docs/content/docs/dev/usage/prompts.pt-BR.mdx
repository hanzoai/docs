## Prompts personalizados

O Hanzo Dev permite salvar e gerenciar trechos de prompt para reutilizar.

### Gerenciar prompts

- Abra o gerenciador de prompts com `/prompts` na TUI
- Crie, edite e apague trechos de prompt
- Os prompts ficam em `~/.code/config.toml`

### Uso

Acesse os prompts salvos por:
- O comando de barra `/prompts`
- A camada de Configurações (seção Prompts)

Os prompts personalizados entram no contexto da conversa quando selecionados, o que facilita reutilizar instruções comuns entre sessões.
