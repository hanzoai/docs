A camada de ajustes muda modelos, temas, padrões do Auto Drive, agentes, notificações e mais sem sair do chat.

## Abrir e navegar

- `/settings` abre a visão geral
- `/settings <section>` salta direto para uma seção
- `/auto settings` e `/update` entram nas respectivas seções

### Controles de teclado

| Tecla | Ação |
| --- | --- |
| `↑/↓` ou `j/k` | Mover a seleção |
| `Tab/Shift+Tab` | Percorrer as seções |
| `Home/End` | Ir às pontas da lista |
| `Enter` | Abrir ou ativar |
| `Esc` | Fechar a seção (duas vezes fecha a camada) |
| `?` | Mostrar ou ocultar a ajuda na linha |

## Seções

| Seção | Descrição |
| --- | --- |
| **Model** | Escolhe o modelo de chat padrão e o esforço de raciocínio |
| **Theme** | Escolhe o tema e o indicador de atividade |
| **Updates** | Vê o canal de atualização e o estado |
| **Agents** | Vê agentes integrados e próprios, liga ou desliga, força somente leitura |
| **Prompts** | Edita trechos de prompt salvos |
| **Auto Drive** | Interruptores de revisão, agentes e QA, modo continuar, modelo substituto |
| **Review** | Escolhe o modelo de revisão e a resolução automática |
| **Planning** | Escolhe modelo e esforço para os turnos de planejamento |
| **Validation** | Liga grupos e ferramentas de validação |
| **Limits** | Visão somente leitura de limites de taxa e uso de contexto |
| **Chrome** | Opções de conexão do navegador |
| **MCP** | Liga ou desliga servidores MCP |
| **Notifications** | Liga e filtra notificações |

## Persistência

As mudanças vão para `~/.code/config.toml` quando ele existe. O modo de acesso pode ficar por espaço de trabalho; o resto vale globalmente, salvo substituição por projeto.

## Comandos

```bash
/settings [section]
/auto settings
/update
/notifications [on|off|status]
```
