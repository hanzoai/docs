Hanzo Dev có nhiều chế độ vận hành cho trợ giúp phát triển bằng AI.

## Chế độ tương tác

Mở TUI để lập trình trong hội thoại:

```bash
dev "Help me refactor this function"
```

## Chế độ không tương tác

Chạy từng tác vụ không có giao diện:

```bash
dev exec "Add error handling to main.py"
```

## Lái tự động

Thực thi tác vụ nhiều lượt, hoàn toàn tự động:

```bash
dev auto "Refactor the database module"
```

## Điều phối nhiều tác nhân

Chia việc cho nhiều tác nhân AI:

```bash
/plan <task>    # Create a comprehensive plan
/solve <problem> # Solve challenging problems
/code <task>    # Perform coding tasks
```
