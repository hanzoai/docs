Hanzo Dev bietet mehrere Betriebsarten für KI-gestützte Entwicklungshilfe.

## Interaktiver Modus

Starten Sie die TUI für die Programmierung im Gespräch:

```bash
dev "Help me refactor this function"
```

## Nicht interaktiver Modus

Führen Sie einzelne Aufgaben ohne Oberfläche aus:

```bash
dev exec "Add error handling to main.py"
```

## Automatischer Lauf

Vollautomatische Aufgabenausführung über mehrere Runden:

```bash
dev auto "Refactor the database module"
```

## Orchestrierung mehrerer Agenten

Verteilen Sie die Arbeit auf mehrere KI-Agenten:

```bash
/plan <task>    # Create a comprehensive plan
/solve <problem> # Solve challenging problems
/code <task>    # Perform coding tasks
```
