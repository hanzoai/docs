## Eigene Prompts

Hanzo Dev kann eigene Prompt-Schnipsel speichern und zur Wiederverwendung verwalten.

### Prompts verwalten

- Öffnen Sie die Prompt-Verwaltung mit `/prompts` in der TUI
- Legen Sie Prompt-Schnipsel an, bearbeiten und löschen Sie sie
- Prompts liegen in `~/.code/config.toml`

### Verwendung

Gespeicherte Prompts erreichen Sie über:
- Den Schrägstrichbefehl `/prompts`
- Die Einstellungsfläche (Abschnitt Prompts)

Ausgewählte eigene Prompts werden in den Gesprächskontext eingefügt, sodass sich häufige Anweisungen sitzungsübergreifend leicht wiederverwenden lassen.
