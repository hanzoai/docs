يوفر Hanzo Dev عدة أوضاع عمل للمساعدة في التطوير بالذكاء الاصطناعي.

## الوضع التفاعلي

افتح TUI للبرمجة بالحوار:

```bash
dev "Help me refactor this function"
```

## الوضع غير التفاعلي

نفّذ مهامًا مفردة بلا واجهة:

```bash
dev exec "Add error handling to main.py"
```

## القيادة الآلية

تنفيذ المهام متعددة الأدوار بشكل آلي بالكامل:

```bash
dev auto "Refactor the database module"
```

## تنسيق عدة وكلاء

وزّع العمل على عدة وكلاء ذكاء اصطناعي:

```bash
/plan <task>    # Create a comprehensive plan
/solve <problem> # Solve challenging problems
/code <task>    # Perform coding tasks
```
