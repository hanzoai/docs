## カスタムプロンプト

Hanzo Dev は、再利用のためのカスタムプロンプト断片を保存し、管理できます。

### プロンプトの管理

- TUI で `/prompts` を開き、プロンプト管理を表示します
- プロンプト断片を作成、編集、削除します
- プロンプトは `~/.code/config.toml` に保存されます

### 使い方

保存したプロンプトには次から届きます。
- スラッシュコマンド `/prompts`
- 設定オーバーレイ（プロンプトの節）

選んだカスタムプロンプトは会話の文脈に差し込まれるので、よく使う指示をセッションをまたいで再利用しやすくなります。
