Hanzo Dev एआई-संचालित विकास सहायता के लिए कई संचालन मोड देता है।

## इंटरैक्टिव मोड

बातचीत में कोडिंग के लिए TUI खोलें:

```bash
dev "Help me refactor this function"
```

## गैर-इंटरैक्टिव मोड

एकल कार्य बिना इंटरफ़ेस चलाएँ:

```bash
dev exec "Add error handling to main.py"
```

## स्वचालित ड्राइव

कई चरणों वाले कार्यों का पूरी तरह स्वचालित निष्पादन:

```bash
dev auto "Refactor the database module"
```

## बहु-एजेंट ऑर्केस्ट्रेशन

काम कई एआई एजेंटों में बाँटें:

```bash
/plan <task>    # Create a comprehensive plan
/solve <problem> # Solve challenging problems
/code <task>    # Perform coding tasks
```
