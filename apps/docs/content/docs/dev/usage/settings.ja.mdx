---

設定オーバーレイは、チャットを離れずにモデル、テーマ、Auto Drive の既定、エージェント、通知などを変える。

## 開く、移動する

- `/settings` は概要を開く
- `/settings <section>` は節へ直接飛ぶ
- `/auto settings` と `/update` はそれぞれの節へ入る

### キー

| キー | 操作 |
| --- | --- |
| `↑/↓` または `j/k` | 選択を動かす |
| `Tab/Shift+Tab` | 節を巡る |
| `Home/End` | 一覧の端へ |
| `Enter` | 開く、または有効にする |
| `Esc` | 節を閉じる（二度でオーバーレイを閉じる） |
| `?` | 行内ヘルプ |

## 節

| 節 | 説明 |
| --- | --- |
| **Model** | 既定のチャットモデルと推論の強さ |
| **Theme** | テーマとスピナー |
| **Updates** | 更新チャネルと状態 |
| **Agents** | 組み込みと独自のエージェント、有効化、読み取り専用の強制 |
| **Prompts** | 保存したプロンプト断片の編集 |
| **Auto Drive** | レビュー、エージェント、QA の切替、継続モード、モデルの差し替え |
| **Review** | レビューモデル、自動解決 |
| **Planning** | 計画ターンのモデルと強さ |
| **Validation** | 検証グループとツール |
| **Limits** | レート制限とコンテキスト使用量の読み取り専用 |
| **Chrome** | ブラウザ接続 |
| **MCP** | MCP サーバーの有効化 |
| **Notifications** | 通知の切替と絞り込み |

## 保存

変更はファイルがあれば `~/.code/config.toml` に書く。アクセスモードはワークスペースごと。ほかはプロジェクトが上書きしない限り全体に効く。

## コマンド

```bash
/settings [section]
/auto settings
/update
/notifications [on|off|status]
```
