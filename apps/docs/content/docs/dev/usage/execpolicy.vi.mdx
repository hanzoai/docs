## Chính sách thực thi

Hanzo Dev dùng chính sách thực thi để quyết định lệnh nào tác nhân được chạy và khi nào cần phê duyệt.

### Chế độ sandbox

| Chế độ | Mô tả |
| --- | --- |
| `off` | Không sandbox (lệnh chạy trực tiếp) |
| `workspace-read` | Chỉ đọc không gian làm việc |
| `workspace-write` | Đọc và ghi không gian làm việc (mặc định của full-auto) |
| `network-off` | Tắt truy cập mạng |

### Chính sách phê duyệt

| Chính sách | Mô tả |
| --- | --- |
| `always` | Luôn hỏi phê duyệt trước khi thực thi |
| `on-failure` | Chỉ hỏi khi một lệnh thất bại (mặc định của full-auto) |
| `on-request` | Hỏi khi mô hình yêu cầu phê duyệt một cách rõ ràng |
| `never` | Không bao giờ hỏi phê duyệt |

### Cách dùng

```bash
# Set sandbox mode
dev --sandbox workspace-write "your prompt"

# Set approval policy
dev --ask-for-approval on-failure "your prompt"

# Full auto (sandboxed + auto-approve)
dev --full-auto "your prompt"
```
