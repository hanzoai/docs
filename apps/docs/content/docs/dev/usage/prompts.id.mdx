## Prompt kustom

Hanzo Dev mendukung penyimpanan dan pengelolaan cuplikan prompt kustom untuk dipakai ulang.

### Mengelola prompt

- Buka pengelola prompt dengan `/prompts` di TUI
- Buat, sunting, dan hapus cuplikan prompt
- Prompt disimpan di `~/.code/config.toml`

### Penggunaan

Akses prompt tersimpan lewat:
- Perintah garis miring `/prompts`
- Lapisan Pengaturan (bagian Prompt)

Prompt kustom disuntikkan ke konteks percakapan saat dipilih, sehingga instruksi yang sering dipakai mudah diulang antar sesi.
