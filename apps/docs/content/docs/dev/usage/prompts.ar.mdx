## مطالبات مخصصة

يدعم Hanzo Dev حفظ أجزاء المطالبات المخصصة وإدارتها لإعادة استخدامها.

### إدارة المطالبات

- افتح مدير المطالبات بـ `/prompts` في TUI
- أنشئ أجزاء المطالبات وعدّلها واحذفها
- تُخزَّن المطالبات في `~/.code/config.toml`

### الاستخدام

تصل إلى المطالبات المحفوظة عبر:
- أمر الشرطة المائلة `/prompts`
- طبقة الإعدادات (قسم المطالبات)

تُحقن المطالبات المخصصة في سياق المحادثة عند اختيارها، فيسهل إعادة استخدام التعليمات الشائعة بين الجلسات.
