Lapisan pengaturan mengubah model, tema, bawaan Auto Drive, agen, pemberitahuan, dan lainnya tanpa meninggalkan obrolan.

## Buka dan navigasi

- `/settings` membuka ikhtisar
- `/settings <section>` langsung ke suatu bagian
- `/auto settings` dan `/update` masuk ke bagian masing-masing

### Tombol

| Tombol | Tindakan |
| --- | --- |
| `↑/↓` atau `j/k` | Pindahkan pilihan |
| `Tab/Shift+Tab` | Ganti bagian |
| `Home/End` | Ke ujung daftar |
| `Enter` | Buka atau aktifkan |
| `Esc` | Tutup bagian (dua kali menutup lapisan) |
| `?` | Bantuan sebaris |

## Bagian

| Bagian | Keterangan |
| --- | --- |
| **Model** | Pilih model obrolan bawaan dan upaya penalaran |
| **Theme** | Pilih tema dan pemutar |
| **Updates** | Lihat kanal pemutakhiran dan status |
| **Agents** | Lihat agen bawaan dan khusus, aktifkan, paksa hanya-baca |
| **Prompts** | Sunting cuplikan prompt tersimpan |
| **Auto Drive** | Sakelar tinjauan, agen, dan QA, mode lanjut, pengganti model |
| **Review** | Pilih model tinjauan, sakelar penyelesaian otomatis |
| **Planning** | Pilih model dan upaya untuk giliran perencanaan |
| **Validation** | Sakelar kelompok dan alat validasi |
| **Limits** | Tampilan hanya-baca batas laju dan pemakaian konteks |
| **Chrome** | Opsi koneksi peramban |
| **MCP** | Aktifkan atau nonaktifkan server MCP |
| **Notifications** | Sakelar dan saring pemberitahuan |

## Persistensi

Perubahan ditulis ke `~/.code/config.toml` bila ada. Mode akses dapat disimpan per ruang kerja; sisanya global kecuali ditimpa per proyek.

## Perintah

```bash
/settings [section]
/auto settings
/update
/notifications [on|off|status]
```
