Hanzo Dev предлагает несколько режимов работы для помощи в разработке с ИИ.

## Интерактивный режим

Запустите TUI для программирования в диалоге:

```bash
dev "Help me refactor this function"
```

## Неинтерактивный режим

Выполняйте отдельные задачи без интерфейса:

```bash
dev exec "Add error handling to main.py"
```

## Автоматический ход

Полностью автоматическое выполнение задач в несколько ходов:

```bash
dev auto "Refactor the database module"
```

## Оркестрация нескольких агентов

Распределите работу между несколькими ИИ-агентами:

```bash
/plan <task>    # Create a comprehensive plan
/solve <problem> # Solve challenging problems
/code <task>    # Perform coding tasks
```
