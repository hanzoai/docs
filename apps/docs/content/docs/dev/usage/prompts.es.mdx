## Indicaciones personalizadas

Hanzo Dev permite guardar y administrar fragmentos de indicaciones para reutilizarlos.

### Administrar las indicaciones

- Abre el administrador de indicaciones con `/prompts` en la TUI
- Crea, edita y borra fragmentos de indicaciones
- Las indicaciones se guardan en `~/.code/config.toml`

### Uso

Accede a las indicaciones guardadas mediante:
- El comando de barra `/prompts`
- La capa de Ajustes (sección Indicaciones)

Al seleccionarlas, las indicaciones personalizadas se inyectan en el contexto de la conversación, así es fácil reutilizar instrucciones habituales entre sesiones.
