सेटिंग परत चैट छोड़े बिना मॉडल, थीम, Auto Drive के डिफ़ॉल्ट, एजेंट, सूचनाएँ और अन्य बदलती है.

## खोलना और चलना

- `/settings` अवलोकन खोलता है
- `/settings <section>` सीधे एक अनुभाग पर जाता है
- `/auto settings` और `/update` अपने अनुभागों में जाते हैं

### कुंजीपटल

| कुंजी | क्रिया |
| --- | --- |
| `↑/↓` या `j/k` | चयन हिलाएँ |
| `Tab/Shift+Tab` | अनुभाग बदलें |
| `Home/End` | सूची के सिरों पर जाएँ |
| `Enter` | खोलें या सक्रिय करें |
| `Esc` | अनुभाग बंद करें (दो बार परत बंद) |
| `?` | पंक्ति में सहायता टॉगल करें |

## अनुभाग

| अनुभाग | विवरण |
| --- | --- |
| **Model** | डिफ़ॉल्ट चैट मॉडल और तर्क प्रयास चुनें |
| **Theme** | थीम और स्पिनर चुनें |
| **Updates** | अपग्रेड चैनल और स्थिति देखें |
| **Agents** | अंतर्निहित और अपने एजेंट देखें, चालू/बंद करें, केवल-पढ़ने के लिए बाध्य करें |
| **Prompts** | सहेजे प्रॉम्प्ट अंश संपादित करें |
| **Auto Drive** | समीक्षा, एजेंट और QA स्विच, जारी मोड, मॉडल प्रतिस्थापन |
| **Review** | समीक्षा मॉडल चुनें, स्वतः समाधान टॉगल करें |
| **Planning** | योजना मोड़ों के लिए मॉडल और प्रयास चुनें |
| **Validation** | सत्यापन समूह और उपकरण टॉगल करें |
| **Limits** | दर सीमा और संदर्भ उपयोग का केवल-पढ़ने का दृश्य |
| **Chrome** | ब्राउज़र कनेक्शन विकल्प |
| **MCP** | MCP सर्वर चालू या बंद करें |
| **Notifications** | सूचनाएँ टॉगल और फ़िल्टर करें |

## स्थायित्व

बदलाव उपलब्ध होने पर `~/.code/config.toml` में लिखे जाते हैं. पहुँच मोड प्रति कार्यक्षेत्र रह सकता है; शेष सेटिंग वैश्विक हैं जब तक कोई परियोजना उन्हें न बदले.

## कमांड

```bash
/settings [section]
/auto settings
/update
/notifications [on|off|status]
```
