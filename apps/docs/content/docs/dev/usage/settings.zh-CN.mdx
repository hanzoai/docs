设置浮层让你不离开对话就能改模型、主题、Auto Drive 默认值、代理、通知等。

## 打开与导航

- `/settings` 打开概览
- `/settings <section>` 直接跳到某一节
- `/auto settings` 和 `/update` 进入各自的节

### 键盘

| 键 | 动作 |
| --- | --- |
| `↑/↓` 或 `j/k` | 移动选择 |
| `Tab/Shift+Tab` | 循环各节 |
| `Home/End` | 跳到列表两端 |
| `Enter` | 打开或激活 |
| `Esc` | 关闭本节（两次关闭浮层） |
| `?` | 切换行内帮助 |

## 各节

| 节 | 说明 |
| --- | --- |
| **Model** | 选择默认聊天模型和推理强度 |
| **Theme** | 选择主题和旋转指示 |
| **Updates** | 查看升级通道和状态 |
| **Agents** | 查看内置和自定义代理，启用、强制只读 |
| **Prompts** | 编辑已保存的提示片段 |
| **Auto Drive** | 评审、代理和 QA 开关，继续模式，替换模型 |
| **Review** | 选择评审模型，切换自动解决 |
| **Planning** | 为规划回合选择模型和强度 |
| **Validation** | 切换验证组和工具 |
| **Limits** | 速率限制和上下文用量的只读视图 |
| **Chrome** | 浏览器连接选项 |
| **MCP** | 启用或停用 MCP 服务器 |
| **Notifications** | 开关并过滤通知 |

## 持久化

有文件时，更改写入 `~/.code/config.toml`。访问模式可以按工作区保存；其余设置全局生效，除非项目覆盖。

## 命令

```bash
/settings [section]
/auto settings
/update
/notifications [on|off|status]
```
