## Política de ejecución

Hanzo Dev usa políticas de ejecución para controlar qué comandos puede lanzar el agente y cuándo hace falta aprobación.

### Modos de aislamiento

| Modo | Descripción |
| --- | --- |
| `off` | Sin aislamiento (los comandos se ejecutan directamente) |
| `workspace-read` | Acceso de solo lectura al espacio de trabajo |
| `workspace-write` | Acceso de lectura y escritura al espacio de trabajo (predeterminado en full-auto) |
| `network-off` | Desactiva el acceso a la red |

### Políticas de aprobación

| Política | Descripción |
| --- | --- |
| `always` | Pide aprobación siempre antes de ejecutar |
| `on-failure` | Pide solo cuando un comando falla (predeterminado en full-auto) |
| `on-request` | Pide cuando el modelo solicita aprobación de forma explícita |
| `never` | Nunca pide aprobación |

### Uso

```bash
# Set sandbox mode
dev --sandbox workspace-write "your prompt"

# Set approval policy
dev --ask-for-approval on-failure "your prompt"

# Full auto (sandboxed + auto-approve)
dev --full-auto "your prompt"
```
