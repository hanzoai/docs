O Hanzo Dev oferece vários modos de operação para assistência ao desenvolvimento com IA.

## Modo interativo

Abra a TUI para programar em conversa:

```bash
dev "Help me refactor this function"
```

## Modo não interativo

Execute tarefas avulsas sem interface:

```bash
dev exec "Add error handling to main.py"
```

## Condução automática

Execução de tarefas em vários turnos, totalmente automatizada:

```bash
dev auto "Refactor the database module"
```

## Orquestração de vários agentes

Distribua o trabalho entre vários agentes de IA:

```bash
/plan <task>    # Create a comprehensive plan
/solve <problem> # Solve challenging problems
/code <task>    # Perform coding tasks
```
