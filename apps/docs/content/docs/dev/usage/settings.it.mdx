---
title: Impostazioni
description: Pannello impostazioni a schermo intero nella TUI per modello, tema, agenti e altro.
---

La sovrapposizione delle impostazioni cambia modelli, temi, predefiniti di Auto Drive, agenti, notifiche e altro senza uscire dalla chat.

## Aprire e navigare

- `/settings` apre la panoramica
- `/settings <section>` salta direttamente a una sezione
- `/auto settings` e `/update` portano alle rispettive sezioni

### Controlli da tastiera

| Tasto | Azione |
| --- | --- |
| `↑/↓` o `j/k` | Sposta la selezione |
| `Tab/Shift+Tab` | Scorri le sezioni |
| `Home/End` | Vai agli estremi dell’elenco |
| `Enter` | Apri o attiva |
| `Esc` | Chiudi la sezione (due volte chiude la sovrapposizione) |
| `?` | Mostra o nascondi l’aiuto in linea |

## Sezioni

| Sezione | Descrizione |
| --- | --- |
| **Model** | Scegli il modello di chat predefinito e lo sforzo di ragionamento |
| **Theme** | Scegli tema e indicatore di attività |
| **Updates** | Vedi canale di aggiornamento e stato |
| **Agents** | Vedi agenti integrati e personalizzati, attivali, forza sola lettura |
| **Prompts** | Modifica i frammenti di prompt salvati |
| **Auto Drive** | Interruttori review, agenti e QA, modalità continua, modello sostitutivo |
| **Review** | Scegli il modello di review, attiva la risoluzione automatica |
| **Planning** | Scegli modello e sforzo per i turni di pianificazione |
| **Validation** | Attiva gruppi e strumenti di validazione |
| **Limits** | Vista in sola lettura di limiti di tasso e uso del contesto |
| **Chrome** | Opzioni di connessione del browser |
| **MCP** | Attiva o disattiva i server MCP |
| **Notifications** | Attiva e filtra le notifiche |

## Persistenza

Le modifiche si scrivono in `~/.code/config.toml` quando è disponibile. La modalità di accesso può stare per spazio di lavoro; il resto vale globalmente salvo override di progetto.

## Comandi

```bash
/settings [section]
/auto settings
/update
/notifications [on|off|status]
```
