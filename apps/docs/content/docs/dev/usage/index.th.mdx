Hanzo Dev มีหลายโหมดการทำงานสำหรับความช่วยเหลือในการพัฒนาที่ขับเคลื่อนด้วย AI

## โหมดโต้ตอบ

เปิด TUI เพื่อเขียนโค้ดแบบสนทนา:

```bash
dev "Help me refactor this function"
```

## โหมดไม่โต้ตอบ

รันงานเดี่ยวโดยไม่มีส่วนติดต่อ:

```bash
dev exec "Add error handling to main.py"
```

## ขับอัตโนมัติ

การทำงานของงานหลายรอบแบบอัตโนมัติทั้งหมด:

```bash
dev auto "Refactor the database module"
```

## การประสานงานหลายเอเจนต์

กระจายงานไปยังเอเจนต์ AI หลายตัว:

```bash
/plan <task>    # Create a comprehensive plan
/solve <problem> # Solve challenging problems
/code <task>    # Perform coding tasks
```
