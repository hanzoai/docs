## Prompt personalizzati

Hanzo Dev consente di salvare e gestire frammenti di prompt da riutilizzare.

### Gestire i prompt

- Apri il gestore dei prompt con `/prompts` nella TUI
- Crea, modifica ed elimina frammenti di prompt
- I prompt sono conservati in `~/.code/config.toml`

### Uso

Accedi ai prompt salvati tramite:
- Il comando con barra `/prompts`
- Il riquadro Impostazioni (sezione Prompt)

I prompt personalizzati, una volta scelti, vengono inseriti nel contesto della conversazione, così è facile riusare istruzioni abituali fra una sessione e l'altra.
