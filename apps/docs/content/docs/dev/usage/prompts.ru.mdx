## Свои подсказки

Hanzo Dev умеет сохранять и вести фрагменты подсказок для повторного использования.

### Ведение подсказок

- Откройте диспетчер подсказок командой `/prompts` в TUI
- Создавайте, правьте и удаляйте фрагменты подсказок
- Подсказки хранятся в `~/.code/config.toml`

### Использование

К сохранённым подсказкам можно перейти через:
- Команду с косой чертой `/prompts`
- Панель настроек (раздел подсказок)

Выбранные свои подсказки вставляются в контекст разговора, поэтому обычные указания легко переносить между сессиями.
