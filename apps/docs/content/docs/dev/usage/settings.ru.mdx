---
title: Настройки
description: Полноэкранная панель настроек в TUI для модели, темы, агентов и прочего.
---

Панель настроек меняет модели, темы, значения Auto Drive по умолчанию, агентов, уведомления и другое, не выходя из чата.

## Открытие и навигация

- `/settings` открывает обзор
- `/settings <section>` переходит сразу к разделу
- `/auto settings` и `/update` ведут в свои разделы

### Клавиши

| Клавиша | Действие |
| --- | --- |
| `↑/↓` или `j/k` | Двигать выбор |
| `Tab/Shift+Tab` | Листать разделы |
| `Home/End` | К концам списка |
| `Enter` | Открыть или активировать |
| `Esc` | Закрыть раздел (дважды закрывает панель) |
| `?` | Встроенная справка |

## Разделы

| Раздел | Описание |
| --- | --- |
| **Model** | Модель чата по умолчанию и усилие рассуждения |
| **Theme** | Тема и индикатор активности |
| **Updates** | Канал обновления и состояние |
| **Agents** | Встроенные и свои агенты, включение, принудительное чтение |
| **Prompts** | Правка сохранённых фрагментов промптов |
| **Auto Drive** | Переключатели обзора, агентов и QA, режим продолжения, замена модели |
| **Review** | Модель обзора и авторазрешение |
| **Planning** | Модель и усилие для ходов планирования |
| **Validation** | Группы и инструменты проверки |
| **Limits** | Только чтение: лимиты частоты и использование контекста |
| **Chrome** | Параметры подключения браузера |
| **MCP** | Включение серверов MCP |
| **Notifications** | Уведомления и фильтр |

## Сохранение

Изменения пишутся в `~/.code/config.toml`, если файл есть. Режим доступа можно хранить по рабочему пространству; остальное глобально, пока проект не переопределит.

## Команды

```bash
/settings [section]
/auto settings
/update
/notifications [on|off|status]
```
