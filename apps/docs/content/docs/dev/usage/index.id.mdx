Hanzo Dev menyediakan beberapa mode operasi untuk bantuan pengembangan berbasis AI.

## Mode interaktif

Buka TUI untuk pemrograman dalam percakapan:

```bash
dev "Help me refactor this function"
```

## Mode non-interaktif

Jalankan tugas tunggal tanpa antarmuka:

```bash
dev exec "Add error handling to main.py"
```

## Kemudi otomatis

Eksekusi tugas banyak giliran yang sepenuhnya otomatis:

```bash
dev auto "Refactor the database module"
```

## Orkestrasi banyak agen

Sebarkan kerja ke beberapa agen AI:

```bash
/plan <task>    # Create a comprehensive plan
/solve <problem> # Solve challenging problems
/code <task>    # Perform coding tasks
```
