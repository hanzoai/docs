## Invites personnalisées

Hanzo Dev permet d'enregistrer et de gérer des extraits d'invites pour les réutiliser.

### Gérer les invites

- Ouvrez le gestionnaire d'invites avec `/prompts` dans la TUI
- Créez, modifiez et supprimez des extraits d'invites
- Les invites sont stockées dans `~/.code/config.toml`

### Utilisation

Accédez aux invites enregistrées par :
- La commande barre oblique `/prompts`
- La couche Réglages (section Invites)

Une fois sélectionnées, les invites personnalisées sont injectées dans le contexte de la conversation, ce qui facilite la réutilisation d'instructions courantes d'une session à l'autre.
