Hanzo Dev offre diverse modalità di funzionamento per l'assistenza allo sviluppo con IA.

## Modalità interattiva

Avvia la TUI per programmare in conversazione:

```bash
dev "Help me refactor this function"
```

## Modalità non interattiva

Esegui singoli compiti senza interfaccia:

```bash
dev exec "Add error handling to main.py"
```

## Guida automatica

Esecuzione di compiti su più turni, del tutto automatizzata:

```bash
dev auto "Refactor the database module"
```

## Orchestrazione di più agenti

Distribuisci il lavoro fra più agenti di IA:

```bash
/plan <task>    # Create a comprehensive plan
/solve <problem> # Solve challenging problems
/code <task>    # Perform coding tasks
```
