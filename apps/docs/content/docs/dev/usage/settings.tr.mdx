Ayar katmanı sohbetten çıkmadan modelleri, temaları, Auto Drive varsayılanlarını, ajanları, bildirimleri ve daha fazlasını değiştirir.

## Açma ve gezinme

- `/settings` genel bakışı açar
- `/settings <section>` doğrudan bir bölüme gider
- `/auto settings` ve `/update` kendi bölümlerine gider

### Klavye

| Tuş | Eylem |
| --- | --- |
| `↑/↓` veya `j/k` | Seçimi taşı |
| `Tab/Shift+Tab` | Bölümler arasında dön |
| `Home/End` | Listenin uçlarına git |
| `Enter` | Aç veya etkinleştir |
| `Esc` | Bölümü kapat (iki kez katmanı kapatır) |
| `?` | Satır içi yardımı aç/kapat |

## Bölümler

| Bölüm | Açıklama |
| --- | --- |
| **Model** | Varsayılan sohbet modelini ve akıl yürütme çabasını seç |
| **Theme** | Tema ve döndürücüyü seç |
| **Updates** | Yükseltme kanalını ve durumu gör |
| **Agents** | Yerleşik ve özel ajanları gör, aç/kapat, salt okunur zorla |
| **Prompts** | Kayıtlı istem parçalarını düzenle |
| **Auto Drive** | İnceleme, ajan ve QA anahtarları, sürdürme kipi, model değişimi |
| **Review** | İnceleme modelini seç, otomatik çözümü aç |
| **Planning** | Planlama turları için model ve çaba seç |
| **Validation** | Doğrulama gruplarını ve araçlarını aç |
| **Limits** | Hız sınırları ve bağlam kullanımının salt okunur görünümü |
| **Chrome** | Tarayıcı bağlantı seçenekleri |
| **MCP** | MCP sunucularını aç veya kapat |
| **Notifications** | Bildirimleri aç ve süz |

## Kalıcılık

Değişiklikler varsa `~/.code/config.toml` dosyasına yazılır. Erişim kipi çalışma alanına göre durabilir; geri kalanı proje geçersiz kılmadıkça geneldir.

## Komutlar

```bash
/settings [section]
/auto settings
/update
/notifications [on|off|status]
```
