---
title: Réglages
description: Panneau de réglages plein écran dans le TUI pour le modèle, le thème, les agents et le reste.
---

La couche de réglages permet de changer modèles, thèmes, valeurs par défaut d’Auto Drive, agents, notifications et plus sans quitter la conversation.

## Ouvrir et naviguer

- `/settings` ouvre la vue d’ensemble
- `/settings <section>` saute directement à une section
- `/auto settings` et `/update` mènent à leurs sections

### Contrôles clavier

| Touche | Action |
| --- | --- |
| `↑/↓` ou `j/k` | Déplacer la sélection |
| `Tab/Shift+Tab` | Faire défiler les sections |
| `Home/End` | Aller aux extrémités de la liste |
| `Enter` | Ouvrir ou activer |
| `Esc` | Fermer la section (deux fois ferme la couche) |
| `?` | Afficher ou masquer l’aide en ligne |

## Sections

| Section | Description |
| --- | --- |
| **Model** | Choisir le modèle de chat par défaut et l’effort de raisonnement |
| **Theme** | Choisir le thème et l’indicateur d’activité |
| **Updates** | Voir le canal de mise à jour et l’état |
| **Agents** | Voir les agents intégrés et personnels, les activer, forcer la lecture seule |
| **Prompts** | Modifier les extraits d’invite enregistrés |
| **Auto Drive** | Interrupteurs revue, agents et QA, mode continuer, modèle de remplacement |
| **Review** | Choisir le modèle de revue, activer la résolution automatique |
| **Planning** | Choisir modèle et effort pour les tours de planification |
| **Validation** | Activer les groupes et outils de validation |
| **Limits** | Vue en lecture seule des limites de débit et de l’usage du contexte |
| **Chrome** | Options de connexion du navigateur |
| **MCP** | Activer ou désactiver les serveurs MCP |
| **Notifications** | Activer et filtrer les notifications |

## Persistance

Les changements s’écrivent dans `~/.code/config.toml` lorsqu’il est disponible. Le mode d’accès peut être stocké par espace de travail ; le reste s’applique globalement sauf surcharge par projet.

## Commandes

```bash
/settings [section]
/auto settings
/update
/notifications [on|off|status]
```
