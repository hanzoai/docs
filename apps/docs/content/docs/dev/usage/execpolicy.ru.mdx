## Политика выполнения

Hanzo Dev использует политики выполнения, чтобы решать, какие команды агент может запускать и когда нужно подтверждение.

### Режимы песочницы

| Режим | Описание |
| --- | --- |
| `off` | Без песочницы (команды выполняются напрямую) |
| `workspace-read` | Доступ к рабочему пространству только на чтение |
| `workspace-write` | Чтение и запись в рабочем пространстве (по умолчанию для full-auto) |
| `network-off` | Отключить доступ к сети |

### Политики подтверждения

| Политика | Описание |
| --- | --- |
| `always` | Всегда спрашивать подтверждение перед выполнением |
| `on-failure` | Спрашивать только при сбое команды (по умолчанию для full-auto) |
| `on-request` | Спрашивать, когда модель явно просит подтверждение |
| `never` | Никогда не спрашивать подтверждение |

### Использование

```bash
# Set sandbox mode
dev --sandbox workspace-write "your prompt"

# Set approval policy
dev --ask-for-approval on-failure "your prompt"

# Full auto (sandboxed + auto-approve)
dev --full-auto "your prompt"
```
