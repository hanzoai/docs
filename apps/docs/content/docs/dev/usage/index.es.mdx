Hanzo Dev ofrece varios modos de funcionamiento para la asistencia al desarrollo con IA.

## Modo interactivo

Abre la TUI para programar en conversación:

```bash
dev "Help me refactor this function"
```

## Modo no interactivo

Ejecuta tareas sueltas sin interfaz:

```bash
dev exec "Add error handling to main.py"
```

## Conducción automática

Ejecución de tareas de varios turnos, del todo automatizada:

```bash
dev auto "Refactor the database module"
```

## Orquestación de varios agentes

Reparte el trabajo entre varios agentes de IA:

```bash
/plan <task>    # Create a comprehensive plan
/solve <problem> # Solve challenging problems
/code <task>    # Perform coding tasks
```
