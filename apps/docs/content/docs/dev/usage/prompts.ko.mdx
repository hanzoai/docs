## 사용자 지정 프롬프트

Hanzo Dev는 다시 쓰려고 사용자 지정 프롬프트 조각을 저장하고 관리할 수 있습니다.

### 프롬프트 관리

- TUI에서 `/prompts`로 프롬프트 관리자를 엽니다
- 프롬프트 조각을 만들고, 고치고, 지웁니다
- 프롬프트는 `~/.code/config.toml`에 저장됩니다

### 사용법

저장한 프롬프트는 다음으로 엽니다.
- 슬래시 명령 `/prompts`
- 설정 오버레이(프롬프트 구역)

고른 사용자 지정 프롬프트는 대화 맥락에 끼워지므로, 자주 쓰는 지시를 세션 사이에 다시 쓰기 쉽습니다.
