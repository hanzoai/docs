Lớp cài đặt đổi mô hình, giao diện, mặc định Auto Drive, tác tử, thông báo và hơn thế mà không rời cuộc trò chuyện.

## Mở và di chuyển

- `/settings` mở phần tổng quan
- `/settings <section>` nhảy thẳng tới một mục
- `/auto settings` và `/update` vào đúng mục của chúng

### Phím

| Phím | Hành động |
| --- | --- |
| `↑/↓` hoặc `j/k` | Di chuyển lựa chọn |
| `Tab/Shift+Tab` | Đổi mục |
| `Home/End` | Tới hai đầu danh sách |
| `Enter` | Mở hoặc kích hoạt |
| `Esc` | Đóng mục (hai lần đóng lớp) |
| `?` | Bật trợ giúp ngay dòng |

## Các mục

| Mục | Mô tả |
| --- | --- |
| **Model** | Chọn mô hình trò chuyện mặc định và mức suy luận |
| **Theme** | Chọn giao diện và vòng quay |
| **Updates** | Xem kênh nâng cấp và trạng thái |
| **Agents** | Xem tác tử dựng sẵn và tùy biến, bật tắt, buộc chỉ đọc |
| **Prompts** | Sửa đoạn prompt đã lưu |
| **Auto Drive** | Công tắc duyệt, tác tử và QA, chế độ tiếp tục, mô hình thay thế |
| **Review** | Chọn mô hình duyệt, bật tự giải quyết |
| **Planning** | Chọn mô hình và mức cho lượt lập kế hoạch |
| **Validation** | Bật nhóm và công cụ kiểm tra |
| **Limits** | Xem chỉ đọc hạn mức và mức dùng ngữ cảnh |
| **Chrome** | Tùy chọn kết nối trình duyệt |
| **MCP** | Bật hoặc tắt máy chủ MCP |
| **Notifications** | Bật và lọc thông báo |

## Lưu giữ

Thay đổi ghi vào `~/.code/config.toml` khi có tệp. Chế độ truy cập có thể theo không gian làm việc; phần còn lại áp dụng toàn cục trừ khi dự án ghi đè.

## Lệnh

```bash
/settings [section]
/auto settings
/update
/notifications [on|off|status]
```
