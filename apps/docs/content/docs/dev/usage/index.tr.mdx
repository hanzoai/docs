Hanzo Dev, yapay zekâ destekli geliştirme yardımı için birkaç çalışma kipi sunar.

## Etkileşimli kip

Konuşarak kodlamak için TUI'yi açın:

```bash
dev "Help me refactor this function"
```

## Etkileşimsiz kip

Tek görevleri arayüz olmadan çalıştırın:

```bash
dev exec "Add error handling to main.py"
```

## Otomatik sürüş

Birden çok turlu görevlerin tamamen otomatik yürütülmesi:

```bash
dev auto "Refactor the database module"
```

## Çoklu ajan orkestrasyonu

İşi birden çok yapay zekâ ajanına yayın:

```bash
/plan <task>    # Create a comprehensive plan
/solve <problem> # Solve challenging problems
/code <task>    # Perform coding tasks
```
