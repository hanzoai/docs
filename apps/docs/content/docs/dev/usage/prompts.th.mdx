## พรอมต์กำหนดเอง

Hanzo Dev รองรับการบันทึกและจัดการชิ้นส่วนพรอมต์กำหนดเองเพื่อใช้ซ้ำ

### จัดการพรอมต์

- เปิดตัวจัดการพรอมต์ด้วย `/prompts` ใน TUI
- สร้าง แก้ไข และลบชิ้นส่วนพรอมต์
- พรอมต์ถูกเก็บใน `~/.code/config.toml`

### การใช้งาน

เข้าถึงพรอมต์ที่บันทึกไว้ผ่าน:
- คำสั่งทับ `/prompts`
- ชั้นการตั้งค่า (ส่วนพรอมต์)

พรอมต์กำหนดเองถูกฉีดเข้าบริบทการสนทนาเมื่อเลือก จึงนำคำสั่งที่ใช้บ่อยกลับมาใช้ข้ามเซสชันได้ง่าย
