title: Ajustes

---

La capa de ajustes permite cambiar modelos, temas, valores por defecto de Auto Drive, agentes, notificaciones y más sin salir del chat.

## Abrir y navegar

- `/settings` abre el resumen
- `/settings <section>` salta directo a una sección
- `/auto settings` y `/update` entran en sus secciones

### Controles de teclado

| Tecla | Acción |
| --- | --- |
| `↑/↓` o `j/k` | Mover la selección |
| `Tab/Shift+Tab` | Recorrer las secciones |
| `Home/End` | Ir a los extremos de la lista |
| `Enter` | Abrir o activar |
| `Esc` | Cerrar la sección (dos veces cierra la capa) |
| `?` | Mostrar u ocultar la ayuda en línea |

## Secciones

| Sección | Descripción |
| --- | --- |
| **Model** | Elige el modelo de chat por defecto y el esfuerzo de razonamiento |
| **Theme** | Elige el tema y el indicador de actividad |
| **Updates** | Ve el canal de actualización y el estado |
| **Agents** | Ve agentes integrados y propios, actívalos o desactívalos, fuerza solo lectura |
| **Prompts** | Edita fragmentos de prompt guardados |
| **Auto Drive** | Interruptores de revisión, agentes y QA, modo continuar, modelo alternativo |
| **Review** | Elige el modelo de revisión y la resolución automática |
| **Planning** | Elige modelo y esfuerzo para los turnos de planificación |
| **Validation** | Activa grupos y herramientas de validación |
| **Limits** | Vista de solo lectura de límites de tasa y uso de contexto |
| **Chrome** | Opciones de conexión del navegador |
| **MCP** | Activa o desactiva servidores MCP |
| **Notifications** | Activa y filtra notificaciones |

## Persistencia

Los cambios se escriben en `~/.code/config.toml` cuando existe. El modo de acceso puede guardarse por espacio de trabajo; el resto se aplica de forma global salvo que un proyecto lo anule.

## Comandos

```bash
/settings [section]
/auto settings
/update
/notifications [on|off|status]
```
