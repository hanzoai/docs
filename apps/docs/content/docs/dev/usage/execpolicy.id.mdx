## Kebijakan eksekusi

Hanzo Dev memakai kebijakan eksekusi untuk mengatur perintah mana yang boleh dijalankan agen dan kapan persetujuan diperlukan.

### Mode sandbox

| Mode | Deskripsi |
| --- | --- |
| `off` | Tanpa sandbox (perintah berjalan langsung) |
| `workspace-read` | Akses baca saja ke ruang kerja |
| `workspace-write` | Akses baca dan tulis ke ruang kerja (bawaan untuk full-auto) |
| `network-off` | Menonaktifkan akses jaringan |

### Kebijakan persetujuan

| Kebijakan | Deskripsi |
| --- | --- |
| `always` | Selalu meminta persetujuan sebelum menjalankan |
| `on-failure` | Meminta hanya saat perintah gagal (bawaan untuk full-auto) |
| `on-request` | Meminta saat model secara eksplisit meminta persetujuan |
| `never` | Tidak pernah meminta persetujuan |

### Penggunaan

```bash
# Set sandbox mode
dev --sandbox workspace-write "your prompt"

# Set approval policy
dev --ask-for-approval on-failure "your prompt"

# Full auto (sandboxed + auto-approve)
dev --full-auto "your prompt"
```
