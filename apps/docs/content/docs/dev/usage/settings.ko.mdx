설정 오버레이는 채팅을 떠나지 않고 모델, 테마, Auto Drive 기본값, 에이전트, 알림 등을 바꾼다.

## 열기와 이동

- `/settings`는 개요를 연다
- `/settings <section>`은 구역으로 바로 간다
- `/auto settings`와 `/update`는 각자 구역으로 들어간다

### 키

| 키 | 동작 |
| --- | --- |
| `↑/↓` 또는 `j/k` | 선택을 옮긴다 |
| `Tab/Shift+Tab` | 구역을 순환한다 |
| `Home/End` | 목록 끝으로 간다 |
| `Enter` | 열거나 활성화한다 |
| `Esc` | 구역을 닫는다(두 번이면 오버레이를 닫는다) |
| `?` | 줄 안 도움말 |

## 구역

| 구역 | 설명 |
| --- | --- |
| **Model** | 기본 채팅 모델과 추론 강도 |
| **Theme** | 테마와 스피너 |
| **Updates** | 업그레이드 채널과 상태 |
| **Agents** | 내장·사용자 에이전트, 켜기, 읽기 전용 강제 |
| **Prompts** | 저장한 프롬프트 조각 편집 |
| **Auto Drive** | 검토·에이전트·QA 스위치, 계속 모드, 모델 대체 |
| **Review** | 검토 모델, 자동 해결 |
| **Planning** | 계획 차례의 모델과 강도 |
| **Validation** | 검증 그룹과 도구 |
| **Limits** | 속도 제한과 컨텍스트 사용의 읽기 전용 보기 |
| **Chrome** | 브라우저 연결 옵션 |
| **MCP** | MCP 서버 켜기/끄기 |
| **Notifications** | 알림 전환과 필터 |

## 저장

변경은 파일이 있으면 `~/.code/config.toml`에 쓴다. 접근 모드는 작업 공간별로 둘 수 있고, 나머지는 프로젝트가 덮어쓰지 않는 한 전역이다.

## 명령

```bash
/settings [section]
/auto settings
/update
/notifications [on|off|status]
```
