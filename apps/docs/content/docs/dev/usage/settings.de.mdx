title: Einstellungen

---

Die Einstellungsfläche ändert Modelle, Themen, Auto-Drive-Standards, Agenten, Benachrichtigungen und mehr, ohne den Chat zu verlassen.

## Öffnen und navigieren

- `/settings` öffnet die Übersicht
- `/settings <section>` springt direkt zu einem Abschnitt
- `/auto settings` und `/update` führen in ihre Abschnitte

### Tastatur

| Taste | Aktion |
| --- | --- |
| `↑/↓` oder `j/k` | Auswahl bewegen |
| `Tab/Shift+Tab` | Abschnitte durchschalten |
| `Home/End` | An die Listenenden springen |
| `Enter` | Öffnen oder aktivieren |
| `Esc` | Abschnitt schließen (zweimal schließt die Fläche) |
| `?` | Inline-Hilfe umschalten |

## Abschnitte

| Abschnitt | Beschreibung |
| --- | --- |
| **Model** | Standard-Chatmodell und Reasoning-Aufwand wählen |
| **Theme** | Thema und Spinner wählen |
| **Updates** | Update-Kanal und Status ansehen |
| **Agents** | Eingebaute und eigene Agenten sehen, an- und ausschalten, nur lesen erzwingen |
| **Prompts** | Gespeicherte Prompt-Schnipsel bearbeiten |
| **Auto Drive** | Schalter für Review, Agenten und QA, Continue-Modus, Modellersatz |
| **Review** | Review-Modell wählen, Auto-Auflösung umschalten |
| **Planning** | Modell und Aufwand für Planungsturns wählen |
| **Validation** | Validierungsgruppen und Werkzeuge umschalten |
| **Limits** | Nur-Lese-Ansicht von Ratenlimits und Kontextnutzung |
| **Chrome** | Optionen für die Browserverbindung |
| **MCP** | MCP-Server an- und ausschalten |
| **Notifications** | Benachrichtigungen schalten und filtern |

## Speicherung

Änderungen schreiben nach `~/.code/config.toml`, wenn die Datei da ist. Der Zugriffsmodus kann je Workspace liegen; alles andere gilt global, sofern ein Projekt es nicht überschreibt.

## Befehle

```bash
/settings [section]
/auto settings
/update
/notifications [on|off|status]
```
