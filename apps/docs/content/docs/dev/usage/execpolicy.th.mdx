## นโยบายการดำเนินการ

Hanzo Dev ใช้นโยบายการดำเนินการเพื่อกำหนดว่าเอเจนต์รันคำสั่งใดได้ และต้องขออนุมัติเมื่อใด

### โหมดแซนด์บ็อกซ์

| โหมด | คำอธิบาย |
| --- | --- |
| `off` | ไม่มีแซนด์บ็อกซ์ (คำสั่งรันตรง) |
| `workspace-read` | เข้าถึงพื้นที่ทำงานแบบอ่านอย่างเดียว |
| `workspace-write` | เข้าถึงพื้นที่ทำงานแบบอ่านและเขียน (ค่าเริ่มต้นของ full-auto) |
| `network-off` | ปิดการเข้าถึงเครือข่าย |

### นโยบายการอนุมัติ

| นโยบาย | คำอธิบาย |
| --- | --- |
| `always` | ขออนุมัติทุกครั้งก่อนดำเนินการ |
| `on-failure` | ขอเฉพาะเมื่อคำสั่งล้มเหลว (ค่าเริ่มต้นของ full-auto) |
| `on-request` | ขอเมื่อโมเดลขออนุมัติอย่างชัดเจน |
| `never` | ไม่ขออนุมัติเลย |

### การใช้งาน

```bash
# Set sandbox mode
dev --sandbox workspace-write "your prompt"

# Set approval policy
dev --ask-for-approval on-failure "your prompt"

# Full auto (sandboxed + auto-approve)
dev --full-auto "your prompt"
```
