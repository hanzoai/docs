Hanzo Dev is a coding agent in your terminal. You can talk to it in an interactive session, run it without a person attached (the way a CI job would), hand work to more than one agent, and keep the commands it runs inside a sandbox. The sandbox matters. An agent that can type is an agent that can type `rm`, and you want that power inside a fence you understand.

The install below gets you to a first question. The links after it are for when the first question worked and you want the controls.

## Quick Start

```bash tab="npm"
npm install -g @hanzo/dev
```

```bash tab="Homebrew"
brew tap hanzoai/tap
brew install hanzo-dev
```

```bash tab="From source"
git clone https://github.com/hanzoai/dev.git
cd dev/codex-rs
cargo build --release
```

Then launch:

```bash
dev "explain this codebase to me"
```
