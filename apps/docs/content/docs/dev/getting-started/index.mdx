## 1. Install

```bash
npm install -g @hanzo/dev
```

See [Install](/docs/dev/getting-started/install) for the supported platforms.

## 2. Sign in

```bash
dev login
```

Choose **Hanzo account (recommended)**. See [Sign in](/docs/dev/getting-started/authentication) for the other choices.

## 3. Run it in a repository

```bash
cd your-repo
dev "explain this codebase to me"
```

The first time you open a directory, Hanzo Dev asks whether you trust its contents. Answer **Yes, continue** to let the project's own configuration, hooks and command rules load; **No, quit** exits.
