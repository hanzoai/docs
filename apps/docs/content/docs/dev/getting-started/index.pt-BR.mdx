O Hanzo Dev é um assistente de programação com IA que roda no seu terminal. Ele oferece sessões interativas de TUI, execução não interativa para CI/CD, orquestração de vários agentes e execução de comandos em sandbox.

## Início rápido

```bash tab="npm"
npm install -g @hanzo/dev
```

```bash tab="Homebrew"
brew tap hanzoai/tap
brew install hanzo-dev
```

```bash tab="From source"
git clone https://github.com/hanzoai/dev.git
cd dev/codex-rs
cargo build --release
```

Depois, inicie:

```bash
dev "explain this codebase to me"
```
