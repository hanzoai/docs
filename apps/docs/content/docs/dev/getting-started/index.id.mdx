Hanzo Dev adalah asisten pemrograman berbasis AI yang berjalan di terminal Anda. Ia menyediakan sesi TUI interaktif, eksekusi non-interaktif untuk CI/CD, orkestrasi banyak agen, dan eksekusi perintah di dalam sandbox.

## Mulai cepat

```bash tab="npm"
npm install -g @hanzo/dev
```

```bash tab="Homebrew"
brew tap hanzoai/tap
brew install hanzo-dev
```

```bash tab="From source"
git clone https://github.com/hanzoai/dev.git
cd dev/codex-rs
cargo build --release
```

Lalu jalankan:

```bash
dev "explain this codebase to me"
```
