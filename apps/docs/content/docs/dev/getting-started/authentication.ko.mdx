## 인증

Hanzo Dev는 여러 인증 방법을 지원합니다.

### API 키

환경 변수로 API 키를 설정합니다.

```bash
export OPENAI_API_KEY="sk-..."
```

또는 대화형으로 로그인합니다.

```bash
dev login
```

### stdin의 API 키로 로그인

```bash
printenv OPENAI_API_KEY | dev login --with-api-key
```

### 상태 확인

```bash
dev login status
```

### 로그아웃

```bash
dev logout
```

### 환경 변수

| 변수 | 설명 |
| --- | --- |
| `OPENAI_API_KEY` | OpenAI API 키 |
| `CODE_HOME` | 구성 디렉터리를 덮어씁니다(기본값: `~/.hanzo`) |
| `CODEX_HOME` | 이전 구성 디렉터리(대체) |
| `CODEX_SECURE_MODE` | `"1"`로 설정하면 보안 강화를 켭니다 |
