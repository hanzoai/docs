## 驗證

Hanzo Dev 支援多種驗證方式。

### API 金鑰

用環境變數設定 API 金鑰：

```bash
export OPENAI_API_KEY="sk-..."
```

或互動式登入：

```bash
dev login
```

### 從 stdin 以 API 金鑰登入

```bash
printenv OPENAI_API_KEY | dev login --with-api-key
```

### 查看狀態

```bash
dev login status
```

### 登出

```bash
dev logout
```

### 環境變數

| 變數 | 說明 |
| --- | --- |
| `OPENAI_API_KEY` | OpenAI API 金鑰 |
| `CODE_HOME` | 覆寫設定目錄（預設：`~/.hanzo`） |
| `CODEX_HOME` | 舊版設定目錄（後援） |
| `CODEX_SECURE_MODE` | 設為 `"1"` 時啟用安全強化 |
