## Autenticación

Hanzo Dev admite varios métodos de autenticación.

### Clave de API

Define tu clave de API con una variable de entorno:

```bash
export OPENAI_API_KEY="sk-..."
```

O inicia sesión de forma interactiva:

```bash
dev login
```

### Iniciar sesión con la clave de API desde stdin

```bash
printenv OPENAI_API_KEY | dev login --with-api-key
```

### Comprobar el estado

```bash
dev login status
```

### Cerrar sesión

```bash
dev logout
```

### Variables de entorno

| Variable | Descripción |
| --- | --- |
| `OPENAI_API_KEY` | Clave de API de OpenAI |
| `CODE_HOME` | Sustituye el directorio de configuración (predeterminado: `~/.hanzo`) |
| `CODEX_HOME` | Directorio de configuración heredado (respaldo) |
| `CODEX_SECURE_MODE` | Activa el endurecimiento de seguridad cuando vale `"1"` |
