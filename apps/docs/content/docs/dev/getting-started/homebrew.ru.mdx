## Homebrew (macOS)

В этом репозитории есть вспомогательный скрипт, который собирает формулу Homebrew из артефактов последнего релиза на GitHub. Публикация в Homebrew требует репозитория tap.

### Установка

```bash
brew tap hanzoai/tap
brew install hanzo-dev
```

### Создание формулы

Если вы ведёте tap, создайте формулу для последней версии:

```bash
scripts/generate-homebrew-formula.sh
```

Скопируйте полученную формулу в репозиторий tap в каталог `Formula/` и при необходимости обновите `url` и `sha256`.

### Заметки

- Формула ожидает артефакты релиза с такими именами:
  - `dev-aarch64-apple-darwin.tar.gz`
  - `dev-x86_64-apple-darwin.tar.gz`
- CLI устанавливается как `dev`, с прослойками совместимости.
