## การยืนยันตัวตน

Hanzo Dev รองรับหลายวิธีในการยืนยันตัวตน

### คีย์ API

ตั้งคีย์ API ผ่านตัวแปรสภาพแวดล้อม:

```bash
export OPENAI_API_KEY="sk-..."
```

หรือเข้าสู่ระบบแบบโต้ตอบ:

```bash
dev login
```

### เข้าสู่ระบบด้วยคีย์ API จาก stdin

```bash
printenv OPENAI_API_KEY | dev login --with-api-key
```

### ตรวจสถานะ

```bash
dev login status
```

### ออกจากระบบ

```bash
dev logout
```

### ตัวแปรสภาพแวดล้อม

| ตัวแปร | คำอธิบาย |
| --- | --- |
| `OPENAI_API_KEY` | คีย์ API ของ OpenAI |
| `CODE_HOME` | เขียนทับไดเรกทอรีการกำหนดค่า (ค่าเริ่มต้น: `~/.hanzo`) |
| `CODEX_HOME` | ไดเรกทอรีการกำหนดค่าแบบเก่า (สำรอง) |
| `CODEX_SECURE_MODE` | เปิดการเพิ่มความปลอดภัยเมื่อตั้งเป็น `"1"` |
