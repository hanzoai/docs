Hanzo Dev es un asistente de programación con IA que se ejecuta en tu terminal. Ofrece sesiones interactivas de TUI, ejecución no interactiva para CI/CD, orquestación de varios agentes y ejecución de comandos en un entorno aislado.

## Inicio rápido

```bash tab="npm"
npm install -g @hanzo/dev
```

```bash tab="Homebrew"
brew tap hanzoai/tap
brew install hanzo-dev
```

```bash tab="From source"
git clone https://github.com/hanzoai/dev.git
cd dev/codex-rs
cargo build --release
```

Después, arranca:

```bash
dev "explain this codebase to me"
```
