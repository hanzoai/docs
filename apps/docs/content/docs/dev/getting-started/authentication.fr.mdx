## Authentification

Hanzo Dev prend en charge plusieurs méthodes d'authentification.

### Clé API

Définissez votre clé API avec une variable d'environnement :

```bash
export OPENAI_API_KEY="sk-..."
```

Ou connectez-vous de façon interactive :

```bash
dev login
```

### Connexion avec une clé API depuis stdin

```bash
printenv OPENAI_API_KEY | dev login --with-api-key
```

### Vérifier l'état

```bash
dev login status
```

### Déconnexion

```bash
dev logout
```

### Variables d'environnement

| Variable | Description |
| --- | --- |
| `OPENAI_API_KEY` | Clé API OpenAI |
| `CODE_HOME` | Remplace le répertoire de configuration (par défaut : `~/.hanzo`) |
| `CODEX_HOME` | Répertoire de configuration hérité (repli) |
| `CODEX_SECURE_MODE` | Active le durcissement de sécurité lorsqu'elle vaut `"1"` |
