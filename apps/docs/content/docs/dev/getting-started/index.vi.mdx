Hanzo Dev là trợ lý lập trình chạy bằng AI trong terminal của bạn. Nó cung cấp phiên TUI tương tác, thực thi không tương tác cho CI/CD, điều phối nhiều tác nhân và thực thi lệnh trong sandbox.

## Khởi động nhanh

```bash tab="npm"
npm install -g @hanzo/dev
```

```bash tab="Homebrew"
brew tap hanzoai/tap
brew install hanzo-dev
```

```bash tab="From source"
git clone https://github.com/hanzoai/dev.git
cd dev/codex-rs
cargo build --release
```

Sau đó khởi chạy:

```bash
dev "explain this codebase to me"
```
