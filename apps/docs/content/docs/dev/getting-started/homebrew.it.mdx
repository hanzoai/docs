## Homebrew (macOS)

Questo repository include uno script di supporto per generare una formula Homebrew dagli artefatti dell'ultima release su GitHub. Pubblicare su Homebrew richiede un repository tap.

### Installare

```bash
brew tap hanzoai/tap
brew install hanzo-dev
```

### Generare la formula

Se gestisci il tap, genera la formula dell'ultima versione:

```bash
scripts/generate-homebrew-formula.sh
```

Copia la formula generata nel repository del tap sotto `Formula/` e aggiorna `url` e `sha256` se serve.

### Note

- La formula si aspetta asset della release con nomi come:
  - `dev-aarch64-apple-darwin.tar.gz`
  - `dev-x86_64-apple-darwin.tar.gz`
- La CLI viene installata come `dev`, con adattatori di compatibilità.
