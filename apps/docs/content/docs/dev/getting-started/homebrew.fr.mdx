## Homebrew (macOS)

Ce dépôt contient un script d'aide qui génère une formule Homebrew à partir des artefacts de la dernière publication GitHub. Publier sur Homebrew exige un dépôt tap.

### Installer

```bash
brew tap hanzoai/tap
brew install hanzo-dev
```

### Générer la formule

Si vous maintenez le tap, générez la formule de la dernière version :

```bash
scripts/generate-homebrew-formula.sh
```

Copiez la formule générée dans votre dépôt tap, sous `Formula/`, et mettez à jour `url` et `sha256` si nécessaire.

### Notes

- La formule attend des artefacts de publication nommés ainsi :
  - `dev-aarch64-apple-darwin.tar.gz`
  - `dev-x86_64-apple-darwin.tar.gz`
- La CLI est installée sous le nom `dev`, avec des adaptateurs de compatibilité.
