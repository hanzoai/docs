## Homebrew (macOS)

Repositori ini menyertakan skrip pembantu untuk membuat formula Homebrew dari artefak rilis GitHub terbaru. Menerbitkan ke Homebrew memerlukan repositori tap.

### Pasang

```bash
brew tap hanzoai/tap
brew install hanzo-dev
```

### Buat formula

Jika Anda memelihara tap, buat formula untuk versi terbaru:

```bash
scripts/generate-homebrew-formula.sh
```

Salin formula yang dihasilkan ke repositori tap Anda di bawah `Formula/`, lalu perbarui `url` dan `sha256` bila perlu.

### Catatan

- Formula mengharapkan aset rilis dengan nama seperti:
  - `dev-aarch64-apple-darwin.tar.gz`
  - `dev-x86_64-apple-darwin.tar.gz`
- CLI dipasang sebagai `dev`, dengan adaptor kompatibilitas.
