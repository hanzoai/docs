## Homebrew（macOS）

本仓库带有一个辅助脚本，可根据最新 GitHub 发布产物生成 Homebrew formula。发布到 Homebrew 需要一个 tap 仓库。

### 安装

```bash
brew tap hanzoai/tap
brew install hanzo-dev
```

### 生成 formula

如果你维护这个 tap，请为最新版本生成 formula：

```bash
scripts/generate-homebrew-formula.sh
```

把生成的 formula 复制到 tap 仓库的 `Formula/` 下，并在需要时更新 `url` 和 `sha256`。

### 说明

- formula 期望的发布资产名称类似：
  - `dev-aarch64-apple-darwin.tar.gz`
  - `dev-x86_64-apple-darwin.tar.gz`
- CLI 以 `dev` 安装，并带有兼容垫片。
