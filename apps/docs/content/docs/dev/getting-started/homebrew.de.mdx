## Homebrew (macOS)

Dieses Repository enthält ein Hilfsskript, das aus den Artefakten des neuesten GitHub-Release eine Homebrew-Formula erzeugt. Die Veröffentlichung über Homebrew setzt ein Tap-Repository voraus.

### Installieren

```bash
brew tap hanzoai/tap
brew install hanzo-dev
```

### Formula erzeugen

Wenn Sie den Tap pflegen, erzeugen Sie die Formula für die neueste Version:

```bash
scripts/generate-homebrew-formula.sh
```

Kopieren Sie die erzeugte Formula in Ihr Tap-Repository unter `Formula/` und aktualisieren Sie bei Bedarf `url` und `sha256`.

### Hinweise

- Die Formula erwartet Release-Assets mit Namen wie:
  - `dev-aarch64-apple-darwin.tar.gz`
  - `dev-x86_64-apple-darwin.tar.gz`
- Die CLI wird als `dev` installiert, mit Kompatibilitätsadaptern.
