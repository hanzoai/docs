## Kimlik doğrulama

Hanzo Dev birden fazla kimlik doğrulama yöntemini destekler.

### API anahtarı

API anahtarınızı bir ortam değişkeniyle ayarlayın:

```bash
export OPENAI_API_KEY="sk-..."
```

Ya da etkileşimli olarak oturum açın:

```bash
dev login
```

### stdin üzerinden API anahtarıyla oturum açma

```bash
printenv OPENAI_API_KEY | dev login --with-api-key
```

### Durumu denetleme

```bash
dev login status
```

### Oturumu kapatma

```bash
dev logout
```

### Ortam değişkenleri

| Değişken | Açıklama |
| --- | --- |
| `OPENAI_API_KEY` | OpenAI API anahtarı |
| `CODE_HOME` | Yapılandırma dizinini geçersiz kılar (varsayılan: `~/.hanzo`) |
| `CODEX_HOME` | Eski yapılandırma dizini (yedek) |
| `CODEX_SECURE_MODE` | `"1"` olarak ayarlandığında güvenlik sıkılaştırmasını açar |
