## प्रमाणीकरण

Hanzo Dev कई प्रमाणीकरण तरीके समर्थित करता है।

### API कुंजी

अपनी API कुंजी पर्यावरण चर से सेट करें:

```bash
export OPENAI_API_KEY="sk-..."
```

या इंटरैक्टिव रूप से लॉग इन करें:

```bash
dev login
```

### stdin से API कुंजी के साथ लॉग इन

```bash
printenv OPENAI_API_KEY | dev login --with-api-key
```

### स्थिति जाँचें

```bash
dev login status
```

### लॉग आउट

```bash
dev logout
```

### पर्यावरण चर

| चर | विवरण |
| --- | --- |
| `OPENAI_API_KEY` | OpenAI API कुंजी |
| `CODE_HOME` | कॉन्फ़िग निर्देशिका बदलें (डिफ़ॉल्ट: `~/.hanzo`) |
| `CODEX_HOME` | पुरानी कॉन्फ़िग निर्देशिका (फ़ॉलबैक) |
| `CODEX_SECURE_MODE` | `"1"` होने पर सुरक्षा कड़ापन चालू करता है |
