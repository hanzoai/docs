## Homebrew（macOS）

このリポジトリには、最新の GitHub リリースの成果物から Homebrew の formula を生成する補助スクリプトがあります。Homebrew へ公開するには tap リポジトリが必要です。

### インストール

```bash
brew tap hanzoai/tap
brew install hanzo-dev
```

### formula の生成

tap を保守している場合は、最新版の formula を生成します。

```bash
scripts/generate-homebrew-formula.sh
```

生成された formula を tap リポジトリの `Formula/` にコピーし、必要なら `url` と `sha256` を更新します。

### メモ

- formula は次のような名前のリリース資産を想定します。
  - `dev-aarch64-apple-darwin.tar.gz`
  - `dev-x86_64-apple-darwin.tar.gz`
- CLI は `dev` として、互換シム付きでインストールされます。
