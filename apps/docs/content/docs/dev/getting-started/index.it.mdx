Hanzo Dev è un assistente di programmazione basato sull'IA che gira nel terminale. Offre sessioni TUI interattive, esecuzione non interattiva per CI/CD, orchestrazione di più agenti ed esecuzione dei comandi in una sandbox.

## Avvio rapido

```bash tab="npm"
npm install -g @hanzo/dev
```

```bash tab="Homebrew"
brew tap hanzoai/tap
brew install hanzo-dev
```

```bash tab="From source"
git clone https://github.com/hanzoai/dev.git
cd dev/codex-rs
cargo build --release
```

Poi avvia:

```bash
dev "explain this codebase to me"
```
