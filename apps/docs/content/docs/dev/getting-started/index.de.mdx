Hanzo Dev ist ein KI-gestützter Programmierassistent, der in Ihrem Terminal läuft. Er bietet interaktive TUI-Sitzungen, nicht interaktive Ausführung für CI/CD, Orchestrierung mehrerer Agenten und die Ausführung von Befehlen in einer Sandbox.

## Schnellstart

```bash tab="npm"
npm install -g @hanzo/dev
```

```bash tab="Homebrew"
brew tap hanzoai/tap
brew install hanzo-dev
```

```bash tab="From source"
git clone https://github.com/hanzoai/dev.git
cd dev/codex-rs
cargo build --release
```

Starten Sie anschließend:

```bash
dev "explain this codebase to me"
```
