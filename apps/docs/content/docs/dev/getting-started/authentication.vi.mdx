## Xác thực

Hanzo Dev hỗ trợ nhiều cách xác thực.

### Khóa API

Đặt khóa API bằng biến môi trường:

```bash
export OPENAI_API_KEY="sk-..."
```

Hoặc đăng nhập tương tác:

```bash
dev login
```

### Đăng nhập bằng khóa API từ stdin

```bash
printenv OPENAI_API_KEY | dev login --with-api-key
```

### Kiểm tra trạng thái

```bash
dev login status
```

### Đăng xuất

```bash
dev logout
```

### Biến môi trường

| Biến | Mô tả |
| --- | --- |
| `OPENAI_API_KEY` | Khóa API của OpenAI |
| `CODE_HOME` | Ghi đè thư mục cấu hình (mặc định: `~/.hanzo`) |
| `CODEX_HOME` | Thư mục cấu hình cũ (dự phòng) |
| `CODEX_SECURE_MODE` | Bật tăng cường bảo mật khi đặt thành `"1"` |
