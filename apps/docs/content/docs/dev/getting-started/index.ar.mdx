Hanzo Dev مساعد برمجة مدعوم بالذكاء الاصطناعي يعمل في الطرفية. يوفّر جلسات TUI تفاعلية، وتنفيذًا غير تفاعلي لـ CI/CD، وتنسيق عدة وكلاء، وتنفيذ الأوامر داخل صندوق عزل.

## بداية سريعة

```bash tab="npm"
npm install -g @hanzo/dev
```

```bash tab="Homebrew"
brew tap hanzoai/tap
brew install hanzo-dev
```

```bash tab="From source"
git clone https://github.com/hanzoai/dev.git
cd dev/codex-rs
cargo build --release
```

ثم شغّل:

```bash
dev "explain this codebase to me"
```
