Hanzo Dev — это ИИ-ассистент для программирования, который работает в терминале. Он даёт интерактивные сессии TUI, неинтерактивный запуск для CI/CD, оркестрацию нескольких агентов и выполнение команд в песочнице.

## Быстрый старт

```bash tab="npm"
npm install -g @hanzo/dev
```

```bash tab="Homebrew"
brew tap hanzoai/tap
brew install hanzo-dev
```

```bash tab="From source"
git clone https://github.com/hanzoai/dev.git
cd dev/codex-rs
cargo build --release
```

Затем запустите:

```bash
dev "explain this codebase to me"
```
