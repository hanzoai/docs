## المصادقة

يدعم Hanzo Dev عدة طرق للمصادقة.

### مفتاح API

اضبط مفتاح API عبر متغير بيئة:

```bash
export OPENAI_API_KEY="sk-..."
```

أو سجّل الدخول بشكل تفاعلي:

```bash
dev login
```

### تسجيل الدخول بمفتاح API من stdin

```bash
printenv OPENAI_API_KEY | dev login --with-api-key
```

### التحقق من الحالة

```bash
dev login status
```

### تسجيل الخروج

```bash
dev logout
```

### متغيرات البيئة

| المتغير | الوصف |
| --- | --- |
| `OPENAI_API_KEY` | مفتاح API لـ OpenAI |
| `CODE_HOME` | يستبدل دليل الضبط (الافتراضي: `~/.hanzo`) |
| `CODEX_HOME` | دليل الضبط القديم (احتياطي) |
| `CODEX_SECURE_MODE` | يفعّل تقوية الأمان عند ضبطه على `"1"` |
