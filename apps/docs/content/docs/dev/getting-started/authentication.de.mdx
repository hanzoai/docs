## Authentifizierung

Hanzo Dev unterstützt mehrere Authentifizierungsverfahren.

### API-Schlüssel

Legen Sie Ihren API-Schlüssel über eine Umgebungsvariable fest:

```bash
export OPENAI_API_KEY="sk-..."
```

Oder melden Sie sich interaktiv an:

```bash
dev login
```

### Anmeldung mit API-Schlüssel über stdin

```bash
printenv OPENAI_API_KEY | dev login --with-api-key
```

### Status prüfen

```bash
dev login status
```

### Abmelden

```bash
dev logout
```

### Umgebungsvariablen

| Variable | Beschreibung |
| --- | --- |
| `OPENAI_API_KEY` | OpenAI-API-Schlüssel |
| `CODE_HOME` | Konfigurationsverzeichnis überschreiben (Standard: `~/.hanzo`) |
| `CODEX_HOME` | Älteres Konfigurationsverzeichnis (Ausweichwert) |
| `CODEX_SECURE_MODE` | Aktiviert die Sicherheitshärtung, wenn der Wert `"1"` ist |
