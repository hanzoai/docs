Hanzo Dev, terminalinizde çalışan yapay zekâ destekli bir kodlama asistanıdır. Etkileşimli TUI oturumları, CI/CD için etkileşimsiz çalıştırma, çoklu ajan orkestrasyonu ve korumalı alanda komut yürütme sunar.

## Hızlı başlangıç

```bash tab="npm"
npm install -g @hanzo/dev
```

```bash tab="Homebrew"
brew tap hanzoai/tap
brew install hanzo-dev
```

```bash tab="From source"
git clone https://github.com/hanzoai/dev.git
cd dev/codex-rs
cargo build --release
```

Ardından başlatın:

```bash
dev "explain this codebase to me"
```
