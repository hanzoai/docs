## Autenticação

O Hanzo Dev aceita vários métodos de autenticação.

### Chave de API

Defina sua chave de API por variável de ambiente:

```bash
export OPENAI_API_KEY="sk-..."
```

Ou entre de forma interativa:

```bash
dev login
```

### Entrar com a chave de API a partir do stdin

```bash
printenv OPENAI_API_KEY | dev login --with-api-key
```

### Verificar o status

```bash
dev login status
```

### Sair

```bash
dev logout
```

### Variáveis de ambiente

| Variável | Descrição |
| --- | --- |
| `OPENAI_API_KEY` | Chave de API da OpenAI |
| `CODE_HOME` | Substitui o diretório de configuração (padrão: `~/.hanzo`) |
| `CODEX_HOME` | Diretório de configuração legado (reserva) |
| `CODEX_SECURE_MODE` | Ativa o reforço de segurança quando definido como `"1"` |
