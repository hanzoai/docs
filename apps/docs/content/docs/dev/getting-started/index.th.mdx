Hanzo Dev คือผู้ช่วยเขียนโค้ดที่ขับเคลื่อนด้วย AI และทำงานในเทอร์มินัลของคุณ มีเซสชัน TUI แบบโต้ตอบ การทำงานแบบไม่โต้ตอบสำหรับ CI/CD การประสานงานหลายเอเจนต์ และการรันคำสั่งในแซนด์บ็อกซ์

## เริ่มอย่างรวดเร็ว

```bash tab="npm"
npm install -g @hanzo/dev
```

```bash tab="Homebrew"
brew tap hanzoai/tap
brew install hanzo-dev
```

```bash tab="From source"
git clone https://github.com/hanzoai/dev.git
cd dev/codex-rs
cargo build --release
```

จากนั้นเปิดใช้งาน:

```bash
dev "explain this codebase to me"
```
