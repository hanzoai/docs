## Homebrew (macOS)

इस रिपॉज़िटरी में नवीनतम GitHub रिलीज़ की कलाकृतियों से Homebrew फ़ॉर्मूला बनाने की एक सहायक स्क्रिप्ट है। Homebrew पर प्रकाशित करने के लिए एक tap रिपॉज़िटरी चाहिए।

### इंस्टॉल करें

```bash
brew tap hanzoai/tap
brew install hanzo-dev
```

### फ़ॉर्मूला बनाएँ

यदि आप tap का रखरखाव करते हैं, तो नवीनतम संस्करण का फ़ॉर्मूला बनाएँ:

```bash
scripts/generate-homebrew-formula.sh
```

बनाया गया फ़ॉर्मूला अपनी tap रिपॉज़िटरी में `Formula/` के नीचे कॉपी करें और ज़रूरत हो तो `url` तथा `sha256` अपडेट करें।

### नोट

- फ़ॉर्मूला ऐसी नाम वाली रिलीज़ संपत्तियाँ चाहता है:
  - `dev-aarch64-apple-darwin.tar.gz`
  - `dev-x86_64-apple-darwin.tar.gz`
- CLI `dev` के रूप में, संगतता एडाप्टर के साथ इंस्टॉल होती है।
