## Homebrew(macOS)

이 저장소에는 최신 GitHub 릴리스 산출물로 Homebrew formula를 만드는 도우미 스크립트가 있습니다. Homebrew에 게시하려면 tap 저장소가 필요합니다.

### 설치

```bash
brew tap hanzoai/tap
brew install hanzo-dev
```

### formula 생성

tap을 유지한다면 최신 버전의 formula를 생성하세요.

```bash
scripts/generate-homebrew-formula.sh
```

생성된 formula를 tap 저장소의 `Formula/` 아래에 복사하고, 필요하면 `url`과 `sha256`을 갱신하세요.

### 참고

- formula는 다음과 같은 이름의 릴리스 자산을 기대합니다.
  - `dev-aarch64-apple-darwin.tar.gz`
  - `dev-x86_64-apple-darwin.tar.gz`
- CLI는 호환 심과 함께 `dev`로 설치됩니다.
