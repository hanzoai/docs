## 認証

Hanzo Dev は複数の認証方法に対応しています。

### API キー

環境変数で API キーを設定します。

```bash
export OPENAI_API_KEY="sk-..."
```

または対話的にログインします。

```bash
dev login
```

### stdin から API キーでログイン

```bash
printenv OPENAI_API_KEY | dev login --with-api-key
```

### 状態の確認

```bash
dev login status
```

### ログアウト

```bash
dev logout
```

### 環境変数

| 変数 | 説明 |
| --- | --- |
| `OPENAI_API_KEY` | OpenAI の API キー |
| `CODE_HOME` | 設定ディレクトリを上書きする（既定: `~/.hanzo`） |
| `CODEX_HOME` | 旧来の設定ディレクトリ（代替） |
| `CODEX_SECURE_MODE` | `"1"` のときセキュリティ強化を有効にする |
