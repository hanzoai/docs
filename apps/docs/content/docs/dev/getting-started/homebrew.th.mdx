## Homebrew (macOS)

ที่เก็บนี้มีสคริปต์ตัวช่วยสำหรับสร้างสูตร Homebrew จากสิ่งประดิษฐ์ของรีลีส GitHub ล่าสุด การเผยแพร่ไปยัง Homebrew ต้องมีที่เก็บ tap

### ติดตั้ง

```bash
brew tap hanzoai/tap
brew install hanzo-dev
```

### สร้างสูตร

ถ้าคุณดูแล tap ให้สร้างสูตรของรุ่นล่าสุด:

```bash
scripts/generate-homebrew-formula.sh
```

คัดลอกสูตรที่สร้างไว้ไปยังที่เก็บ tap ใต้ `Formula/` แล้วอัปเดต `url` และ `sha256` หากจำเป็น

### หมายเหตุ

- สูตรคาดหวังไฟล์ของรีลีสที่มีชื่อเช่น:
  - `dev-aarch64-apple-darwin.tar.gz`
  - `dev-x86_64-apple-darwin.tar.gz`
- CLI ถูกติดตั้งในชื่อ `dev` พร้อมตัวปรับความเข้ากันได้
