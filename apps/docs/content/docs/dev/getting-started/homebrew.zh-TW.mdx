## Homebrew（macOS）

這個存放庫附有輔助腳本，可從最新的 GitHub 發行產物產生 Homebrew formula。發佈到 Homebrew 需要一個 tap 存放庫。

### 安裝

```bash
brew tap hanzoai/tap
brew install hanzo-dev
```

### 產生 formula

如果你維護這個 tap，請為最新版本產生 formula：

```bash
scripts/generate-homebrew-formula.sh
```

把產生的 formula 複製到 tap 存放庫的 `Formula/` 下，並在需要時更新 `url` 與 `sha256`。

### 說明

- formula 預期的發行資產名稱類似：
  - `dev-aarch64-apple-darwin.tar.gz`
  - `dev-x86_64-apple-darwin.tar.gz`
- CLI 以 `dev` 安裝，並附有相容墊片。
