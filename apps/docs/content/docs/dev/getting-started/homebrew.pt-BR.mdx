## Homebrew (macOS)

Este repositório inclui um script auxiliar para gerar uma fórmula do Homebrew a partir dos artefatos da release mais recente no GitHub. Publicar no Homebrew exige um repositório tap.

### Instalar

```bash
brew tap hanzoai/tap
brew install hanzo-dev
```

### Gerar a fórmula

Se você mantém o tap, gere a fórmula da versão mais recente:

```bash
scripts/generate-homebrew-formula.sh
```

Copie a fórmula gerada para o repositório do tap, em `Formula/`, e atualize `url` e `sha256` se precisar.

### Observações

- A fórmula espera artefatos da release com nomes como:
  - `dev-aarch64-apple-darwin.tar.gz`
  - `dev-x86_64-apple-darwin.tar.gz`
- A CLI é instalada como `dev`, com adaptadores de compatibilidade.
