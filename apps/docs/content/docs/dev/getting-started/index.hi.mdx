Hanzo Dev एक एआई-संचालित कोडिंग सहायक है जो आपके टर्मिनल में चलता है। यह इंटरैक्टिव TUI सत्र, CI/CD के लिए गैर-इंटरैक्टिव निष्पादन, कई एजेंटों का ऑर्केस्ट्रेशन और सैंडबॉक्स में कमांड निष्पादन देता है।

## त्वरित शुरुआत

```bash tab="npm"
npm install -g @hanzo/dev
```

```bash tab="Homebrew"
brew tap hanzoai/tap
brew install hanzo-dev
```

```bash tab="From source"
git clone https://github.com/hanzoai/dev.git
cd dev/codex-rs
cargo build --release
```

फिर चलाएँ:

```bash
dev "explain this codebase to me"
```
