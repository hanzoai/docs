## 身份验证

Hanzo Dev 支持多种身份验证方式。

### API 密钥

通过环境变量设置 API 密钥：

```bash
export OPENAI_API_KEY="sk-..."
```

或交互式登录：

```bash
dev login
```

### 从 stdin 用 API 密钥登录

```bash
printenv OPENAI_API_KEY | dev login --with-api-key
```

### 查看状态

```bash
dev login status
```

### 退出登录

```bash
dev logout
```

### 环境变量

| 变量 | 说明 |
| --- | --- |
| `OPENAI_API_KEY` | OpenAI API 密钥 |
| `CODE_HOME` | 覆盖配置目录（默认：`~/.hanzo`） |
| `CODEX_HOME` | 旧版配置目录（回退） |
| `CODEX_SECURE_MODE` | 设为 `"1"` 时启用安全加固 |
