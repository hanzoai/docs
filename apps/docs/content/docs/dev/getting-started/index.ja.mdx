Hanzo Dev はターミナルで動く AI コーディングアシスタントです。対話型の TUI セッション、CI/CD 向けの非対話実行、複数エージェントのオーケストレーション、サンドボックスでのコマンド実行を備えています。

## クイックスタート

```bash tab="npm"
npm install -g @hanzo/dev
```

```bash tab="Homebrew"
brew tap hanzoai/tap
brew install hanzo-dev
```

```bash tab="From source"
git clone https://github.com/hanzoai/dev.git
cd dev/codex-rs
cargo build --release
```

起動します。

```bash
dev "explain this codebase to me"
```
