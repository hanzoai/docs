## Homebrew (macOS)

Bu depo, en son GitHub sürümünün yapıtlarından bir Homebrew formülü üretmek için bir yardımcı betik içerir. Homebrew'da yayımlamak bir tap deposu gerektirir.

### Kurulum

```bash
brew tap hanzoai/tap
brew install hanzo-dev
```

### Formül oluşturma

Tap'i siz bakıyorsanız, en son sürüm için formülü oluşturun:

```bash
scripts/generate-homebrew-formula.sh
```

Oluşan formülü tap deponuzda `Formula/` altına kopyalayın ve gerekirse `url` ile `sha256` değerlerini güncelleyin.

### Notlar

- Formül, şu adlara benzer sürüm varlıkları bekler:
  - `dev-aarch64-apple-darwin.tar.gz`
  - `dev-x86_64-apple-darwin.tar.gz`
- CLI, `dev` olarak ve uyumluluk adaptörleriyle kurulur.
