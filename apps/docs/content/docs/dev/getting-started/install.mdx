---
title: Install
description: Install Hanzo Dev from npm.
---

```bash
npm install -g @hanzo/dev
```

This installs the `dev` command. It needs Node.js 16 or later.

The package carries a prebuilt native binary for each supported platform:

| OS | Architectures |
| --- | --- |
| macOS | Apple silicon (arm64), Intel (x64) |
| Linux | x64, arm64 |
| Windows | x64 |

## Install the Hanzo toolset

A new configuration attaches the Hanzo MCP toolset to every session by running the `hanzo-mcp` command. Install it so that command is on your `PATH`:

```bash
npm install -g @hanzo/mcp
```

See [MCP servers and plugins](/docs/dev/usage/mcp).

## Check the install

```bash
dev --version
dev doctor
```

`dev doctor` reports on the installation, configuration, sign-in, terminal, sandbox and network, and suggests a fix for anything that fails. It changes nothing.

## Update

Run the install command again:

```bash
npm install -g @hanzo/dev
```
