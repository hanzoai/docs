## Homebrew ‏(macOS)

يتضمن هذا المستودع برنامجًا مساعدًا لتوليد صيغة Homebrew من مصنوعات أحدث إصدار على GitHub. النشر إلى Homebrew يتطلب مستودع tap.

### التثبيت

```bash
brew tap hanzoai/tap
brew install hanzo-dev
```

### توليد الصيغة

إذا كنت تصون الـ tap، ولّد صيغة أحدث إصدار:

```bash
scripts/generate-homebrew-formula.sh
```

انسخ الصيغة المولَّدة إلى مستودع الـ tap ضمن `Formula/` وحدّث `url` و`sha256` عند الحاجة.

### ملاحظات

- تتوقع الصيغة أصول إصدار بأسماء مثل:
  - `dev-aarch64-apple-darwin.tar.gz`
  - `dev-x86_64-apple-darwin.tar.gz`
- تُثبَّت CLI باسم `dev` مع محوّلات توافق.
