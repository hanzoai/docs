Hanzo Dev는 터미널에서 동작하는 AI 코딩 도우미입니다. 대화형 TUI 세션, CI/CD용 비대화형 실행, 여러 에이전트의 오케스트레이션, 샌드박스에서의 명령 실행을 제공합니다.

## 빠른 시작

```bash tab="npm"
npm install -g @hanzo/dev
```

```bash tab="Homebrew"
brew tap hanzoai/tap
brew install hanzo-dev
```

```bash tab="From source"
git clone https://github.com/hanzoai/dev.git
cd dev/codex-rs
cargo build --release
```

그런 다음 실행합니다.

```bash
dev "explain this codebase to me"
```
