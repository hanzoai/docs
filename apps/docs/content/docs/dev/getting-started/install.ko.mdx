## 시스템 요구 사항

| 요구 사항 | 세부 내용 |
| --- | --- |
| 운영 체제 | macOS 12+, Ubuntu 20.04+/Debian 10+ 또는 Windows 11(**WSL2를 통해**) |
| Git(선택, 권장) | 기본 제공 PR 도우미를 위해 2.23 이상 |
| RAM | 최소 4 GB(8 GB 권장) |

## npm으로 설치

```bash
npm install -g @hanzo/dev
```

## npx로 설치

```bash
npx @hanzo/dev
```

## DotSlash

GitHub 릴리스에는 Hanzo Dev용 [DotSlash](https://dotslash-cli.com/) 파일 `dev`도 들어 있습니다. DotSlash 파일을 쓰면 소스 제어에 가벼운 커밋만으로, 플랫폼과 관계없이 모든 기여자가 같은 실행 파일 버전을 쓰게 할 수 있습니다.

## 소스에서 빌드

```bash
# Clone the repository
git clone https://github.com/hanzoai/dev.git
cd dev

# Install the Rust toolchain if necessary
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
source "$HOME/.cargo/env"

# Build (~20 min cold, ~2 min incremental)
./build-fast.sh

# Launch the TUI
./hanzo-dev/target/dev-fast/dev
```

## 추적과 상세 로깅

Hanzo Dev는 Rust로 작성되어 있으며 환경 변수 `RUST_LOG`를 따릅니다.

TUI의 기본값은 `RUST_LOG=hanzo_core=info,hanzo_tui=info`이며 로그를 `~/.hanzo/log/codex-tui.log`에 씁니다. 한 번의 실행에서만 로그 디렉터리를 바꾸려면 `-c log_dir=...`를 사용하세요.

```bash
tail -F ~/.hanzo/log/codex-tui.log
```

비대화형 모드(`dev exec`)의 기본값은 `RUST_LOG=error`이며 출력은 인라인으로 나옵니다.

모든 구성 옵션은 Rust의 [`RUST_LOG` 문서](https://docs.rs/env_logger/latest/env_logger/#enabling-logging)를 보세요.
