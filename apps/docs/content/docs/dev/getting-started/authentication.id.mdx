## Autentikasi

Hanzo Dev mendukung beberapa metode autentikasi.

### Kunci API

Atur kunci API lewat variabel lingkungan:

```bash
export OPENAI_API_KEY="sk-..."
```

Atau masuk secara interaktif:

```bash
dev login
```

### Masuk dengan kunci API dari stdin

```bash
printenv OPENAI_API_KEY | dev login --with-api-key
```

### Periksa status

```bash
dev login status
```

### Keluar

```bash
dev logout
```

### Variabel lingkungan

| Variabel | Deskripsi |
| --- | --- |
| `OPENAI_API_KEY` | Kunci API OpenAI |
| `CODE_HOME` | Mengganti direktori konfigurasi (bawaan: `~/.hanzo`) |
| `CODEX_HOME` | Direktori konfigurasi lama (cadangan) |
| `CODEX_SECURE_MODE` | Mengaktifkan penguatan keamanan bila disetel ke `"1"` |
