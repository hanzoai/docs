## Autenticazione

Hanzo Dev supporta diversi metodi di autenticazione.

### Chiave API

Imposta la chiave API con una variabile d'ambiente:

```bash
export OPENAI_API_KEY="sk-..."
```

Oppure accedi in modo interattivo:

```bash
dev login
```

### Accesso con chiave API da stdin

```bash
printenv OPENAI_API_KEY | dev login --with-api-key
```

### Controllare lo stato

```bash
dev login status
```

### Disconnessione

```bash
dev logout
```

### Variabili d'ambiente

| Variabile | Descrizione |
| --- | --- |
| `OPENAI_API_KEY` | Chiave API di OpenAI |
| `CODE_HOME` | Sostituisce la directory di configurazione (predefinita: `~/.hanzo`) |
| `CODEX_HOME` | Directory di configurazione legacy (ripiego) |
| `CODEX_SECURE_MODE` | Abilita l'irrigidimento della sicurezza quando vale `"1"` |
