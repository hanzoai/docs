## Homebrew (macOS)

Kho này có một script trợ giúp để tạo công thức Homebrew từ các tạo phẩm của bản phát hành GitHub mới nhất. Đăng lên Homebrew cần một kho tap.

### Cài đặt

```bash
brew tap hanzoai/tap
brew install hanzo-dev
```

### Tạo công thức

Nếu bạn duy trì tap, hãy tạo công thức cho phiên bản mới nhất:

```bash
scripts/generate-homebrew-formula.sh
```

Sao chép công thức đã tạo vào kho tap, trong `Formula/`, và cập nhật `url` cùng `sha256` nếu cần.

### Ghi chú

- Công thức chờ các tạo phẩm phát hành có tên như:
  - `dev-aarch64-apple-darwin.tar.gz`
  - `dev-x86_64-apple-darwin.tar.gz`
- CLI được cài với tên `dev`, kèm bộ thích ứng tương thích.
