## Аутентификация

Hanzo Dev поддерживает несколько способов аутентификации.

### Ключ API

Задайте ключ API через переменную окружения:

```bash
export OPENAI_API_KEY="sk-..."
```

Или войдите интерактивно:

```bash
dev login
```

### Вход с ключом API из stdin

```bash
printenv OPENAI_API_KEY | dev login --with-api-key
```

### Проверить состояние

```bash
dev login status
```

### Выход

```bash
dev logout
```

### Переменные окружения

| Переменная | Описание |
| --- | --- |
| `OPENAI_API_KEY` | Ключ API OpenAI |
| `CODE_HOME` | Переопределяет каталог конфигурации (по умолчанию: `~/.hanzo`) |
| `CODEX_HOME` | Устаревший каталог конфигурации (запасной вариант) |
| `CODEX_SECURE_MODE` | Включает усиление защиты, если значение равно `"1"` |
