Hanzo Dev est un assistant de programmation piloté par l'IA qui s'exécute dans votre terminal. Il propose des sessions TUI interactives, une exécution non interactive pour le CI/CD, une orchestration multi-agents et l'exécution de commandes dans un bac à sable.

## Démarrage rapide

```bash tab="npm"
npm install -g @hanzo/dev
```

```bash tab="Homebrew"
brew tap hanzoai/tap
brew install hanzo-dev
```

```bash tab="From source"
git clone https://github.com/hanzoai/dev.git
cd dev/codex-rs
cargo build --release
```

Lancez ensuite :

```bash
dev "explain this codebase to me"
```
