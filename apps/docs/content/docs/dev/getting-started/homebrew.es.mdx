## Homebrew (macOS)

Este repositorio incluye un script auxiliar para generar una fórmula de Homebrew a partir de los artefactos de la última publicación en GitHub. Publicar en Homebrew exige un repositorio tap.

### Instalar

```bash
brew tap hanzoai/tap
brew install hanzo-dev
```

### Generar la fórmula

Si mantienes el tap, genera la fórmula de la última versión:

```bash
scripts/generate-homebrew-formula.sh
```

Copia la fórmula generada en tu repositorio tap, dentro de `Formula/`, y actualiza `url` y `sha256` si hace falta.

### Notas

- La fórmula espera activos de la publicación con nombres como:
  - `dev-aarch64-apple-darwin.tar.gz`
  - `dev-x86_64-apple-darwin.tar.gz`
- La CLI se instala como `dev`, con adaptadores de compatibilidad.
