## कौन से मॉडल समर्थित हैं?

हम GPT-5.2 को लपेटने वाले अंतर्निहित प्रीसेट सुझाते हैं (जैसे `code-gpt-5.2-codex`). डिफ़ॉल्ट तर्क स्तर medium है — जटिल काम के लिए `/model` से high करें.

API प्रमाणीकरण और `--model` फ़्लैग से अन्य मॉडल भी चल सकते हैं.

## Hanzo Dev को मेरी फ़ाइलें बदलने से कैसे रोकूँ?

डिफ़ॉल्ट रूप से Hanzo Dev वर्तमान कार्य निर्देशिका की फ़ाइलें बदल सकता है (Auto मोड). बदलाव रोकने के लिए केवल-पढ़ने के मोड में चलाएँ:

```bash
dev --sandbox read-only
```

या बातचीत के बीच `/approvals` से अनुमोदन स्तर बदलें.

## क्या यह Windows पर चलता है?

सीधे Windows पर चलना संभव हो सकता है, पर आधिकारिक समर्थन नहीं है. हम [Windows Subsystem for Linux (WSL2)](https://learn.microsoft.com/en-us/windows/wsl/install) सुझाते हैं.

## Windows पर Hanzo Dev मेरे एजेंट क्यों नहीं ढूँढता?

Windows पर एजेंट खोज PATH और फ़ाइल एक्सटेंशन से प्रभावित हो सकती है. उपाय:

### पूर्ण पथ इस्तेमाल करें (सुझाव)

```toml
[[agents]]
name = "claude"
command = "C:\\Users\\YourUser\\AppData\\Roaming\\npm\\claude.cmd"
enabled = true
```

### npm की वैश्विक स्थापना का स्थान खोजें

```cmd
npm config get prefix
```

### जाँचें कि PATH में npm निर्देशिका है

```powershell
$env:PATH -split ';' | Select-String "npm"
```

### फ़ाइल एक्सटेंशन जाँचें

Windows पर Hanzo Dev `.exe`, `.cmd`, `.bat` और `.com` एक्सटेंशन वाली निष्पादन फ़ाइलें खोजता है. पूर्ण पथ में सही एक्सटेंशन लिखें.

## OpenAI Codex से क्या संबंध है?

Hanzo Dev Rust में लिखा एजेंटिक विकास CLI है: बहु-एजेंट समन्वय, MCP क्लाइंट और सर्वर, सैंडबॉक्स निष्पादन नीति, और Hanzo AI अवसंरचना से सीधा जुड़ाव. नाम का OpenAI के 2021 के Codex मॉडल से कोई संबंध नहीं, जिसे मार्च 2023 में हटा दिया गया.
