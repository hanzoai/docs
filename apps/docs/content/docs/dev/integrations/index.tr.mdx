Hanzo Dev, düzenleyiciler ve geliştirici araçlarıyla Ajan İletişim Protokolü (ACP) ve MCP üzerinden bütünleşir.

## Kullanılabilir bütünleştirmeler

- [Zed düzenleyicisi](/docs/dev/integrations/zed) — Zed düzenleyicisi için ACP bütünleştirmesi
- [GitHub Copilot](/docs/dev/integrations/copilot) — CLI tabanlı Copilot özellikleri

## MCP sunucusu

Hanzo Dev, MCP ile uyumlu herhangi bir istemciyle kullanılmak üzere MCP sunucusu olarak da çalışabilir:

```bash
dev mcp
```
