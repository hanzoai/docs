Hanzo Dev संपादकों और डेवलपर औज़ारों से एजेंट संचार प्रोटोकॉल (ACP) और MCP के माध्यम से जुड़ता है।

## उपलब्ध एकीकरण

- [Zed संपादक](/docs/dev/integrations/zed) — Zed संपादक के लिए ACP एकीकरण
- [GitHub Copilot](/docs/dev/integrations/copilot) — CLI पर आधारित Copilot सुविधाएँ

## MCP सर्वर

Hanzo Dev किसी भी MCP-संगत क्लाइंट के साथ उपयोग के लिए MCP सर्वर के रूप में भी चल सकता है:

```bash
dev mcp
```
