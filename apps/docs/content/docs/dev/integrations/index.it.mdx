Hanzo Dev si integra con editor e strumenti di sviluppo tramite il protocollo di comunicazione degli agenti (ACP) e tramite MCP.

## Integrazioni disponibili

- [Editor Zed](/docs/dev/integrations/zed) — Integrazione ACP per l'editor Zed
- [GitHub Copilot](/docs/dev/integrations/copilot) — Funzioni Copilot basate sulla CLI

## Server MCP

Hanzo Dev può anche girare come server MCP, con qualsiasi client compatibile con MCP:

```bash
dev mcp
```
