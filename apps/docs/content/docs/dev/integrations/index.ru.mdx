Hanzo Dev связывается с редакторами и инструментами разработчика через протокол связи агентов (ACP) и через MCP.

## Доступные интеграции

- [Редактор Zed](/docs/dev/integrations/zed) — Интеграция ACP для редактора Zed
- [GitHub Copilot](/docs/dev/integrations/copilot) — Возможности Copilot на основе CLI

## Сервер MCP

Hanzo Dev может также работать как сервер MCP для любого совместимого с MCP клиента:

```bash
dev mcp
```
