Hanzo Dev terintegrasi dengan editor dan alat pengembang melalui Protokol Komunikasi Agen (ACP) dan MCP.

## Integrasi yang tersedia

- [Editor Zed](/docs/dev/integrations/zed) — Integrasi ACP untuk editor Zed
- [GitHub Copilot](/docs/dev/integrations/copilot) — Fitur Copilot berbasis CLI

## Server MCP

Hanzo Dev juga dapat berjalan sebagai server MCP untuk klien apa pun yang kompatibel dengan MCP:

```bash
dev mcp
```
