Hanzo Dev s'intègre aux éditeurs et aux outils de développement par le protocole de communication des agents (ACP) et par MCP.

## Intégrations disponibles

- [Éditeur Zed](/docs/dev/integrations/zed) — Intégration ACP pour l'éditeur Zed
- [GitHub Copilot](/docs/dev/integrations/copilot) — Fonctions Copilot fondées sur la CLI

## Serveur MCP

Hanzo Dev peut aussi tourner comme serveur MCP, pour tout client compatible MCP :

```bash
dev mcp
```
