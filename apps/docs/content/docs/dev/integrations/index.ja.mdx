Hanzo Dev は、エージェント通信プロトコル（ACP）と MCP を通じてエディタや開発ツールと連携します。

## 利用できる連携

- [Zed エディタ](/docs/dev/integrations/zed) — Zed エディタ向けの ACP 連携
- [GitHub Copilot](/docs/dev/integrations/copilot) — CLI ベースの Copilot 機能

## MCP サーバー

Hanzo Dev は MCP サーバーとしても動き、MCP に対応した任意のクライアントから使えます。

```bash
dev mcp
```
