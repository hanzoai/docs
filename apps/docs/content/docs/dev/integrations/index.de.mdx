Hanzo Dev verbindet sich mit Editoren und Entwicklerwerkzeugen über das Agentenkommunikationsprotokoll (ACP) und über MCP.

## Verfügbare Integrationen

- [Editor Zed](/docs/dev/integrations/zed) — ACP-Integration für den Editor Zed
- [GitHub Copilot](/docs/dev/integrations/copilot) — CLI-gestützte Copilot-Funktionen

## MCP-Server

Hanzo Dev kann auch als MCP-Server laufen, für jeden MCP-kompatiblen Client:

```bash
dev mcp
```
