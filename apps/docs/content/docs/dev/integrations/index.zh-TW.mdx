Hanzo Dev 透過代理通訊協定（ACP）和 MCP 與編輯器及開發工具整合。

## 可用整合

- [Zed 編輯器](/docs/dev/integrations/zed) — 面向 Zed 編輯器的 ACP 整合
- [GitHub Copilot](/docs/dev/integrations/copilot) — 以 CLI 為基礎的 Copilot 功能

## MCP 伺服器

Hanzo Dev 也可以作為 MCP 伺服器執行，供任何相容 MCP 的用戶端使用：

```bash
dev mcp
```
