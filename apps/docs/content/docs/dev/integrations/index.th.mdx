Hanzo Dev ผสานกับเอดิเตอร์และเครื่องมือนักพัฒนาผ่านโปรโตคอลสื่อสารเอเจนต์ (ACP) และ MCP

## การผสานรวมที่มี

- [เอดิเตอร์ Zed](/docs/dev/integrations/zed) — การผสาน ACP สำหรับเอดิเตอร์ Zed
- [GitHub Copilot](/docs/dev/integrations/copilot) — ความสามารถ Copilot ที่อาศัย CLI

## เซิร์ฟเวอร์ MCP

Hanzo Dev ยังรันเป็นเซิร์ฟเวอร์ MCP ได้ สำหรับไคลเอนต์ที่เข้ากันได้กับ MCP:

```bash
dev mcp
```
