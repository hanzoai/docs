O Hanzo Dev se integra a editores e ferramentas de desenvolvimento pelo Protocolo de comunicação de agentes (ACP) e pelo MCP.

## Integrações disponíveis

- [Editor Zed](/docs/dev/integrations/zed) — Integração ACP para o editor Zed
- [GitHub Copilot](/docs/dev/integrations/copilot) — Recursos do Copilot baseados na CLI

## Servidor MCP

O Hanzo Dev também pode rodar como servidor MCP, para qualquer cliente compatível com MCP:

```bash
dev mcp
```
