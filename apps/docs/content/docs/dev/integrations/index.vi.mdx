Hanzo Dev tích hợp với trình soạn thảo và công cụ cho nhà phát triển qua Giao thức giao tiếp tác nhân (ACP) và MCP.

## Tích hợp sẵn có

- [Trình soạn thảo Zed](/docs/dev/integrations/zed) — Tích hợp ACP cho trình soạn thảo Zed
- [GitHub Copilot](/docs/dev/integrations/copilot) — Tính năng Copilot dựa trên CLI

## Máy chủ MCP

Hanzo Dev cũng có thể chạy như một máy chủ MCP, dùng với bất kỳ máy khách tương thích MCP nào:

```bash
dev mcp
```
