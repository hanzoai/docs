يتكامل Hanzo Dev مع المحررات وأدوات المطوّرين عبر بروتوكول اتصال الوكلاء (ACP) وعبر MCP.

## التكاملات المتاحة

- [محرر Zed](/docs/dev/integrations/zed) — تكامل ACP لمحرر Zed
- [GitHub Copilot](/docs/dev/integrations/copilot) — ميزات Copilot القائمة على CLI

## خادم MCP

يمكن لـ Hanzo Dev أن يعمل أيضًا كخادم MCP مع أي عميل متوافق مع MCP:

```bash
dev mcp
```
