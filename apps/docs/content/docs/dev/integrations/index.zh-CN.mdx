Hanzo Dev 通过智能体通信协议（ACP）和 MCP 与编辑器及开发工具集成。

## 可用集成

- [Zed 编辑器](/docs/dev/integrations/zed) — 面向 Zed 编辑器的 ACP 集成
- [GitHub Copilot](/docs/dev/integrations/copilot) — 基于 CLI 的 Copilot 功能

## MCP 服务器

Hanzo Dev 也可以作为 MCP 服务器运行，供任何兼容 MCP 的客户端使用：

```bash
dev mcp
```
