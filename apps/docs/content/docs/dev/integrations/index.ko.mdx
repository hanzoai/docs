Hanzo Dev는 에이전트 통신 프로토콜(ACP)과 MCP를 통해 편집기와 개발 도구에 통합됩니다.

## 사용할 수 있는 통합

- [Zed 편집기](/docs/dev/integrations/zed) — Zed 편집기용 ACP 통합
- [GitHub Copilot](/docs/dev/integrations/copilot) — CLI 기반 Copilot 기능

## MCP 서버

Hanzo Dev는 MCP와 호환되는 아무 클라이언트에서나 쓰도록 MCP 서버로도 동작합니다.

```bash
dev mcp
```
