Hanzo Dev se integra con editores y herramientas de desarrollo a través del Protocolo de comunicación de agentes (ACP) y de MCP.

## Integraciones disponibles

- [Editor Zed](/docs/dev/integrations/zed) — Integración ACP para el editor Zed
- [GitHub Copilot](/docs/dev/integrations/copilot) — Funciones de Copilot basadas en la CLI

## Servidor MCP

Hanzo Dev también puede ejecutarse como servidor MCP para usarlo con cualquier cliente compatible con MCP:

```bash
dev mcp
```
