Hanzo Dev is a coding agent that lives in your terminal, in the repository you already have open. These pages are how to install it, how to tell it what it may run, and how to operate it once it is there. The list below is a map, not a curriculum. Start at getting started if you have not run it yet. If you have, and something surprised you, the surprise is probably in usage or configuration.
