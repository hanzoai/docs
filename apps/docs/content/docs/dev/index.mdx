Hanzo Dev is a coding agent that runs in your terminal. It reads and edits the repository you open it in, runs commands inside a sandbox, and reaches the models Hanzo serves through one metered gateway at `api.hanzo.ai`. The command is `dev`.

```bash
npm install -g @hanzo/dev
dev login
dev
```
