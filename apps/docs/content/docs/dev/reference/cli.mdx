```bash
dev [OPTIONS] [PROMPT]
dev [OPTIONS] <COMMAND> [ARGS]
```

With no command, `dev` opens the interactive session; `PROMPT` starts it with a task.

## Options

These apply to the interactive session. `dev exec` takes the same ones except `-a`, `--search` and `--no-alt-screen`.

| Option | Meaning |
| --- | --- |
| `-m, --model <MODEL>` | Model to use. |
| `-p, --profile <NAME>` | Layer `~/.hanzo/dev/<NAME>.config.toml` over your config. |
| `-s, --sandbox <MODE>` | `read-only`, `workspace-write` or `danger-full-access`. |
| `-a, --ask-for-approval <POLICY>` | `on-request` or `never`. |
| `--approve-for-me` | Send approval requests to an automatic reviewer, in `workspace-write`. |
| `--dangerously-bypass-approvals-and-sandbox` | No sandbox, no approvals. Only for machines isolated some other way. |
| `-C, --cd <DIR>` | Working directory. |
| `--add-dir <DIR>` | Another writable directory (repeatable). |
| `--worktree` | Run in a new managed Git worktree. |
| `-i, --image <FILE>` | Attach images to the first prompt (comma-separated or repeated). |
| `--oss` | Use a local model provider. |
| `--local-provider <NAME>` | `ollama` or `lmstudio`, with `--oss`. |
| `--search` | Live web search for this session. |
| `--no-alt-screen` | Run inline and keep the terminal's scrollback. |
| `--strict-config` | Fail on unknown keys in `config.toml`. |
| `--dangerously-bypass-hook-trust` | Run enabled hooks without recorded hook trust. |
| `-c, --config <KEY=VALUE>` | Override one configuration value (repeatable). See [Override one setting](/docs/dev/configuration#override-one-setting-for-a-run). |
| `-V, --version` | Print the version. |
| `-h, --help` | Print help. |

## Commands

| Command | What it does |
| --- | --- |
| [`exec`](#exec) | Run a task to completion without the interface. Alias `e`. |
| [`review`](#review) | Review the changes in this repository. |
| [`login`](#login) | Sign in to Hanzo, or to ChatGPT. |
| `logout` | Discard stored credentials. |
| [`resume`](#resume-and-fork) | Continue an earlier session. |
| [`fork`](#resume-and-fork) | Start a new session from an earlier one. |
| `agents` | Switch between the sessions running here. |
| `queue --thread <SESSION> --message <TEXT>` | Send a message to a running session. |
| `archive <SESSION>` | Archive a session. |
| `unarchive <SESSION>` | Bring an archived session back. |
| `delete <SESSION> [--force]` | Delete a session for good. `--force` skips the confirmation and needs the session id. |
| [`mcp`](#mcp) | Manage MCP servers. |
| [`plugin`](#plugin) | Manage plugins and marketplaces. |
| [`cloud`](#cloud) | Browse cloud tasks and apply their changes here. |
| [`features`](#features) | List, enable and disable features. |
| [`flow`](#flow) | Run a flow over this repository. |
| [`doctor`](#doctor) | Report on the installation and configuration. |
| [`sandbox`](#sandbox) | Run a command inside the sandbox. |
| `serve` | Speak the agent protocol (JSON lines) on stdin and stdout, for editors and other clients. |
| `app` | Open this workspace in the desktop app (macOS and Windows). |
| `completion [SHELL]` | Print a shell completion script: `bash` (default), `zsh`, `fish`, `powershell` or `elvish`. |

## exec

```bash
dev exec [OPTIONS] [PROMPT]
dev exec resume [--last] [--all] [SESSION] [PROMPT]
dev exec fork <SESSION> [PROMPT]
dev exec review [REVIEW OPTIONS]
```

| Option | Meaning |
| --- | --- |
| `--json` | Print events to stdout as JSON lines. |
| `-o, --output-last-message <FILE>` | Write the final message to a file. |
| `--output-schema <FILE>` | JSON Schema the final message must match. |
| `--color <MODE>` | `always`, `never` or `auto` (default). |
| `--skip-git-repo-check` | Allow running outside a Git repository. |
| `--ephemeral` | Do not save the session. |
| `--ignore-user-config` | Do not load `~/.hanzo/dev/config.toml` (credentials still come from `~/.hanzo/dev`). |
| `--ignore-rules` | Do not load your or the project's [command rules](/docs/dev/usage/execpolicy). |

A missing prompt, or `-`, reads the prompt from stdin. Exit status is `0` on success and `1` on any error. See [Headless runs and CI](/docs/dev/usage/exec).

## review

```bash
dev review (--uncommitted | --base <BRANCH> | --commit <SHA> [--title <TITLE>] | <PROMPT>)
```

## login

```bash
dev login                       # picker
dev login --hanzo               # Hanzo account
dev login --chatgpt [--device-auth]
dev login --with-api-key        # paste or pipe a Hanzo key; add --chatgpt for an OpenAI key
dev login status
```

See [Sign in](/docs/dev/getting-started/authentication).

## resume and fork

```bash
dev resume [SESSION] [--last] [--all]
dev fork [SESSION] [--last] [--all]
```

`SESSION` is an id or name. With neither it nor `--last`, a picker opens. `--all` includes sessions from other directories.

## mcp

```bash
dev mcp list [--json]
dev mcp get <NAME> [--json]
dev mcp add <NAME> [--env KEY=VALUE]... -- <COMMAND>...
dev mcp add <NAME> --url <URL> [--bearer-token-env-var <VAR>]
dev mcp remove <NAME>
dev mcp login <NAME> [--scopes <A,B>]
dev mcp logout <NAME>
```

## plugin

```bash
dev plugin list [--marketplace <NAME>] [--json]
dev plugin add <PLUGIN[@MARKETPLACE]>
dev plugin remove <PLUGIN[@MARKETPLACE]>
dev plugin marketplace add <SOURCE> [--ref <REF>]
dev plugin marketplace list
dev plugin marketplace upgrade [NAME]
dev plugin marketplace remove <NAME>
```

`SOURCE` is a local path, `owner/repo[@ref]`, or a Git URL.

## cloud

```bash
dev cloud                                   # browse tasks
dev cloud exec --env <ENV_ID> [--attempts <1-4>] [--branch <BRANCH>] [QUERY]
dev cloud list [--env <ENV_ID>] [--limit <N>] [--json]
dev cloud status <TASK_ID>
dev cloud diff <TASK_ID> [--attempt <N>]
dev cloud apply <TASK_ID> [--attempt <N>]
```

## features

```bash
dev features list
dev features enable <FEATURE>
dev features disable <FEATURE>
```

`enable` and `disable` write `[features]` in `config.toml`.

## flow

```bash
dev flow fix --test <CMD> [--goal <TEXT>] [--max <N>] [--control kai|rule] [--timeout <SECONDS>]
```

See [Flows](/docs/dev/usage/flow).

## doctor

```bash
dev doctor [--summary] [--all] [--json] [--no-color] [--ascii]
```

Exits `1` when a check fails.

## sandbox

```bash
dev sandbox [OPTIONS] -- <COMMAND>...
```

On macOS, `--log-denials` prints what the sandbox refused. See [Platform sandboxing](/docs/dev/configuration/platform-sandboxing).

## Environment variables

| Variable | Meaning |
| --- | --- |
| `DEV_HOME` | Home directory for configuration, credentials and sessions (default `~/.hanzo/dev`). |
| `HANZO_USER_KEY` | Hanzo API key. Takes precedence over stored credentials. |
| `RUST_LOG` | Log filter. See [Logs and diagnostics](/docs/dev/usage/advanced). |
