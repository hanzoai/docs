# وحدة التحكم

وحدة تحكم Hanzo هي سطح التحكم الموحّد لـ Hanzo Cloud -- التطبيق الذي تنظر إليه. تجمع كل منتج سحابي في مكان واحد: الهوية والمفاتيح والأسرار والنماذج والفوترة وعمليات النشر ولوحات المعلومات، وكل ذلك ضمن نطاق مؤسستك.

## تطبيق واحد لكل منتج

تُرسم وحدة التحكم من كتالوج منتجات واحد، لذلك يمكن الوصول إلى كل خدمة في Hanzo Cloud من التنقل نفسه والنظرة العامة ولوحة الأوامر. كل منتج وحدة أصلية -- وليس رابطًا خارجيًا -- يستند إلى واجهة API `/v1` الحقيقية:

- **الذكاء الاصطناعي** -- النماذج وساحة التجريب والمزوّدون وembeddings
- **الأمان** -- [IAM](/docs/openapi/iam) و[KMS](/docs/openapi/kms) و[Authz](/docs/openapi/authz) و[MPC](/docs/openapi) و[Zero Trust](/docs/openapi/network)
- **المراقبة** -- [لوحات المعلومات](/docs/openapi/o11y) والتكلفة و[الفوترة](/docs/openapi/billing) والحالة
- **النشر** -- المشاريع والبيئات والدوال والعناقيد

## تسجيل الدخول والنطاق

تسجّل وحدة التحكم الدخول عبر Hanzo IAM على [hanzo.id](https://hanzo.id) بصفتها تطبيق `hanzo-cloud`. جلستك محددة النطاق بـ**مؤسسة**، ويمكن لمسؤول عام تبديل النطاق إلى أي مؤسسة؛ تُعاد مواءمة البيانات في مكانها بينما تبقى هوية العلامة ثابتة. انظر [IAM](/docs/openapi/iam) و[المؤسسات](/docs/openapi/iam).

## كيف تُسلَّم

وحدة التحكم تطبيق من صفحة واحدة مضمَّن (`go:embed`) مباشرة في ثنائي Hanzo Cloud ويُقدَّم على `console.hanzo.ai`. هي عميل خالص فوق الواجهة الخلفية الموحّدة `/v1` -- لا تحتفظ بقاعدة بيانات خاصة بها؛ كل عرض بيانات حقيقية من واجهة API لخدمة.

```bash
# The console calls the same API you can call directly, with the same key
curl https://api.hanzo.ai/v1/models \
  -H "Authorization: Bearer sk-..."
```
