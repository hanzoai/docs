## 把它带走

上面的云和你可以自己跑的那一个是[同一套
软件](/docs/network) — 同一个二进制、同一份契约、同样的 `/v1` 路由。带上
你自己的 GPU 或 Kubernetes，或在任何设备上挖矿。

```bash
curl -fsSL https://hanzo.sh | sh
```

<Callout type="info">
这是 **V8 · Open Edition**，写在 [HIP-0127](https://hips.hanzo.ai) 里：
一份契约、多种绑定、瘦客户端，语言之间是一根线 — 从不用 FFI。
*为什么*见[工程哲学](/docs/architecture/philosophy)。
</Callout>

## 用它来构建

- [`hanzo` CLI](/docs/openapi/platform) — 大约 15 MB 的 Rust 二进制，能跟任何在线的云说话：生产、笔记本或自托管
- [SDK](/docs/sdks) — Python、TypeScript、Go、Rust 等等，都从同一份契约派生
- [API 参考](/docs/openapi) — 每个端点，从它的规范生成
- [ZAP 协议](/docs/zap) — Zero-Copy App Proto，Go 和 Rust 两半说的那根线
- [Zen 模型](https://zenlm.org) — 前沿开源权重，从 4B 边缘到 1T+ 推理
- [架构](/docs/architecture) — 一个二进制、一份契约，以及为什么
