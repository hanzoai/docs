Setiap model di bawah dijangkau dengan satu kunci pada satu alamat. Teruskan `id` sebagai
`model` dan sisa permintaan sama, mana pun yang Anda pilih.

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"<id from below>","messages":[{"role":"user","content":"Hello"}]}'
```

Tabel diambil dari [`/v1/models`](/docs/openapi/ai) di peramban saat
halaman dimuat, jadi ini katalog yang sedang dilayani gateway, bukan
salinan yang ditulis saat halaman dibangun.

## Apa arti sebuah tarif

Tarif dihitung per juta token, masukan dan keluaran dihargai terpisah, dan sama
entah Anda memanggil dari CLI, SDK, HTTP, atau alat MCP — harga adalah sifat model,
bukan permukaan yang Anda lalui.

[Harga](/docs/pricing) menjelaskan bagaimana pemakaian menjadi tagihan. [Kredit](/docs/credits)
mencakup apa yang terjadi saat saldo habis.
