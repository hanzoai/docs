# 개발 — GitHub와 GitLab

자동 코드 검토, 이슈와 병합 요청 분류, 멘션으로 받는 즉시 도움. 모두 저장소 안에서 이루어집니다.

## GitHub App

조직이나 저장소에 설치되며 다음을 더합니다.

- **요청 검토** — Hanzo가 풀 리퀘스트를 검토하고 줄 안에 댓글을 남깁니다.
- **이슈 분류** — 새 이슈에 라벨을 붙이고, 요약하고, 보냅니다.
- **`@hanzo` 멘션** — 질문하거나, 변경을 요청하거나, 에이전트를 띄우려면 요청이나 이슈에서 `@hanzo`를 언급합니다.

**설치** — [콘솔](https://console.hanzo.ai)에서 **GitHub**를 고르고 Hanzo GitHub App을 설치한 뒤, 권한을 줄 조직이나 저장소를 선택합니다. 요청된 권한을 승인하면 Hanzo가 새 요청과 이슈 검토를 시작합니다.

## GitLab

GitLab 병합 요청과 이슈에 같은 검토와 분류 흐름입니다.

- **병합 요청 검토** — 병합 요청의 줄 안 검토 댓글.
- **이슈 분류** — 이슈를 요약하고, 라벨을 붙이고, 보냅니다.
- **`@hanzo` 멘션** — 에이전트를 부르려면 병합 요청이나 이슈에서 `@hanzo`를 언급합니다.

**연결** — [콘솔](https://console.hanzo.ai)에서 **GitLab**을 고르고 OAuth로 승인합니다(GitLab.com 또는 자체 운영). 켤 그룹이나 프로젝트를 고릅니다.

> **하나의 신원, 어디서나.** Hanzo로 로그인하거나([IAM](/docs/openapi/iam) OAuth) `sk-` [API 키](/docs/api-keys)를 붙여 넣으세요. 같은 자격 증명이 Hanzo의 모든 표면에서 동작합니다 — [통합 및 확장](/docs/apps)을 보세요.
