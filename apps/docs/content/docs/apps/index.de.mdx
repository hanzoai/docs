# Integrationen und Erweiterungen

Hanzo läuft dort, wo Sie arbeiten. Installieren Sie eine Erweiterung, laden Sie ein Add-in seitlich oder verbinden Sie eine App per OAuth — und dieselbe KI, dieselben Werkzeuge und dieselben Agenten folgen Ihnen in den Browser, den Editor, den Posteingang, das CRM und auf den Desktop.

## Ein API-Schlüssel, eine Identität, überall

Jede Oberfläche unten ist ein schlanker Client auf demselben Fundament:

- **[Gateway `@hanzo/ai`](/docs/openapi/gateway)** — eine mit OpenAI kompatible Basis-URL, `https://api.hanzo.ai/v1`, vor jedem Modell und Werkzeug.
- **[Identität `@hanzo/iam`](/docs/openapi/iam)** — ein Konto in jeder App, auf die Organisation begrenzt und SSO-bereit.

Sie authentifizieren sich **einmal**, auf einem der beiden Wege:

1. **Mit Hanzo anmelden** — OAuth über [Hanzo IAM](/docs/openapi/iam). Klicken Sie auf **Anmelden**, stimmen Sie zu, fertig.
2. **Einen `sk-`-Schlüssel einfügen** — legen Sie einen in der [Konsole](https://console.hanzo.ai) an (siehe [API-Schlüssel](/docs/api-keys)) und fügen Sie ihn in die Einstellungen der Oberfläche ein.

Derselbe Schlüssel und dieselbe Identität funktionieren in jeder Erweiterung, jedem Add-in und jeder verbundenen App. Wechseln Sie die Organisation einmal, und es gilt überall.

## Verwandt

- [Gateway](/docs/openapi/gateway) — die eine API, die jede Oberfläche aufruft
- [API-Schlüssel](/docs/api-keys) — den `sk-`-Schlüssel ausstellen, den Sie einfügen
- [IAM](/docs/openapi/iam) — die Identität, mit der Sie sich anmelden
- [Integrationen](/docs/openapi/integrations) — Datenquellen (Objektspeicher, Slack-Alarme, Analytik) mit einem Projekt verbinden
