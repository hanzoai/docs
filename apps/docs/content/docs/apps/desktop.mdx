# Hanzo Desktop

**Hanzo Desktop is the Hanzo app on your computer**: Chat, Dev, Studio and your
agents in one window, and a global hotkey that brings Hanzo to whatever you are
doing. Agents can run against models on your own machine or on Hanzo Cloud. If
you are not sure which Hanzo to install, install this one.

## Install

1. Open **[hanzo.ai/download](https://hanzo.ai/download)**. The button offers the
   latest build for your system: a `.dmg` for macOS (Apple Silicon and Intel), a
   setup `.exe` for Windows, an AppImage or `.deb` for Linux (x86_64 and arm64).
2. Install it like any other app, and open it.
3. Choose **Sign in with Hanzo**. Your browser opens the Hanzo sign-in page (create
   an account there if you have none) and hands you back to the app. Or choose
   **Continue without login** to run on a local model with no account.

No terminal, no `curl`, `npm` or `brew`. Every build and its checksums are on
[GitHub](https://github.com/hanzoai/desktop/releases/latest).

Nothing to install at all: the same app runs in your browser at
[hanzo.app](https://hanzo.app).

### macOS signing and notarization

Hanzo Desktop v1.1.83 for macOS was signed ad hoc and lacked an Apple
notarization ticket. Gatekeeper can block this download even when its SHA-256
checksum matches the one Hanzo publishes. The checksum confirms the file
matches the published download. Developer ID signing and notarization allow
macOS to verify the publisher and check Apple's notarization record.

If macOS blocks the app, you can use [hanzo.app](https://hanzo.app) in your
browser. Apple documents a per-app exception under **System Settings →
Privacy & Security → Open Anyway** for downloads you have verified and trust.
Follow [Apple's instructions for opening apps safely](https://support.apple.com/en-us/102445).

With access to the Hanzo Desktop source, you can build and run it on your own
Mac using the free Xcode tools and the commands in
[Build from source](#build-from-source). A free Apple Account is sufficient for
local development. A free account does not grant access to a private source
repository or supply the Developer ID certificate and notarization used to
distribute a release to other Macs. Those distribution features require Apple
Developer Program membership. See [Apple's developer account overview](https://developer.apple.com/help/account/basics/about-your-developer-account).

## Local Cloud & Custom API Endpoint

To point Hanzo Desktop at a local Cloud stack (`hanzo up` or `make dev` in [`hanzoai/cloud`](https://github.com/hanzoai/cloud) on `http://127.0.0.1:8080`), Devnet (`https://api-dev.hanzo.ai`), or any custom endpoint:

1. Open **Settings → Environments & Machines → Cloud API Endpoint** (or **Settings → Advanced → Local services**).
2. Select **`Local Cloud`** (`http://127.0.0.1:8080`), click **Test** to verify `/v1/health`, and click **Apply & Reload** (or launch from the terminal with `HANZO_CLOUD_API=http://127.0.0.1:8080 hanzo-desktop`).

## Build from source (Open Source)

Core desktop clients are open source under [`github.com/hanzoai`](https://github.com/hanzoai):

- **Hanzo Desktop** ([`hanzoai/desktop`](https://github.com/hanzoai/desktop)) — Chat, local inference, and workspace shell for macOS, Windows, and Linux.
- **Hanzo Dev Desktop** ([`hanzoai/dev`](https://github.com/hanzoai/dev)) — Standalone open-source coding workspace and Tauri desktop app:

```bash
git clone https://github.com/hanzoai/dev.git && cd dev
pnpm install
pnpm run build:desktop
```

To build custom modular apps that mount into the Hanzo shell on top of the same IAM, AI, and MCP primitives, use the **`@hanzo/mod` App SDK** — see [Building Apps & Mods](/docs/apps/mods). On macOS, install Apple's Command Line Tools with `xcode-select --install` if they are missing.

## Desktop or the CLI?

The [Hanzo CLI](/docs/cli) (`hanzo`) is for developers: it runs in a terminal,
starts [Hanzo Dev](/docs/dev) (the coding agent) with `hanzo dev`, and drives your
account and the cloud from scripts. You do not need it to use Hanzo Desktop.

## Connect Hanzo to ChatGPT or Claude

Use `https://api.hanzo.ai/v1/mcp` as the server URL for Hanzo Cloud tools.
Choose **OAuth** and sign in at `https://hanzo.ai` when prompted.

- **ChatGPT.** Open **Plugins**, select **+**, then **Add custom MCP server**.
  Enter the URL, choose **OAuth**, and create and install the plugin. Your
  workspace may require permission to add custom servers.
  [ChatGPT setup](https://developers.openai.com/api/docs/guides/custom-mcp-server)
- **Claude.** Open **Customize → Connectors → Add → Custom → Web**.
  Enter the URL, choose **Sign in now**, and complete the Hanzo sign-in flow.
  [Claude setup](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)

### Use the local MCP server

For local tools in Claude Desktop, add the [Hanzo MCP configuration](/docs/mcp#client-setup)
under **Settings → Developer → Edit Config** and restart.

To share one Chrome page with ChatGPT, run `hanzo-mcp share` through a private
Secure MCP Tunnel on the computer running the Hanzo browser extension. The
command requires you to select the browser, tab, and exact page URL.
[Native browser sharing setup](https://github.com/hanzoai/mcp#share-a-browser-page-through-a-private-mcp-tunnel)
