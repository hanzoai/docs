# Designwerkzeuge

Holen Sie Hanzo auf Ihre Arbeitsfläche: Texte erzeugen und umschreiben, Ebenen benennen und kommentieren und KI-Aktionen auf eine Auswahl in Figma und Sketch ausführen.

## Figma

| Paket |
|-------|
| [`hanzo-ai-figma-v1.9.31.zip`](https://github.com/hanzoai/extension/releases/download/v1.9.31/hanzo-ai-figma-v1.9.31.zip) |

**Installieren**

1. Laden Sie das Figma-Paket herunter und entpacken Sie es (es enthält `manifest.json`).
2. In der Figma-Desktop-App: **Plugins → Entwicklung → Plugin aus Manifest importieren…**
3. Wählen Sie die `manifest.json`. Starten Sie es über **Plugins → Entwicklung → Hanzo**.

## Sketch

| Paket |
|-------|
| [`hanzo-ai-sketch-v1.9.31.zip`](https://github.com/hanzoai/extension/releases/download/v1.9.31/hanzo-ai-sketch-v1.9.31.zip) |

**Installieren** — entpacken und doppelklicken Sie das `.sketchplugin`-Bündel; Sketch installiert es und fügt **Hanzo** dem Menü **Plugins** hinzu.

Die neuesten Builds liegen immer auf dem [neuesten Release](https://github.com/hanzoai/extension/releases/latest).

## Anmelden

Öffnen Sie das Plugin und wählen Sie **Mit Hanzo anmelden**, oder fügen Sie einen `sk-`-Schlüssel in den Einstellungen ein.

> **Eine Identität, überall.** Melden Sie sich mit Hanzo an ([IAM](/docs/openapi/iam)-OAuth) oder fügen Sie einen `sk-`-[API-Schlüssel](/docs/api-keys) ein. Dieselbe Anmeldung funktioniert auf jeder Hanzo-Oberfläche — siehe [Integrationen und Erweiterungen](/docs/apps).
