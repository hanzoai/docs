# 設計工具

把 Hanzo 帶進畫布 — 產生並改寫文案，為圖層命名與標註，並在 Figma 與 Sketch 的選取範圍上執行 AI 動作。

## Figma

| 資源 |
|-------|
| [`hanzo-ai-figma-v1.9.31.zip`](https://github.com/hanzoai/extension/releases/download/v1.9.31/hanzo-ai-figma-v1.9.31.zip) |

**安裝**

1. 下載並解壓縮 Figma 資源（其中包含 `manifest.json`）。
2. 在 Figma 桌面應用程式中：**外掛程式 → 開發 → 從資訊清單匯入外掛程式…**
3. 選取 `manifest.json`。從 **外掛程式 → 開發 → Hanzo** 執行它。

## Sketch

| 資源 |
|-------|
| [`hanzo-ai-sketch-v1.9.31.zip`](https://github.com/hanzoai/extension/releases/download/v1.9.31/hanzo-ai-sketch-v1.9.31.zip) |

**安裝** — 解壓縮並連按兩下 `.sketchplugin` 套件；Sketch 會安裝它，並把 **Hanzo** 加到 **外掛程式** 選單。

最新組建始終在[最新版本](https://github.com/hanzoai/extension/releases/latest)。

## 登入

開啟外掛程式並選擇 **使用 Hanzo 登入**，或在其設定中貼上 `sk-` 金鑰。

> **一個身分，處處可用。** 使用 Hanzo 登入（[IAM](/docs/openapi/iam) OAuth），或貼上一把 `sk-` [API 金鑰](/docs/api-keys)。同一組憑證適用於 Hanzo 的每一個表面 — 參見[整合與擴充功能](/docs/apps)。
