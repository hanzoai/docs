# 連携と拡張機能

Hanzo は、あなたが働く場所で動きます。拡張機能を入れ、アドインをサイドロードし、またはアプリを OAuth でつなぐと、同じ AI、ツール、エージェントがブラウザー、エディター、受信箱、CRM、デスクトップまで付いてきます。

## 一つの API キー、一つのアイデンティティ、どこでも

下の各画面は、同じ土台の上の薄いクライアントです。

- **[`@hanzo/ai` ゲートウェイ](/docs/openapi/gateway)** — OpenAI 互換の一つのベース URL、`https://api.hanzo.ai/v1` が、すべてのモデルとツールの前に立ちます。
- **[`@hanzo/iam` アイデンティティ](/docs/openapi/iam)** — すべてのアプリで一つのアカウント。組織に範囲が限定され、SSO に対応しています。

認証は **一度** です。どちらかの方法で:

1. **Hanzo でサインイン** — [Hanzo IAM](/docs/openapi/iam) を通じた OAuth。**サインイン**をクリックし、承認すれば完了です。
2. **`sk-` キーを貼り付ける** — [コンソール](https://console.hanzo.ai)で作成し（[API キー](/docs/api-keys)を参照）、画面の設定に貼り付けます。

同じキーと同じアイデンティティが、すべての拡張機能、アドイン、接続済みアプリで使えます。組織を一度切り替えれば、どこにでも適用されます。
