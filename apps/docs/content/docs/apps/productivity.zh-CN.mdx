# 效率

从你用来安排一天的工具里直接到达 Hanzo。

## Clio

在 Clio（法律事务管理）里汇总事项、起草往来函件，并查询你的事务所数据。

**连接** — 打开[控制台](https://console.hanzo.ai)，选择 **Clio**，并通过 OAuth 授权；Hanzo 会遵守你在事项、联系人和文档上的 Clio 权限。

## Raycast

从 Raycast 命令栏运行 Hanzo — 不用离开键盘就能提问、起草并运行智能体。

**安装** — 打开 Raycast，在 **Raycast Store** 中搜索 **Hanzo** 并添加扩展。在扩展偏好设置里填写 `sk-` 密钥，或运行 **使用 Hanzo 登录** 命令。

> **一个身份，处处可用。** 使用 Hanzo 登录（[IAM](/docs/openapi/iam) OAuth），或粘贴一把 `sk-` [API 密钥](/docs/api-keys)。同一套凭据适用于 Hanzo 的每一个表面 — 参见[集成与扩展](/docs/apps)。
