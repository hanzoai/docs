# 生産性

一日を動かす道具から Hanzo に届きます。

## Clio

Clio（法律事務所の業務管理）の中で案件を要約し、書簡を下書きし、事務所のデータを問い合わせます。

**接続** — [コンソール](https://console.hanzo.ai)を開き、**Clio** を選び、OAuth で承認します。Hanzo は案件、連絡先、文書に対するあなたの Clio の権限を尊重します。

## Raycast

Raycast のコマンドバーから Hanzo を実行します。キーボードから手を離さずに質問し、下書きし、エージェントを動かせます。

**インストール** — Raycast を開き、**Raycast Store** で **Hanzo** を検索して拡張機能を追加します。拡張機能の設定で `sk-` キーを設定するか、**Hanzo でサインイン** コマンドを実行します。

> **ひとつのアイデンティティを、どこでも。** Hanzo でサインインする（[IAM](/docs/openapi/iam) の OAuth）か、`sk-` の [API キー](/docs/api-keys)を貼り付けます。同じ資格情報は Hanzo のあらゆる画面で使えます — [連携と拡張機能](/docs/apps)を参照してください。
