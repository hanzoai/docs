# 集成与扩展

Hanzo 在你工作的地方运行。安装扩展、旁加载项，或通过 OAuth 连接应用 — 同一套 AI、工具和智能体就会跟着你进入浏览器、编辑器、收件箱、CRM 和桌面。

## 一把 API 密钥，一个身份，处处可用

下面的每个表面都是同一套基础之上的瘦客户端：

- **[`@hanzo/ai` 网关](/docs/openapi/gateway)** — 一个与 OpenAI 兼容的基础 URL，`https://api.hanzo.ai/v1`，位于每个模型和工具之前。
- **[`@hanzo/iam` 身份](/docs/openapi/iam)** — 每个应用一个账户，限定在组织范围，并已准备好 SSO。

你**只认证一次**，两种方式任选：

1. **使用 Hanzo 登录** — 通过 [Hanzo IAM](/docs/openapi/iam) 的 OAuth。点击**登录**，批准，完成。
2. **粘贴一把 `sk-` 密钥** — 在[控制台](https://console.hanzo.ai)创建（参见 [API 密钥](/docs/api-keys)），再粘贴到该表面的设置里。

同一把密钥和同一个身份适用于每一个扩展、加载项和已连接的应用。切换一次组织，就会应用到各处。
