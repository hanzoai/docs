# 生產力

從你用來安排一整天的工具裡直接抵達 Hanzo。

## Clio

在 Clio（法律事務所管理）裡摘要案件、起草往來函件，並查詢事務所資料。

**連接** — 開啟[主控台](https://console.hanzo.ai)，選擇 **Clio**，並透過 OAuth 授權；Hanzo 會遵守你在案件、聯絡人與文件上的 Clio 權限。

## Raycast

從 Raycast 命令列執行 Hanzo — 手不離開鍵盤就能提問、起草並執行代理程式。

**安裝** — 開啟 Raycast，在 **Raycast Store** 搜尋 **Hanzo** 並加入擴充功能。在擴充功能偏好設定中填入 `sk-` 金鑰，或執行 **使用 Hanzo 登入** 命令。

> **一個身分，處處可用。** 使用 Hanzo 登入（[IAM](/docs/openapi/iam) OAuth），或貼上一把 `sk-` [API 金鑰](/docs/api-keys)。同一組憑證適用於 Hanzo 的每一個表面 — 參見[整合與擴充功能](/docs/apps)。
