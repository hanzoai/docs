# Entwicklung — GitHub und GitLab

Automatisierte Codeprüfung, Einordnung von Tickets und Merge-Anfragen sowie Hilfe auf Zuruf per Erwähnung — direkt in Ihren Repositories.

## GitHub App

Installiert sich in Ihrer Organisation oder in Repositories und ergänzt:

- **Prüfung von Änderungsanfragen** — Hanzo prüft Änderungsanfragen und hinterlässt Kommentare in der Zeile.
- **Einordnung von Tickets** — versieht neue Tickets mit Labels, fasst sie zusammen und leitet sie weiter.
- **`@hanzo`-Erwähnungen** — erwähnen Sie `@hanzo` in einer Änderungsanfrage oder einem Ticket, um eine Frage zu stellen, Änderungen anzufordern oder einen Agenten zu starten.

**Installieren** — wählen Sie in der [Konsole](https://console.hanzo.ai) **GitHub**, installieren Sie die Hanzo GitHub App und wählen Sie die Organisation oder die Repositories, denen Sie sie gewähren. Stimmen Sie den angeforderten Berechtigungen zu, und Hanzo beginnt, neue Änderungsanfragen und Tickets zu prüfen.

## GitLab

Derselbe Prüf- und Einordnungsablauf für GitLab-Merge-Anfragen und Tickets.

- **Prüfung von Merge-Anfragen** — Prüfkommentare in der Zeile an Merge-Anfragen.
- **Einordnung von Tickets** — zusammenfassen, labeln und weiterleiten.
- **`@hanzo`-Erwähnungen** — erwähnen Sie `@hanzo` in einer Merge-Anfrage oder einem Ticket, um den Agenten aufzurufen.

**Verbinden** — wählen Sie in der [Konsole](https://console.hanzo.ai) **GitLab**, autorisieren Sie per OAuth (GitLab.com oder selbst betrieben) und wählen Sie die Gruppen oder Projekte, die Sie aktivieren.

> **Eine Identität, überall.** Melden Sie sich mit Hanzo an ([IAM](/docs/openapi/iam)-OAuth) oder fügen Sie einen `sk-`-[API-Schlüssel](/docs/api-keys) ein. Dieselbe Anmeldung funktioniert auf jeder Hanzo-Oberfläche — siehe [Integrationen und Erweiterungen](/docs/apps).

## Verwandt

- [Hanzo Dev](/docs/dev) — der Coding-Agent, der die Prüfungen antreibt
