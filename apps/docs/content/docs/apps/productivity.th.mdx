# ผลิตภาพ

เข้าถึง Hanzo จากเครื่องมือที่คุณใช้ขับเคลื่อนทั้งวัน

## Clio

สรุปคดี ร่างจดหมายโต้ตอบ และสอบถามข้อมูลสำนักงานภายใน Clio (การบริหารสำนักงานกฎหมาย)

**เชื่อมต่อ** — เปิด[คอนโซล](https://console.hanzo.ai) เลือก **Clio** แล้วอนุญาตผ่าน OAuth Hanzo เคารพสิทธิ์ Clio ของคุณในเรื่องคดี ผู้ติดต่อ และเอกสาร

## Raycast

เรียกใช้ Hanzo จากแถบคำสั่ง Raycast — ถาม ร่าง และเรียกเอเจนต์โดยไม่ต้องยกมือจากแป้นพิมพ์

**ติดตั้ง** — เปิด Raycast ค้นหา **Hanzo** ใน **Raycast Store** แล้วเพิ่มส่วนขยาย ตั้งค่าคีย์ `sk-` ในการตั้งค่าส่วนขยาย หรือเรียกคำสั่ง **ลงชื่อเข้าใช้ด้วย Hanzo**

> **ตัวตนเดียว ทุกที่** ลงชื่อเข้าใช้ด้วย Hanzo (OAuth ของ [IAM](/docs/openapi/iam)) หรือวาง[คีย์ API](/docs/api-keys) แบบ `sk-` ข้อมูลประจำตัวเดียวกันใช้ได้บนทุกพื้นผิวของ Hanzo — ดู[การเชื่อมต่อและส่วนขยาย](/docs/apps)
