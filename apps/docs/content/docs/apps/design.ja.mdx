# デザインツール

Hanzo をカンバスへ。コピーを生成して書き直し、レイヤーに名前と注釈を付け、Figma と Sketch の選択範囲で AI の操作を実行します。

## Figma

| アセット |
|-------|
| [`hanzo-ai-figma-v1.9.31.zip`](https://github.com/hanzoai/extension/releases/download/v1.9.31/hanzo-ai-figma-v1.9.31.zip) |

**インストール**

1. Figma のアセットをダウンロードして展開します（`manifest.json` が入っています）。
2. Figma デスクトップアプリで: **プラグイン → 開発 → マニフェストからプラグインをインポート…**
3. `manifest.json` を選びます。**プラグイン → 開発 → Hanzo** から実行します。

## Sketch

| アセット |
|-------|
| [`hanzo-ai-sketch-v1.9.31.zip`](https://github.com/hanzoai/extension/releases/download/v1.9.31/hanzo-ai-sketch-v1.9.31.zip) |

**インストール** — 展開して `.sketchplugin` バンドルをダブルクリックします。Sketch がインストールし、**プラグイン**メニューに **Hanzo** を追加します。

最新のビルドは常に[最新リリース](https://github.com/hanzoai/extension/releases/latest)にあります。

## サインイン

プラグインを開き、**Hanzo でサインイン**するか、設定に `sk-` キーを貼り付けます。

> **ひとつのアイデンティティを、どこでも。** Hanzo でサインインする（[IAM](/docs/openapi/iam) の OAuth）か、`sk-` の [API キー](/docs/api-keys)を貼り付けます。同じ資格情報は Hanzo のあらゆる画面で使えます — [連携と拡張機能](/docs/apps)を参照してください。
