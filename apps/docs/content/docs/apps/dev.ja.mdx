# 開発 — GitHub と GitLab

自動のコードレビュー、課題とマージリクエストの仕分け、メンションによるその場の支援。すべてリポジトリの中で行います。

## GitHub App

組織またはリポジトリに入り、次を加えます。

- **変更のレビュー** — Hanzo がプルリクエストをレビューし、行内コメントを残します。
- **課題の仕分け** — 新しい課題にラベルを付け、要約し、振り分けます。
- **`@hanzo` メンション** — 質問する、変更を頼む、エージェントを動かすために、プルリクエストまたは課題で `@hanzo` に言及します。

**インストール** — [コンソール](https://console.hanzo.ai)から **GitHub** を選び、Hanzo の GitHub App を入れ、アクセスを与える組織またはリポジトリを選びます。求められた権限を承認すると、Hanzo は新しいプルリクエストと課題のレビューを始めます。

## GitLab

GitLab のマージリクエストと課題に、同じレビューと仕分けの流れです。

- **マージリクエストのレビュー** — マージリクエストへの行内レビューコメント。
- **課題の仕分け** — 要約し、ラベルを付け、振り分けます。
- **`@hanzo` メンション** — エージェントを呼ぶために、マージリクエストまたは課題で `@hanzo` に言及します。

**接続** — [コンソール](https://console.hanzo.ai)から **GitLab** を選び、OAuth で承認し（GitLab.com または自前運用）、有効にするグループまたはプロジェクトを選びます。

> **ひとつのアイデンティティを、どこでも。** Hanzo でサインインする（[IAM](/docs/openapi/iam) の OAuth）か、`sk-` の [API キー](/docs/api-keys)を貼り付けます。同じ資格情報は Hanzo のあらゆる画面で使えます — [連携と拡張機能](/docs/apps)を参照してください。
