# Alat desain

Bawa Hanzo ke kanvas Anda — buat dan tulis ulang teks, beri nama serta anotasi lapisan, dan jalankan tindakan AI pada sebuah pilihan di Figma dan Sketch.

## Figma

| Paket |
|-------|
| [`hanzo-ai-figma-v1.9.31.zip`](https://github.com/hanzoai/extension/releases/download/v1.9.31/hanzo-ai-figma-v1.9.31.zip) |

**Pasang**

1. Unduh dan ekstrak paket Figma (berisi `manifest.json`).
2. Di aplikasi desktop Figma: **Plugin → Pengembangan → Impor plugin dari manifes…**
3. Pilih `manifest.json`. Jalankan dari **Plugin → Pengembangan → Hanzo**.

## Sketch

| Paket |
|-------|
| [`hanzo-ai-sketch-v1.9.31.zip`](https://github.com/hanzoai/extension/releases/download/v1.9.31/hanzo-ai-sketch-v1.9.31.zip) |

**Pasang** — ekstrak dan klik ganda bundel `.sketchplugin`; Sketch memasangnya dan menambahkan **Hanzo** ke menu **Plugin**.

Build terbaru selalu ada di [rilis terbaru](https://github.com/hanzoai/extension/releases/latest).

## Masuk

Buka plugin dan pilih **Masuk dengan Hanzo**, atau tempel kunci `sk-` di pengaturannya.

> **Satu identitas, di mana saja.** Masuk dengan Hanzo (OAuth [IAM](/docs/openapi/iam)) atau tempel [kunci API](/docs/api-keys) `sk-`. Kredensial yang sama berfungsi di setiap permukaan Hanzo — lihat [Integrasi dan ekstensi](/docs/apps).
