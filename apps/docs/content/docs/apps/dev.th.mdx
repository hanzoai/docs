# การพัฒนา — GitHub และ GitLab

ตรวจทานโค้ดอัตโนมัติ คัดแยกปัญหาและคำขอรวม ตลอดจนความช่วยเหลือตามต้องการด้วยการกล่าวถึง — ในรีโพซิทอรีของคุณโดยตรง

## GitHub App

ติดตั้งบนองค์กรหรือรีโพซิทอรีของคุณ และเพิ่ม:

- **การตรวจทานคำขอ** — Hanzo ตรวจทานคำขอดึงและใส่ความคิดเห็นในบรรทัด
- **การคัดแยกปัญหา** — ติดป้าย สรุป และส่งต่อปัญหาใหม่
- **การกล่าวถึง `@hanzo`** — กล่าวถึง `@hanzo` ในคำขอหรือปัญหาเพื่อถาม ขอการเปลี่ยนแปลง หรือเริ่มเอเจนต์

**ติดตั้ง** — จาก[คอนโซล](https://console.hanzo.ai) เลือก **GitHub** ติดตั้ง GitHub App ของ Hanzo แล้วเลือกองค์กรหรือรีโพซิทอรีที่จะให้สิทธิ์ อนุมัติสิทธิ์ที่ขอ แล้ว Hanzo จะเริ่มตรวจทานคำขอและปัญหาใหม่

## GitLab

ลำดับการตรวจทานและคัดแยกเดียวกันสำหรับคำขอรวมและปัญหาของ GitLab

- **การตรวจทานคำขอรวม** — ความคิดเห็นตรวจทานในบรรทัดบนคำขอรวม
- **การคัดแยกปัญหา** — สรุป ติดป้าย และส่งต่อปัญหา
- **การกล่าวถึง `@hanzo`** — กล่าวถึง `@hanzo` ในคำขอรวมหรือปัญหาเพื่อเรียกเอเจนต์

**เชื่อมต่อ** — จาก[คอนโซล](https://console.hanzo.ai) เลือก **GitLab** อนุญาตผ่าน OAuth (GitLab.com หรือที่คุณโฮสต์เอง) แล้วเลือกกลุ่มหรือโปรเจกต์ที่จะเปิดใช้

> **ตัวตนเดียว ทุกที่** ลงชื่อเข้าใช้ด้วย Hanzo (OAuth ของ [IAM](/docs/openapi/iam)) หรือวาง[คีย์ API](/docs/api-keys) แบบ `sk-` ข้อมูลประจำตัวเดียวกันใช้ได้บนทุกพื้นผิวของ Hanzo — ดู[การเชื่อมต่อและส่วนขยาย](/docs/apps)

## ที่เกี่ยวข้อง
