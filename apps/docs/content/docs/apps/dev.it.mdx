# Sviluppo — GitHub e GitLab

Revisione del codice automatica, smistamento di issue e richieste di unione, e aiuto su richiesta tramite menzione — direttamente nei tuoi repository.

## GitHub App

Si installa sulla tua organizzazione o sui repository e aggiunge:

- **Revisione delle richieste** — Hanzo revisiona le richieste di estrazione e lascia commenti in linea.
- **Smistamento delle issue** — etichetta, riassume e indirizza le nuove issue.
- **Menzioni `@hanzo`** — menziona `@hanzo` in una richiesta o in una issue per fare una domanda, chiedere modifiche o avviare un agente.

**Installa** — dalla [console](https://console.hanzo.ai), scegli **GitHub**, installa la GitHub App di Hanzo e seleziona l'organizzazione o i repository a cui concederla. Approva i permessi richiesti e Hanzo inizia a revisionare le nuove richieste e le nuove issue.

## GitLab

Lo stesso flusso di revisione e smistamento per le richieste di unione e le issue di GitLab.

- **Revisione delle richieste di unione** — commenti di revisione in linea sulle richieste di unione.
- **Smistamento delle issue** — riassume, etichetta e indirizza le issue.
- **Menzioni `@hanzo`** — menziona `@hanzo` in una richiesta di unione o in una issue per invocare l'agente.

**Connetti** — dalla [console](https://console.hanzo.ai), scegli **GitLab**, autorizza tramite OAuth (GitLab.com o autogestito) e scegli i gruppi o i progetti da abilitare.

> **Un'identità, ovunque.** Accedi con Hanzo (OAuth [IAM](/docs/openapi/iam)) oppure incolla una [chiave API](/docs/api-keys) `sk-`. La stessa credenziale funziona su ogni superficie Hanzo — vedi [Integrazioni ed estensioni](/docs/apps).

## Correlati
