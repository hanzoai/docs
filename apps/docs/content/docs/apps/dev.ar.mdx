# التطوير — GitHub وGitLab

مراجعة آلية للتعليمات البرمجية، وفرز المشكلات وطلبات الدمج، ومساعدة عند الطلب عبر الإشارة — مباشرة في مستودعاتك.

## GitHub App

يُثبَّت على مؤسستك أو مستودعاتك ويضيف:

- **مراجعة الطلبات** — يراجع Hanzo طلبات السحب ويترك تعليقات ضمن السطر.
- **فرز المشكلات** — يضع وسومًا ويلخّص ويوجّه المشكلات الجديدة.
- **إشارات `@hanzo`** — اذكر `@hanzo` في طلب أو مشكلة لطرح سؤال أو طلب تغييرات أو إطلاق وكيل.

**التثبيت** — من [وحدة التحكم](https://console.hanzo.ai)، اختر **GitHub**، وثبّت GitHub App الخاص بـ Hanzo، وحدد المؤسسة أو المستودعات التي تمنحه الوصول. وافق على الأذونات المطلوبة ويبدأ Hanzo بمراجعة الطلبات والمشكلات الجديدة.

## GitLab

تدفّق المراجعة والفرز نفسه لطلبات الدمج ومشكلات GitLab.

- **مراجعة طلبات الدمج** — تعليقات مراجعة ضمن السطر على طلبات الدمج.
- **فرز المشكلات** — تلخيص المشكلات ووضع وسوم لها وتوجيهها.
- **إشارات `@hanzo`** — اذكر `@hanzo` في طلب دمج أو مشكلة لاستدعاء الوكيل.

**اتصال** — من [وحدة التحكم](https://console.hanzo.ai)، اختر **GitLab**، وفوّض عبر OAuth (GitLab.com أو مستضاف ذاتيًا)، واختر المجموعات أو المشاريع التي تريد تفعيلها.

> **هوية واحدة، في كل مكان.** سجّل الدخول باستخدام Hanzo (OAuth من [IAM](/docs/openapi/iam)) أو الصق [مفتاح API](/docs/api-keys) من نوع `sk-`. تعمل بيانات الاعتماد نفسها في كل سطح من سطوح Hanzo — انظر [عمليات التكامل والإضافات](/docs/apps).
