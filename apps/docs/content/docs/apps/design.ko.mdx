# 디자인 도구

Hanzo를 캔버스로 가져오세요. 문구를 만들고 다시 쓰고, 레이어에 이름과 주석을 달고, Figma와 Sketch의 선택 영역에서 AI 동작을 실행합니다.

## Figma

| 자산 |
|-------|
| [`hanzo-ai-figma-v1.9.31.zip`](https://github.com/hanzoai/extension/releases/download/v1.9.31/hanzo-ai-figma-v1.9.31.zip) |

**설치**

1. Figma 자산을 받아 압축을 풉니다(`manifest.json`이 들어 있습니다).
2. Figma 데스크톱 앱에서: **플러그인 → 개발 → 매니페스트에서 플러그인 가져오기…**
3. `manifest.json`을 선택합니다. **플러그인 → 개발 → Hanzo**에서 실행합니다.

## Sketch

| 자산 |
|-------|
| [`hanzo-ai-sketch-v1.9.31.zip`](https://github.com/hanzoai/extension/releases/download/v1.9.31/hanzo-ai-sketch-v1.9.31.zip) |

**설치** — 압축을 풀고 `.sketchplugin` 번들을 두 번 클릭합니다. Sketch가 설치하고 **플러그인** 메뉴에 **Hanzo**를 추가합니다.

가장 새로운 빌드는 항상 [최신 릴리스](https://github.com/hanzoai/extension/releases/latest)에 있습니다.

## 로그인

플러그인을 열고 **Hanzo로 로그인**을 선택하거나, 설정에 `sk-` 키를 붙여 넣습니다.

> **하나의 신원, 어디서나.** Hanzo로 로그인하거나([IAM](/docs/openapi/iam) OAuth) `sk-` [API 키](/docs/api-keys)를 붙여 넣으세요. 같은 자격 증명이 Hanzo의 모든 표면에서 동작합니다 — [통합 및 확장](/docs/apps)을 보세요.
