# ビジネスと CRM

レコードを要約し、文面を下書きし、CRM、契約、文書、店舗に対して操作を起こします。OAuth でつながり、ダウンロードは不要です。

ここの各アプリは同じ手順でつながります。[コンソール](https://console.hanzo.ai)を開き、アプリを選び、自分のアカウントで承認し、（該当する場合）Hanzo が読み書きできるオブジェクトを範囲指定します。

## Salesforce

取引先と商談を要約し、フォローアップを下書きし、チャットからレコードを更新します。

**接続** — [コンソール](https://console.hanzo.ai) → **Salesforce** → 接続アプリを承認します。Hanzo は Salesforce のオブジェクトと項目に対するあなたの権限を尊重します。

## DocuSign

合意書を要約し、エンベロープを下書きし、署名状況を確認します。

**接続** — [コンソール](https://console.hanzo.ai) → **DocuSign** → OAuth で承認します。

## Notion

Notion のワークスペースで問い合わせ、要約し、下書きします。

**接続** — [コンソール](https://console.hanzo.ai) → **Notion** → 承認し、共有するページとデータベースを選びます。

## HubSpot

連絡先と取引を要約し、メールを下書きし、CRM のレコードを更新します。

**接続** — [コンソール](https://console.hanzo.ai) → **HubSpot** → OAuth で承認します。

## Shopify

店舗の質問に答え、注文を要約し、商品コピーを下書きします。

**接続** — [コンソール](https://console.hanzo.ai) → **Shopify** → 店舗向けにアプリを承認します。

> **ひとつのアイデンティティを、どこでも。** Hanzo でサインインする（[IAM](/docs/openapi/iam) の OAuth）か、`sk-` の [API キー](/docs/api-keys)を貼り付けます。同じ資格情報は Hanzo のあらゆる画面で使えます — [連携と拡張機能](/docs/apps)を参照してください。
