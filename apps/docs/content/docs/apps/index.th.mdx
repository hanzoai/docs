# การเชื่อมต่อและส่วนขยาย

Hanzo ทำงานในที่ที่คุณทำงาน ติดตั้งส่วนขยาย โหลดแอดอินจากด้านข้าง หรือเชื่อมแอปผ่าน OAuth — แล้ว AI เครื่องมือ และเอเจนต์ชุดเดียวกันจะตามคุณเข้าเบราว์เซอร์ ตัวแก้ไข กล่องจดหมาย CRM และเดสก์ท็อป

## คีย์ API เดียว ตัวตนเดียว ทุกที่

ทุกพื้นผิวด้านล่างเป็นไคลเอนต์บางบนรากฐานเดียวกัน:

- **[เกตเวย์ `@hanzo/ai`](/docs/openapi/gateway)** — URL ฐานเดียวที่เข้ากันได้กับ OpenAI คือ `https://api.hanzo.ai/v1` อยู่หน้าทุกโมเดลและเครื่องมือ
- **[ตัวตน `@hanzo/iam`](/docs/openapi/iam)** — บัญชีเดียวทุกแอป อยู่ในขอบเขตองค์กร และพร้อมสำหรับ SSO

คุณยืนยันตัวตน **ครั้งเดียว** ด้วยวิธีใดวิธีหนึ่ง:

1. **ลงชื่อเข้าใช้ด้วย Hanzo** — OAuth ผ่าน [Hanzo IAM](/docs/openapi/iam) คลิก **ลงชื่อเข้าใช้** อนุมัติ เสร็จ
2. **วางคีย์ `sk-`** — สร้างใน[คอนโซล](https://console.hanzo.ai) (ดู[คีย์ API](/docs/api-keys)) แล้ววางในการตั้งค่าของพื้นผิว

คีย์เดียวกันและตัวตนเดียวกันใช้ได้ในทุกส่วนขยาย แอดอิน และแอปที่เชื่อม เปลี่ยนองค์กรครั้งเดียว แล้วมีผลทุกที่

## ที่เกี่ยวข้อง

- [เกตเวย์](/docs/openapi/gateway) — API เดียวที่ทุกพื้นผิวเรียกใช้
