# Intégrations et extensions

Hanzo s'exécute là où vous travaillez. Installez une extension, chargez un complément en parallèle ou connectez une app via OAuth — et la même IA, les mêmes outils et les mêmes agents vous suivent dans le navigateur, l'éditeur, la boîte de réception, le CRM et le bureau.

## Une clé d'API, une identité, partout

Chaque surface ci-dessous est un client léger sur le même socle :

- **[Passerelle `@hanzo/ai`](/docs/openapi/gateway)** — une URL de base compatible OpenAI, `https://api.hanzo.ai/v1`, devant chaque modèle et outil.
- **[Identité `@hanzo/iam`](/docs/openapi/iam)** — un compte dans chaque app, limité à l'organisation et prêt pour le SSO.

Vous vous authentifiez **une seule fois**, de l'une ou l'autre façon :

1. **Se connecter avec Hanzo** — OAuth via [Hanzo IAM](/docs/openapi/iam). Cliquez sur **Se connecter**, approuvez, c'est fait.
2. **Coller une clé `sk-`** — créez-en une dans la [console](https://console.hanzo.ai) (voir [Clés d'API](/docs/api-keys)) et collez-la dans les réglages de la surface.

La même clé et la même identité fonctionnent dans chaque extension, complément et app connectée. Changez d'organisation une fois, et cela s'applique partout.
