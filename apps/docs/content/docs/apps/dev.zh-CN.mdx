# 开发 — GitHub 与 GitLab

自动代码审查、议题与合并请求分流，以及通过提及获得的即时帮助 — 就在你的仓库里。

## GitHub App

安装到你的组织或仓库，并加入：

- **请求审查** — Hanzo 审查拉取请求，并留下行内评论。
- **议题分流** — 为新议题打标签、写摘要并转发。
- **`@hanzo` 提及** — 在拉取请求或议题里提及 `@hanzo`，即可提问、请求修改或启动智能体。

**安装** — 在[控制台](https://console.hanzo.ai)选择 **GitHub**，安装 Hanzo GitHub App，并选择要授权的组织或仓库。批准所请求的权限后，Hanzo 就会开始审查新的拉取请求和议题。

## GitLab

对 GitLab 的合并请求和议题使用同一套审查与分流流程。

- **合并请求审查** — 在合并请求上留下行内审查评论。
- **议题分流** — 摘要、打标签并转发议题。
- **`@hanzo` 提及** — 在合并请求或议题里提及 `@hanzo` 以调用智能体。

**连接** — 在[控制台](https://console.hanzo.ai)选择 **GitLab**，通过 OAuth 授权（GitLab.com 或自托管），并挑选要启用的群组或项目。

> **一个身份，处处可用。** 使用 Hanzo 登录（[IAM](/docs/openapi/iam) OAuth），或粘贴一把 `sk-` [API 密钥](/docs/api-keys)。同一套凭据适用于 Hanzo 的每一个表面 — 参见[集成与扩展](/docs/apps)。
