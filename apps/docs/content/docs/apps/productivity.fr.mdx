# Productivité

Atteignez Hanzo depuis les outils qui rythment votre journée.

## Clio

Résumez les dossiers, rédigez la correspondance et interrogez les données de votre cabinet dans Clio (gestion de cabinet juridique).

**Connecter** — ouvrez la [console](https://console.hanzo.ai), choisissez **Clio** et autorisez via OAuth ; Hanzo respecte vos autorisations Clio sur les dossiers, les contacts et les documents.

## Raycast

Lancez Hanzo depuis la barre de commandes Raycast : interrogez, rédigez et exécutez des agents sans quitter le clavier.

**Installer** — ouvrez Raycast, recherchez **Hanzo** dans le **Raycast Store** et ajoutez l'extension. Définissez votre clé `sk-` dans les préférences de l'extension, ou exécutez la commande **Se connecter avec Hanzo**.

> **Une identité, partout.** Connectez-vous avec Hanzo (OAuth [IAM](/docs/openapi/iam)) ou collez une [clé d'API](/docs/api-keys) `sk-`. Le même identifiant fonctionne sur chaque surface Hanzo — voir [Intégrations et extensions](/docs/apps).
