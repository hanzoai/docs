# 통합 및 확장

Hanzo는 당신이 일하는 곳에서 실행됩니다. 확장을 설치하거나, 추가 기능을 옆으로 불러오거나, 앱을 OAuth로 연결하면 같은 AI, 도구, 에이전트가 브라우저, 편집기, 받은편지함, CRM, 데스크톱까지 따라옵니다.

## API 키 하나, 신원 하나, 어디서나

아래의 각 표면은 같은 기반 위의 얇은 클라이언트입니다.

- **[`@hanzo/ai` 게이트웨이](/docs/openapi/gateway)** — OpenAI와 호환되는 하나의 기본 URL, `https://api.hanzo.ai/v1`이 모든 모델과 도구 앞에 섭니다.
- **[`@hanzo/iam` 신원](/docs/openapi/iam)** — 모든 앱에 하나의 계정. 조직 범위이며 SSO에 준비되어 있습니다.

인증은 **한 번**입니다. 둘 중 하나로:

1. **Hanzo로 로그인** — [Hanzo IAM](/docs/openapi/iam)을 통한 OAuth. **로그인**을 누르고, 승인하면 끝입니다.
2. **`sk-` 키를 붙여 넣기** — [콘솔](https://console.hanzo.ai)에서 만들고([API 키](/docs/api-keys) 참조) 표면의 설정에 붙여 넣습니다.

같은 키와 같은 신원이 모든 확장, 추가 기능, 연결된 앱에서 동작합니다. 조직을 한 번 바꾸면 어디에나 적용됩니다.
