# 開發 — GitHub 與 GitLab

自動程式碼審查、議題與合併請求分流，以及透過提及取得的即時協助 — 就在你的存放庫裡。

## GitHub App

安裝到你的組織或存放庫，並加入：

- **請求審查** — Hanzo 審查拉取請求，並留下行內評論。
- **議題分流** — 為新議題加上標籤、寫摘要並轉送。
- **`@hanzo` 提及** — 在拉取請求或議題裡提及 `@hanzo`，即可提問、要求修改或啟動代理程式。

**安裝** — 在[主控台](https://console.hanzo.ai)選擇 **GitHub**，安裝 Hanzo GitHub App，並選擇要授權的組織或存放庫。核准所要求的權限後，Hanzo 就會開始審查新的拉取請求與議題。

## GitLab

對 GitLab 的合併請求與議題使用同一套審查與分流流程。

- **合併請求審查** — 在合併請求上留下行內審查評論。
- **議題分流** — 摘要、加上標籤並轉送議題。
- **`@hanzo` 提及** — 在合併請求或議題裡提及 `@hanzo` 以呼叫代理程式。

**連接** — 在[主控台](https://console.hanzo.ai)選擇 **GitLab**，透過 OAuth 授權（GitLab.com 或自行託管），並挑選要啟用的群組或專案。

> **一個身分，處處可用。** 使用 Hanzo 登入（[IAM](/docs/openapi/iam) OAuth），或貼上一把 `sk-` [API 金鑰](/docs/api-keys)。同一組憑證適用於 Hanzo 的每一個表面 — 參見[整合與擴充功能](/docs/apps)。
