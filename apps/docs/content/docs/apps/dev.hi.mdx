# विकास — GitHub और GitLab

स्वचालित कोड समीक्षा, इश्यू और मर्ज अनुरोधों की छँटाई, और उल्लेख पर माँग के अनुसार सहायता — सीधे आपके रिपॉज़िटरी में।

## GitHub App

आपके संगठन या रिपॉज़िटरी पर स्थापित होता है और जोड़ता है:

- **अनुरोध समीक्षा** — Hanzo पुल अनुरोधों की समीक्षा करता है और पंक्ति में टिप्पणियाँ छोड़ता है।
- **इश्यू छँटाई** — नए इश्यू को लेबल करता है, सार देता है और आगे भेजता है।
- **`@hanzo` उल्लेख** — प्रश्न पूछने, बदलाव माँगने या एजेंट शुरू करने के लिए किसी अनुरोध या इश्यू में `@hanzo` लिखें।

**इंस्टॉल करें** — [कंसोल](https://console.hanzo.ai) से **GitHub** चुनें, Hanzo GitHub App स्थापित करें, और जिस संगठन या रिपॉज़िटरी को पहुँच देनी है उसे चुनें। माँगी गई अनुमतियाँ स्वीकृत करें और Hanzo नए अनुरोधों और इश्यू की समीक्षा शुरू करता है।

## GitLab

GitLab मर्ज अनुरोधों और इश्यू के लिए वही समीक्षा और छँटाई प्रवाह।

- **मर्ज अनुरोध समीक्षा** — मर्ज अनुरोधों पर पंक्ति में समीक्षा टिप्पणियाँ।
- **इश्यू छँटाई** — इश्यू का सार, लेबल और मार्ग।
- **`@hanzo` उल्लेख** — एजेंट बुलाने के लिए मर्ज अनुरोध या इश्यू में `@hanzo` लिखें।

**कनेक्ट करें** — [कंसोल](https://console.hanzo.ai) से **GitLab** चुनें, OAuth से अधिकृत करें (GitLab.com या स्वयं होस्ट किया हुआ), और सक्षम करने के लिए समूह या प्रोजेक्ट चुनें।

> **एक पहचान, हर जगह।** Hanzo से साइन इन करें ([IAM](/docs/openapi/iam) OAuth) या एक `sk-` [API कुंजी](/docs/api-keys) चिपकाएँ। वही क्रेडेंशियल हर Hanzo सतह पर काम करता है — देखें [इंटीग्रेशन और एक्सटेंशन](/docs/apps)।
