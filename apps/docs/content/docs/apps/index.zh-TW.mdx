# 整合與擴充功能

Hanzo 在你工作的地方執行。安裝擴充功能、側載增益集，或透過 OAuth 連接應用程式 — 同一套 AI、工具與代理程式就會跟著你進入瀏覽器、編輯器、收件匣、CRM 與桌面。

## 一把 API 金鑰，一個身分，處處可用

下面的每個表面都是同一套基礎之上的精簡用戶端：

- **[`@hanzo/ai` 閘道](/docs/openapi/gateway)** — 一個與 OpenAI 相容的基底 URL，`https://api.hanzo.ai/v1`，位於每個模型與工具之前。
- **[`@hanzo/iam` 身分](/docs/openapi/iam)** — 每個應用程式一個帳戶，限定在組織範圍，並已準備好 SSO。

你**只認證一次**，兩種方式任選：

1. **使用 Hanzo 登入** — 透過 [Hanzo IAM](/docs/openapi/iam) 的 OAuth。點選**登入**，核准，完成。
2. **貼上一把 `sk-` 金鑰** — 在[主控台](https://console.hanzo.ai)建立（參見 [API 金鑰](/docs/api-keys)），再貼到該表面的設定裡。

同一把金鑰與同一個身分適用於每一個擴充功能、增益集與已連接的應用程式。切換一次組織，就會套用到各處。

## 開發者 SDK：建構應用程式與模組
