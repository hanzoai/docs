# 생산성

하루를 움직이는 도구에서 Hanzo에 닿으세요.

## Clio

Clio(법률 실무 관리) 안에서 사건을 요약하고, 서신을 작성하고, 실무 데이터를 조회합니다.

**연결** — [콘솔](https://console.hanzo.ai)을 열고 **Clio**를 선택한 뒤 OAuth로 승인합니다. Hanzo는 사건, 연락처, 문서에 대한 Clio 권한을 그대로 따릅니다.

## Raycast

Raycast 명령 막대에서 Hanzo를 실행합니다. 키보드에서 손을 떼지 않고 묻고, 초안을 쓰고, 에이전트를 돌립니다.

**설치** — Raycast를 열고 **Raycast Store**에서 **Hanzo**를 검색해 확장을 추가합니다. 확장 환경설정에 `sk-` 키를 설정하거나 **Hanzo로 로그인** 명령을 실행합니다.

> **하나의 신원, 어디서나.** Hanzo로 로그인하거나([IAM](/docs/openapi/iam) OAuth) `sk-` [API 키](/docs/api-keys)를 붙여 넣으세요. 같은 자격 증명이 Hanzo의 모든 표면에서 동작합니다 — [통합 및 확장](/docs/apps)을 보세요.
