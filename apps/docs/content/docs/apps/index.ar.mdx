# عمليات التكامل والإضافات

يعمل Hanzo حيث تعمل أنت. ثبّت امتدادًا، أو حمّل إضافة من الجانب، أو اربط تطبيقًا عبر OAuth — فيتبعك الذكاء الاصطناعي نفسه والأدوات نفسها والوكلاء أنفسهم إلى المتصفح والمحرّر وصندوق الوارد وCRM وسطح المكتب.

## مفتاح API واحد، هوية واحدة، في كل مكان

كل سطح أدناه عميل خفيف فوق الأساس نفسه:

- **[بوابة `@hanzo/ai`](/docs/openapi/gateway)** — عنوان URL أساسي واحد متوافق مع OpenAI، وهو `https://api.hanzo.ai/v1`، أمام كل نموذج وأداة.
- **[هوية `@hanzo/iam`](/docs/openapi/iam)** — حساب واحد عبر كل تطبيق، بنطاق المؤسسة وجاهز لـ SSO.

تُصادق **مرة واحدة**، بأي من الطريقتين:

1. **تسجيل الدخول باستخدام Hanzo** — OAuth عبر [Hanzo IAM](/docs/openapi/iam). انقر **تسجيل الدخول**، وافق، وانتهى الأمر.
2. **لصق مفتاح `sk-`** — أنشئ واحدًا في [وحدة التحكم](https://console.hanzo.ai) (انظر [مفاتيح API](/docs/api-keys)) والصقه في إعدادات السطح.

يعمل المفتاح نفسه والهوية نفسها في كل امتداد وإضافة وتطبيق مرتبط. بدّل المؤسسة مرة واحدة فيسري ذلك في كل مكان.
