Каждая модель ниже достигается одним ключом по одному адресу. Передайте `id` как
`model`, и остальная часть запроса одинакова, что бы вы ни выбрали.

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"<id from below>","messages":[{"role":"user","content":"Hello"}]}'
```

Таблица берётся из [`/v1/models`](/docs/openapi/ai) в браузере, когда
страница загружается, так что это каталог, который шлюз отдаёт сейчас, а не
копия, записанная при сборке страницы.

## Что означает тариф

Тарифы — за миллион токенов, вход и выход оцениваются отдельно, и они
одинаковы, зовёте ли вы из CLI, SDK, HTTP или инструмента MCP — цена
это свойство модели, а не поверхности, через которую вы к ней приходите.

[Цены](/docs/pricing) объясняют, как использование становится счётом. [Кредиты](/docs/credits)
описывают, что происходит, когда баланс кончается.
