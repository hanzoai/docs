# Консоль

Консоль Hanzo — единая поверхность управления Hanzo Cloud, то самое приложение, которое вы видите. Она собирает каждый облачный продукт в одном месте: учётные данные, ключи, секреты, модели, биллинг, развёртывания и панели, всё в пределах вашей организации.

## Одно приложение для каждого продукта

Консоль строится из единого каталога продуктов, поэтому каждый сервис Hanzo Cloud доступен из той же навигации, обзора и палитры команд. Каждый продукт — собственный модуль, а не внешняя ссылка, и опирается на настоящий API `/v1`:

- **ИИ** -- модели, песочница, поставщики, embeddings
- **Безопасность** -- [IAM](/docs/openapi/iam), [KMS](/docs/openapi/kms), [Authz](/docs/openapi/authz), [MPC](/docs/openapi), [Zero Trust](/docs/openapi/network)
- **Наблюдение** -- [панели](/docs/openapi/o11y), стоимость, [биллинг](/docs/openapi/billing), состояние
- **Развёртывание** -- проекты, среды, функции, кластеры

## Вход и область

Консоль входит через Hanzo IAM на [hanzo.id](https://hanzo.id) как приложение `hanzo-cloud`. Сеанс ограничен **организацией**, а глобальный администратор может переключить область на любую организацию; данные переназначаются на месте, а фирменный облик остаётся неизменным. См. [IAM](/docs/openapi/iam) и [Организации](/docs/openapi/iam).

## Как она поставляется

Консоль — одностраничное приложение, встроенное (`go:embed`) прямо в двоичный файл Hanzo Cloud и отдаваемое на `console.hanzo.ai`. Это чистый клиент над единым бэкендом `/v1`: своей базы данных у неё нет, каждое представление — реальные данные API сервиса.

```bash
# The console calls the same API you can call directly, with the same key
curl https://api.hanzo.ai/v1/models \
  -H "Authorization: Bearer sk-..."
```

## Связанное

- [IAM](/docs/openapi/iam) -- учётная запись и область организации за каждым представлением консоли
- [Ключи API](/docs/api-keys) -- создавайте ключи из консоли для API
- [Панели](/docs/openapi/o11y) -- поверхности аналитики и наблюдаемости
- [Биллинг](/docs/openapi/billing) -- баланс, использование и счета
- [API](/docs/openapi) -- та же поверхность `/v1`, которую отображает консоль
