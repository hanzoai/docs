**이 페이지를 읽고 나면 무엇을 쓰는지, 어디서 읽는지, 그리고
다 떨어지면 무슨 일이 일어나는지 압니다.**

좌석 라이선스도 없고 최소 금액도 없습니다. 잔액을 보유하고, 종량 호출은
공개된 요율로 그것을 깎으며, 아무것도 보내지 않는 계정에는
아무것도 청구되지 않습니다.

## 네 개의 명사

돈은 네 가지 기능이며, 서로 겹치지 않습니다.

| | 무엇을 답하는가 | 주소 |
|---|---|---|
| **[요금](/docs/openapi/pricing)** | 쓰기 전에, 한 단위가 얼마인가 | `/v1/pricing` |
| **[사용량](/docs/openapi/usage)** | 실제로 소비한 것 | `/v1/usage` |
| **[청구](/docs/openapi/billing)** | 잔액, 크레딧, 청구서 | `/v1/billing` |
| **[상거래](/docs/openapi/commerce)** | 위의 각각이 읽는 원장 | `/v1/commerce` |

그 순서로 읽으면 경제 전체가 한 문장입니다. **요금**이 요율을 말하고,
**사용량**이 수량을 말하고, **청구**가 돈을 말하며,
**상거래**는 나머지 셋이 렌즈로 들여다보는 원장입니다.

## 잔액 읽기

```bash
hanzo billing balance
```

```bash
curl https://api.hanzo.ai/v1/billing/balance \
  -H "Authorization: Bearer $HANZO_API_KEY"
```

크레딧은 `https://api.hanzo.ai/v1/billing/credits`에서 사거나 — 부여되며 —
모든 차감은 원장 항목이므로, 잔액은 누군가 손으로
유지한 숫자가 아닙니다. 소비한 것은 별도의 읽기입니다. 소비와
돈은 서로 다른 질문이기 때문입니다.

```bash
hanzo usage summary
```

## 두 개의 천장, 그리고 같은 것이 아닙니다

<Callout>
**잔액**은 가진 것입니다. **허용량**과 **상한**은 그중에서 쓰도록
허락된 것입니다. 이 셋을 혼동하는 것이, 잔액은 아직 건강해 보이는데 호출이
거절되는 흔한 이유입니다.
</Callout>

- **[허용량](/docs/openapi/allowance)** — 호출자가 그것에 대해 쓰는 상설 부여이며,
  `/v1/allowance`에 있습니다. 조직이 프로젝트, 키, 또는
  구성원에게 잔액 전체를 넘기지 않고 예산을 넘기는 방법입니다.
- **이동 상한** — 추론 관문에서 적용되는, AI 지출의 후행 창 천장입니다. 경계가 아니라 계속 재설정됩니다. 창보다 오래된 지출은 후행 합계에서 빠지므로, 월간 절벽도
  자정 재설정도 없습니다. 그 자체로 기능이 아니라 관문의 고리이므로
  주소도 페이지도 없습니다. 상한 자체는 운영자가 고치는
  플랫폼 깃발입니다.

## 0에서 일어나는 일

종량 호출은 거절됩니다. 일이 일어나기 전 관문에서 거절되므로,
실패할 호출에 대해 청구되지 않습니다 — 그리고 거절은
일반 오류를 돌려주는 대신 이유를 이름 붙이므로, 클라이언트는 짐작 없이
«크레딧 없음»과 «잘못된 키»를 구분합니다. 비용이 없는 읽기는
계속 응답합니다. 쓸 수 없는 잔액도 언제나 확인할 수 있습니다.

## 무엇이 비용을 내는 호출인가

대부분은 그렇지 않습니다. 기능은 코드 옆에 가격을 선언합니다 — 무료, 정액, 또는
종량 — 그리고 무료가 다수입니다. 프로젝트 나열, webhook의
전달 읽기, 자신의 프로필 가져오기입니다. 종량인 것은
실제 자원을 소비하는 것입니다 — 추론 토큰, 샌드박스 초, 발신 SMS,
수집한 페이지입니다.

각 기능 페이지가 자신의 답을 말하고, [요금](/docs/pricing)이
모든 모델과 도구의 요율표를 담습니다.
