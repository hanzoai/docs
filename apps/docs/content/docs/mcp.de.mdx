# MCP

Ein Server des Modellkontextprotokolls, eine Werkzeugoberfläche. Fügen Sie **`hanzo-mcp`** zu Claude Code hinzu (oder zu Cursor, Claude Desktop oder jedem MCP-Client), und jede Hanzo-Fähigkeit erscheint über eine einzige Verbindung — ohne Verdrahtung je Werkzeug.

> Sie suchen stattdessen den gehosteten MCP-Server? **[Cloud-MCP](/docs/mcp-tools)** ist eine URL ohne Installation, und jedes seiner Werkzeuge ist im [Werkzeugkatalog](/docs/mcp-tools/all-tools) aufgezählt. Diese Seite ist der Server, der neben Ihrem Editor läuft.

```bash title="Add the Hanzo MCP to Claude Code"
claude mcp add hanzo -- npx -y @hanzo/mcp serve
```

Dieser eine Befehl legt die ganze Oberfläche frei:

- **13 vereinheitlichte Werkzeuge** — `fs`, `exec`, `code`, `git`, `fetch`, `workspace`, `ui`, plus die optionalen `think`, `memory`, `hanzo`, `plan`, `tasks`, `mode`. Ein nach Aktion geroutetes Werkzeug je Fähigkeit (HIP-0300), sodass der Client eine kleine, stabile Menge sieht statt Hunderter sich überlappender Namen.
- **Cloud-Dienste** — das Werkzeug `hanzo` leitet nativ zu Ihrer Plattform: IAM (Identität), Commerce, Storage und die KI-API unter `api.hanzo.ai/v1`, authentifiziert mit Ihrem Token.
- **Ihre Konnektoren** — GitHub, Slack, Google, Discord, X und mehr, über dieselbe Verbindung sichtbar, sobald sie in der Konsole verknüpft sind.

Dieselbe Oberfläche wird auf drei Wegen ausgeliefert — TypeScript (`@hanzo/mcp`), Python (`hanzo-mcp` auf PyPI) und Rust (`hanzo-mcp::brain`) — eins zu eins gespiegelt, über die MCP-Transporte **stdio** und **streamable-http**.

## Client-Einrichtung

```json title="Claude Desktop / Cursor — mcp config"
{
  "mcpServers": {
    "hanzo": {
      "command": "npx",
      "args": ["-y", "@hanzo/mcp", "serve"]
    }
  }
}
```

Melden Sie sich einmal an (`hanzo auth login`), und das Cloud-Werkzeug `hanzo` plus Ihre Konnektoren authentifizieren sich von selbst; die lokalen Werkzeuge (`fs`, `exec`, `git`, …) funktionieren ohne Konto.

## Der Werkzeugindex

Jedes Werkzeug, das die Plattform offenlegen kann, ist unter `GET api.hanzo.ai/v1/tools` indexiert (authentifiziert). Heute sind das **1,468 Werkzeuge** aus fünf Quellen — der vereinheitlichte Server stellt sie über die kompakte, nach Aktion geroutete Oberfläche oben dar:

| Quelle | Was es ist |
|--------|-----------|
| `builtin` | Lokale Kernwerkzeuge (fs, exec, git, code, …) |
| `skill` | Gepackte Fertigkeiten |
| `connector` | Verknüpfte Cloud-Integrationen (GitHub, Slack, Google, Discord, X, …) |
| `agent` | Einstiegspunkte von Agenten |
| `function` | Vom Benutzer definierte Funktionen |

## MCP als Dienst

Über den vereinheitlichten Server hinaus kann Hanzo auch jeden MCP-Server für Sie **hosten** — bereitstellen aus jedem npx-, uvx- oder eigenen Paket, mit sofortiger Skalierung und null zu verwaltender Infrastruktur.

```bash title="Launch an MCP server"
hanzo mcp launch npx @modelcontextprotocol/server-filesystem
```

## Zentrale Fähigkeiten

- **Jeder MCP-Server** — Dateisystem, Git, SQL, KV, Slack, GitHub, Notion und mehr
- **Bereitstellung mit einem Klick** — starten Sie jeden MCP-Server mit einem Befehl
- **Automatische Skalierung** — skalieren Sie automatisch von 0 auf Tausende von Instanzen
- **Leerlaufkosten von $0** — Sie zahlen nur, was Sie nutzen, keine Leerlaufgebühren
- **Sichere Sandbox** — isolierte Container mit feinkörnigen Berechtigungen
- **Mehr als 15 Regionen** — Randbereitstellung für die geringste Latenz weltweit

## Startmethoden

### NPX-Pakete

```bash
hanzo mcp launch npx @modelcontextprotocol/server-filesystem
hanzo mcp launch npx @modelcontextprotocol/server-github
hanzo mcp launch npx @modelcontextprotocol/server-slack
```

### UVX / Python

```bash
hanzo mcp launch uvx mcp-server-sqlite
hanzo mcp launch uvx mcp-server-postgres
```

### Eigene Server

```bash
hanzo mcp launch git://github.com/you/mcp-server
hanzo mcp launch docker://your-org/mcp-custom:latest
```

## Konfiguration

Stellen Sie mehrere Server mit einer einzigen Konfigurationsdatei bereit:

```yaml title="mcp-config.yaml"
version: "1"
servers:
  filesystem:
    package: "@modelcontextprotocol/server-filesystem"
    runtime: npx
    args: ["/workspace"]

  database:
    package: "mcp-server-postgres"
    runtime: uvx
    env:
      DATABASE_URL: "${secrets.DATABASE_URL}"

  github:
    package: "@modelcontextprotocol/server-github"
    runtime: npx
    env:
      GITHUB_TOKEN: "${secrets.GITHUB_TOKEN}"

  custom:
    image: "your-org/mcp-custom:latest"
    runtime: docker
    replicas: 3
```

```bash
hanzo mcp deploy
```

## Nächste Entwicklung: ZAP

MCP hat die Werkzeugintegration leicht gemacht. **ZAP macht sie schnell.** Das Zero-Copy-Agentenprotokoll ist die nächste Entwicklung: Serialisierung ohne Kopie, 40- bis 50-fach geringerer Aufwand, gebaut für Agentenschwärme in der Fläche.

ZAP enthält den **MCP-Gateway-Modus** für eine nahtlose Migration.
