**После этой страницы у вас есть рабочее удостоверение и один вызов, который ответил.**

Hanzo — одно облако за одним ключом. Каждая возможность — инференс, личность,
хранилище, деньги, агенты — отвечает на `https://api.hanzo.ai`, а CLI,
SDK и инструменты MCP порождены одним и тем же описанием. Ничего не нужно
подключать по сервисам: один ключ — и всё досягаемо.

## 1. Установка

<Tabs items={['npm', 'Script', 'Homebrew', 'Из исходников']}>
<Tab value="npm">
```bash

```

`hanzo` — это CLI и клиент в одной установке.
</Tab>
<Tab value="Script">
```bash

```

Ставится в `~/.local/bin`. `https://hanzo.sh/cli` ставит только CLI.
</Tab>

</Tab>
<Tab value="Из исходников">
```bash
git clone https://github.com/hanzoai/cli && cd cli && cargo install --path .
```
</Tab>
</Tabs>

```bash
hanzo version
```

## 2. Вход

```bash
hanzo auth login
```

Открывается браузер на [hanzo.id](https://hanzo.id), провайдере личности
Hanzo, и удостоверение сохраняется локально. `hanzo auth show` печатает,
кто вы; `hanzo auth list` показывает каждую личность на этой машине, а
`hanzo auth use` переключает их.

На сервере выпустите ключ, а не входите как человек: **console.hanzo.ai →
ключи API**. Секретный ключ — это *вы*, поэтому он живёт на сервере и никогда
в браузере — [Аутентификация](/docs/api-keys) и есть всё правило.

```bash
export HANZO_API_KEY=sk-...
```

Все они порождены одним описанием API, поэтому имена
методов совпадают между языками. [C++](/docs/sdks/cpp) — тот, что ещё
доезжает.
</Tab>
<Tab value="HTTP">
```bash
curl https://api.hanzo.ai/v1/models \
  -H "Authorization: Bearer $HANZO_API_KEY"
```
</Tab>
<Tab value="MCP">
```bash
curl -X POST https://api.hanzo.ai/v1/mcp \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

Одна конечная точка, один инструмент на возможность. `tools/call` называет возможность и
операцию; `describe` объясняет вход любой операции.
</Tab>
</Tabs>

Это один API, увиденный из четырёх мест, и вкладки выше — вся
разница. Выберите то, на чём будете писать:

- **[CLI](/docs/cli)** — каждая возможность как группа команд, по странице на каждую.
- **[SDK](/docs/sdks)** — Python, TypeScript, Go, Rust, C++, Swift и Kotlin,
  порождённые тем же описанием, что CLI и инструменты.
- **[MCP](/docs/mcp)** — одна конечная точка, к которой подключается агент; [инструменты](/docs/mcp-tools)
  перечислены по одному на возможность.

HTTP не нужна страница: это `https://api.hanzo.ai` и ключ, который вы только что экспортировали.

## 4. Отправьте завершение

Это первый шаг, который тратит кредит; всё выше можно выполнить бесплатно.

```bash
hanzo chat completions --model zen-1 --messages '[{"role":"user","content":"hello"}]'
```

Затем прочитайте, сколько он списал:

```bash
hanzo billing balance
hanzo usage summary
```

[Кредиты и счета](/docs/credits) объясняют, что такое кредит и что происходит на
нуле; [Цены](/docs/pricing) — ставка каждой модели и инструмента.

## 5. Запустите облако локально

Тот же бинарник, что обслуживает `api.hanzo.ai`, работает на вашей машине:

```bash
hanzo up cloud
```

Просто `hanzo up` — то же самое, `cloud` по умолчанию. Назовите один сервис, чтобы
запустить его отдельно: `hanzo up iam`, `hanzo up kms`, `hanzo up gateway`, `hanzo up
storage`, `hanzo up pubsub`. Смотрите [Запустите своё](/docs/network), что это
значит и что для этого нужно.
