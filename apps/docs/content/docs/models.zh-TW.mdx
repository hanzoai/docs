下面的每個模型都用一把鑰匙、一個位址就能到達。把 `id` 當作
`model` 傳入，無論選哪個，請求的其餘部分都一樣。

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"<id from below>","messages":[{"role":"user","content":"Hello"}]}'
```

頁面載入時，瀏覽器從 [`/v1/models`](/docs/openapi/ai) 取這張表，所以它是閘道此刻
在提供的目錄，不是建頁面時抄下來的副本。

## 費率是什麼意思

費率按每百萬 token 計，輸入和輸出分開定價，從 CLI、SDK、HTTP 或 MCP 工具
呼叫都一樣 — 價格是模型的屬性，不是你到達它的那個表面的屬性。

[價格](/docs/pricing)說明用量如何變成帳單。[額度](/docs/credits)
說明餘額用盡時會發生什麼。
