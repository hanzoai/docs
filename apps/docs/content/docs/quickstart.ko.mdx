**이 페이지가 끝나면 동작하는 자격 증명과 답을 받은 호출이 하나 있습니다.**

Hanzo는 열쇠 하나 뒤의 클라우드 하나입니다. 추론, 신원,
저장, 돈, 에이전트 — 모든 능력은 `https://api.hanzo.ai`에서 답하고, CLI와
SDK, MCP 도구는 같은 설명에서 만들어집니다. 서비스마다 연결할
것은 없습니다. 열쇠를 한 번 받으면 전부가 닿습니다.

## 1. 설치

<Tabs items={['npm', 'Script', 'Homebrew', '소스에서']}>
<Tab value="npm">
```bash
npm i -g hanzo
```

`hanzo`는 한 번의 설치에 CLI이자 클라이언트입니다.
</Tab>
<Tab value="Script">
```bash
curl -fsSL https://hanzo.sh | sh
```

`~/.local/bin`에 설치됩니다. `https://hanzo.sh/cli`는 CLI만 설치합니다.
</Tab>
<Tab value="Homebrew">
```bash
brew install hanzoai/tap/hanzo
```
</Tab>
<Tab value="소스에서">
```bash
git clone https://github.com/hanzoai/cli && cd cli && cargo install --path .
```
</Tab>
</Tabs>

```bash
hanzo version
```

## 2. 로그인

```bash
hanzo auth login
```

Hanzo의 신원 제공자 [hanzo.id](https://hanzo.id)로 브라우저가 열리고
자격 증명은 로컬에 저장됩니다. `hanzo auth show`는 당신이
누구인지 출력하고, `hanzo auth list`는 이 머신의 모든 신원을 보여 주며
`hanzo auth use`는 그 사이를 바꿉니다.

서버에서는 사람을 로그인시키지 말고 키를 만드세요. **console.hanzo.ai →
API 키**. 비밀 키는 *당신*이므로 서버에 두고 브라우저에는
절대 두지 않습니다 — [인증](/docs/api-keys)이 규칙의 전부입니다.

```bash
export HANZO_API_KEY=sk-...
```

## 3. 모델 나열

게이트웨이가 지금 제공하는 모델 목록입니다. 읽기이고, 필요한 것은
키뿐이며, 네 표면에서 같은 연산입니다.

<Tabs items={['CLI', 'SDK', 'HTTP', 'MCP']}>
<Tab value="CLI">
```bash
hanzo models list
```
</Tab>
<Tab value="SDK">
<Tabs items={['.ts', '.py', '.go', '.rs', '.swift', '.kt']}>
<Tab value=".ts">
```bash
npm i hanzo
```

```ts

const hanzo = new Hanzo({ apiKey: process.env.HANZO_API_KEY })
const models = await hanzo.models.list()
```
</Tab>
<Tab value=".py">
```bash
pip install hanzo
```

```python
from hanzo import Hanzo

hanzo = Hanzo(api_key=os.environ["HANZO_API_KEY"])
models = hanzo.models.list()
```
</Tab>
<Tab value=".go">
```bash
go get github.com/hanzoai/go-sdk
```

```go
client := hanzo.NewClient(hanzo.WithAPIKey(os.Getenv("HANZO_API_KEY")))
models, err := client.Models.List(ctx)
```
</Tab>
<Tab value=".rs">
```bash
cargo add hanzo
```

```rust
let hanzo = hanzo::Client::from_env()?;
let models = hanzo.models().list().await?;
```
</Tab>
<Tab value=".swift">
```swift
// Package.swift: .package(url: "https://github.com/hanzoai/swift-sdk", from: "1.0.0")

```
</Tab>
<Tab value=".kt">
```kotlin

val models = hanzo.models.list()
```
</Tab>
</Tabs>

모두 같은 API 설명에서 만들어지므로 메서드 이름이
언어 사이에서 맞습니다. [C++](/docs/sdks/cpp)는 아직
도착 중인 것입니다.
</Tab>
<Tab value="HTTP">
```bash
curl https://api.hanzo.ai/v1/models \
  -H "Authorization: Bearer $HANZO_API_KEY"
```
</Tab>
<Tab value="MCP">
```bash
curl -X POST https://api.hanzo.ai/v1/mcp \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

엔드포인트 하나, 능력마다 도구 하나. `tools/call`은 능력과
연산을 이름 붙이고, `describe`는 어떤 연산의 입력이든 설명합니다.
</Tab>
</Tabs>

한 API를 네 곳에서 본 것이고, 위의 탭이 차이의
전부입니다. 쓸 것을 고르세요.

- **[CLI](/docs/cli)** — 능력마다 명령 그룹, 각각 한 페이지.
- **[SDK](/docs/sdks)** — Python, TypeScript, Go, Rust, C++, Swift, Kotlin.
  CLI와 도구와 같은 설명에서 생성됩니다.
- **[MCP](/docs/mcp)** — 에이전트가 붙는 엔드포인트 하나. [도구](/docs/mcp-tools)는
  능력마다 하나씩 나열됩니다.

HTTP에는 페이지가 필요 없습니다. `https://api.hanzo.ai`와 방금 내보낸 키입니다.

## 4. 완성을 보내기

크레딧을 쓰는 첫 단계입니다. 그 위는 무료로 실행할 수 있습니다.

```bash
hanzo chat completions --model zen-1 --messages '[{"role":"user","content":"hello"}]'
```

그런 다음 얼마를 썼는지 읽으세요.

```bash
hanzo billing balance
hanzo usage summary
```

[크레딧과 청구](/docs/credits)는 크레딧이 무엇이고 0에서 무슨 일이 일어나는지 설명합니다.
[가격](/docs/pricing)은 모델과 도구마다의 요율입니다.

## 5. 클라우드를 로컬에서 실행

`api.hanzo.ai`를 제공하는 같은 바이너리가 당신의 머신에서 돕니다.

```bash
hanzo up cloud
```

그냥 `hanzo up`도 같습니다 — `cloud`가 기본입니다. 하나만 돌리려면 서비스를 이름 붙이세요.
`hanzo up iam`, `hanzo up kms`, `hanzo up gateway`, `hanzo up
storage`, `hanzo up pubsub`. 그것이 무슨 뜻이고 무엇이 필요한지는 [직접 실행](/docs/network)을 보세요.
