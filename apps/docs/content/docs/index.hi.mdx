## हर मॉडल, एक कुंजी

<ProviderStrip />

[हम जो हर मॉडल देते हैं](/docs/openapi/ai) उसे देखें — सूची लाइव है, इसलिए जो id आप
कॉपी करते हैं और उसके बगल की दर गेटवे का अभी का उत्तर है — भेजने से पहले [एक अनुरोध की
कीमत](/docs/pricing) भी देखें.

## इसे साथ ले जाएँ

ऊपर का क्लाउड और जिसे आप खुद चला सकते हैं [वही
सॉफ़्टवेयर](/docs/network) है — वही बाइनरी, वही अनुबंध, वही `/v1` मार्ग. अपना
GPU या Kubernetes लाएँ, या किसी भी डिवाइस पर माइन करें.

```bash
curl -fsSL https://hanzo.sh | sh
```

<Callout type="info">
यह **V8 · Open Edition** है, [HIP-0127](https://hips.hanzo.ai) में लिखा हुआ:
एक अनुबंध, कई बाइंडिंग, पतले क्लाइंट, और भाषाओं के बीच एक तार — कभी FFI नहीं.
*क्यों* के लिए [इंजीनियरिंग दर्शन](/docs/architecture/philosophy) देखें.
</Callout>

## इससे बनाएँ

- [`hanzo` CLI](/docs/openapi/platform) — लगभग 15 MB का Rust बाइनरी, जो किसी भी चालू क्लाउड से बात करता है: प्रोड, लैपटॉप या खुद होस्ट
- [SDK](/docs/sdks) — Python, TypeScript, Go, Rust और अन्य, सब एक अनुबंध से निकले
- [API संदर्भ](/docs/openapi) — हर एंडपॉइंट, अपनी स्पेक से बना
- [ZAP प्रोटोकॉल](/docs/zap) — Zero-Copy App Proto, वह तार जिससे Go और Rust आधे बात करते हैं
- [Zen मॉडल](https://zenlm.org) — अग्रिम ओपन-वेट मॉडल, 4B एज से 1T+ तर्क तक
- [आर्किटेक्चर](/docs/architecture) — एक बाइनरी, एक अनुबंध, और क्यों
