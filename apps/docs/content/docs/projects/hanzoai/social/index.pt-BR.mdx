## O que é isto

Hanzo Social é uma bifurcação firme de [`gitroomhq/postiz-app`](https://github.com/gitroomhq/postiz-app) (AGPL-3.0), com marca nova e integrada à plataforma Hanzo:

- **Autenticação** — Hanzo IAM (`hanzo.id`) via OIDC (`IAM_CLIENT_ID=hanzo-social`).
- **Armazenamento** — Hanzo S3 (`s3-api.hanzo.ai`).
- **Segredos** — Hanzo KMS (`kms.hanzo.ai`) pelo contêiner de arranque `kms-fetch`.
- **E-mail** — `social@hanzo.ai` a partir do relé SMTP compartilhado.
- **Robô** — `~/work/hanzo/bot` expõe `/social {schedule|draft|integrations}` contra este serviço.

A origem continua sendo a fonte da verdade do motor de agendamento; a marca e a cola com a plataforma vivem neste repositório.

## Desenvolver

```bash
pnpm install
pnpm dev
```

Veja `CLAUDE.md` para a disposição do repositório e `apps/`, `libraries/` para o serviço NestJS, a face Vite e o trabalhador Temporal.
