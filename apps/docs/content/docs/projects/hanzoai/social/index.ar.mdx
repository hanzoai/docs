## ما هذا

Hanzo Social تفرع حاد من [`gitroomhq/postiz-app`](https://github.com/gitroomhq/postiz-app) (AGPL-3.0)، أُعيدت تسميته ودُمج في منصة Hanzo:

- **المصادقة** — Hanzo IAM (`hanzo.id`) عبر OIDC (`IAM_CLIENT_ID=hanzo-social`).
- **التخزين** — Hanzo S3 (`s3-api.hanzo.ai`).
- **الأسرار** — Hanzo KMS (`kms.hanzo.ai`) عبر حاوية البدء `kms-fetch`.
- **البريد** — `social@hanzo.ai` من مرحّل SMTP المشترك.
- **الروبوت** — `~/work/hanzo/bot` يعرض `/social {schedule|draft|integrations}` مقابل هذه الخدمة.

يبقى المنبع مصدر الحقيقة لمحرك الجدولة؛ والعلامة وصمغ المنصة يعيشان في هذا المستودع.

## التطوير

```bash
pnpm install
pnpm dev
```

انظر `CLAUDE.md` لتخطيط المستودع و`apps/` و`libraries/` لخدمة NestJS ووجه Vite وعامل Temporal.
