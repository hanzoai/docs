## Bu nedir

Hanzo Social, [`gitroomhq/postiz-app`](https://github.com/gitroomhq/postiz-app) (AGPL-3.0) projesinin sert bir çatalıdır; yeniden markalanmış ve Hanzo platformuna bağlanmıştır:

- **Kimlik doğrulama** — OIDC ile Hanzo IAM (`hanzo.id`) (`IAM_CLIENT_ID=hanzo-social`).
- **Depolama** — Hanzo S3 (`s3-api.hanzo.ai`).
- **Gizler** — `kms-fetch` başlangıç kapsayıcısı üzerinden Hanzo KMS (`kms.hanzo.ai`).
- **E-posta** — paylaşılan SMTP rölesinden `social@hanzo.ai`.
- **Bot** — `~/work/hanzo/bot`, bu hizmete karşı `/social {schedule|draft|integrations}` açar.

Yukarı akış, zamanlama motoru için doğruluk kaynağı olarak kalır; marka ve platform yapıştırıcısı bu depoda durur.

## Geliştirme

```bash
pnpm install
pnpm dev
```

Depo düzeni için `CLAUDE.md` dosyasına, NestJS hizmeti, Vite yüzü ve Temporal işçisi için `apps/` ile `libraries/` dizinlerine bakın.
