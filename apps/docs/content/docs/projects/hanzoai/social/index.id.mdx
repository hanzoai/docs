## Apa ini

Hanzo Social adalah cabang tegas dari [`gitroomhq/postiz-app`](https://github.com/gitroomhq/postiz-app) (AGPL-3.0), diberi merek baru dan disatukan dengan platform Hanzo:

- **Autentikasi** — Hanzo IAM (`hanzo.id`) lewat OIDC (`IAM_CLIENT_ID=hanzo-social`).
- **Penyimpanan** — Hanzo S3 (`s3-api.hanzo.ai`).
- **Rahasia** — Hanzo KMS (`kms.hanzo.ai`) lewat kontainer awal `kms-fetch`.
- **Surel** — `social@hanzo.ai` dari relai SMTP bersama.
- **Robot** — `~/work/hanzo/bot` membuka `/social {schedule|draft|integrations}` terhadap layanan ini.

Hulu tetap menjadi sumber kebenaran mesin penjadwalan; merek dan perekat platform tinggal di repositori ini.

## Mengembangkan

```bash
pnpm install
pnpm dev
```

Lihat `CLAUDE.md` untuk tata repositori dan `apps/`, `libraries/` untuk layanan NestJS, muka Vite, dan pekerja Temporal.
