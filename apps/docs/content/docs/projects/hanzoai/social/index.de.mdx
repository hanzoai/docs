## Worum es geht

Hanzo Social ist eine bewusste Abspaltung von [`gitroomhq/postiz-app`](https://github.com/gitroomhq/postiz-app) (AGPL-3.0), neu benannt und in die Hanzo-Plattform eingebunden:

- **Anmeldung** — Hanzo IAM (`hanzo.id`) über OIDC (`IAM_CLIENT_ID=hanzo-social`).
- **Speicher** — Hanzo S3 (`s3-api.hanzo.ai`).
- **Geheimnisse** — Hanzo KMS (`kms.hanzo.ai`) über den Anfangscontainer `kms-fetch`.
- **E-Mail** — `social@hanzo.ai` über das gemeinsame SMTP-Relais.
- **Automat** — `~/work/hanzo/bot` bietet `/social {schedule|draft|integrations}` gegen diesen Dienst an.

Der Ursprung bleibt die maßgebliche Quelle der Planungsmechanik; Marke und die Verbindung zur Plattform leben in diesem Repository.

## Entwickeln

```bash
pnpm install
pnpm dev
```

Siehe `CLAUDE.md` für den Aufbau des Repositorys und `apps/`, `libraries/` für den NestJS-Dienst, die Vite-Oberfläche und den Temporal-Arbeiter.
