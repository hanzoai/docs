## สิ่งนี้คืออะไร

Hanzo Social เป็นการแยกสาขาอย่างชัดจาก [`gitroomhq/postiz-app`](https://github.com/gitroomhq/postiz-app) (AGPL-3.0) เปลี่ยนแบรนด์และผสานเข้ากับแพลตฟอร์ม Hanzo:

- **การยืนยันตัวตน** — Hanzo IAM (`hanzo.id`) ผ่าน OIDC (`IAM_CLIENT_ID=hanzo-social`).
- **ที่เก็บ** — Hanzo S3 (`s3-api.hanzo.ai`).
- **ความลับ** — Hanzo KMS (`kms.hanzo.ai`) ผ่านคอนเทนเนอร์เริ่มต้น `kms-fetch`.
- **อีเมล** — `social@hanzo.ai` จากรีเลย์ SMTP ที่ใช้ร่วมกัน
- **บอต** — `~/work/hanzo/bot` เปิด `/social {schedule|draft|integrations}` ต่อบริการนี้

ต้นน้ำยังเป็นแหล่งความจริงของเครื่องตั้งเวลา แบรนด์และกาวของแพลตฟอร์มอยู่ในที่เก็บนี้

## พัฒนา

```bash
pnpm install
pnpm dev
```

ดู `CLAUDE.md` สำหรับผังที่เก็บ และ `apps/`, `libraries/` สำหรับบริการ NestJS, หน้า Vite และคนทำงาน Temporal
