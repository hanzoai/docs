## Che cos'è

Hanzo Social è una diramazione netta di [`gitroomhq/postiz-app`](https://github.com/gitroomhq/postiz-app) (AGPL-3.0), rinominata e integrata nella piattaforma Hanzo:

- **Autenticazione** — Hanzo IAM (`hanzo.id`) tramite OIDC (`IAM_CLIENT_ID=hanzo-social`).
- **Archiviazione** — Hanzo S3 (`s3-api.hanzo.ai`).
- **Segreti** — Hanzo KMS (`kms.hanzo.ai`) tramite il contenitore di avvio `kms-fetch`.
- **Posta** — `social@hanzo.ai` dal relè SMTP condiviso.
- **Automa** — `~/work/hanzo/bot` espone `/social {schedule|draft|integrations}` verso questo servizio.

La sorgente a monte resta la fonte di verità del motore di pianificazione; il marchio e la colla con la piattaforma vivono in questo deposito.

## Sviluppare

```bash
pnpm install
pnpm dev
```

Vedi `CLAUDE.md` per la disposizione del deposito e `apps/`, `libraries/` per il servizio NestJS, la facciata Vite e il lavoratore Temporal.
