## これは何か

Hanzo Social は [`gitroomhq/postiz-app`](https://github.com/gitroomhq/postiz-app)（AGPL-3.0）の明確な分岐で、名称を改め、Hanzo プラットフォームに組み込んである。

- **認証** — OIDC 経由の Hanzo IAM（`hanzo.id`）（`IAM_CLIENT_ID=hanzo-social`）。
- **ストレージ** — Hanzo S3（`s3-api.hanzo.ai`）。
- **秘密** — 初期化コンテナ `kms-fetch` 経由の Hanzo KMS（`kms.hanzo.ai`）。
- **メール** — 共有 SMTP 中継からの `social@hanzo.ai`。
- **ボット** — `~/work/hanzo/bot` がこのサービスに対して `/social {schedule|draft|integrations}` を出す。

上流はスケジューリング機構の正とする源のまま。ブランドとプラットフォームとの接着は、このリポジトリにある。

## 開発

```bash
pnpm install
pnpm dev
```

リポジトリの配置は `CLAUDE.md`。NestJS のサービス、Vite の面、Temporal の作業者は `apps/` と `libraries/`。
