## 这是什么

Hanzo Social 是 [`gitroomhq/postiz-app`](https://github.com/gitroomhq/postiz-app)（AGPL-3.0）的硬分叉，已更换品牌并接入 Hanzo 平台：

- **认证** — 经 OIDC 的 Hanzo IAM（`hanzo.id`）（`IAM_CLIENT_ID=hanzo-social`）。
- **存储** — Hanzo S3（`s3-api.hanzo.ai`）。
- **机密** — 经初始化容器 `kms-fetch` 的 Hanzo KMS（`kms.hanzo.ai`）。
- **邮件** — 来自共享 SMTP 中继的 `social@hanzo.ai`。
- **机器人** — `~/work/hanzo/bot` 对着这个服务开放 `/social {schedule|draft|integrations}`。

上游仍是排程引擎的事实来源；品牌和与平台的粘合位于本仓库。

## 开发

```bash
pnpm install
pnpm dev
```

仓库布局见 `CLAUDE.md`；NestJS 服务、Vite 界面与 Temporal 工作者见 `apps/`、`libraries/`。
