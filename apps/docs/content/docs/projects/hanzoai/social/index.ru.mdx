## Что это

Hanzo Social — жёсткое ответвление [`gitroomhq/postiz-app`](https://github.com/gitroomhq/postiz-app) (AGPL-3.0), с новой маркой и встройкой в платформу Hanzo:

- **Проверка личности** — Hanzo IAM (`hanzo.id`) через OIDC (`IAM_CLIENT_ID=hanzo-social`).
- **Хранилище** — Hanzo S3 (`s3-api.hanzo.ai`).
- **Секреты** — Hanzo KMS (`kms.hanzo.ai`) через начальный контейнер `kms-fetch`.
- **Почта** — `social@hanzo.ai` с общего реле SMTP.
- **Бот** — `~/work/hanzo/bot` открывает `/social {schedule|draft|integrations}` к этой службе.

Вышестоящий источник остаётся истиной для движка планирования; марка и связка с платформой живут в этом репозитории.

## Разработка

```bash
pnpm install
pnpm dev
```

См. `CLAUDE.md` про раскладку репозитория и `apps/`, `libraries/` — служба NestJS, лицо Vite и работник Temporal.
