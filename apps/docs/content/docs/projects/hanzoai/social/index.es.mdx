## Qué es esto

Hanzo Social es una bifurcación firme de [`gitroomhq/postiz-app`](https://github.com/gitroomhq/postiz-app) (AGPL-3.0), con marca nueva e integrada en la plataforma Hanzo:

- **Autenticación** — Hanzo IAM (`hanzo.id`) mediante OIDC (`IAM_CLIENT_ID=hanzo-social`).
- **Almacenamiento** — Hanzo S3 (`s3-api.hanzo.ai`).
- **Secretos** — Hanzo KMS (`kms.hanzo.ai`) mediante el contenedor de arranque `kms-fetch`.
- **Correo** — `social@hanzo.ai` desde el relé SMTP compartido.
- **Robot** — `~/work/hanzo/bot` expone `/social {schedule|draft|integrations}` frente a este servicio.

El origen sigue siendo la fuente de verdad del motor de programación; la marca y el pegamento con la plataforma viven en este repositorio.

## Desarrollar

```bash
pnpm install
pnpm dev
```

Consulta `CLAUDE.md` para la disposición del repositorio y `apps/`, `libraries/` para el servicio NestJS, la cara Vite y el trabajador Temporal.
