## 이것이 무엇인가

Hanzo Social은 [`gitroomhq/postiz-app`](https://github.com/gitroomhq/postiz-app)(AGPL-3.0)의 분명한 분기이며, 이름을 바꾸고 Hanzo 플랫폼에 묶어 두었다.

- **인증** — OIDC를 거친 Hanzo IAM(`hanzo.id`) (`IAM_CLIENT_ID=hanzo-social`).
- **저장소** — Hanzo S3 (`s3-api.hanzo.ai`).
- **비밀** — 시작 컨테이너 `kms-fetch`를 거친 Hanzo KMS (`kms.hanzo.ai`).
- **메일** — 공유 SMTP 중계에서 오는 `social@hanzo.ai`.
- **봇** — `~/work/hanzo/bot`이 이 서비스에 대해 `/social {schedule|draft|integrations}`를 연다.

상류는 일정 엔진의 기준 원본으로 남는다. 브랜드와 플랫폼 접착은 이 저장소에 있다.

## 개발

```bash
pnpm install
pnpm dev
```

저장소 배치는 `CLAUDE.md`. NestJS 서비스, Vite 면, Temporal 작업자는 `apps/`와 `libraries/`.
