## De quoi il s'agit

Hanzo Social est une divergence assumée de [`gitroomhq/postiz-app`](https://github.com/gitroomhq/postiz-app) (AGPL-3.0), rebaptisée et intégrée à la plateforme Hanzo :

- **Authentification** — Hanzo IAM (`hanzo.id`) par OIDC (`IAM_CLIENT_ID=hanzo-social`).
- **Stockage** — Hanzo S3 (`s3-api.hanzo.ai`).
- **Secrets** — Hanzo KMS (`kms.hanzo.ai`) par le conteneur d'initialisation `kms-fetch`.
- **Courriel** — `social@hanzo.ai` depuis le relais SMTP partagé.
- **Robot** — `~/work/hanzo/bot` expose `/social {schedule|draft|integrations}` face à ce service.

L'amont reste la source de vérité du moteur de planification ; la marque et la colle avec la plateforme vivent dans ce dépôt.

## Développer

```bash
pnpm install
pnpm dev
```

Voir `CLAUDE.md` pour la disposition du dépôt, et `apps/`, `libraries/` pour le service NestJS, la face Vite et le travailleur Temporal.
