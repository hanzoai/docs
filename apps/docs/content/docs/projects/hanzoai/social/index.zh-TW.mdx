## 這是什麼

Hanzo Social 是 [`gitroomhq/postiz-app`](https://github.com/gitroomhq/postiz-app)（AGPL-3.0）的強硬分叉，已改名並整合進 Hanzo 平台：

- **驗證** — 經 OIDC 的 Hanzo IAM（`hanzo.id`）（`IAM_CLIENT_ID=hanzo-social`）。
- **儲存** — Hanzo S3（`s3-api.hanzo.ai`）。
- **機密** — 經初始化容器 `kms-fetch` 的 Hanzo KMS（`kms.hanzo.ai`）。
- **郵件** — 來自共用 SMTP 轉送的 `social@hanzo.ai`。
- **機器人** — `~/work/hanzo/bot` 對這項服務開放 `/social {schedule|draft|integrations}`。

上游依舊是排程引擎的依據；品牌與平台的黏著層放在這個儲存庫裡。

## 開發

```bash
pnpm install
pnpm dev
```

儲存庫的安排見 `CLAUDE.md`；NestJS 服務、Vite 介面與 Temporal 工作行程見 `apps/`、`libraries/`。
