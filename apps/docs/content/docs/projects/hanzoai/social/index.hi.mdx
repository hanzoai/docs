## यह क्या है

Hanzo Social, [`gitroomhq/postiz-app`](https://github.com/gitroomhq/postiz-app) (AGPL-3.0) की दृढ़ शाखा है, नया नाम देकर Hanzo प्लेटफ़ॉर्म में जोड़ी गई है:

- **प्रमाणीकरण** — OIDC के द्वारा Hanzo IAM (`hanzo.id`) (`IAM_CLIENT_ID=hanzo-social`).
- **भंडारण** — Hanzo S3 (`s3-api.hanzo.ai`).
- **रहस्य** — आरंभ कंटेनर `kms-fetch` के द्वारा Hanzo KMS (`kms.hanzo.ai`).
- **ईमेल** — साझा SMTP रिले से `social@hanzo.ai`.
- **यंत्र** — `~/work/hanzo/bot` इस सेवा के सामने `/social {schedule|draft|integrations}` खोलता है।

मूल धारा अनुसूचन इंजन का सत्य स्रोत बनी रहती है; ब्रांड और प्लेटफ़ॉर्म का जोड़ इस रिपॉजिटरी में रहता है।

## विकास

```bash
pnpm install
pnpm dev
```

रिपॉजिटरी विन्यास के लिए `CLAUDE.md` देखें, और NestJS सेवा, Vite मुख तथा Temporal कार्यकर्ता के लिए `apps/`, `libraries/` देखें।
