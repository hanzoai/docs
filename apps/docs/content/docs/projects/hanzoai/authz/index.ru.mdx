Библиотека контроля доступа, которой пользуется каждый сервис Go в Hanzo, чтобы прочитать токен и решить, может ли вызывающий что-то сделать: проверка JWT, утверждения и исчисление разрешений по организациям, приложениям и путям.

## Установка

```bash
go get github.com/hanzoai/authz
```

## Как пользоваться

Проверьте токен — это та же библиотека, которой подписывает IAM, поэтому читающий здесь не может разойтись с издателем в том, что было подписано:

```go
claims, err := authz.Verify(token, keys, []string{"https://hanzo.id"})
```

`keys` — это `func(kid string) []crypto.PublicKey`. Материал ключей — **вход**: получить JWKS и положить его в кэш есть ввод-вывод, и этот пакет ничего из этого не делает — край владеет получением и передаёт результат внутрь. nil-`Keys`, или такой, который ничего не разрешает, ничего не проверяет.

Дальше `Claims` несёт личность вызывающего, членства в организациях и разрешения приложений; `ParsePath` и `VerbOf` превращают запрос в пару, по которой решает исчисление разрешений. `IsAPIKey` отличает ключ `hk-` от JWT.

Принимаются только алгоритмы, которые выдаёт подписант IAM — RSA и EC, плюс ML-DSA-65 для постквантового сертификата. `none` и HMAC отвергаются.
