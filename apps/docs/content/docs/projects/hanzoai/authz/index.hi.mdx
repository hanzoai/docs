पहुँच-नियंत्रण पुस्तकालय जिसका उपयोग Hanzo की हर Go सेवा एक टोकन पढ़कर यह तय करने के लिए करती है कि कॉल करने वाला कोई काम कर सकता है या नहीं: JWT सत्यापन, दावे, और संगठनों, ऐप तथा पथों पर अनुदान की गणना।

## स्थापना

```bash
go get github.com/hanzoai/authz
```

## उपयोग

एक टोकन सत्यापित करें — यही वह पुस्तकालय है जिससे IAM हस्ताक्षर करता है, इसलिए यहाँ पढ़ने वाला जारीकर्ता से इस बात पर असहमत नहीं हो सकता कि क्या हस्ताक्षरित हुआ:

```go
claims, err := authz.Verify(token, keys, []string{"https://hanzo.id"})
```

`keys` एक `func(kid string) []crypto.PublicKey` है। कुंजी सामग्री एक **आगत** है: JWKS लाना और कैश करना निवेश-निर्गम है, और यह पैकेज उनमें से कुछ नहीं करता — किनारा लाने का स्वामी है और परिणाम अंदर देता है। nil `Keys`, या जो कुछ भी हल न करे, कुछ भी सत्यापित नहीं करता।

`Claims` वहाँ से कॉल करने वाले की पहचान, संगठन सदस्यताएँ और ऐप अनुदान ले जाता है; `ParsePath` और `VerbOf` एक अनुरोध को उस जोड़े में बदलते हैं जिस पर अनुदान गणना निर्णय करती है। `IsAPIKey` एक `hk-` कुंजी को JWT से अलग पहचानता है।

केवल वे एल्गोरिदम स्वीकार होते हैं जो IAM का हस्ताक्षरकर्ता बनाता है — RSA और EC, तथा पोस्ट-क्वांटम प्रमाणपत्र के लिए ML-DSA-65। `none` और HMAC अस्वीकार होते हैं।
