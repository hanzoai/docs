ไลบรารีควบคุมการเข้าถึงที่บริการ Go ทุกตัวของ Hanzo ใช้เพื่ออ่านโทเคนและตัดสินว่าผู้เรียกทำสิ่งหนึ่งได้หรือไม่: การตรวจ JWT, เคลม, และการคำนวณการให้สิทธิเหนือองค์กร แอป และเส้นทาง

## การติดตั้ง

```bash
go get github.com/hanzoai/authz
```

## วิธีใช้

ตรวจโทเคน — นี่คือไลบรารีเดียวกับที่ IAM ใช้ลงนาม ดังนั้นผู้อ่านที่นี่จะขัดแย้งกับผู้ออกไม่ได้ว่าอะไรได้รับการลงนาม:

```go
claims, err := authz.Verify(token, keys, []string{"https://hanzo.id"})
```

`keys` คือ `func(kid string) []crypto.PublicKey` วัตถุดิบกุญแจเป็น**ข้อมูลเข้า**: การดึง JWKS แล้วเก็บแคชเป็นขาเข้า/ขาออก และแพ็กเกจนี้ไม่ทำสิ่งนั้น — ขอบเป็นผู้ดึงและส่งผลลัพธ์เข้ามา `Keys` ที่เป็น nil หรือที่ไม่แก้ค่าอะไรเลย จะไม่ตรวจอะไรเลย

จากนั้น `Claims` ถือตัวตนของผู้เรียก สมาชิกภาพองค์กร และการให้สิทธิแอป; `ParsePath` และ `VerbOf` เปลี่ยนคำขอเป็นคู่ที่การคำนวณการให้สิทธิใช้ตัดสิน `IsAPIKey` แยกกุญแจ `hk-` ออกจาก JWT

ยอมรับเฉพาะอัลกอริทึมที่ผู้ลงนามของ IAM สร้าง — RSA และ EC บวก ML-DSA-65 สำหรับใบรับรองหลังควอนตัม `none` และ HMAC ถูกปฏิเสธ
