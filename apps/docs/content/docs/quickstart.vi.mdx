**Sau trang này bạn có một thông tin xác thực đang chạy và một cuộc gọi đã trả lời.**

Hanzo là một đám mây sau một khóa. Mọi năng lực — suy luận, danh tính,
lưu trữ, tiền, tác tử — trả lời tại `https://api.hanzo.ai`, và CLI,
SDK cùng các công cụ MCP đều sinh từ cùng một mô tả. Không có gì phải
nối theo từng dịch vụ: lấy khóa một lần là chạm được mọi thứ.

## 1. Cài đặt

<Tabs items={['npm', 'Script', 'Homebrew', 'Từ mã nguồn']}>
<Tab value="npm">
```bash
npm i -g hanzo
```

`hanzo` là CLI và máy khách trong một lần cài.
</Tab>
<Tab value="Script">
```bash
curl -fsSL https://hanzo.sh | sh
```

Cài vào `~/.local/bin`. `https://hanzo.sh/cli` chỉ cài CLI.
</Tab>
<Tab value="Homebrew">
```bash
brew install hanzoai/tap/hanzo
```
</Tab>
<Tab value="Từ mã nguồn">
```bash
git clone https://github.com/hanzoai/cli && cd cli && cargo install --path .
```
</Tab>
</Tabs>

```bash
hanzo version
```

## 2. Đăng nhập

```bash
hanzo auth login
```

Việc đó mở trình duyệt tới [hanzo.id](https://hanzo.id), nhà cung cấp danh tính
của Hanzo, và lưu thông tin xác thực tại chỗ. `hanzo auth show` in
bạn là ai; `hanzo auth list` cho thấy mọi danh tính trên máy này và
`hanzo auth use` chuyển giữa chúng.

Trên máy chủ, hãy phát một khóa thay vì cho một người đăng nhập: **console.hanzo.ai →
khóa API**. Khóa bí mật là *bạn*, nên nó ở trên máy chủ và không bao giờ
ở trong trình duyệt — [Xác thực](/docs/api-keys) là toàn bộ quy tắc.

```bash
export HANZO_API_KEY=sk-...
```

## 3. Liệt kê mô hình

Danh mục mô hình mà cổng đang phục vụ. Đây là một lần đọc, chỉ cần
khóa, và là cùng một thao tác trên cả bốn bề mặt.

<Tabs items={['CLI', 'SDK', 'HTTP', 'MCP']}>
<Tab value="CLI">
```bash
hanzo models list
```
</Tab>
<Tab value="SDK">
<Tabs items={['.ts', '.py', '.go', '.rs', '.swift', '.kt']}>
<Tab value=".ts">
```bash
npm i hanzo
```


</Tab>
<Tab value=".py">
```bash
pip install hanzo
```

```python

hanzo = Hanzo(api_key=os.environ["HANZO_API_KEY"])
models = hanzo.models.list()
```
</Tab>
<Tab value=".go">
```bash
go get github.com/hanzoai/go-sdk
```


</Tab>
<Tab value=".rs">
```bash
cargo add hanzo
```


</Tab>
<Tab value=".swift">

</Tab>
<Tab value=".kt">
```kotlin

```
</Tab>
</Tabs>

Tất cả được sinh từ cùng mô tả API, nên tên phương thức
khớp nhau giữa các ngôn ngữ. [C++](/docs/sdks/cpp) là cái vẫn đang
đến nơi.
</Tab>
<Tab value="HTTP">
```bash
curl https://api.hanzo.ai/v1/models \
  -H "Authorization: Bearer $HANZO_API_KEY"
```
</Tab>
<Tab value="MCP">
```bash
curl -X POST https://api.hanzo.ai/v1/mcp \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

Một điểm cuối, một công cụ cho mỗi năng lực. `tools/call` gọi tên năng lực và
thao tác; `describe` giải thích đầu vào của bất kỳ thao tác nào.
</Tab>
</Tabs>

Đó là một API nhìn từ bốn chỗ, và các thẻ ở trên là toàn bộ
khác biệt. Chọn cái bạn sẽ viết:

- **[CLI](/docs/cli)** — mỗi năng lực là một nhóm lệnh, mỗi cái một trang.
- **[SDK](/docs/sdks)** — Python, TypeScript, Go, Rust, C++, Swift và Kotlin,
  sinh từ cùng mô tả với CLI và các công cụ.
- **[MCP](/docs/mcp)** — một điểm cuối mà tác tử kết nối tới; [các công cụ](/docs/mcp-tools)
  được liệt kê một cái cho mỗi năng lực.

HTTP không cần trang: đó là `https://api.hanzo.ai` và khóa bạn vừa xuất.

## 4. Gửi một lần hoàn thành

Đây là bước đầu tiên rút tín dụng; mọi thứ phía trên chạy miễn phí.

```bash
hanzo chat completions --model zen-1 --messages '[{"role":"user","content":"hello"}]'
```

Rồi đọc xem nó đã rút bao nhiêu:

```bash
hanzo billing balance
hanzo usage summary
```

[Tín dụng và thanh toán](/docs/credits) giải thích tín dụng là gì và chuyện gì xảy ra khi về
không; [Giá](/docs/pricing) là mức của từng mô hình và công cụ.

## 5. Chạy đám mây tại chỗ

Cùng tệp nhị phân phục vụ `api.hanzo.ai` chạy trên máy của bạn:

```bash
hanzo up cloud
```

`hanzo up` trần là cùng một việc — `cloud` là mặc định. Gọi tên một dịch vụ để
chạy riêng nó: `hanzo up iam`, `hanzo up kms`, `hanzo up gateway`, `hanzo up
storage`, `hanzo up pubsub`. Xem [Tự chạy](/docs/network) để biết điều đó
có nghĩa gì và cần gì.
