# SDK ของ Hanzo

**Hanzo AI — API เดียวสำหรับทุกโมเดล, SDK เดียวสำหรับทุกภาษา** พูดกับ
Open AI Cloud จากภาษาที่คุณใช้อยู่แล้ว SDK ทุกตัวถูกสร้างจาก
ข้อกำหนด OpenAPI 3.1 เดียวกัน และใช้ข้อมูลประจำตัวร่วมกันหนึ่งชุด

## สองไลบรารีต่อภาษา

แต่ละภาษามีสองสายชั้นหนึ่ง — ติดตั้งสายที่เข้ากับงาน หรือ
ทั้งคู่:

<Cards>
  <Card title="Cloud SDK">
    ไคลเอนต์ที่สร้างขึ้นแบบเต็มสำหรับ Open AI Cloud **ทั้งก้อน** (`/v1/*`): ปัญญาประดิษฐ์,
    เอเจนต์, การคำนวณ, ข้อมูล, เครือข่าย, ความปลอดภัย, แพลตฟอร์ม, การสังเกต, web3, แอป
    เป็นสำนวนและมีชนิดตามระบบนิเวศ โค้ดจริงอยู่ใน `hanzo-<lang>/sdk`
  </Card>
  <Card title="ไลบรารีปัญญาประดิษฐ์ / เอเจนต์">
    ไลบรารีที่เขียนด้วยมือและให้ปัญญาประดิษฐ์มาก่อน — โมเดล, เอเจนต์, เครื่องมือ, ความจำ, MCP และ
    การอนุมาน เรือธงคือ Python (`pip install hanzo`); Node ส่ง
    `@hanzo/ai`
  </Card>
</Cards>

## ตารางการติดตั้ง

เฉพาะแพ็กเกจที่พร้อมใช้ทั่วไปจึงแสดงเป็นการติดตั้งที่รันได้ ที่เหลือ
อยู่ระหว่างพัฒนา — แต่ละรายการเชื่อมไปยังองค์กรของภาษานั้น ซึ่งซอร์ส
อยู่แล้ว

| ภาษา | ไลบรารี | การติดตั้ง | สถานะ |
|----------|---------|---------|--------|
| **Python** | ปัญญาประดิษฐ์ / เอเจนต์ (เรือธง) | `pip install hanzo` | พร้อมใช้ทั่วไป |
| **Python** | Cloud SDK | `pip install hanzoai` | พร้อมใช้ทั่วไป |
| **TypeScript** | ไลบรารีปัญญาประดิษฐ์ | `npm i @hanzo/ai` | พร้อมใช้ทั่วไป |
| **TypeScript** | Cloud SDK | `npm i @hanzo/sdk` | พร้อมใช้ทั่วไป |
| **Go** | Cloud SDK | `go get github.com/hanzoai/go-sdk` | พร้อมใช้ทั่วไป |
| **Rust** | Cloud SDK | `cargo add hanzo` | พร้อมใช้ทั่วไป |
| **C++** | Cloud SDK | `find_package(hanzo)` | เร็วๆ นี้ |
| **Swift** | Cloud SDK | `.package(url: "https://github.com/hanzo-swift/sdk")` | พร้อมใช้ทั่วไป |
| **Kotlin** | Cloud SDK | Gradle / Maven | เร็วๆ นี้ |

<Callout title="เข้ากันได้บนสายวันนี้">
ทุกภาษาเข้าถึง Open AI Cloud ได้แล้วผ่านไคลเอนต์ที่เข้ากับ OpenAI หรือ
Anthropic — ชี้ URL ฐานไปที่
`https://api.hanzo.ai/v1` แล้วใช้คีย์ Hanzo SDK พื้นเมืองด้านบนเพิ่ม
โมเดลมีชนิด, การลองใหม่, ตัวช่วยสตรีม และพื้นผิวเอเจนต์/MCP
</Callout>

## เริ่มต้นอย่างรวดเร็ว

```bash tab="Python (AI)"
pip install hanzo
```

```bash tab="Python (Cloud)"
pip install hanzoai
```

```bash tab="TypeScript (AI)"
npm i @hanzo/ai
```

```bash tab="TypeScript (Cloud)"
npm i @hanzo/sdk
```

```bash tab="Go"
go get github.com/hanzoai/go-sdk
```

ไคลเอนต์ทุกรายตามรูปเดียวกัน — สร้างด้วยคีย์ของคุณ เรียกทรัพยากร `/v1`:

```python tab="Python"
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-key")
response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
```

```typescript tab="TypeScript"
import Hanzo from '@hanzo/sdk';

const client = new Hanzo({ apiKey: 'sk-your-key' });
const response = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello' }],
});
```

```go tab="Go"
client := hanzoai.NewClient(option.WithAPIKey("sk-your-key"))
response, _ := client.Chat.Completions.New(ctx, hanzoai.ChatCompletionNewParams{
    Model:    hanzoai.F("zen5"),
    Messages: hanzoai.F([]hanzoai.ChatCompletionMessageParamUnion{
        hanzoai.UserMessage("Hello"),
    }),
})
```

## คีย์เดียว, URL ฐานเดียว

```bash
export HANZO_API_KEY="sk-..."   # from console.hanzo.ai
# Base URL for every service: https://api.hanzo.ai/v1
```

รับคีย์ได้ที่ [console.hanzo.ai](https://console.hanzo.ai)
