# SDK Hanzo

**Hanzo AI — un'API per ogni modello, un SDK per ogni linguaggio.** Parla con
Open AI Cloud dal linguaggio in cui lavori già. Ogni SDK è generato dalla
stessa specifica OpenAPI 3.1 e condivide una credenziale.

## Due librerie per linguaggio

Ogni linguaggio ha due linee di primo piano — installa quella adatta al lavoro, o
entrambe:

<Cards>
  <Card title="SDK Cloud">
    Il client generato e completo per **tutta** Open AI Cloud (`/v1/*`): IA,
    agenti, calcolo, dati, rete, sicurezza, piattaforma, osservazione, web3, app.
    Idiomatico e tipizzato per il suo ecosistema. Il codice vero vive in `hanzo-<lang>/sdk`.
  </Card>
  <Card title="Libreria IA / agenti">
    La libreria fatta a mano e incentrata sull'IA — modelli, agenti, strumenti, memoria, MCP e
    inferenza. L'ammiraglia è Python (`pip install hanzo`); Node pubblica
    `@hanzo/ai`.
  </Card>
</Cards>

## Matrice di installazione

Solo i pacchetti in disponibilità generale sono mostrati come installazioni eseguibili. Il resto è
in sviluppo attivo — ognuno rimanda alla propria organizzazione per linguaggio, dove il codice
vive già.

| Linguaggio | Libreria | Installazione | Stato |
|----------|---------|---------|--------|
| **Python** | IA / agenti (ammiraglia) | `pip install hanzo` | Disponibilità generale |
| **Python** | SDK Cloud | `pip install hanzoai` | Disponibilità generale |
| **TypeScript** | Libreria IA | `npm i @hanzo/ai` | Disponibilità generale |
| **TypeScript** | SDK Cloud | `npm i @hanzo/sdk` | Disponibilità generale |
| **Go** | SDK Cloud | `go get github.com/hanzoai/go-sdk` | Disponibilità generale |
| **Rust** | SDK Cloud | `cargo add hanzo` | Disponibilità generale |
| **C++** | SDK Cloud | `find_package(hanzo)` | In arrivo |
| **Swift** | SDK Cloud | `.package(url: "https://github.com/hanzo-swift/sdk")` | Disponibilità generale |
| **Kotlin** | SDK Cloud | Gradle / Maven | In arrivo |

<Callout title="Compatibile sul filo oggi">
Ogni linguaggio può già raggiungere Open AI Cloud tramite qualsiasi client compatibile con OpenAI o
Anthropic — punta l'URL di base a
`https://api.hanzo.ai/v1` e usa la tua chiave Hanzo. Gli SDK nativi sopra aggiungono
modelli tipizzati, nuovi tentativi, aiuti allo streaming e la superficie agenti/MCP.
</Callout>

## Avvio rapido

```bash tab="Python (AI)"
pip install hanzo
```

```bash tab="Python (Cloud)"
pip install hanzoai
```

```bash tab="TypeScript (AI)"
npm i @hanzo/ai
```

```bash tab="TypeScript (Cloud)"
npm i @hanzo/sdk
```

```bash tab="Go"
go get github.com/hanzoai/go-sdk
```

Ogni client segue la stessa forma — costruiscilo con la tua chiave, chiama una risorsa `/v1`:

```python tab="Python"
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-key")
response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
```

```typescript tab="TypeScript"
import Hanzo from '@hanzo/sdk';

const client = new Hanzo({ apiKey: 'sk-your-key' });
const response = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello' }],
});
```

```go tab="Go"
client := hanzoai.NewClient(option.WithAPIKey("sk-your-key"))
response, _ := client.Chat.Completions.New(ctx, hanzoai.ChatCompletionNewParams{
    Model:    hanzoai.F("zen5"),
    Messages: hanzoai.F([]hanzoai.ChatCompletionMessageParamUnion{
        hanzoai.UserMessage("Hello"),
    }),
})
```

## Una chiave, un URL di base

```bash
export HANZO_API_KEY="sk-..."   # from console.hanzo.ai
# Base URL for every service: https://api.hanzo.ai/v1
```

Ottieni la chiave su [console.hanzo.ai](https://console.hanzo.ai).
