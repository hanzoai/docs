# SDK Hanzo

**Hanzo AI — một API cho mọi mô hình, một SDK cho mọi ngôn ngữ.** Nói với
Open AI Cloud từ ngôn ngữ bạn đang dùng. Mỗi SDK được sinh từ
cùng một đặc tả OpenAPI 3.1 và dùng chung một thông tin xác thực.

## Hai thư viện mỗi ngôn ngữ

Mỗi ngôn ngữ có hai tuyến hạng nhất — cài tuyến hợp việc, hoặc
cả hai:

<Cards>
  <Card title="SDK Cloud">
    Máy khách sinh đầy đủ cho **toàn bộ** Open AI Cloud (`/v1/*`): AI,
    tác tử, tính toán, dữ liệu, mạng, bảo mật, nền tảng, quan sát, web3, ứng dụng.
    Đúng thành ngữ và có kiểu cho hệ sinh thái của nó. Mã thật nằm ở `hanzo-<lang>/sdk`.
  </Card>
  <Card title="Thư viện AI / tác tử">
    Thư viện viết tay, ưu tiên AI — mô hình, tác tử, công cụ, bộ nhớ, MCP và
    suy luận. Soái hạm là Python (`pip install hanzo`); Node phát hành
    `@hanzo/ai`.
  </Card>
</Cards>

## Ma trận cài đặt

Chỉ các gói đã phát hành rộng được hiện như lệnh cài chạy được. Phần còn lại
đang phát triển — mỗi gói nối tới tổ chức ngôn ngữ của nó, nơi mã nguồn
đã nằm.

| Ngôn ngữ | Thư viện | Cài đặt | Trạng thái |
|----------|---------|---------|--------|
| **Python** | AI / tác tử (soái hạm) | `pip install hanzo` | Phát hành rộng |
| **Python** | SDK Cloud | `pip install hanzoai` | Phát hành rộng |
| **TypeScript** | Thư viện AI | `npm i @hanzo/ai` | Phát hành rộng |
| **TypeScript** | SDK Cloud | `npm i @hanzo/sdk` | Phát hành rộng |
| **Go** | SDK Cloud | `go get github.com/hanzoai/go-sdk` | Phát hành rộng |
| **Rust** | SDK Cloud | `cargo add hanzo` | Phát hành rộng |
| **C++** | SDK Cloud | `find_package(hanzo)` | Sắp có |
| **Swift** | SDK Cloud | `.package(url: "https://github.com/hanzo-swift/sdk")` | Phát hành rộng |
| **Kotlin** | SDK Cloud | Gradle / Maven | Sắp có |

<Callout title="Tương thích trên dây ngay hôm nay">
Mọi ngôn ngữ đã tới được Open AI Cloud qua bất kỳ máy khách tương thích OpenAI hoặc
Anthropic — chỉ cần trỏ URL gốc tới
`https://api.hanzo.ai/v1` và dùng khóa Hanzo. Các SDK gốc ở trên thêm
mô hình có kiểu, thử lại, trợ giúp luồng và bề mặt tác tử/MCP.
</Callout>

## Bắt đầu nhanh

```bash tab="Python (AI)"
pip install hanzo
```

```bash tab="Python (Cloud)"
pip install hanzoai
```

```bash tab="TypeScript (AI)"
npm i @hanzo/ai
```

```bash tab="TypeScript (Cloud)"
npm i @hanzo/sdk
```

```bash tab="Go"
go get github.com/hanzoai/go-sdk
```

Mọi máy khách theo cùng một dạng — dựng bằng khóa của bạn, gọi một tài nguyên `/v1`:

```python tab="Python"
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-key")
response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
```

```typescript tab="TypeScript"
import Hanzo from '@hanzo/sdk';

const client = new Hanzo({ apiKey: 'sk-your-key' });
const response = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello' }],
});
```

```go tab="Go"
client := hanzoai.NewClient(option.WithAPIKey("sk-your-key"))
response, _ := client.Chat.Completions.New(ctx, hanzoai.ChatCompletionNewParams{
    Model:    hanzoai.F("zen5"),
    Messages: hanzoai.F([]hanzoai.ChatCompletionMessageParamUnion{
        hanzoai.UserMessage("Hello"),
    }),
})
```

## Một khóa, một URL gốc

```bash
export HANZO_API_KEY="sk-..."   # from console.hanzo.ai
# Base URL for every service: https://api.hanzo.ai/v1
```

Lấy khóa tại [console.hanzo.ai](https://console.hanzo.ai).
