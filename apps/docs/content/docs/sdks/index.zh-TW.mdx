# Hanzo SDK

**Hanzo AI — 每個模型一個 API，每種語言一個 SDK。** 用你已經在用的語言與
Open AI Cloud 對話。每個 SDK 都從同一份 OpenAPI 3.1 規範產生，並共用一份憑證。

## 每種語言兩個程式庫

每種語言有兩條一等產品線 — 安裝適合這份工作的，或
兩個都裝：

<Cards>
  <Card title="Cloud SDK">
    面向**整個** Open AI Cloud（`/v1/*`）的完整產生用戶端：人工智慧、
    代理、計算、資料、網路、安全、平台、觀測、web3、應用程式。
    對其生態來說符合習慣且帶型別。真正的程式碼在 `hanzo-<lang>/sdk`。
  </Card>
  <Card title="人工智慧 / 代理程式庫">
    手工打造、以人工智慧為先的程式庫 — 模型、代理、工具、記憶、MCP 與
    推論。旗艦是 Python（`pip install hanzo`）；Node 發布
    `@hanzo/ai`。
  </Card>
</Cards>

## 安裝矩陣

只有正式發行的套件才顯示為可執行的安裝。其餘
正在積極開發 — 每一項都連到其語言組織，原始碼已經在那裡。

| 語言 | 程式庫 | 安裝 | 狀態 |
|----------|---------|---------|--------|
| **Python** | 人工智慧 / 代理（旗艦） | `pip install hanzo` | 正式發行 |
| **Python** | Cloud SDK | `pip install hanzoai` | 正式發行 |
| **TypeScript** | 人工智慧程式庫 | `npm i @hanzo/ai` | 正式發行 |
| **TypeScript** | Cloud SDK | `npm i @hanzo/sdk` | 正式發行 |
| **Go** | Cloud SDK | `go get github.com/hanzoai/go-sdk` | 正式發行 |
| **Rust** | Cloud SDK | `cargo add hanzo` | 正式發行 |
| **C++** | Cloud SDK | `find_package(hanzo)` | 即將推出 |
| **Swift** | Cloud SDK | `.package(url: "https://github.com/hanzo-swift/sdk")` | 正式發行 |
| **Kotlin** | Cloud SDK | Gradle / Maven | 即將推出 |

<Callout title="今天就在線路上相容">
每種語言都已經能透過任何相容 OpenAI 或
Anthropic 的用戶端到達 Open AI Cloud — 把基底網址指向
`https://api.hanzo.ai/v1` 並使用你的 Hanzo 金鑰。上面的原生 SDK 額外提供
帶型別的模型、重試、串流輔助，以及代理/MCP 表面。
</Callout>

## 快速開始

```bash tab="Python (AI)"
pip install hanzo
```

```bash tab="Python (Cloud)"
pip install hanzoai
```

```bash tab="TypeScript (AI)"
npm i @hanzo/ai
```

```bash tab="TypeScript (Cloud)"
npm i @hanzo/sdk
```

```bash tab="Go"
go get github.com/hanzoai/go-sdk
```

每個用戶端都是同一形狀 — 用你的金鑰建構，呼叫一個 `/v1` 資源：

```python tab="Python"
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-key")
response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
```

```typescript tab="TypeScript"
import Hanzo from '@hanzo/sdk';

const client = new Hanzo({ apiKey: 'sk-your-key' });
const response = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello' }],
});
```

```go tab="Go"
client := hanzoai.NewClient(option.WithAPIKey("sk-your-key"))
response, _ := client.Chat.Completions.New(ctx, hanzoai.ChatCompletionNewParams{
    Model:    hanzoai.F("zen5"),
    Messages: hanzoai.F([]hanzoai.ChatCompletionMessageParamUnion{
        hanzoai.UserMessage("Hello"),
    }),
})
```

## 一把金鑰，一個基底網址

```bash
export HANZO_API_KEY="sk-..."   # from console.hanzo.ai
# Base URL for every service: https://api.hanzo.ai/v1
```

在 [console.hanzo.ai](https://console.hanzo.ai) 取得金鑰。
