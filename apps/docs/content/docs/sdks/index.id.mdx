# SDK Hanzo

**Hanzo AI — satu API untuk setiap model, satu SDK untuk setiap bahasa.** Bicara dengan
Open AI Cloud dari bahasa yang sudah Anda pakai. Setiap SDK dihasilkan dari
spesifikasi OpenAPI 3.1 yang sama dan berbagi satu kredensial.

## Dua pustaka per bahasa

Setiap bahasa punya dua jalur kelas utama — pasang yang cocok dengan pekerjaan, atau
keduanya:

<Cards>
  <Card title="SDK Cloud">
    Klien yang dihasilkan dan lengkap untuk **seluruh** Open AI Cloud (`/v1/*`): AI,
    agen, komputasi, data, jaringan, keamanan, platform, observasi, web3, aplikasi.
    Idiomatis dan bertipe untuk ekosistemnya. Kode sungguhan hidup di `hanzo-<lang>/sdk`.
  </Card>
  <Card title="Pustaka AI / agen">
    Pustaka yang dibuat tangan dan mengutamakan AI — model, agen, alat, memori, MCP, dan
    inferensi. Unggulannya adalah Python (`pip install hanzo`); Node mengirim
    `@hanzo/ai`.
  </Card>
</Cards>

## Matriks pemasangan

Hanya paket yang tersedia umum ditampilkan sebagai pemasangan yang dapat dijalankan. Sisanya
sedang dikembangkan — masing-masing menaut ke organisasi bahasanya, tempat sumber
sudah hidup.

| Bahasa | Pustaka | Pemasangan | Status |
|----------|---------|---------|--------|
| **Python** | AI / agen (unggulan) | `pip install hanzo` | Ketersediaan umum |
| **Python** | SDK Cloud | `pip install hanzoai` | Ketersediaan umum |
| **TypeScript** | Pustaka AI | `npm i @hanzo/ai` | Ketersediaan umum |
| **TypeScript** | SDK Cloud | `npm i @hanzo/sdk` | Ketersediaan umum |
| **Go** | SDK Cloud | `go get github.com/hanzoai/go-sdk` | Ketersediaan umum |
| **Rust** | SDK Cloud | `cargo add hanzo` | Ketersediaan umum |
| **C++** | SDK Cloud | `find_package(hanzo)` | Segera hadir |
| **Swift** | SDK Cloud | `.package(url: "https://github.com/hanzo-swift/sdk")` | Ketersediaan umum |
| **Kotlin** | SDK Cloud | Gradle / Maven | Segera hadir |

<Callout title="Kompatibel di kabel hari ini">
Setiap bahasa sudah dapat menjangkau Open AI Cloud lewat klien mana pun yang kompatibel dengan OpenAI atau
Anthropic — arahkan URL dasar ke
`https://api.hanzo.ai/v1` dan gunakan kunci Hanzo Anda. SDK asli di atas menambah
model bertipe, percobaan ulang, pembantu streaming, dan permukaan agen/MCP.
</Callout>

## Mulai cepat

```bash tab="Python (AI)"
pip install hanzo
```

```bash tab="Python (Cloud)"
pip install hanzoai
```

```bash tab="TypeScript (AI)"
npm i @hanzo/ai
```

```bash tab="TypeScript (Cloud)"
npm i @hanzo/sdk
```

```bash tab="Go"
go get github.com/hanzoai/go-sdk
```

Setiap klien mengikuti bentuk yang sama — bangun dengan kunci Anda, panggil sumber daya `/v1`:

```python tab="Python"
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-key")
response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
```

```typescript tab="TypeScript"
import Hanzo from '@hanzo/sdk';

const client = new Hanzo({ apiKey: 'sk-your-key' });
const response = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello' }],
});
```

```go tab="Go"
client := hanzoai.NewClient(option.WithAPIKey("sk-your-key"))
response, _ := client.Chat.Completions.New(ctx, hanzoai.ChatCompletionNewParams{
    Model:    hanzoai.F("zen5"),
    Messages: hanzoai.F([]hanzoai.ChatCompletionMessageParamUnion{
        hanzoai.UserMessage("Hello"),
    }),
})
```

## Satu kunci, satu URL dasar

```bash
export HANZO_API_KEY="sk-..."   # from console.hanzo.ai
# Base URL for every service: https://api.hanzo.ai/v1
```

Ambil kunci Anda di [console.hanzo.ai](https://console.hanzo.ai).
