# SDK Hanzo

**Hanzo AI — une API pour chaque modèle, un SDK pour chaque langage.** Parlez à
Open AI Cloud depuis le langage dans lequel vous travaillez déjà. Chaque SDK est généré à partir
de la même spécification OpenAPI 3.1 et partage un justificatif.

## Deux bibliothèques par langage

Chaque langage a deux lignes de premier plan — installez celle qui convient au travail, ou
les deux :

<Cards>
  <Card title="SDK Cloud">
    Le client généré et complet pour **toute** Open AI Cloud (`/v1/*`) : IA,
    agents, calcul, données, réseau, sécurité, plateforme, observation, web3, applications.
    Idiomatique et typé pour son écosystème. Le code réel vit dans `hanzo-<lang>/sdk`.
  </Card>
  <Card title="Bibliothèque IA / agents">
    La bibliothèque façonnée à la main et tournée vers l'IA — modèles, agents, outils, mémoire, MCP et
    inférence. Le vaisseau amiral est Python (`pip install hanzo`) ; Node publie
    `@hanzo/ai`.
  </Card>
</Cards>

## Matrice d'installation

Seuls les paquets en disponibilité générale sont montrés comme installations exécutables. Le reste est
en développement actif — chacun renvoie vers son organisation par langage, où le code
vit déjà.

| Langage | Bibliothèque | Installation | État |
|----------|---------|---------|--------|
| **Python** | IA / agents (vaisseau amiral) | `pip install hanzo` | Disponibilité générale |
| **Python** | SDK Cloud | `pip install hanzoai` | Disponibilité générale |
| **TypeScript** | Bibliothèque IA | `npm i @hanzo/ai` | Disponibilité générale |
| **TypeScript** | SDK Cloud | `npm i @hanzo/sdk` | Disponibilité générale |
| **Go** | SDK Cloud | `go get github.com/hanzoai/go-sdk` | Disponibilité générale |
| **Rust** | SDK Cloud | `cargo add hanzo` | Disponibilité générale |
| **C++** | SDK Cloud | `find_package(hanzo)` | Bientôt |
| **Swift** | SDK Cloud | `.package(url: "https://github.com/hanzo-swift/sdk")` | Disponibilité générale |
| **Kotlin** | SDK Cloud | Gradle / Maven | Bientôt |

<Callout title="Compatible sur le fil dès aujourd'hui">
Chaque langage peut déjà atteindre Open AI Cloud via n'importe quel client compatible OpenAI ou
Anthropic — pointez simplement l'URL de base vers
`https://api.hanzo.ai/v1` et utilisez votre clé Hanzo. Les SDK natifs ci-dessus ajoutent
des modèles typés, des nouvelles tentatives, des aides au flux et la surface agents/MCP.
</Callout>

## Démarrage rapide

```bash tab="Python (AI)"
pip install hanzo
```

```bash tab="Python (Cloud)"
pip install hanzoai
```

```bash tab="TypeScript (AI)"
npm i @hanzo/ai
```

```bash tab="TypeScript (Cloud)"
npm i @hanzo/sdk
```

```bash tab="Go"
go get github.com/hanzoai/go-sdk
```

Chaque client suit la même forme — construisez-le avec votre clé, appelez une ressource `/v1` :

```python tab="Python"
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-key")
response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
```

```typescript tab="TypeScript"
import Hanzo from '@hanzo/sdk';

const client = new Hanzo({ apiKey: 'sk-your-key' });
const response = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello' }],
});
```

```go tab="Go"
client := hanzoai.NewClient(option.WithAPIKey("sk-your-key"))
response, _ := client.Chat.Completions.New(ctx, hanzoai.ChatCompletionNewParams{
    Model:    hanzoai.F("zen5"),
    Messages: hanzoai.F([]hanzoai.ChatCompletionMessageParamUnion{
        hanzoai.UserMessage("Hello"),
    }),
})
```

## Une clé, une URL de base

```bash
export HANZO_API_KEY="sk-..."   # from console.hanzo.ai
# Base URL for every service: https://api.hanzo.ai/v1
```

Obtenez votre clé sur [console.hanzo.ai](https://console.hanzo.ai).
