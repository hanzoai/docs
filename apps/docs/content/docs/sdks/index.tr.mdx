# Hanzo SDK'leri

**Hanzo AI — her model için bir API, her dil için bir SDK.** Zaten çalıştığınız dilden
Open AI Cloud ile konuşun. Her SDK aynı OpenAPI 3.1 belirtiminden üretilir ve bir kimlik bilgisini paylaşır.

## Dil başına iki kitaplık

Her dilin iki birinci sınıf hattı vardır — işe uyanı kurun, ya da
ikisini birden:

<Cards>
  <Card title="Cloud SDK">
    **Tüm** Open AI Cloud (`/v1/*`) için üretilmiş tam istemci: yapay zekâ,
    ajanlar, hesaplama, veri, ağ, güvenlik, platform, gözlem, web3, uygulamalar.
    Ekosistemine göre deyimsel ve tipli. Gerçek kod `hanzo-<lang>/sdk` içindedir.
  </Card>
  <Card title="Yapay zekâ / ajanlar kitaplığı">
    Elle yazılmış, yapay zekâ öncelikli kitaplık — modeller, ajanlar, araçlar, bellek, MCP ve
    çıkarım. Amiral gemisi Python'dur (`pip install hanzo`); Node
    `@hanzo/ai` yayınlar.
  </Card>
</Cards>

## Kurulum matrisi

Yalnızca genel kullanıma açık paketler çalıştırılabilir kurulum olarak gösterilir. Geri kalanı
etkin geliştirmededir — her biri, kaynağın zaten yaşadığı dil kuruluşuna bağlanır.

| Dil | Kitaplık | Kurulum | Durum |
|----------|---------|---------|--------|
| **Python** | Yapay zekâ / ajanlar (amiral gemisi) | `pip install hanzo` | Genel kullanım |
| **Python** | Cloud SDK | `pip install hanzoai` | Genel kullanım |
| **TypeScript** | Yapay zekâ kitaplığı | `npm i @hanzo/ai` | Genel kullanım |
| **TypeScript** | Cloud SDK | `npm i @hanzo/sdk` | Genel kullanım |
| **Go** | Cloud SDK | `go get github.com/hanzoai/go-sdk` | Genel kullanım |
| **Rust** | Cloud SDK | `cargo add hanzo` | Genel kullanım |
| **C++** | Cloud SDK | `find_package(hanzo)` | Yakında |
| **Swift** | Cloud SDK | `.package(url: "https://github.com/hanzo-swift/sdk")` | Genel kullanım |
| **Kotlin** | Cloud SDK | Gradle / Maven | Yakında |

<Callout title="Bugün tel üzerinde uyumlu">
Her dil Open AI Cloud'a OpenAI veya
Anthropic uyumlu herhangi bir istemciyle şimdiden ulaşır — taban URL'yi
`https://api.hanzo.ai/v1` adresine yöneltin ve Hanzo anahtarınızı kullanın. Yukarıdaki yerel SDK'ler
tipli modeller, yeniden denemeler, akış yardımcıları ve ajan/MCP yüzeyini ekler.
</Callout>

## Hızlı başlangıç

```bash tab="Python (AI)"
pip install hanzo
```

```bash tab="Python (Cloud)"
pip install hanzoai
```

```bash tab="TypeScript (AI)"
npm i @hanzo/ai
```

```bash tab="TypeScript (Cloud)"
npm i @hanzo/sdk
```

```bash tab="Go"
go get github.com/hanzoai/go-sdk
```

Her istemci aynı biçimi izler — anahtarınızla kurun, bir `/v1` kaynağını çağırın:

```python tab="Python"
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-key")
response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
```

```typescript tab="TypeScript"
import Hanzo from '@hanzo/sdk';

const client = new Hanzo({ apiKey: 'sk-your-key' });
const response = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello' }],
});
```

```go tab="Go"
client := hanzoai.NewClient(option.WithAPIKey("sk-your-key"))
response, _ := client.Chat.Completions.New(ctx, hanzoai.ChatCompletionNewParams{
    Model:    hanzoai.F("zen5"),
    Messages: hanzoai.F([]hanzoai.ChatCompletionMessageParamUnion{
        hanzoai.UserMessage("Hello"),
    }),
})
```

## Bir anahtar, bir taban URL

```bash
export HANZO_API_KEY="sk-..."   # from console.hanzo.ai
# Base URL for every service: https://api.hanzo.ai/v1
```

Anahtarınızı [console.hanzo.ai](https://console.hanzo.ai) adresinden alın.
