# Hanzo-SDKs

**Hanzo AI — eine API für jedes Modell, ein SDK für jede Sprache.** Sprechen Sie mit
Open AI Cloud aus der Sprache, in der Sie bereits arbeiten. Jedes SDK wird aus
derselben OpenAPI-3.1-Spezifikation erzeugt und teilt sich einen Berechtigungsnachweis.

## Zwei Bibliotheken je Sprache

Jede Sprache hat zwei erstklassige Linien — installieren Sie die, die zur Aufgabe passt, oder
beide:

<Cards>
  <Card title="Cloud-SDK">
    Der vollständige, erzeugte Client für die **gesamte** Open AI Cloud (`/v1/*`): KI,
    Agenten, Rechnen, Daten, Netz, Sicherheit, Plattform, Beobachten, web3, Apps.
    Idiomatisch und typisiert für sein Ökosystem. Der echte Code liegt in `hanzo-<lang>/sdk`.
  </Card>
  <Card title="KI- / Agenten-Bibliothek">
    Die von Hand gefertigte, KI-zuerst-Bibliothek — Modelle, Agenten, Werkzeuge, Speicher, MCP und
    Inferenz. Das Flaggschiff ist Python (`pip install hanzo`); Node liefert
    `@hanzo/ai`.
  </Card>
</Cards>

## Installationsmatrix

Nur allgemein verfügbare Pakete werden als ausführbare Installationen gezeigt. Der Rest ist
in aktiver Entwicklung — jedes verlinkt zu seiner sprachspezifischen Organisation, wo der Quelltext
bereits liegt.

| Sprache | Bibliothek | Installation | Status |
|----------|---------|---------|--------|
| **Python** | KI / Agenten (Flaggschiff) | `pip install hanzo` | Allgemeine Verfügbarkeit |
| **Python** | Cloud-SDK | `pip install hanzoai` | Allgemeine Verfügbarkeit |
| **TypeScript** | KI-Bibliothek | `npm i @hanzo/ai` | Allgemeine Verfügbarkeit |
| **TypeScript** | Cloud-SDK | `npm i @hanzo/sdk` | Allgemeine Verfügbarkeit |
| **Go** | Cloud-SDK | `go get github.com/hanzoai/go-sdk` | Allgemeine Verfügbarkeit |
| **Rust** | Cloud-SDK | `cargo add hanzo` | Allgemeine Verfügbarkeit |
| **C++** | Cloud-SDK | `find_package(hanzo)` | Demnächst |

<Callout title="Heute schon drahtkompatibel">
Jede Sprache erreicht Open AI Cloud bereits über jeden OpenAI- oder
Anthropic-kompatiblen Client — richten Sie die Basis-URL auf
`https://api.hanzo.ai/v1` und verwenden Sie Ihren Hanzo-Schlüssel. Die nativen SDKs oben ergänzen
typisierte Modelle, Wiederholungen, Streaming-Helfer und die Agenten-/MCP-Oberfläche.
</Callout>

## Schnellstart

```bash tab="Python (AI)"
pip install hanzo
```

```bash tab="Python (Cloud)"
pip install hanzoai
```

```bash tab="TypeScript (AI)"
npm i @hanzo/ai
```

```bash tab="TypeScript (Cloud)"
npm i @hanzo/sdk
```

```bash tab="Go"
go get github.com/hanzoai/go-sdk
```

Jeder Client folgt derselben Form — mit Ihrem Schlüssel konstruieren, eine `/v1`-Ressource aufrufen:

```python tab="Python"
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-key")
response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
```

```typescript tab="TypeScript"
import Hanzo from '@hanzo/sdk';

const client = new Hanzo({ apiKey: 'sk-your-key' });
const response = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello' }],
});
```

```go tab="Go"
client := hanzoai.NewClient(option.WithAPIKey("sk-your-key"))
response, _ := client.Chat.Completions.New(ctx, hanzoai.ChatCompletionNewParams{
    Model:    hanzoai.F("zen5"),
    Messages: hanzoai.F([]hanzoai.ChatCompletionMessageParamUnion{
        hanzoai.UserMessage("Hello"),
    }),
})
```

## Ein Schlüssel, eine Basis-URL

```bash
export HANZO_API_KEY="sk-..."   # from console.hanzo.ai
# Base URL for every service: https://api.hanzo.ai/v1
```

Holen Sie Ihren Schlüssel unter [console.hanzo.ai](https://console.hanzo.ai).
