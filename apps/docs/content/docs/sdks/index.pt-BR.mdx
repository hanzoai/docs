# SDKs da Hanzo

**Hanzo AI — uma API para cada modelo, um SDK para cada linguagem.** Fale com a
Open AI Cloud a partir da linguagem em que você já trabalha. Cada SDK é gerado a partir
da mesma especificação OpenAPI 3.1 e compartilha uma credencial.

## Duas bibliotecas por linguagem

Cada linguagem tem duas linhas de primeira classe — instale a que cabe no trabalho, ou
as duas:

<Cards>
  <Card title="SDK Cloud">
    O cliente gerado e completo para **toda** a Open AI Cloud (`/v1/*`): IA,
    agentes, computação, dados, rede, segurança, plataforma, observação, web3, aplicativos.
    Idiomático e tipado para o seu ecossistema. O código de verdade vive em `hanzo-<lang>/sdk`.
  </Card>
  <Card title="Biblioteca de IA / agentes">
    A biblioteca feita à mão e voltada à IA — modelos, agentes, ferramentas, memória, MCP e
    inferência. O carro-chefe é Python (`pip install hanzo`); o Node publica
    `@hanzo/ai`.
  </Card>
</Cards>

## Matriz de instalação

Só os pacotes em disponibilidade geral aparecem como instalações executáveis. O resto está
em desenvolvimento ativo — cada um aponta para a organização da linguagem, onde o código
já vive.

| Linguagem | Biblioteca | Instalação | Estado |
|----------|---------|---------|--------|
| **Python** | IA / agentes (carro-chefe) | `pip install hanzo` | Disponibilidade geral |
| **Python** | SDK Cloud | `pip install hanzoai` | Disponibilidade geral |
| **TypeScript** | Biblioteca de IA | `npm i @hanzo/ai` | Disponibilidade geral |
| **TypeScript** | SDK Cloud | `npm i @hanzo/sdk` | Disponibilidade geral |
| **Go** | SDK Cloud | `go get github.com/hanzoai/go-sdk` | Disponibilidade geral |
| **Rust** | SDK Cloud | `cargo add hanzo` | Disponibilidade geral |
| **C++** | SDK Cloud | `find_package(hanzo)` | Em breve |
| **Swift** | SDK Cloud | `.package(url: "https://github.com/hanzo-swift/sdk")` | Disponibilidade geral |
| **Kotlin** | SDK Cloud | Gradle / Maven | Em breve |

<Callout title="Compatível no fio hoje">
Toda linguagem já alcança a Open AI Cloud por qualquer cliente compatível com OpenAI ou
Anthropic — basta apontar a URL base para
`https://api.hanzo.ai/v1` e usar sua chave Hanzo. Os SDKs nativos acima acrescentam
modelos tipados, novas tentativas, auxiliares de streaming e a superfície de agentes/MCP.
</Callout>

## Início rápido

```bash tab="Python (AI)"
pip install hanzo
```

```bash tab="Python (Cloud)"
pip install hanzoai
```

```bash tab="TypeScript (AI)"
npm i @hanzo/ai
```

```bash tab="TypeScript (Cloud)"
npm i @hanzo/sdk
```

```bash tab="Go"
go get github.com/hanzoai/go-sdk
```

Todo cliente segue a mesma forma — construa com sua chave, chame um recurso `/v1`:

```python tab="Python"
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-key")
response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
```

```typescript tab="TypeScript"
import Hanzo from '@hanzo/sdk';

const client = new Hanzo({ apiKey: 'sk-your-key' });
const response = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello' }],
});
```

```go tab="Go"
client := hanzoai.NewClient(option.WithAPIKey("sk-your-key"))
response, _ := client.Chat.Completions.New(ctx, hanzoai.ChatCompletionNewParams{
    Model:    hanzoai.F("zen5"),
    Messages: hanzoai.F([]hanzoai.ChatCompletionMessageParamUnion{
        hanzoai.UserMessage("Hello"),
    }),
})
```

## Uma chave, uma URL base

```bash
export HANZO_API_KEY="sk-..."   # from console.hanzo.ai
# Base URL for every service: https://api.hanzo.ai/v1
```

Pegue sua chave em [console.hanzo.ai](https://console.hanzo.ai).
