# SDK Hanzo

**Hanzo AI — один API для каждой модели, один SDK для каждого языка.** Говорите с
Open AI Cloud на языке, на котором вы уже работаете. Каждый SDK порождается из
одной спецификации OpenAPI 3.1 и делит одно удостоверение.

## Две библиотеки на язык

У каждого языка две первоклассные линии — ставьте ту, что подходит к задаче, или
обе:

<Cards>
  <Card title="Cloud SDK">
    Полный сгенерированный клиент для **всей** Open AI Cloud (`/v1/*`): ИИ,
    агенты, вычисления, данные, сеть, безопасность, платформа, наблюдение, web3, приложения.
    Идиоматичный и типизированный для своей экосистемы. Настоящий код лежит в `hanzo-<lang>/sdk`.
  </Card>
  <Card title="Библиотека ИИ / агентов">
    Сделанная вручную библиотека с ИИ на первом месте — модели, агенты, инструменты, память, MCP и
    инференс. Флагман — Python (`pip install hanzo`); Node поставляет
    `@hanzo/ai`.
  </Card>
</Cards>

## Матрица установки

Как исполняемые установки показаны только общедоступные пакеты. Остальное
в активной разработке — каждый ведёт в организацию языка, где исходный код
уже лежит.

| Язык | Библиотека | Установка | Состояние |
|----------|---------|---------|--------|
| **Python** | ИИ / агенты (флагман) | `pip install hanzo` | Общая доступность |
| **Python** | Cloud SDK | `pip install hanzoai` | Общая доступность |
| **TypeScript** | Библиотека ИИ | `npm i @hanzo/ai` | Общая доступность |
| **TypeScript** | Cloud SDK | `npm i @hanzo/sdk` | Общая доступность |
| **Go** | Cloud SDK | `go get github.com/hanzoai/go-sdk` | Общая доступность |
| **Rust** | Cloud SDK | `cargo add hanzo` | Общая доступность |
| **C++** | Cloud SDK | `find_package(hanzo)` | Скоро |
| **Swift** | Cloud SDK | `.package(url: "https://github.com/hanzo-swift/sdk")` | Общая доступность |
| **Kotlin** | Cloud SDK | Gradle / Maven | Скоро |

<Callout title="Совместимо по проводу уже сегодня">
Каждый язык уже достигает Open AI Cloud через любой клиент, совместимый с OpenAI или
Anthropic — направьте базовый URL на
`https://api.hanzo.ai/v1` и используйте ключ Hanzo. Нативные SDK выше добавляют
типизированные модели, повторы, помощники потоковой передачи и поверхность агентов/MCP.
</Callout>

## Быстрый старт

```bash tab="Python (AI)"
pip install hanzo
```

```bash tab="Python (Cloud)"
pip install hanzoai
```

```bash tab="TypeScript (AI)"
npm i @hanzo/ai
```

```bash tab="TypeScript (Cloud)"
npm i @hanzo/sdk
```

```bash tab="Go"
go get github.com/hanzoai/go-sdk
```

Каждый клиент следует одной форме — соберите его ключом, вызовите ресурс `/v1`:

```python tab="Python"
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-key")
response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
```

```typescript tab="TypeScript"
import Hanzo from '@hanzo/sdk';

const client = new Hanzo({ apiKey: 'sk-your-key' });
const response = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello' }],
});
```

```go tab="Go"
client := hanzoai.NewClient(option.WithAPIKey("sk-your-key"))
response, _ := client.Chat.Completions.New(ctx, hanzoai.ChatCompletionNewParams{
    Model:    hanzoai.F("zen5"),
    Messages: hanzoai.F([]hanzoai.ChatCompletionMessageParamUnion{
        hanzoai.UserMessage("Hello"),
    }),
})
```

## Один ключ, один базовый URL

```bash
export HANZO_API_KEY="sk-..."   # from console.hanzo.ai
# Base URL for every service: https://api.hanzo.ai/v1
```

Получите ключ на [console.hanzo.ai](https://console.hanzo.ai).
