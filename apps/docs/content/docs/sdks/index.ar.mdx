# حزم SDK من Hanzo

**Hanzo AI — واجهة API واحدة لكل نموذج، وحزمة SDK واحدة لكل لغة.** خاطب
Open AI Cloud من اللغة التي تعمل بها أصلًا. كل حزمة SDK تُولَّد من
مواصفة OpenAPI 3.1 نفسها وتشارك اعتمادًا واحدًا.

## مكتبتان لكل لغة

لكل لغة خطان من الدرجة الأولى — ثبّت ما يناسب العمل، أو
كليهما:

<Cards>
  <Card title="Cloud SDK">
    العميل المولَّد الكامل لـ Open AI Cloud **بأكملها** (`/v1/*`): الذكاء الاصطناعي،
    الوكلاء، الحوسبة، البيانات، الشبكة، الأمان، المنصة، المراقبة، web3، التطبيقات.
    اصطلاحي ومُنمَّط لنظامه. الكود الحقيقي يعيش في `hanzo-<lang>/sdk`.
  </Card>
  <Card title="مكتبة الذكاء الاصطناعي / الوكلاء">
    المكتبة المصنوعة يدويًا والتي تقدّم الذكاء الاصطناعي — النماذج والوكلاء والأدوات والذاكرة وMCP و
    الاستدلال. الرائدة هي Python (`pip install hanzo`)؛ وNode ينشر
    `@hanzo/ai`.
  </Card>
</Cards>

## مصفوفة التثبيت

لا تُعرض كعمليات تثبيت قابلة للتشغيل إلا الحزم المتاحة عمومًا. الباقي
قيد التطوير النشط — وكل واحد يربط بمؤسسة لغته حيث يعيش المصدر
فعلًا.

| اللغة | المكتبة | التثبيت | الحالة |
|----------|---------|---------|--------|
| **Python** | ذكاء اصطناعي / وكلاء (الرائدة) | `pip install hanzo` | توافر عام |
| **Python** | Cloud SDK | `pip install hanzoai` | توافر عام |
| **TypeScript** | مكتبة الذكاء الاصطناعي | `npm i @hanzo/ai` | توافر عام |
| **TypeScript** | Cloud SDK | `npm i @hanzo/sdk` | توافر عام |
| **Go** | Cloud SDK | `go get github.com/hanzoai/go-sdk` | توافر عام |
| **Rust** | Cloud SDK | `cargo add hanzo` | توافر عام |
| **C++** | Cloud SDK | `find_package(hanzo)` | قريبًا |
| **Swift** | Cloud SDK | `.package(url: "https://github.com/hanzo-swift/sdk")` | توافر عام |
| **Kotlin** | Cloud SDK | Gradle / Maven | قريبًا |

<Callout title="متوافق على السلك اليوم">
كل لغة تصل أصلًا إلى Open AI Cloud عبر أي عميل متوافق مع OpenAI أو
Anthropic — وجّه عنوان URL الأساسي إلى
`https://api.hanzo.ai/v1` واستخدم مفتاح Hanzo. حزم SDK الأصيلة أعلاه تضيف
نماذج منمطة، وإعادات محاولة، ومساعدات البث، وسطح الوكلاء/MCP.
</Callout>

## بدء سريع

```bash tab="Python (AI)"
pip install hanzo
```

```bash tab="Python (Cloud)"
pip install hanzoai
```

```bash tab="TypeScript (AI)"
npm i @hanzo/ai
```

```bash tab="TypeScript (Cloud)"
npm i @hanzo/sdk
```

```bash tab="Go"
go get github.com/hanzoai/go-sdk
```

كل عميل يتبع الشكل نفسه — ابنِه بمفتاحك، واستدعِ مورد `/v1`:

```python tab="Python"
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-key")
response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
```

```typescript tab="TypeScript"
import Hanzo from '@hanzo/sdk';

const client = new Hanzo({ apiKey: 'sk-your-key' });
const response = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello' }],
});
```

```go tab="Go"
client := hanzoai.NewClient(option.WithAPIKey("sk-your-key"))
response, _ := client.Chat.Completions.New(ctx, hanzoai.ChatCompletionNewParams{
    Model:    hanzoai.F("zen5"),
    Messages: hanzoai.F([]hanzoai.ChatCompletionMessageParamUnion{
        hanzoai.UserMessage("Hello"),
    }),
})
```

## مفتاح واحد، وعنوان URL أساسي واحد

```bash
export HANZO_API_KEY="sk-..."   # from console.hanzo.ai
# Base URL for every service: https://api.hanzo.ai/v1
```

احصل على مفتاحك من [console.hanzo.ai](https://console.hanzo.ai).
