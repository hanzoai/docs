# Hanzo SDK

**Hanzo AI — すべてのモデルに一つの API、すべての言語に一つの SDK。** すでに使っている言語から
Open AI Cloud に話しかけます。各 SDK は同じ OpenAPI 3.1 仕様から生成され、一つの資格情報を共有します。

## 言語ごとに二つのライブラリ

各言語には二つの第一級の系統があります — 仕事に合う方を入れるか、
両方を入れます。

<Cards>
  <Card title="Cloud SDK">
    **全体**の Open AI Cloud (`/v1/*`) 向けに生成された完全なクライアント。AI、
    エージェント、計算、データ、ネットワーク、セキュリティ、プラットフォーム、観測、web3、アプリ。
    その生態系に合わせて慣用的で型付きです。実コードは `hanzo-<lang>/sdk` にあります。
  </Card>
  <Card title="AI／エージェントのライブラリ">
    手で作った、AI を先に置くライブラリ — モデル、エージェント、ツール、メモリ、MCP、
    推論。旗艦は Python（`pip install hanzo`）です。Node は
    `@hanzo/ai` を出します。
  </Card>
</Cards>


どのクライアントも同じ形です — キーで組み立て、`/v1` のリソースを呼びます。

```python tab="Python"
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-key")
response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
```

```typescript tab="TypeScript"
import Hanzo from '@hanzo/sdk';

const client = new Hanzo({ apiKey: 'sk-your-key' });
const response = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello' }],
});
```

```go tab="Go"
client := hanzoai.NewClient(option.WithAPIKey("sk-your-key"))
response, _ := client.Chat.Completions.New(ctx, hanzoai.ChatCompletionNewParams{
    Model:    hanzoai.F("zen5"),
    Messages: hanzoai.F([]hanzoai.ChatCompletionMessageParamUnion{
        hanzoai.UserMessage("Hello"),
    }),
})
```

## 一つのキー、一つのベース URL

```bash
export HANZO_API_KEY="sk-..."   # from console.hanzo.ai
# Base URL for every service: https://api.hanzo.ai/v1
```

キーは [console.hanzo.ai](https://console.hanzo.ai) で取得します。
