# Hanzo SDK

**Hanzo AI — हर मॉडल के लिए एक API, हर भाषा के लिए एक SDK।** जिस भाषा में आप पहले से काम करते हैं, उसी से
Open AI Cloud से बात करें। हर SDK उसी OpenAPI 3.1 विनिर्देश से बनता है और एक प्रमाण-पत्र साझा करता है।

## प्रत्येक भाषा के दो पुस्तकालय

हर भाषा की दो प्रथम श्रेणी की पंक्तियाँ हैं — जो काम के अनुकूल हो उसे स्थापित करें, या
दोनों:

<Cards>
  <Card title="Cloud SDK">
    **पूरी** Open AI Cloud (`/v1/*`) का उत्पन्न पूर्ण क्लाइंट: कृत्रिम बुद्धि,
    एजेंट, संगणना, डेटा, नेटवर्क, सुरक्षा, मंच, अवलोकन, web3, अनुप्रयोग।
    अपने पारिस्थितिकी तंत्र के लिए मुहावरेदार और टाइप किया हुआ। असली कोड `hanzo-<lang>/sdk` में रहता है।
  </Card>
  <Card title="कृत्रिम बुद्धि / एजेंट पुस्तकालय">
    हाथ से बना, कृत्रिम बुद्धि को आगे रखने वाला पुस्तकालय — मॉडल, एजेंट, उपकरण, स्मृति, MCP और
    अनुमान। ध्वजवाहक Python है (`pip install hanzo`); Node
    `@hanzo/ai` भेजता है।
  </Card>
</Cards>

## स्थापना आव्यूह

केवल सामान्य उपलब्धता वाले पैकेज चलने योग्य स्थापना के रूप में दिखाए जाते हैं। शेष
सक्रिय विकास में हैं — प्रत्येक अपनी भाषा-संस्था से जुड़ता है, जहाँ स्रोत
पहले से रहता है।

| भाषा | पुस्तकालय | स्थापना | स्थिति |
|----------|---------|---------|--------|
| **Python** | कृत्रिम बुद्धि / एजेंट (ध्वजवाहक) | `pip install hanzo` | सामान्य उपलब्धता |
| **Python** | Cloud SDK | `pip install hanzoai` | सामान्य उपलब्धता |
| **TypeScript** | कृत्रिम बुद्धि पुस्तकालय | `npm i @hanzo/ai` | सामान्य उपलब्धता |
| **TypeScript** | Cloud SDK | `npm i @hanzo/sdk` | सामान्य उपलब्धता |
| **Go** | Cloud SDK | `go get github.com/hanzoai/go-sdk` | सामान्य उपलब्धता |
| **Rust** | Cloud SDK | `cargo add hanzo` | सामान्य उपलब्धता |
| **C++** | Cloud SDK | `find_package(hanzo)` | जल्द आ रहा है |
| **Swift** | Cloud SDK | `.package(url: "https://github.com/hanzo-swift/sdk")` | सामान्य उपलब्धता |
| **Kotlin** | Cloud SDK | Gradle / Maven | जल्द आ रहा है |

<Callout title="आज तार पर संगत">
हर भाषा OpenAI- या
Anthropic-संगत किसी भी क्लाइंट से Open AI Cloud तक पहले से पहुँचती है — आधार URL को
`https://api.hanzo.ai/v1` पर रखें और अपनी Hanzo कुंजी का उपयोग करें। ऊपर के देशी SDK
टाइप किए मॉडल, पुनःप्रयास, स्ट्रीमिंग सहायक और एजेंट/MCP सतह जोड़ते हैं।
</Callout>

## त्वरित आरंभ

```bash tab="Python (AI)"
pip install hanzo
```

```bash tab="Python (Cloud)"
pip install hanzoai
```

```bash tab="TypeScript (AI)"
npm i @hanzo/ai
```

```bash tab="TypeScript (Cloud)"
npm i @hanzo/sdk
```

```bash tab="Go"
go get github.com/hanzoai/go-sdk
```

हर क्लाइंट एक ही रूप का अनुसरण करता है — अपनी कुंजी से बनाएँ, एक `/v1` संसाधन बुलाएँ:

```python tab="Python"
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-key")
response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
```

```typescript tab="TypeScript"
import Hanzo from '@hanzo/sdk';

const client = new Hanzo({ apiKey: 'sk-your-key' });
const response = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello' }],
});
```

```go tab="Go"
client := hanzoai.NewClient(option.WithAPIKey("sk-your-key"))
response, _ := client.Chat.Completions.New(ctx, hanzoai.ChatCompletionNewParams{
    Model:    hanzoai.F("zen5"),
    Messages: hanzoai.F([]hanzoai.ChatCompletionMessageParamUnion{
        hanzoai.UserMessage("Hello"),
    }),
})
```

## एक कुंजी, एक आधार URL

```bash
export HANZO_API_KEY="sk-..."   # from console.hanzo.ai
# Base URL for every service: https://api.hanzo.ai/v1
```

अपनी कुंजी [console.hanzo.ai](https://console.hanzo.ai) पर लें।
