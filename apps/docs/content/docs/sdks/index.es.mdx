# SDK de Hanzo

**Hanzo AI — una API para cada modelo, un SDK para cada lenguaje.** Habla con
Open AI Cloud desde el lenguaje en el que ya trabajas. Cada SDK se genera a partir
de la misma especificación OpenAPI 3.1 y comparte una credencial.

## Dos bibliotecas por lenguaje

Cada lenguaje tiene dos líneas de primer nivel — instala la que encaje con el trabajo, o
las dos:

<Cards>
  <Card title="SDK de Cloud">
    El cliente generado y completo para **toda** Open AI Cloud (`/v1/*`): IA,
    agentes, cómputo, datos, red, seguridad, plataforma, observación, web3, aplicaciones.
    Idiomático y tipado para su ecosistema. El código real vive en `hanzo-<lang>/sdk`.
  </Card>
  <Card title="Biblioteca de IA / agentes">
    La biblioteca hecha a mano y centrada en la IA — modelos, agentes, herramientas, memoria, MCP e
    inferencia. La insignia es Python (`pip install hanzo`); Node publica
    `@hanzo/ai`.
  </Card>
</Cards>

## Matriz de instalación

Solo los paquetes de disponibilidad general se muestran como instalaciones ejecutables. El resto está
en desarrollo activo — cada uno enlaza a su organización por lenguaje, donde el código
ya vive.

| Lenguaje | Biblioteca | Instalación | Estado |
|----------|---------|---------|--------|
| **Python** | IA / agentes (insignia) | `pip install hanzo` | Disponibilidad general |
| **Python** | SDK de Cloud | `pip install hanzoai` | Disponibilidad general |
| **TypeScript** | Biblioteca de IA | `npm i @hanzo/ai` | Disponibilidad general |
| **TypeScript** | SDK de Cloud | `npm i @hanzo/sdk` | Disponibilidad general |
| **Go** | SDK de Cloud | `go get github.com/hanzoai/go-sdk` | Disponibilidad general |
| **Rust** | SDK de Cloud | `cargo add hanzo` | Disponibilidad general |
| **C++** | SDK de Cloud | `find_package(hanzo)` | Próximamente |
| **Swift** | SDK de Cloud | `.package(url: "https://github.com/hanzo-swift/sdk")` | Disponibilidad general |
| **Kotlin** | SDK de Cloud | Gradle / Maven | Próximamente |

<Callout title="Compatible en el cable hoy">
Cada lenguaje ya puede alcanzar Open AI Cloud a través de cualquier cliente compatible con OpenAI o
Anthropic — basta con apuntar la URL base a
`https://api.hanzo.ai/v1` y usar tu clave de Hanzo. Los SDK nativos de arriba añaden
modelos tipados, reintentos, ayudas de transmisión y la superficie de agentes/MCP.
</Callout>

## Inicio rápido

```bash tab="Python (AI)"
pip install hanzo
```

```bash tab="Python (Cloud)"
pip install hanzoai
```

```bash tab="TypeScript (AI)"
npm i @hanzo/ai
```

```bash tab="TypeScript (Cloud)"
npm i @hanzo/sdk
```

```bash tab="Go"
go get github.com/hanzoai/go-sdk
```

Cada cliente sigue la misma forma — constrúyelo con tu clave, llama a un recurso `/v1`:

```python tab="Python"
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-key")
response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
```

```typescript tab="TypeScript"
import Hanzo from '@hanzo/sdk';

const client = new Hanzo({ apiKey: 'sk-your-key' });
const response = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello' }],
});
```

```go tab="Go"
client := hanzoai.NewClient(option.WithAPIKey("sk-your-key"))
response, _ := client.Chat.Completions.New(ctx, hanzoai.ChatCompletionNewParams{
    Model:    hanzoai.F("zen5"),
    Messages: hanzoai.F([]hanzoai.ChatCompletionMessageParamUnion{
        hanzoai.UserMessage("Hello"),
    }),
})
```

## Una clave, una URL base

```bash
export HANZO_API_KEY="sk-..."   # from console.hanzo.ai
# Base URL for every service: https://api.hanzo.ai/v1
```

Obtén tu clave en [console.hanzo.ai](https://console.hanzo.ai).
