**Dopo questa pagina hai una credenziale che funziona e una chiamata che ha risposto.**

Hanzo è un cloud dietro una chiave. Ogni capacità — inferenza, identità,
archiviazione, denaro, agenti — risponde su `https://api.hanzo.ai`, e la CLI, gli
SDK e gli strumenti MCP sono generati dalla stessa descrizione. Non c’è nulla
da collegare per servizio: una chiave e tutto è raggiungibile.

## 1. Installa

<Tabs items={['npm', 'Script', 'Homebrew', 'Dal codice sorgente']}>
<Tab value="npm">
```bash
npm i -g hanzo
```

`hanzo` è la CLI e il client in una sola installazione.
</Tab>
<Tab value="Script">
```bash
curl -fsSL https://hanzo.sh | sh
```

Si installa in `~/.local/bin`. `https://hanzo.sh/cli` installa solo la CLI.
</Tab>
<Tab value="Homebrew">
```bash
brew install hanzoai/tap/hanzo
```
</Tab>
<Tab value="Dal codice sorgente">
```bash
git clone https://github.com/hanzoai/cli && cd cli && cargo install --path .
```
</Tab>
</Tabs>

```bash
hanzo version
```

## 2. Accedi

```bash
hanzo auth login
```

Si apre un browser su [hanzo.id](https://hanzo.id), il provider di identità
di Hanzo, e la credenziale resta in locale. `hanzo auth show` stampa
chi sei; `hanzo auth list` mostra ogni identità su questa macchina e
`hanzo auth use` passa dall’una all’altra.

Su un server crea una chiave invece di far accedere una persona: **console.hanzo.ai →
chiavi API**. Una chiave segreta sei *tu*, quindi sta su un server e mai
in un browser — [Autenticazione](/docs/api-keys) è tutta la regola.

```bash
export HANZO_API_KEY=sk-...
```

## 3. Elenca i modelli

Il catalogo dei modelli che il gateway serve adesso. È una lettura, serve
solo la chiave, ed è la stessa operazione sulle quattro superfici.

<Tabs items={['CLI', 'SDK', 'HTTP', 'MCP']}>
<Tab value="CLI">
```bash

```
</Tab>
<Tab value="SDK">
<Tabs items={['.ts', '.py', '.go', '.rs', '.swift', '.kt']}>
<Tab value=".ts">

</Tab>

</Tab>
<Tab value=".rs">

```rust

```
</Tab>
<Tab value=".swift">

</Tab>
<Tab value=".kt">
```kotlin

```
</Tab>
</Tabs>

Sono tutti generati dalla stessa descrizione dell’API, quindi i nomi dei
metodi coincidono tra i linguaggi. [C++](/docs/sdks/cpp) è quello che sta ancora
arrivando.
</Tab>
<Tab value="HTTP">
```bash
curl https://api.hanzo.ai/v1/models \
  -H "Authorization: Bearer $HANZO_API_KEY"
```
</Tab>
<Tab value="MCP">
```bash
curl -X POST https://api.hanzo.ai/v1/mcp \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

Un endpoint, uno strumento per capacità. `tools/call` nomina la capacità e
l’operazione; `describe` spiega l’input di qualunque operazione.
</Tab>
</Tabs>

Sono una API vista da quattro posti, e le schede sopra sono tutta la
differenza. Scegli quella in cui scriverai:

- **[CLI](/docs/cli)** — ogni capacità come gruppo di comandi, una pagina ciascuna.
- **[SDK](/docs/sdks)** — Python, TypeScript, Go, Rust, C++, Swift e Kotlin,
  generati dalla stessa descrizione della CLI e degli strumenti.
- **[MCP](/docs/mcp)** — un endpoint a cui si collega un agente; [gli strumenti](/docs/mcp-tools)
  sono elencati uno per capacità.

HTTP non ha bisogno di una pagina: è `https://api.hanzo.ai` e la chiave che hai appena esportato.

## 4. Invia un completamento

Questo è il primo passo che consuma credito; tutto quanto sopra si può eseguire gratis.

```bash
hanzo chat completions --model zen-1 --messages '[{"role":"user","content":"hello"}]'
```

Poi leggi quanto ha consumato:

```bash
hanzo billing balance
hanzo usage summary
```

[Crediti e fatturazione](/docs/credits) spiega che cos’è un credito e che cosa succede a
zero; [Prezzi](/docs/pricing) è la tariffa di ogni modello e strumento.

## 5. Esegui il cloud in locale

Lo stesso binario che serve `api.hanzo.ai` gira sulla tua macchina:

```bash
hanzo up cloud
```

`hanzo up` da solo è la stessa cosa — `cloud` è il valore predefinito. Nomina un servizio per
eseguirlo da solo: `hanzo up iam`, `hanzo up kms`, `hanzo up gateway`, `hanzo up
storage`, `hanzo up pubsub`. Vedi [Esegui il tuo](/docs/network) per capire che cosa
significa e che cosa serve.
