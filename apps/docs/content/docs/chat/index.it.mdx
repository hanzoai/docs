# Hanzo Chat

Hanzo Chat è l'app di chat su Hanzo Cloud, costruita su [LibreChat](https://librechat.ai). Esegue i nostri modelli — la famiglia di frontiera **enso** e la famiglia a pesi aperti **Zen** — con strumenti MCP, agenti configurabili, caricamento di file con RAG, visione, cronologia delle conversazioni, preimpostazioni e plugin. Sono presenti anche modelli di laboratori esterni, e compaiono nello stesso menu dei modelli.

Disponibile come servizio ospitato su [chat.hanzo.ai](https://chat.hanzo.ai) oppure in self-hosting tramite Docker.

## Avvio rapido

### Ospitato (consigliato)

1. Vai su [chat.hanzo.ai](https://chat.hanzo.ai)
2. Accedi con il tuo account Hanzo
3. Il tuo **credito gratuito di $5** viene applicato automaticamente
4. Scegli un modello e inizia a conversare

### Self-hosting

```bash
git clone https://github.com/hanzoai/chat
cd chat
cp .env.example .env
# Edit .env with your HANZO_API_KEY
docker compose up -d
# Open http://localhost:3081
```

### API

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zen5",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

## Uso dell'SDK

### Python

```python
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-api-key")

response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello, Zen."}]
)
print(response.choices[0].message.content)
```

### TypeScript

```typescript
import Hanzo from '@hanzo/ai'

const client = new Hanzo({ apiKey: process.env.HANZO_API_KEY })

const completion = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello, Zen.' }],
})
console.log(completion.choices[0].message.content)
```

### Client HTTP esistenti

`/v1/chat/completions` accetta e restituisce la forma JSON chat-completions, quindi un
client già scritto contro quella forma funziona qui non appena il suo URL di base punta a
`https://api.hanzo.ai/v1` e invia una chiave Hanzo. Gli identificatori di modello non sono portabili
tra fornitori — `zen5` e `enso` esistono solo qui.
