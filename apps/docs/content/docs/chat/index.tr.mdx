# Hanzo Chat

Hanzo Chat, [LibreChat](https://librechat.ai) üzerine kurulu, Hanzo Cloud üzerindeki sohbet uygulamasıdır. Kendi modellerimizi çalıştırır — sınır **enso** ailesi ve açık ağırlıklı **Zen** ailesi — MCP araçları, yapılandırılabilir ajanlar, RAG ile dosya yükleme, görme, konuşma geçmişi, hazır ayarlar ve eklentilerle. Dış laboratuvarların modelleri de taşınır ve aynı model menüsünde görünür.

[chat.hanzo.ai](https://chat.hanzo.ai) adresinde barındırılan bir hizmet olarak ya da Docker ile kendi barındırmanız olarak kullanılabilir.

## Hızlı başlangıç

### Barındırılan (önerilen)

1. [chat.hanzo.ai](https://chat.hanzo.ai) adresine gidin
2. Hanzo hesabınızla oturum açın
3. **$5 ücretsiz krediniz** otomatik uygulanır
4. Bir model seçin ve sohbete başlayın

### Kendi barındırmanız

```bash
git clone https://github.com/hanzoai/chat
cd chat
cp .env.example .env
# Edit .env with your HANZO_API_KEY
docker compose up -d
# Open http://localhost:3081
```

### API

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zen5",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

## SDK kullanımı

### Python

```python
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-api-key")

response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello, Zen."}]
)
print(response.choices[0].message.content)
```

### TypeScript

```typescript
import Hanzo from '@hanzo/ai'

const client = new Hanzo({ apiKey: process.env.HANZO_API_KEY })

const completion = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello, Zen.' }],
})
console.log(completion.choices[0].message.content)
```

### Var olan HTTP istemcileri

`/v1/chat/completions` chat-completions JSON biçimini alır ve döndürür, bu yüzden
bu biçime karşı yazılmış bir istemci, taban URL'si
`https://api.hanzo.ai/v1` adresini gösterdiğinde ve bir Hanzo anahtarı gönderdiğinde burada çalışır. Model kimlikleri
satıcılar arasında taşınamaz — `zen5` ve `enso` yalnızca burada vardır.

- **Sürpriz fatura yok** — krediler tükenince hizmet durur
