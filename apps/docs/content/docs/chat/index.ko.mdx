# Hanzo Chat

Hanzo Chat은 [LibreChat](https://librechat.ai) 위에 만든 Hanzo Cloud의 채팅 앱입니다. 우리 모델 — 프런티어 계열 **enso**와 오픈 웨이트 계열 **Zen** — 을 MCP 도구, 구성 가능한 에이전트, RAG가 있는 파일 업로드, 시각, 대화 기록, 프리셋, 플러그인과 함께 실행합니다. 외부 연구실의 모델도 실리며, 같은 모델 메뉴에 나타납니다.

호스팅 서비스로 [chat.hanzo.ai](https://chat.hanzo.ai)에서, 또는 Docker로 직접 호스팅할 수 있습니다.

## 빠른 시작

### 호스팅(권장)

1. [chat.hanzo.ai](https://chat.hanzo.ai)로 이동합니다
2. Hanzo 계정으로 로그인합니다
3. **$5 무료 크레딧**이 자동으로 적용됩니다
4. 모델을 고르고 대화를 시작합니다

### 직접 호스팅

```bash
git clone https://github.com/hanzoai/chat
cd chat
cp .env.example .env
# Edit .env with your HANZO_API_KEY
docker compose up -d
# Open http://localhost:3081
```

### API

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zen5",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

## SDK 사용

### Python

```python
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-api-key")

response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello, Zen."}]
)
print(response.choices[0].message.content)
```

### TypeScript

```typescript
import Hanzo from '@hanzo/ai'

const client = new Hanzo({ apiKey: process.env.HANZO_API_KEY })

const completion = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello, Zen.' }],
})
console.log(completion.choices[0].message.content)
```

### 기존 HTTP 클라이언트

`/v1/chat/completions`는 chat-completions JSON 형태를 받고 돌려줍니다. 그래서
그 형태에 맞춰 이미 작성된 클라이언트는 기본 URL이
`https://api.hanzo.ai/v1`을 가리키고 Hanzo 키를 보내면 여기서 동작합니다. 모델 id는 공급자 사이에
옮길 수 없습니다 — `zen5`와 `enso`는 여기에만 있습니다.

## 요금

- 새 계정마다 **$5 무료 크레딧**(30일 후 만료)
- **선불 청구** — [console.hanzo.ai](https://console.hanzo.ai)에서 크레딧을 추가합니다
- 입력 **$0.34/MTok**부터 (`zen5-flash`)
- **뜻밖의 청구서 없음** — 크레딧이 떨어지면 서비스가 멈춥니다
