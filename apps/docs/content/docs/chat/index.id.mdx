# Hanzo Chat

Hanzo Chat adalah aplikasi obrolan di Hanzo Cloud, dibangun di atas [LibreChat](https://librechat.ai). Ia menjalankan model kami sendiri — keluarga perbatasan **enso** dan keluarga bobot terbuka **Zen** — dengan alat MCP, agen yang dapat diatur, unggah berkas dengan RAG, penglihatan, riwayat percakapan, preset, dan plugin. Model dari laboratorium luar juga dibawa, dan muncul di menu model yang sama.

Tersedia sebagai layanan terhosting di [chat.hanzo.ai](https://chat.hanzo.ai) atau dihosting sendiri lewat Docker.

## Mulai cepat

### Terhosting (disarankan)

1. Buka [chat.hanzo.ai](https://chat.hanzo.ai)
2. Masuk dengan akun Hanzo Anda
3. **Kredit gratis $5** Anda diterapkan secara otomatis
4. Pilih model dan mulai mengobrol

### Host sendiri

```bash
git clone https://github.com/hanzoai/chat
cd chat
cp .env.example .env
# Edit .env with your HANZO_API_KEY
docker compose up -d
# Open http://localhost:3081
```

### API

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zen5",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

## Penggunaan SDK

### Python

```python
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-api-key")

response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello, Zen."}]
)
print(response.choices[0].message.content)
```

### TypeScript

```typescript
import Hanzo from '@hanzo/ai'

const client = new Hanzo({ apiKey: process.env.HANZO_API_KEY })

const completion = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello, Zen.' }],
})
console.log(completion.choices[0].message.content)
```

### Klien HTTP yang sudah ada

`/v1/chat/completions` menerima dan mengembalikan bentuk JSON chat-completions, jadi
klien yang sudah ditulis terhadap bentuk itu bekerja di sini begitu URL dasarnya menunjuk ke
`https://api.hanzo.ai/v1` dan mengirim kunci Hanzo. Pengenal model tidak portabel
antar vendor — `zen5` dan `enso` hanya ada di sini.
