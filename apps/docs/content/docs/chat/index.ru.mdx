# Hanzo Chat

Hanzo Chat — это приложение чата на Hanzo Cloud, построенное на [LibreChat](https://librechat.ai). Оно запускает наши собственные модели — передовое семейство **enso** и семейство открытых весов **Zen** — с инструментами MCP, настраиваемыми агентами, загрузкой файлов с RAG, зрением, историей разговоров, пресетами и плагинами. Модели сторонних лабораторий тоже доступны и появляются в том же меню моделей.

Доступно как размещённый сервис на [chat.hanzo.ai](https://chat.hanzo.ai) или самостоятельно через Docker.

## Быстрый старт

### Размещённый (рекомендуется)

1. Откройте [chat.hanzo.ai](https://chat.hanzo.ai)
2. Войдите в свою учётную запись Hanzo
3. Ваш **бесплатный кредит $5** применяется автоматически
4. Выберите модель и начните переписку

### Самостоятельный запуск

```bash
git clone https://github.com/hanzoai/chat
cd chat
cp .env.example .env
# Edit .env with your HANZO_API_KEY
docker compose up -d
# Open http://localhost:3081
```

### API

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zen5",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

## Использование SDK

### Python

```python
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-api-key")

response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello, Zen."}]
)
print(response.choices[0].message.content)
```

### TypeScript

```typescript
import Hanzo from '@hanzo/ai'

const client = new Hanzo({ apiKey: process.env.HANZO_API_KEY })

const completion = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello, Zen.' }],
})
console.log(completion.choices[0].message.content)
```

### Существующие HTTP-клиенты

`/v1/chat/completions` принимает и возвращает JSON-форму chat-completions, поэтому
клиент, уже написанный под эту форму, работает здесь, как только его базовый URL указывает на
`https://api.hanzo.ai/v1` и он отправляет ключ Hanzo. Идентификаторы моделей не переносятся
между поставщиками — `zen5` и `enso` существуют только здесь.

## Цены

- **Бесплатный кредит $5** на каждом новом аккаунте (истекает через 30 дней)
- **Предоплата** — добавьте кредиты через [console.hanzo.ai](https://console.hanzo.ai)
- **От $0.34/MTok** на входе (`zen5-flash`)
- **Без неожиданных счетов** — сервис останавливается, когда кредиты исчерпаны
