# Hanzo Chat

Hanzo Chat ist die Chat-App auf Hanzo Cloud, aufgebaut auf [LibreChat](https://librechat.ai). Sie führt unsere eigenen Modelle aus — die Frontier-Familie **enso** und die Familie mit offenen Gewichten **Zen** — mit MCP-Werkzeugen, konfigurierbaren Agenten, Datei-Uploads mit RAG, Bildverstehen, Gesprächsverlauf, Voreinstellungen und Plugins. Modelle externer Labore werden ebenfalls geführt und erscheinen im selben Modellmenü.

Verfügbar als gehosteter Dienst unter [chat.hanzo.ai](https://chat.hanzo.ai) oder selbst betrieben über Docker.

## Schnellstart

### Gehostet (empfohlen)

1. Öffnen Sie [chat.hanzo.ai](https://chat.hanzo.ai)
2. Melden Sie sich mit Ihrem Hanzo-Konto an
3. Ihr **kostenloses Guthaben von $5** wird automatisch angewendet
4. Wählen Sie ein Modell und beginnen Sie zu chatten

### Selbst betrieben

```bash
git clone https://github.com/hanzoai/chat
cd chat
cp .env.example .env
# Edit .env with your HANZO_API_KEY
docker compose up -d
# Open http://localhost:3081
```

### API

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zen5",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

## SDK-Nutzung

### Python

```python
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-api-key")

response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello, Zen."}]
)
print(response.choices[0].message.content)
```

### TypeScript

```typescript
import Hanzo from '@hanzo/ai'

const client = new Hanzo({ apiKey: process.env.HANZO_API_KEY })

const completion = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello, Zen.' }],
})
console.log(completion.choices[0].message.content)
```

### Vorhandene HTTP-Clients

`/v1/chat/completions` nimmt die JSON-Form chat-completions entgegen und gibt sie zurück, sodass ein
Client, der bereits gegen diese Form geschrieben ist, hier funktioniert, sobald seine Basis-URL auf
`https://api.hanzo.ai/v1` zeigt und er einen Hanzo-Schlüssel sendet. Modellkennungen sind zwischen
Anbietern nicht übertragbar — `zen5` und `enso` gibt es nur hier.
