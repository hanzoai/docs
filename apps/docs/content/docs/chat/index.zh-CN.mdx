# Hanzo Chat

Hanzo Chat 是 Hanzo Cloud 上的聊天应用，构建于 [LibreChat](https://librechat.ai)。它运行我们自己的模型——前沿系列 **enso** 与开放权重系列 **Zen**——并带有 MCP 工具、可配置智能体、带 RAG 的文件上传、视觉、对话历史、预设与插件。外部实验室的模型也会提供，并出现在同一个模型菜单里。

可作为托管服务在 [chat.hanzo.ai](https://chat.hanzo.ai) 使用，或通过 Docker 自行托管。

## 快速开始

### 托管（推荐）

1. 打开 [chat.hanzo.ai](https://chat.hanzo.ai)
2. 使用你的 Hanzo 账户登录
3. **$5 免费积分**会自动入账
4. 选择一个模型并开始聊天

### 自行托管

```bash
git clone https://github.com/hanzoai/chat
cd chat
cp .env.example .env
# Edit .env with your HANZO_API_KEY
docker compose up -d
# Open http://localhost:3081
```

### API

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zen5",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

## SDK 用法

### Python

```python
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-api-key")

response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello, Zen."}]
)
print(response.choices[0].message.content)
```

### TypeScript

```typescript
import Hanzo from '@hanzo/ai'

const client = new Hanzo({ apiKey: process.env.HANZO_API_KEY })

const completion = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello, Zen.' }],
})
console.log(completion.choices[0].message.content)
```

### 已有的 HTTP 客户端

`/v1/chat/completions` 接受并返回 chat-completions 的 JSON 形状，因此
已经按该形状写好的客户端，只要把基址指向
`https://api.hanzo.ai/v1` 并发送 Hanzo 密钥，就能在这里工作。模型 id 不能在
供应商之间搬移——`zen5` 和 `enso` 只存在于这里。
