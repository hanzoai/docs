# Hanzo Chat

Hanzo Chat は Hanzo Cloud 上のチャットアプリで、[LibreChat](https://librechat.ai) の上に構築されています。自社モデル — フロンティア系列の **enso** とオープンウェイト系列の **Zen** — を、MCP ツール、設定可能なエージェント、RAG 付きファイルアップロード、画像理解、会話履歴、プリセット、プラグインとともに動かします。外部ラボのモデルも載せており、同じモデルメニューに現れます。

ホストされたサービスとして [chat.hanzo.ai](https://chat.hanzo.ai) で、または Docker によるセルフホストで利用できます。

## クイックスタート

### ホスト版（推奨）

1. [chat.hanzo.ai](https://chat.hanzo.ai) を開く
2. Hanzo アカウントでサインインする
3. **$5 の無料クレジット**が自動で適用される
4. モデルを選んで会話を始める

### セルフホスト

```bash
git clone https://github.com/hanzoai/chat
cd chat
cp .env.example .env
# Edit .env with your HANZO_API_KEY
docker compose up -d
# Open http://localhost:3081
```

### API

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zen5",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

## SDK の使い方

### Python

```python
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-api-key")

response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello, Zen."}]
)
print(response.choices[0].message.content)
```

### TypeScript

```typescript
import Hanzo from '@hanzo/ai'

const client = new Hanzo({ apiKey: process.env.HANZO_API_KEY })

const completion = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello, Zen.' }],
})
console.log(completion.choices[0].message.content)
```

### 既存の HTTP クライアント

`/v1/chat/completions` は chat-completions の JSON 形を受け取り、同じ形を返します。したがって
その形に対してすでに書かれたクライアントは、ベース URL が
`https://api.hanzo.ai/v1` を指し、Hanzo のキーを送ればここで動きます。モデル id はベンダー間で
持ち運べません — `zen5` と `enso` はここだけにあります。
