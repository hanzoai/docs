# Hanzo Chat

Hanzo Chat, Hanzo Cloud पर चैट ऐप है, जो [LibreChat](https://librechat.ai) पर बना है। यह हमारे अपने मॉडल चलाता है — सीमांत परिवार **enso** और खुले भार वाला परिवार **Zen** — MCP उपकरणों, विन्यास योग्य एजेंटों, RAG के साथ फ़ाइल अपलोड, दृष्टि, बातचीत के इतिहास, प्रीसेट और प्लगइन के साथ। बाहर की प्रयोगशालाओं के मॉडल भी आते हैं, और उसी मॉडल मेनू में दिखते हैं।

[chat.hanzo.ai](https://chat.hanzo.ai) पर होस्ट की गई सेवा के रूप में उपलब्ध है, या Docker से स्वयं होस्ट करें।

## त्वरित आरंभ

### होस्ट किया हुआ (अनुशंसित)

1. [chat.hanzo.ai](https://chat.hanzo.ai) पर जाएँ
2. अपने Hanzo खाते से साइन इन करें
3. आपका **$5 का मुफ़्त क्रेडिट** अपने आप लग जाता है
4. एक मॉडल चुनें और बातचीत शुरू करें

### स्वयं होस्ट

```bash
git clone https://github.com/hanzoai/chat
cd chat
cp .env.example .env
# Edit .env with your HANZO_API_KEY
docker compose up -d
# Open http://localhost:3081
```

### API

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zen5",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

## SDK का उपयोग

### Python

```python
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-api-key")

response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello, Zen."}]
)
print(response.choices[0].message.content)
```

### TypeScript

```typescript
import Hanzo from '@hanzo/ai'

const client = new Hanzo({ apiKey: process.env.HANZO_API_KEY })

const completion = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello, Zen.' }],
})
console.log(completion.choices[0].message.content)
```

### मौजूदा HTTP क्लाइंट

`/v1/chat/completions` chat-completions का JSON आकार लेता और लौटाता है, इसलिए
उस आकार के विरुद्ध पहले से लिखा क्लाइंट यहाँ तब काम करता है जब उसका आधार URL
`https://api.hanzo.ai/v1` की ओर इशारा करे और वह Hanzo कुंजी भेजे। मॉडल पहचान पत्र विक्रेताओं के बीच
साथ नहीं चलते — `zen5` और `enso` केवल यहीं हैं।

## मूल्य

- हर नए खाते पर **$5 का मुफ़्त क्रेडिट** (30 दिनों में समाप्त)
- **पूर्वभुगतान बिलिंग** — [console.hanzo.ai](https://console.hanzo.ai) से क्रेडिट जोड़ें
- इनपुट **$0.34/MTok** से शुरू (`zen5-flash`)
- **अचानक बिल नहीं** — क्रेडिट समाप्त होने पर सेवा रुक जाती है
