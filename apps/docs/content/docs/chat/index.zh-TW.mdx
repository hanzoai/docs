# Hanzo Chat

Hanzo Chat 是 Hanzo Cloud 上的聊天應用程式，建構於 [LibreChat](https://librechat.ai)。它執行我們自己的模型——前沿系列 **enso** 與開放權重系列 **Zen**——並帶有 MCP 工具、可設定的代理、含 RAG 的檔案上傳、視覺、對話紀錄、預設與外掛。外部實驗室的模型也會提供，並出現在同一個模型選單裡。

可作為託管服務在 [chat.hanzo.ai](https://chat.hanzo.ai) 使用，或透過 Docker 自行託管。

## 快速開始

### 託管（建議）

1. 開啟 [chat.hanzo.ai](https://chat.hanzo.ai)
2. 使用你的 Hanzo 帳戶登入
3. **$5 免費點數**會自動入帳
4. 選擇一個模型並開始聊天

### 自行託管

```bash
git clone https://github.com/hanzoai/chat
cd chat
cp .env.example .env
# Edit .env with your HANZO_API_KEY
docker compose up -d
# Open http://localhost:3081
```

### API

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zen5",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

## SDK 用法

### Python

```python
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-api-key")

response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello, Zen."}]
)
print(response.choices[0].message.content)
```

### TypeScript

```typescript
import Hanzo from '@hanzo/ai'

const client = new Hanzo({ apiKey: process.env.HANZO_API_KEY })

const completion = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello, Zen.' }],
})
console.log(completion.choices[0].message.content)
```

### 既有的 HTTP 用戶端

`/v1/chat/completions` 接受並傳回 chat-completions 的 JSON 形狀，因此
已經按該形狀寫好的用戶端，只要把基底網址指向
`https://api.hanzo.ai/v1` 並送出 Hanzo 金鑰，就能在這裡運作。模型 id 不能在
供應商之間搬移——`zen5` 和 `enso` 只存在於這裡。
