# Hanzo Chat

Hanzo Chat คือแอปแชทบน Hanzo Cloud สร้างบน [LibreChat](https://librechat.ai) มันรันโมเดลของเรา — ตระกูลแนวหน้า **enso** และตระกูลน้ำหนักเปิด **Zen** — พร้อมเครื่องมือ MCP, เอเจนต์ที่กำหนดค่าได้, การอัปโหลดไฟล์พร้อม RAG, การมองเห็น, ประวัติการสนทนา, ค่าที่ตั้งไว้ และปลั๊กอิน โมเดลจากห้องทดลองภายนอกก็มีด้วย และปรากฏในเมนูโมเดลเดียวกัน

ใช้ได้ในฐานะบริการที่โฮสต์ที่ [chat.hanzo.ai](https://chat.hanzo.ai) หรือโฮสต์เองผ่าน Docker

## เริ่มต้นอย่างรวดเร็ว

### โฮสต์ (แนะนำ)

1. ไปที่ [chat.hanzo.ai](https://chat.hanzo.ai)
2. ลงชื่อเข้าใช้ด้วยบัญชี Hanzo ของคุณ
3. **เครดิตฟรี $5** ถูกใช้ให้อัตโนมัติ
4. เลือกโมเดลแล้วเริ่มแชท

### โฮสต์เอง

```bash
git clone https://github.com/hanzoai/chat
cd chat
cp .env.example .env
# Edit .env with your HANZO_API_KEY
docker compose up -d
# Open http://localhost:3081
```

### API

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zen5",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

## การใช้ SDK

### Python

```python
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-api-key")

response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello, Zen."}]
)
print(response.choices[0].message.content)
```

### TypeScript

```typescript
import Hanzo from '@hanzo/ai'

const client = new Hanzo({ apiKey: process.env.HANZO_API_KEY })

const completion = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello, Zen.' }],
})
console.log(completion.choices[0].message.content)
```

### ไคลเอนต์ HTTP ที่มีอยู่

`/v1/chat/completions` รับและคืนรูป JSON แบบ chat-completions ดังนั้น
ไคลเอนต์ที่เขียนไว้กับรูปนั้นทำงานที่นี่เมื่อ URL ฐานชี้ไปที่
`https://api.hanzo.ai/v1` และส่งคีย์ Hanzo รหัสโมเดลไม่พกพาข้าม
ผู้ให้บริการ — `zen5` และ `enso` มีอยู่ที่นี่เท่านั้น

## ราคา

- **เครดิตฟรี $5** ในทุกบัญชีใหม่ (หมดอายุใน 30 วัน)
- **เรียกเก็บเงินแบบจ่ายล่วงหน้า** — เพิ่มเครดิตผ่าน [console.hanzo.ai](https://console.hanzo.ai)
- **เริ่มที่ $0.34/MTok** ขาเข้า (`zen5-flash`)
- **ไม่มีบิลเซอร์ไพรส์** — บริการหยุดเมื่อเครดิตหมด
