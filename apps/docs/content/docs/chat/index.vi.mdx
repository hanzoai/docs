# Hanzo Chat

Hanzo Chat là ứng dụng chat trên Hanzo Cloud, xây trên [LibreChat](https://librechat.ai). Nó chạy các mô hình của chúng tôi — họ biên **enso** và họ trọng số mở **Zen** — với công cụ MCP, tác tử cấu hình được, tải tệp lên kèm RAG, thị giác, lịch sử hội thoại, thiết lập sẵn và plugin. Mô hình từ phòng thí nghiệm bên ngoài cũng được mang theo, và xuất hiện trong cùng một menu mô hình.

Có sẵn như dịch vụ lưu trữ tại [chat.hanzo.ai](https://chat.hanzo.ai) hoặc tự lưu trữ qua Docker.

## Bắt đầu nhanh

### Lưu trữ (khuyến nghị)

1. Vào [chat.hanzo.ai](https://chat.hanzo.ai)
2. Đăng nhập bằng tài khoản Hanzo của bạn
3. **Tín dụng miễn phí $5** được áp dụng tự động
4. Chọn một mô hình và bắt đầu trò chuyện

### Tự lưu trữ

```bash
git clone https://github.com/hanzoai/chat
cd chat
cp .env.example .env
# Edit .env with your HANZO_API_KEY
docker compose up -d
# Open http://localhost:3081
```

### API

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zen5",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

## Dùng SDK

### Python

```python
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-api-key")

response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello, Zen."}]
)
print(response.choices[0].message.content)
```

### TypeScript

```typescript
import Hanzo from '@hanzo/ai'

const client = new Hanzo({ apiKey: process.env.HANZO_API_KEY })

const completion = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello, Zen.' }],
})
console.log(completion.choices[0].message.content)
```

### Máy khách HTTP sẵn có

`/v1/chat/completions` nhận và trả về dạng JSON chat-completions, nên một
máy khách đã viết theo dạng đó hoạt động ở đây khi URL gốc của nó trỏ tới
`https://api.hanzo.ai/v1` và gửi một khóa Hanzo. Mã mô hình không mang sang
nhà cung cấp khác — `zen5` và `enso` chỉ tồn tại ở đây.

## Giá

- **Tín dụng miễn phí $5** trên mọi tài khoản mới (hết hạn sau 30 ngày)
- **Thanh toán trả trước** — thêm tín dụng qua [console.hanzo.ai](https://console.hanzo.ai)
- **Từ $0.34/MTok** đầu vào (`zen5-flash`)
- **Không hóa đơn bất ngờ** — dịch vụ dừng khi tín dụng cạn
