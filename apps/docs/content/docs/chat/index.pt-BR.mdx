# Hanzo Chat

Hanzo Chat é o aplicativo de chat na Hanzo Cloud, construído sobre o [LibreChat](https://librechat.ai). Ele executa nossos próprios modelos — a família de fronteira **enso** e a família de pesos abertos **Zen** — com ferramentas MCP, agentes configuráveis, envio de arquivos com RAG, visão, histórico de conversas, predefinições e plugins. Modelos de laboratórios de fora também entram, e aparecem no mesmo menu de modelos.

Disponível como serviço hospedado em [chat.hanzo.ai](https://chat.hanzo.ai) ou auto-hospedado via Docker.

## Início rápido

### Hospedado (recomendado)

1. Acesse [chat.hanzo.ai](https://chat.hanzo.ai)
2. Entre com sua conta Hanzo
3. Seu **crédito grátis de $5** é aplicado automaticamente
4. Selecione um modelo e comece a conversar

### Auto-hospedado

```bash
git clone https://github.com/hanzoai/chat
cd chat
cp .env.example .env
# Edit .env with your HANZO_API_KEY
docker compose up -d
# Open http://localhost:3081
```

### API

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zen5",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

## Uso do SDK

### Python

```python
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-api-key")

response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello, Zen."}]
)
print(response.choices[0].message.content)
```

### TypeScript

```typescript
import Hanzo from '@hanzo/ai'

const client = new Hanzo({ apiKey: process.env.HANZO_API_KEY })

const completion = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello, Zen.' }],
})
console.log(completion.choices[0].message.content)
```

### Clientes HTTP existentes

`/v1/chat/completions` recebe e devolve a forma JSON de chat-completions, então um
cliente já escrito contra essa forma funciona aqui assim que a URL base aponta para
`https://api.hanzo.ai/v1` e ele envia uma chave Hanzo. Os identificadores de modelo não são portáteis
entre fornecedores — `zen5` e `enso` existem apenas aqui.

## Preços

- **Crédito grátis de $5** em toda conta nova (expira em 30 dias)
- **Faturamento pré-pago** — adicione créditos em [console.hanzo.ai](https://console.hanzo.ai)
- **A partir de $0.34/MTok** de entrada (`zen5-flash`)
- **Sem faturas surpresa** — o serviço para quando os créditos acabam
