# Hanzo Chat

Hanzo Chat est l'application de chat sur Hanzo Cloud, construite sur [LibreChat](https://librechat.ai). Elle exécute nos propres modèles — la famille frontière **enso** et la famille à poids ouverts **Zen** — avec des outils MCP, des agents configurables, l'envoi de fichiers avec RAG, la vision, l'historique des conversations, des préréglages et des plugins. Les modèles de laboratoires extérieurs sont également proposés, et apparaissent dans le même menu de modèles.

Disponible comme service hébergé sur [chat.hanzo.ai](https://chat.hanzo.ai) ou auto-hébergée via Docker.

## Démarrage rapide

### Hébergé (recommandé)

1. Allez sur [chat.hanzo.ai](https://chat.hanzo.ai)
2. Connectez-vous avec votre compte Hanzo
3. Votre **crédit gratuit de $5** est appliqué automatiquement
4. Choisissez un modèle et commencez à discuter

### Auto-hébergé

```bash
git clone https://github.com/hanzoai/chat
cd chat
cp .env.example .env
# Edit .env with your HANZO_API_KEY
docker compose up -d
# Open http://localhost:3081
```

### API

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zen5",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

## Utilisation du SDK

### Python

```python
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-api-key")

response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello, Zen."}]
)
print(response.choices[0].message.content)
```

### TypeScript

```typescript
import Hanzo from '@hanzo/ai'

const client = new Hanzo({ apiKey: process.env.HANZO_API_KEY })

const completion = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello, Zen.' }],
})
console.log(completion.choices[0].message.content)
```

### Clients HTTP existants

`/v1/chat/completions` accepte et renvoie la forme JSON chat-completions, donc un
client déjà écrit contre cette forme fonctionne ici dès que son URL de base pointe vers
`https://api.hanzo.ai/v1` et qu'il envoie une clé Hanzo. Les identifiants de modèle ne se transportent pas
d'un fournisseur à l'autre — `zen5` et `enso` n'existent qu'ici.
