# Hanzo Chat

Hanzo Chat es la aplicación de chat en Hanzo Cloud, construida sobre [LibreChat](https://librechat.ai). Ejecuta nuestros propios modelos — la familia de frontera **enso** y la familia de pesos abiertos **Zen** — con herramientas MCP, agentes configurables, carga de archivos con RAG, visión, historial de conversaciones, ajustes predefinidos y complementos. También se incluyen modelos de laboratorios externos, y aparecen en el mismo menú de modelos.

Disponible como servicio alojado en [chat.hanzo.ai](https://chat.hanzo.ai) o autoalojado mediante Docker.

## Inicio rápido

### Alojado (recomendado)

1. Ve a [chat.hanzo.ai](https://chat.hanzo.ai)
2. Inicia sesión con tu cuenta de Hanzo
3. Tu **crédito gratuito de $5** se aplica automáticamente
4. Elige un modelo y empieza a conversar

### Autoalojado

```bash
git clone https://github.com/hanzoai/chat
cd chat
cp .env.example .env
# Edit .env with your HANZO_API_KEY
docker compose up -d
# Open http://localhost:3081
```

### API

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zen5",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

## Uso del SDK

### Python

```python
from hanzoai import Hanzo

client = Hanzo(api_key="sk-your-api-key")

response = client.chat.completions.create(
    model="zen5",
    messages=[{"role": "user", "content": "Hello, Zen."}]
)
print(response.choices[0].message.content)
```

### TypeScript

```typescript
import Hanzo from '@hanzo/ai'

const client = new Hanzo({ apiKey: process.env.HANZO_API_KEY })

const completion = await client.chat.completions.create({
  model: 'zen5',
  messages: [{ role: 'user', content: 'Hello, Zen.' }],
})
console.log(completion.choices[0].message.content)
```

### Clientes HTTP existentes

`/v1/chat/completions` acepta y devuelve la forma JSON de chat-completions, así que un
cliente ya escrito contra esa forma funciona aquí en cuanto su URL base apunta a
`https://api.hanzo.ai/v1` y envía una clave de Hanzo. Los identificadores de modelo no se trasladan
entre proveedores — `zen5` y `enso` solo existen aquí.
