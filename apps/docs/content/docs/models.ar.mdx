كل نموذج أدناه يُبلغ بمفتاح واحد على عنوان واحد. مرّر `id` بوصفه
`model` وبقية الطلب واحدة أيًّا كان اختيارك.

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"<id from below>","messages":[{"role":"user","content":"Hello"}]}'
```

يُجلب الجدول من [`/v1/models`](/docs/openapi/ai) في متصفحك عند
تحميل الصفحة، فهو الفهرس الذي تخدمه البوابة الآن لا
نسخة كُتبت حين بُنيت الصفحة.

## ماذا يعني السعر

الأسعار لكل مليون رمز، والمدخل والمخرج مُسعّران على حدة، وهي
واحدة سواء ناديت من CLI أو SDK أو HTTP أو أداة MCP — السعر
خاصية النموذج لا السطح الذي تصل منه.

[الأسعار](/docs/pricing) تشرح كيف يصير الاستخدام فاتورة. [الأرصدة](/docs/credits)
تغطي ما يحدث حين ينفد الرصيد.
