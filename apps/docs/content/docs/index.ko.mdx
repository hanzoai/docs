## 가져가세요

위의 클라우드와 직접 돌릴 수 있는 클라우드는 [같은
소프트웨어](/docs/network)입니다 — 같은 바이너리, 같은 계약, 같은 `/v1` 경로. 자신의
GPU나 Kubernetes를 가져오거나 어떤 기기에서든 채굴하세요.

```bash
curl -fsSL https://hanzo.sh | sh
```

<Callout type="info">
이것은 **V8 · Open Edition**이며 [HIP-0127](https://hips.hanzo.ai)에 적혀 있습니다.
계약 하나, 바인딩은 많고, 클라이언트는 얇으며, 언어 사이는 선 하나 — FFI는 쓰지 않습니다.
*왜*인지는 [엔지니어링 철학](/docs/architecture/philosophy)을 보세요.
</Callout>

## 이것으로 만들기

- [`hanzo` CLI](/docs/openapi/platform) — 약 15MB Rust 바이너리. 살아 있는 어떤 클라우드와도 이야기합니다. 프로덕션, 노트북, 자체 호스팅
- [SDK](/docs/sdks) — Python, TypeScript, Go, Rust 등. 모두 하나의 계약에서 나옵니다
- [API 레퍼런스](/docs/openapi) — 모든 엔드포인트, 명세에서 생성
- [ZAP 프로토콜](/docs/zap) — Zero-Copy App Proto, Go와 Rust 절반이 말하는 선
- [Zen 모델](https://zenlm.org) — 프론티어 오픈 웨이트, 4B 엣지에서 1T+ 추론까지
- [아키텍처](/docs/architecture) — 바이너리 하나, 계약 하나, 그리고 이유
