아래의 모든 모델은 한 주소에서 열쇠 하나로 닿는다. `id`를
`model`로 넘기면 무엇을 골라도 요청의 나머지는 같다.

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"<id from below>","messages":[{"role":"user","content":"Hello"}]}'
```

이 페이지가 로드될 때 브라우저가 [`/v1/models`](/docs/openapi/ai)에서 표를 가져온다. 그러니 이것은
페이지를 만들 때 적어 둔 사본이 아니라 게이트웨이가 지금 제공하는 목록이다.

## 요율이 뜻하는 것

요율은 백만 토큰당이고 입력과 출력은 따로 가격이 매겨지며, CLI, SDK, HTTP, MCP 도구
어디서 호출해도 같다 — 가격은 모델의 성질이지 도달하는 표면의 성질이 아니다.

[가격](/docs/pricing)은 사용이 청구가 되는 과정을 설명한다. [크레딧](/docs/credits)은
잔액이 떨어지면 무슨 일이 일어나는지 다룬다.
