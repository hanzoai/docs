Chaque modèle ci-dessous se joint avec une clé sur une adresse. Passez l’`id` comme
`model` et le reste de la requête est le même, quel que soit votre choix.

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"<id from below>","messages":[{"role":"user","content":"Hello"}]}'
```

Le tableau est chargé depuis [`/v1/models`](/docs/openapi/ai) dans votre navigateur
au chargement de la page : c’est le catalogue que la passerelle sert maintenant,
pas une copie écrite à la construction de la page.

## Ce que signifie un tarif

Les tarifs sont par million de jetons, entrée et sortie tarifées à part, et ils sont
les mêmes que vous appeliez depuis la CLI, un SDK, HTTP ou un outil MCP — le prix
est une propriété du modèle, pas de la surface par laquelle vous l’atteignez.

[Tarifs](/docs/pricing) explique comment l’usage devient une facture. [Crédits](/docs/credits)
couvre ce qui se passe quand le solde est épuisé.
