# MCP

一台模型情境協定伺服器，一個工具面。把 **`hanzo-mcp`** 加到 Claude Code（或 Cursor、Claude Desktop，或任何 MCP 用戶端），Hanzo 的每項能力都透過一條連線出現——不必按工具逐個接線。

> 要找的是託管的 MCP 伺服器？**[雲端 MCP](/docs/mcp-tools)** 是一個無需安裝的 URL，它的每件工具都列在[工具目錄](/docs/mcp-tools/all-tools)裡。本頁是跑在編輯器旁邊的那台伺服器。

```bash title="Add the Hanzo MCP to Claude Code"
claude mcp add hanzo -- npx -y @hanzo/mcp serve
```

這一條命令露出整個表面：

- **13 個統一工具** — `fs`、`exec`、`code`、`git`、`fetch`、`workspace`、`ui`，外加可選的 `think`、`memory`、`hanzo`、`plan`、`tasks`、`mode`。每項能力一個按動作路由的工具（HIP-0300），於是用戶端看到的是小而穩定的集合，而不是幾百個重疊的名字。
- **雲端服務** — `hanzo` 工具原生路由到你的平台：IAM（身分）、Commerce、Storage，以及 `api.hanzo.ai/v1` 上的人工智慧 API，用你的權杖認證。
- **你的連接器** — GitHub、Slack、Google、Discord、X 等，在主控台連上之後，經同一條連線呈現。

同一表面以三種方式交付 — TypeScript（`@hanzo/mcp`）、Python（PyPI 上的 `hanzo-mcp`）和 Rust（`hanzo-mcp::brain`）— 一對一鏡像，走 MCP 的 **stdio** 與 **streamable-http** 傳輸。

## 用戶端設定

```json title="Claude Desktop / Cursor — mcp config"
{
  "mcpServers": {
    "hanzo": {
      "command": "npx",
      "args": ["-y", "@hanzo/mcp", "serve"]
    }
  }
}
```

登入一次（`hanzo auth login`），`hanzo` 雲端工具和你的連接器就會自行認證；本機工具（`fs`、`exec`、`git`、…）無需帳戶即可使用。

## 工具索引

平台能夠暴露的每件工具都索引在 `GET api.hanzo.ai/v1/tools`（需認證）。今天是來自五個來源的 **1,468 個工具** — 統一伺服器透過上面緊湊的、按動作路由的表面來呈現它們：

| 來源 | 它是什麼 |
|--------|-----------|
| `builtin` | 核心本機工具（fs、exec、git、code、…） |
| `skill` | 封裝的技能 |
| `connector` | 已連接的雲端整合（GitHub、Slack、Google、Discord、X、…） |
| `agent` | 代理入口 |
| `function` | 使用者定義的函式 |

## 作為服務的 MCP

統一伺服器之外，Hanzo 還可以為你**託管**任何 MCP 伺服器 — 從任意 npx、uvx 或自訂套件部署，即時伸縮，沒有要管理的基礎架構。

```bash title="Launch an MCP server"
hanzo mcp launch npx @modelcontextprotocol/server-filesystem
```

## 關鍵能力

- **任意 MCP 伺服器** — 檔案系統、Git、SQL、KV、Slack、GitHub、Notion 等
- **一鍵部署** — 一條命令啟動任意 MCP 伺服器
- **自動伸縮** — 從 0 自動擴到數千個執行個體
- **閒置成本 $0** — 只用多少付多少，沒有閒置費用
- **安全沙箱** — 帶細粒度權限的隔離容器
- **15 個以上區域** — 邊緣部署，以求全球最低延遲

## 啟動方式

### NPX 套件

```bash
hanzo mcp launch npx @modelcontextprotocol/server-filesystem
hanzo mcp launch npx @modelcontextprotocol/server-github
hanzo mcp launch npx @modelcontextprotocol/server-slack
```

### UVX / Python

```bash
hanzo mcp launch uvx mcp-server-sqlite
hanzo mcp launch uvx mcp-server-postgres
```

### 自訂伺服器

```bash
hanzo mcp launch git://github.com/you/mcp-server
hanzo mcp launch docker://your-org/mcp-custom:latest
```

## 組態

用一個組態檔部署多台伺服器：

```yaml title="mcp-config.yaml"
version: "1"
servers:
  filesystem:
    package: "@modelcontextprotocol/server-filesystem"
    runtime: npx
    args: ["/workspace"]

  database:
    package: "mcp-server-postgres"
    runtime: uvx
    env:
      DATABASE_URL: "${secrets.DATABASE_URL}"

  github:
    package: "@modelcontextprotocol/server-github"
    runtime: npx
    env:
      GITHUB_TOKEN: "${secrets.GITHUB_TOKEN}"

  custom:
    image: "your-org/mcp-custom:latest"
    runtime: docker
    replicas: 3
```

```bash
hanzo mcp deploy
```
