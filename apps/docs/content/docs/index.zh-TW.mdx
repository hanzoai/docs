## 把它帶走

上面的雲和你可以自己跑的那一個是[同一套
軟體](/docs/network) — 同一個二進位、同一份契約、同樣的 `/v1` 路由。帶上
你自己的 GPU 或 Kubernetes，或在任何裝置上挖礦。

```bash
curl -fsSL https://hanzo.sh | sh
```

<Callout type="info">
這是 **V8 · Open Edition**，寫在 [HIP-0127](https://hips.hanzo.ai) 裡：
一份契約、多種繫結、瘦用戶端，語言之間是一根線 — 從不用 FFI。
*為什麼*見[工程哲學](/docs/architecture/philosophy)。
</Callout>

## 用它來建構

- [`hanzo` CLI](/docs/openapi/platform) — 大約 15 MB 的 Rust 二進位，能跟任何在線的雲說話：正式環境、筆電或自架
- [SDK](/docs/sdks) — Python、TypeScript、Go、Rust 等等，都從同一份契約派生
- [API 參考](/docs/openapi) — 每個端點，從它的規範產生
- [ZAP 協定](/docs/zap) — Zero-Copy App Proto，Go 和 Rust 兩半說的那根線
- [Zen 模型](https://zenlm.org) — 前沿開放權重，從 4B 邊緣到 1T+ 推理
- [架構](/docs/architecture) — 一個二進位、一份契約，以及為什麼
