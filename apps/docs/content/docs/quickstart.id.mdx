**Setelah halaman ini Anda punya kredensial yang bekerja dan satu panggilan yang menjawab.**

Hanzo adalah satu awan di balik satu kunci. Setiap kemampuan — inferensi, identitas,
penyimpanan, uang, agen — menjawab di `https://api.hanzo.ai`, dan CLI,
SDK, serta alat MCP dihasilkan dari deskripsi yang sama. Tidak ada yang perlu
disambung per layanan: ambil kunci sekali dan semuanya terjangkau.

## 1. Pasang

<Tabs items={['npm', 'Script', 'Homebrew', 'Dari sumber']}>
<Tab value="npm">
```bash
npm i -g hanzo
```

`hanzo` adalah CLI dan klien dalam satu pemasangan.
</Tab>
<Tab value="Script">
```bash
curl -fsSL https://hanzo.sh | sh
```

Terpasang di `~/.local/bin`. `https://hanzo.sh/cli` memasang CLI saja.
</Tab>
<Tab value="Homebrew">
```bash
brew install hanzoai/tap/hanzo
```
</Tab>
<Tab value="Dari sumber">
```bash
git clone https://github.com/hanzoai/cli && cd cli && cargo install --path .
```
</Tab>
</Tabs>

```bash
hanzo version
```

## 2. Masuk

```bash
hanzo auth login
```

Itu membuka peramban ke [hanzo.id](https://hanzo.id), penyedia identitas
Hanzo, dan menyimpan kredensial secara lokal. `hanzo auth show` mencetak
siapa Anda; `hanzo auth list` menunjukkan setiap identitas di mesin ini dan
`hanzo auth use` beralih di antaranya.

Di server, terbitkan kunci alih-alih memasukkan orang: **console.hanzo.ai →
kunci API**. Kunci rahasia adalah *Anda*, jadi ia tinggal di server dan tidak pernah
di peramban — [Autentikasi](/docs/api-keys) adalah seluruh aturannya.

```bash
export HANZO_API_KEY=sk-...
```

## 3. Daftar model

Katalog model yang sedang dilayani gateway. Ini pembacaan, hanya
butuh kunci, dan operasinya sama di keempat permukaan.

<Tabs items={['CLI', 'SDK', 'HTTP', 'MCP']}>
<Tab value="CLI">
```bash
hanzo models list
```
</Tab>
<Tab value="SDK">
<Tabs items={['.ts', '.py', '.go', '.rs', '.swift', '.kt']}>
<Tab value=".ts">
```bash
npm i hanzo
```

```ts
import { Hanzo } from 'hanzo'

const hanzo = new Hanzo({ apiKey: process.env.HANZO_API_KEY })
const models = await hanzo.models.list()
```
</Tab>
<Tab value=".py">
```bash
pip install hanzo
```

```python
from hanzo import Hanzo

hanzo = Hanzo(api_key=os.environ["HANZO_API_KEY"])
models = hanzo.models.list()
```
</Tab>
<Tab value=".go">
```bash
go get github.com/hanzoai/go-sdk
```

```go
client := hanzo.NewClient(hanzo.WithAPIKey(os.Getenv("HANZO_API_KEY")))
models, err := client.Models.List(ctx)
```
</Tab>
<Tab value=".rs">
```bash
cargo add hanzo
```

```rust
let hanzo = hanzo::Client::from_env()?;
let models = hanzo.models().list().await?;
```
</Tab>
<Tab value=".swift">
```swift
// Package.swift: .package(url: "https://github.com/hanzoai/swift-sdk", from: "1.0.0")
let hanzo = Hanzo(apiKey: ProcessInfo.processInfo.environment["HANZO_API_KEY"]!)
let models = try await hanzo.models.list()
```
</Tab>
<Tab value=".kt">
```kotlin
// build.gradle.kts: implementation("ai.hanzo:sdk:latest.release")
val hanzo = Hanzo(apiKey = System.getenv("HANZO_API_KEY"))
val models = hanzo.models.list()
```
</Tab>
</Tabs>

Semuanya dihasilkan dari deskripsi API yang sama, jadi nama
metode sejajar antar bahasa. [C++](/docs/sdks/cpp) adalah yang masih
menuju tempatnya.
</Tab>
<Tab value="HTTP">
```bash
curl https://api.hanzo.ai/v1/models \
  -H "Authorization: Bearer $HANZO_API_KEY"
```
</Tab>
<Tab value="MCP">
```bash
curl -X POST https://api.hanzo.ai/v1/mcp \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

Satu endpoint, satu alat per kemampuan. `tools/call` menamai kemampuan dan
operasi; `describe` menjelaskan masukan operasi mana pun.
</Tab>
</Tabs>

Itu satu API yang dilihat dari empat tempat, dan tab di atas adalah seluruh
perbedaannya. Pilih yang akan Anda tulis:

- **[CLI](/docs/cli)** — setiap kemampuan sebagai kelompok perintah, satu halaman masing-masing.
- **[SDK](/docs/sdks)** — Python, TypeScript, Go, Rust, C++, Swift, dan Kotlin,
  dihasilkan dari deskripsi yang sama dengan CLI dan alat.
- **[MCP](/docs/mcp)** — satu endpoint yang dihubungkan agen; [alat](/docs/mcp-tools)
  tercantum satu per kemampuan.

HTTP tidak perlu halaman: itu `https://api.hanzo.ai` dan kunci yang baru Anda ekspor.

## 4. Kirim sebuah penyelesaian

Ini langkah pertama yang memakai kredit; semua di atasnya gratis dijalankan.

```bash
hanzo chat completions --model zen-1 --messages '[{"role":"user","content":"hello"}]'
```

Lalu baca berapa yang terpakai:

```bash
hanzo billing balance
hanzo usage summary
```

[Kredit dan penagihan](/docs/credits) menjelaskan apa itu kredit dan apa yang terjadi di
nol; [Harga](/docs/pricing) adalah tarif setiap model dan alat.

## 5. Jalankan awan secara lokal

Biner yang sama yang melayani `api.hanzo.ai` berjalan di mesin Anda:

```bash
hanzo up cloud
```

`hanzo up` polos adalah hal yang sama — `cloud` adalah bawaan. Sebut satu layanan untuk
menjalankannya sendiri: `hanzo up iam`, `hanzo up kms`, `hanzo up gateway`, `hanzo up
storage`, `hanzo up pubsub`. Lihat [Jalankan milik Anda](/docs/network) untuk artinya
dan apa yang dibutuhkan.

- **[Kemampuan](/docs/openapi)** — semuanya, berkelompok. Setiap halaman mengatakan apa
