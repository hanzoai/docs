Jedes Modell unten erreichst du mit einem Schlüssel an einer Adresse. Übergib die `id` als
`model` und der Rest der Anfrage ist derselbe, egal welches du wählst.

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"<id from below>","messages":[{"role":"user","content":"Hello"}]}'
```

Die Tabelle kommt beim Laden der Seite im Browser von [`/v1/models`](/docs/openapi/ai),
also ist es der Katalog, den das Gateway gerade ausliefert, keine Abschrift
vom Bau der Seite.

## Was ein Tarif bedeutet

Tarife gelten pro Million Token, Ein- und Ausgabe getrennt bepreist, und sie sind
dieselben, ob du über die CLI, ein SDK, HTTP oder ein MCP-Werkzeug rufst — der Preis
ist eine Eigenschaft des Modells, nicht der Oberfläche.

[Preise](/docs/pricing) erklärt, wie Nutzung eine Rechnung wird. [Guthaben](/docs/credits)
beschreibt, was passiert, wenn das Guthaben leer ist.
