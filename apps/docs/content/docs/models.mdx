There are 500+ models behind one key and one address. Pass the `id` as `model`. The rest of the request is the same whichever you pick. You choose by price, context, and whether the model is good at the job. The request itself does not change, so you can compare two models by changing one string.

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"<id from below>","messages":[{"role":"user","content":"Hello"}]}'
```

The table is fetched from [`/v1/models`](/docs/openapi/ai) in your browser when this page loads. It is the catalogue the gateway is serving right now, not a copy someone typed when the page was built. If a blog post, a slide, or an old tab disagrees with the table, the table is the one having a better day.

## What a rate means

Rates are per million tokens, input and output priced separately, and they are base prices. The fee is not inside them. They are the same whether you call from the CLI, an SDK, HTTP, or an MCP tool. The fee is charged when you buy credits, as its own line on the checkout and on the receipt or invoice. The rates are in [What you pay on top](/docs/pricing#what-you-pay-on-top). Enso's tiers are on [Meet Enso](/docs/enso).

[Pricing](/docs/pricing) is how usage becomes a bill. [Credits](/docs/credits) is what happens when the balance runs out, which is a different surprise and worth meeting in advance.
