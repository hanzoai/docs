## ทุกรุ่น กุญแจเดียว

<ProviderStrip />

เรียกดู[ทุกรุ่นที่เราให้บริการ](/docs/openapi/ai) — แคตตาล็อกเป็นสด ดังนั้นไอดีที่

ราคาเท่าไร](/docs/pricing) ก่อนส่ง

โดเมนเดียว ไม่มีอะไรซ้ำ จึงไม่มีอะไรกำกวม

## เอาไปด้วย

คลาวด์ข้างบนกับคลาวด์ที่คุณรันเองคือ[ซอฟต์แวร์
เดียวกัน](/docs/network) — ไบนารีเดียวกัน สัญญาเดียวกัน เส้นทาง `/v1` เดียวกัน นำ
GPU หรือ Kubernetes ของคุณมา หรือขุดบนอุปกรณ์ใดก็ได้

```bash
curl -fsSL https://hanzo.sh | sh
```

<Callout type="info">
นี่คือ **V8 · Open Edition** ระบุไว้ใน [HIP-0127](https://hips.hanzo.ai):
สัญญาเดียว การผูกรวมหลายแบบ ไคลเอนต์บาง และสายหนึ่งเส้น — ไม่ใช้ FFI — ระหว่าง
ภาษา ดู[ปรัชญาวิศวกรรม](/docs/architecture/philosophy) สำหรับ *เหตุผล*
</Callout>

## สร้างด้วยมัน

- [CLI `hanzo`](/docs/openapi/platform) — ไบนารี Rust ประมาณ 15 MB ที่พูดกับคลาวด์ที่กำลังทำงาน: โปรดักชัน แล็ปท็อป หรือโฮสต์เอง
- [SDK](/docs/sdks) — Python, TypeScript, Go, Rust และอื่น ๆ ทั้งหมดมาจากสัญญาเดียว
- [เอกสาร API](/docs/openapi) — ทุกจุดปลาย สร้างจากสเปกของมัน
- [โปรโตคอล ZAP](/docs/zap) — Zero-Copy App Proto สายที่ครึ่ง Go และครึ่ง Rust พูด
- [โมเดล Zen](https://zenlm.org) — โมเดลเปิดแนวหน้า จากขอบ 4B ถึงการให้เหตุผล 1T+
- [สถาปัตยกรรม](/docs/architecture) — ไบนารีเดียว สัญญาเดียว และเหตุผล
