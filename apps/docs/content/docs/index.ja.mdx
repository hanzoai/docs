ひとつのドメインに属します。重複がないので、曖昧さもありません。

## 持っていく

上のクラウドと、自分で動かせるクラウドは[同じ
ソフトウェア](/docs/network)です — 同じバイナリ、同じ契約、同じ `/v1` ルート。自分の
GPU や Kubernetes を持ってくるか、どの端末でも採掘できます。

```bash
curl -fsSL https://hanzo.sh | sh
```

<Callout type="info">
これは **V8 · Open Edition** で、[HIP-0127](https://hips.hanzo.ai) に定められています。
ひとつの契約、たくさんのバインディング、薄いクライアント、そして言語の間の線 — FFI は使いません。
*なぜ*かは[エンジニアリングの哲学](/docs/architecture/philosophy)を見てください。
</Callout>

## これで作る

- [`hanzo` CLI](/docs/openapi/platform) — 約 15 MB の Rust バイナリ。動いているどのクラウドにも話します。本番、ノート PC、セルフホスト
- [SDK](/docs/sdks) — Python、TypeScript、Go、Rust など。すべてひとつの契約から導かれます
- [API リファレンス](/docs/openapi) — すべてのエンドポイント。仕様から生成
- [ZAP プロトコル](/docs/zap) — Zero-Copy App Proto。Go と Rust の半分が話す線
- [Zen モデル](https://zenlm.org) — フロンティアのオープンウェイト。4B のエッジから 1T+ の推論まで
- [アーキテクチャ](/docs/architecture) — バイナリひとつ、契約ひとつ、そして理由
