下面的每个模型都用一把钥匙、一个地址就能到达。把 `id` 当作
`model` 传入，无论选哪个，请求的其余部分都一样。

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"<id from below>","messages":[{"role":"user","content":"Hello"}]}'
```

页面加载时，浏览器从 [`/v1/models`](/docs/openapi/ai) 取这张表，所以它是网关此刻
在提供的目录，不是建页面时抄下来的副本。

## 费率是什么意思

费率按每百万 token 计，输入和输出分开定价，从 CLI、SDK、HTTP 或 MCP 工具
调用都一样 — 价格是模型的属性，不是你到达它的那个表面的属性。

[价格](/docs/pricing)说明用量如何变成账单。[额度](/docs/credits)
说明余额用尽时会发生什么。
