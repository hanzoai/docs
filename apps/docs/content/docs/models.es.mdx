Cada modelo de abajo se alcanza con una clave en una dirección. Pasa el `id` como
`model` y el resto de la petición es el mismo elijas el que elijas.

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"<id from below>","messages":[{"role":"user","content":"Hello"}]}'
```

La tabla se obtiene de [`/v1/models`](/docs/openapi/ai) en tu navegador cuando
carga esta página, así que es el catálogo que el gateway sirve ahora, no
una copia escrita cuando se construyó la página.

## Qué significa una tarifa

Las tarifas son por millón de tokens, entrada y salida con precio aparte, y son
las mismas llames desde la CLI, un SDK, HTTP o una herramienta MCP — el precio
es una propiedad del modelo, no de la superficie por la que llegas.

[Precios](/docs/pricing) explica cómo el uso se vuelve una factura. [Créditos](/docs/credits)
cubre qué pasa cuando el saldo se agota.
