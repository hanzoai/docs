`hanzo code` รันเอเจนต์เขียนโค้ดกับที่เก็บที่คุณยืนอยู่
รองรับสามเอเจนต์ และการระบุชื่อหนึ่งชื่อได้เอเจนต์นั้นหรือความล้มเหลวที่ชัดเจน —
เป็นผลิตภัณฑ์คนละตัว ไม่ใช่ชื่อเรียกแทนกัน

```bash
hanzo code                      # Hanzo Dev, the default
hanzo code claude               # Claude Code
hanzo code codex                # Codex
```

ส่งงานเป็นอาร์กิวเมนต์ **เดียว** ในเครื่องหมายคำพูด:

```bash
hanzo code "fix the failing test in api/users"
hanzo code claude "port this module to the new store"
```

## การตั้งชื่อเอเจนต์

ทุกการสะกดด้านล่างคลี่ที่เดียว ดังนั้นจึงแยกจากกันไม่ได้:

| | ตามตำแหน่ง | แฟลก | ระบุชัด |
| --- | --- | --- | --- |
| Hanzo Dev | `hanzo code dev` | `hanzo code --dev` | `hanzo code --backend dev` |
| Claude Code | `hanzo code claude` | `hanzo code --claude` | `hanzo code --backend claude` |
| Codex | `hanzo code codex` | `hanzo code --codex` | `hanzo code --backend codex` |

`hanzo dev` เป็นทางลัดระดับบนสุดของ `hanzo code dev` ส่วน `claude-code` และ
`cc` เป็นการสะกดที่ยอมรับของ `claude`

การตั้งชื่อสองครั้งถูกปฏิเสธแทนที่จะถูกคลี่ — `hanzo code claude --codex`
บอกให้ตั้งชื่อครั้งเดียว

## การอนุมัติ

เอเจนต์อนุมัติขั้นตอนของตัวเองโดยค่าเริ่มต้น มีสองทางออก ตามลำดับที่เพิ่มขึ้นของสิ่งที่ยอมทิ้ง:

```bash
hanzo code --ask            # the backend asks before each step
hanzo code --no-sandbox     # bypass approvals AND drop the sandbox
```

`--safe` มีความหมายเดียวกับ `--ask` และทั้งสองชนะ `autoApprove` ใน
`~/.hanzo/settings.json`

## `hanzo code` อีกตัว

`hanzo code context`, `hanzo code file` และ `hanzo code index` เป็นอีกสิ่งที่ใช้คำเดียวกัน: [API ความฉลาดของโค้ด](/docs/openapi/code) — ค้นหาและสัญลักษณ์ทั่วที่เก็บที่ทำดัชนีแล้ว
สำหรับคุณและสำหรับเอเจนต์ ไม่รับแบ็กเอนด์และไม่รันเอเจนต์

กฎคืออาร์กิวเมนต์แรก: คำที่ตั้งชื่อแบ็กเอนด์จะเลือกตัวนั้น และ
อย่างอื่นคืองานหรือคำสั่งย่อย
