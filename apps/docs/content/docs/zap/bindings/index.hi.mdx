## सामान्य पैटर्न

### क्लाइंट बनाना

सभी बाइंडिंग एक जैसे पैटर्न पर चलती हैं:

```rust
// Rust
let client = Zap::connect("zap://localhost:9000").await?;
```

```go
// Go
client, err := zap.Connect(ctx, "zap://localhost:9000")
```

```python
# Python
client = await Zap.connect("zap://localhost:9000")
```

```typescript
// JavaScript
const client = await Zap.connect('zap://localhost:9000');
```

### त्रुटि प्रबंधन

हर बाइंडिंग उस भाषा का स्वाभाविक त्रुटि प्रबंधन इस्तेमाल करती है:

- **Rust**: `Result<T, Error>` `?` ऑपरेटर के साथ
- **Go**: कई रिटर्न मान `(result, error)`
- **Python**: async संदर्भ के साथ अपवाद
- **JavaScript**: try/catch या `.catch()` के साथ Promise

### Async/Await

ज़्यादातर बाइंडिंग async संक्रियाएँ देती हैं:

```rust
// Rust (tokio)
let tools = client.list_tools().await?;
```

```go
// Go (goroutines)
tools, err := client.ListTools(ctx)
```

```python
# Python (asyncio)
tools = await client.list_tools()
```

```typescript
// JavaScript (Promises)
const tools = await client.listTools();
```

## स्कीमा से कोड जनरेशन

ZAP स्कीमा से बाइंडिंग जनरेट करें:

```bash
# Clone the schema
git clone https://github.com/zap-proto/zap
cd zap/schema

# Generate for your language
capnp compile -o rust zap.capnp
capnp compile -o go zap.capnp
capnp compile -o c++ zap.capnp
```

कोड जनरेशन के विस्तृत निर्देशों के लिए भाषा-विशेष पृष्ठ देखें।
