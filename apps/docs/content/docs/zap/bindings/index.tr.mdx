## Ortak kalıplar

### İstemci oluşturma

Tüm bağlamalar benzer bir kalıbı izler:

```rust
// Rust
let client = Zap::connect("zap://localhost:9000").await?;
```

```go
// Go
client, err := zap.Connect(ctx, "zap://localhost:9000")
```

```python
# Python
client = await Zap.connect("zap://localhost:9000")
```

```typescript
// JavaScript
const client = await Zap.connect('zap://localhost:9000');
```

### Hata yönetimi

Her bağlama, dilin doğal hata yönetimini kullanır:

- **Rust**: `Result<T, Error>` `?` işleciyle
- **Go**: Birden çok dönüş değeri `(result, error)`
- **Python**: Async bağlamda istisnalar
- **JavaScript**: try/catch veya `.catch()` ile Promise'ler

### Async/Await

Bağlamaların çoğu async işlemleri destekler:

```rust
// Rust (tokio)
let tools = client.list_tools().await?;
```

```go
// Go (goroutines)
tools, err := client.ListTools(ctx)
```

```python
# Python (asyncio)
tools = await client.list_tools()
```

```typescript
// JavaScript (Promises)
const tools = await client.listTools();
```

## Şemadan kod üretimi

ZAP şemasından bağlamalar üretin:

```bash
# Clone the schema
git clone https://github.com/zap-proto/zap
cd zap/schema

# Generate for your language
capnp compile -o rust zap.capnp
capnp compile -o go zap.capnp
capnp compile -o c++ zap.capnp
```

Ayrıntılı kod üretme yönergeleri için dile özel sayfalara bakın.
