## Motifs courants

### Création du client

Toutes les liaisons suivent un schéma similaire :

```rust
// Rust
let client = Zap::connect("zap://localhost:9000").await?;
```

```go
// Go
client, err := zap.Connect(ctx, "zap://localhost:9000")
```

```python
# Python
client = await Zap.connect("zap://localhost:9000")
```

```typescript
// JavaScript
const client = await Zap.connect('zap://localhost:9000');
```

### Gestion des erreurs

Chaque liaison utilise la gestion d'erreurs idiomatique du langage :

- **Rust**: `Result<T, Error>` avec l'opérateur `?`
- **Go**: Valeurs de retour multiples `(result, error)`
- **Python**: Exceptions avec un contexte async
- **JavaScript**: Promesses avec try/catch ou `.catch()`

### Async/Await

La plupart des liaisons prennent en charge les opérations async :

```rust
// Rust (tokio)
let tools = client.list_tools().await?;
```

```go
// Go (goroutines)
tools, err := client.ListTools(ctx)
```

```python
# Python (asyncio)
tools = await client.list_tools()
```

```typescript
// JavaScript (Promises)
const tools = await client.listTools();
```

## Génération de code à partir du schéma

Générez les liaisons à partir du schéma ZAP :

```bash
# Clone the schema
git clone https://github.com/zap-proto/zap
cd zap/schema

# Generate for your language
capnp compile -o rust zap.capnp
capnp compile -o go zap.capnp
capnp compile -o c++ zap.capnp
```

Consultez les pages de chaque langage pour les instructions détaillées de génération de code.
