# Vinculações de linguagem

O ZAP oferece vinculações nativas para 11 linguagens de programação. Cada vinculação é construída sobre a implementação de referência do Cap'n Proto para essa linguagem.

## Padrões comuns

### Criação do cliente

Todas as vinculações seguem um padrão semelhante:

```rust
// Rust
let client = Zap::connect("zap://localhost:9000").await?;
```

```go
// Go
client, err := zap.Connect(ctx, "zap://localhost:9000")
```

```python
# Python
client = await Zap.connect("zap://localhost:9000")
```

```typescript
// JavaScript
const client = await Zap.connect('zap://localhost:9000');
```

### Tratamento de erros

Cada vinculação usa o tratamento de erros idiomático da linguagem:

- **Rust**: `Result<T, Error>` com o operador `?`
- **Go**: Vários valores de retorno `(result, error)`
- **Python**: Exceções com contexto async
- **JavaScript**: Promises com try/catch ou `.catch()`

### Async/Await

A maioria das vinculações oferece operações async:

```rust
// Rust (tokio)
let tools = client.list_tools().await?;
```

```go
// Go (goroutines)
tools, err := client.ListTools(ctx)
```

```python
# Python (asyncio)
tools = await client.list_tools()
```

```typescript
// JavaScript (Promises)
const tools = await client.listTools();
```

## Geração de código a partir do esquema

Gere as vinculações a partir do esquema do ZAP:

```bash
# Clone the schema
git clone https://github.com/zap-proto/zap
cd zap/schema

# Generate for your language
capnp compile -o rust zap.capnp
capnp compile -o go zap.capnp
capnp compile -o c++ zap.capnp
```

Veja as páginas de cada linguagem para as instruções detalhadas de geração de código.
