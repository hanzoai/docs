## Gemeinsame Muster

### Client erzeugen

Alle Bindungen folgen einem ähnlichen Muster:

```rust
// Rust
let client = Zap::connect("zap://localhost:9000").await?;
```

```go
// Go
client, err := zap.Connect(ctx, "zap://localhost:9000")
```

```python
# Python
client = await Zap.connect("zap://localhost:9000")
```

```typescript
// JavaScript
const client = await Zap.connect('zap://localhost:9000');
```

### Fehlerbehandlung

Jede Bindung verwendet die idiomatische Fehlerbehandlung der Sprache:

- **Rust**: `Result<T, Error>` mit dem Operator `?`
- **Go**: Mehrere Rückgabewerte `(result, error)`
- **Python**: Ausnahmen mit async-Kontext
- **JavaScript**: Promises mit try/catch oder `.catch()`

### Async/Await

Die meisten Bindungen unterstützen async-Operationen:

```rust
// Rust (tokio)
let tools = client.list_tools().await?;
```

```go
// Go (goroutines)
tools, err := client.ListTools(ctx)
```

```python
# Python (asyncio)
tools = await client.list_tools()
```

```typescript
// JavaScript (Promises)
const tools = await client.listTools();
```

## Schemacode erzeugen

Erzeugen Sie Bindungen aus dem ZAP-Schema:

```bash
# Clone the schema
git clone https://github.com/zap-proto/zap
cd zap/schema

# Generate for your language
capnp compile -o rust zap.capnp
capnp compile -o go zap.capnp
capnp compile -o c++ zap.capnp
```

Ausführliche Anleitungen zur Codegenerierung stehen auf den sprachspezifischen Seiten.
