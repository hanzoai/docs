# 言語バインディング

ZAP は 11 のプログラミング言語向けにネイティブバインディングを提供します。各バインディングは、その言語の Cap'n Proto 参照実装の上に構築されています。

## 共通のパターン

### クライアントの作成

どのバインディングも似た形に従います:

```rust
// Rust
let client = Zap::connect("zap://localhost:9000").await?;
```

```go
// Go
client, err := zap.Connect(ctx, "zap://localhost:9000")
```

```python
# Python
client = await Zap.connect("zap://localhost:9000")
```

```typescript
// JavaScript
const client = await Zap.connect('zap://localhost:9000');
```

### エラー処理

各バインディングは、その言語らしいエラー処理を使います:

- **Rust**: `Result<T, Error>` `?` 演算子付き
- **Go**: 複数の戻り値 `(result, error)`
- **Python**: async コンテキストでの例外
- **JavaScript**: try/catch または `.catch()` を使う Promise

### Async/Await

ほとんどのバインディングは async 操作に対応します:

```rust
// Rust (tokio)
let tools = client.list_tools().await?;
```

```go
// Go (goroutines)
tools, err := client.ListTools(ctx)
```

```python
# Python (asyncio)
tools = await client.list_tools()
```

```typescript
// JavaScript (Promises)
const tools = await client.listTools();
```

## スキーマからのコード生成

ZAP スキーマからバインディングを生成します:

```bash
# Clone the schema
git clone https://github.com/zap-proto/zap
cd zap/schema

# Generate for your language
capnp compile -o rust zap.capnp
capnp compile -o go zap.capnp
capnp compile -o c++ zap.capnp
```

コード生成の詳しい手順は、言語ごとのページを参照してください。
