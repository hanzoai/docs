## Общие шаблоны

### Создание клиента

Все привязки следуют похожей схеме:

```rust
// Rust
let client = Zap::connect("zap://localhost:9000").await?;
```

```go
// Go
client, err := zap.Connect(ctx, "zap://localhost:9000")
```

```python
# Python
client = await Zap.connect("zap://localhost:9000")
```

```typescript
// JavaScript
const client = await Zap.connect('zap://localhost:9000');
```

### Обработка ошибок

Каждая привязка использует идиоматичную для языка обработку ошибок:

- **Rust**: `Result<T, Error>` с оператором `?`
- **Go**: Несколько возвращаемых значений `(result, error)`
- **Python**: Исключения в async-контексте
- **JavaScript**: Промисы с try/catch или `.catch()`

### Async/Await

Большинство привязок поддерживает async-операции:

```rust
// Rust (tokio)
let tools = client.list_tools().await?;
```

```go
// Go (goroutines)
tools, err := client.ListTools(ctx)
```

```python
# Python (asyncio)
tools = await client.list_tools()
```

```typescript
// JavaScript (Promises)
const tools = await client.listTools();
```

## Генерация кода из схемы

Сгенерируйте привязки из схемы ZAP:

```bash
# Clone the schema
git clone https://github.com/zap-proto/zap
cd zap/schema

# Generate for your language
capnp compile -o rust zap.capnp
capnp compile -o go zap.capnp
capnp compile -o c++ zap.capnp
```

Подробные инструкции по генерации кода смотрите на страницах отдельных языков.
