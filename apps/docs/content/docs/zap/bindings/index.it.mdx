# Binding di linguaggio

ZAP offre binding nativi per 11 linguaggi di programmazione. Ogni binding si basa sull'implementazione di riferimento di Cap'n Proto per quel linguaggio.

## Pattern comuni

### Creazione del client

Tutti i binding seguono uno schema simile:

```rust
// Rust
let client = Zap::connect("zap://localhost:9000").await?;
```

```go
// Go
client, err := zap.Connect(ctx, "zap://localhost:9000")
```

```python
# Python
client = await Zap.connect("zap://localhost:9000")
```

```typescript
// JavaScript
const client = await Zap.connect('zap://localhost:9000');
```

### Gestione degli errori

Ogni binding usa la gestione degli errori idiomatica del linguaggio:

- **Rust**: `Result<T, Error>` con l'operatore `?`
- **Go**: Valori di ritorno multipli `(result, error)`
- **Python**: Eccezioni con contesto async
- **JavaScript**: Promise con try/catch o `.catch()`

### Async/Await

La maggior parte dei binding supporta operazioni async:

```rust
// Rust (tokio)
let tools = client.list_tools().await?;
```

```go
// Go (goroutines)
tools, err := client.ListTools(ctx)
```

```python
# Python (asyncio)
tools = await client.list_tools()
```

```typescript
// JavaScript (Promises)
const tools = await client.listTools();
```

## Generazione del codice dallo schema

Genera i binding dallo schema ZAP:

```bash
# Clone the schema
git clone https://github.com/zap-proto/zap
cd zap/schema

# Generate for your language
capnp compile -o rust zap.capnp
capnp compile -o go zap.capnp
capnp compile -o c++ zap.capnp
```

Per le istruzioni dettagliate di generazione del codice, vedi le pagine di ciascun linguaggio.
