## รูปแบบร่วม

### การสร้างไคลเอนต์

การผูกทุกแบบเดินตามรูปแบบที่คล้ายกัน:

```rust
// Rust
let client = Zap::connect("zap://localhost:9000").await?;
```

```go
// Go
client, err := zap.Connect(ctx, "zap://localhost:9000")
```

```python
# Python
client = await Zap.connect("zap://localhost:9000")
```

```typescript
// JavaScript
const client = await Zap.connect('zap://localhost:9000');
```

### การจัดการข้อผิดพลาด

การผูกแต่ละแบบใช้การจัดการข้อผิดพลาดตามสำนวนของภาษานั้น:

- **Rust**: `Result<T, Error>` ด้วยตัวดำเนินการ `?`
- **Go**: ค่าที่ส่งกลับหลายค่า `(result, error)`
- **Python**: ข้อยกเว้นพร้อมบริบท async
- **JavaScript**: Promise พร้อม try/catch หรือ `.catch()`

### Async/Await

การผูกส่วนใหญ่รองรับการทำงานแบบ async:

```rust
// Rust (tokio)
let tools = client.list_tools().await?;
```

```go
// Go (goroutines)
tools, err := client.ListTools(ctx)
```

```python
# Python (asyncio)
tools = await client.list_tools()
```

```typescript
// JavaScript (Promises)
const tools = await client.listTools();
```

## การสร้างโค้ดจากสคีมา

สร้างการผูกจากสคีมาของ ZAP:

```bash
# Clone the schema
git clone https://github.com/zap-proto/zap
cd zap/schema

# Generate for your language
capnp compile -o rust zap.capnp
capnp compile -o go zap.capnp
capnp compile -o c++ zap.capnp
```

ดูหน้าของแต่ละภาษาสำหรับวิธีสร้างโค้ดอย่างละเอียด
