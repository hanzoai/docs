## Mẫu chung

### Tạo máy khách

Mọi liên kết đều theo một mẫu tương tự:

```rust
// Rust
let client = Zap::connect("zap://localhost:9000").await?;
```

```go
// Go
client, err := zap.Connect(ctx, "zap://localhost:9000")
```

```python
# Python
client = await Zap.connect("zap://localhost:9000")
```

```typescript
// JavaScript
const client = await Zap.connect('zap://localhost:9000');
```

### Xử lý lỗi

Mỗi liên kết dùng cách xử lý lỗi tự nhiên của ngôn ngữ đó:

- **Rust**: `Result<T, Error>` với toán tử `?`
- **Go**: Nhiều giá trị trả về `(result, error)`
- **Python**: Ngoại lệ với ngữ cảnh async
- **JavaScript**: Promise với try/catch hoặc `.catch()`

### Async/Await

Hầu hết liên kết hỗ trợ thao tác async:

```rust
// Rust (tokio)
let tools = client.list_tools().await?;
```

```go
// Go (goroutines)
tools, err := client.ListTools(ctx)
```

```python
# Python (asyncio)
tools = await client.list_tools()
```

```typescript
// JavaScript (Promises)
const tools = await client.listTools();
```

## Sinh mã từ lược đồ

Sinh liên kết từ lược đồ ZAP:

```bash
# Clone the schema
git clone https://github.com/zap-proto/zap
cd zap/schema

# Generate for your language
capnp compile -o rust zap.capnp
capnp compile -o go zap.capnp
capnp compile -o c++ zap.capnp
```

Xem trang của từng ngôn ngữ để biết hướng dẫn sinh mã chi tiết.
