## أنماط مشتركة

### إنشاء العميل

تتبع كل الروابط نمطًا متشابهًا:

```rust
// Rust
let client = Zap::connect("zap://localhost:9000").await?;
```

```go
// Go
client, err := zap.Connect(ctx, "zap://localhost:9000")
```

```python
# Python
client = await Zap.connect("zap://localhost:9000")
```

```typescript
// JavaScript
const client = await Zap.connect('zap://localhost:9000');
```

### معالجة الأخطاء

يستخدم كل ربط أسلوب معالجة الأخطاء المألوف في تلك اللغة:

- **Rust**: `Result<T, Error>` مع المعامل `?`
- **Go**: قيم إرجاع متعددة `(result, error)`
- **Python**: استثناءات ضمن سياق async
- **JavaScript**: وعود Promise مع try/catch أو `.catch()`

### Async/Await

تدعم معظم الروابط عمليات async:

```rust
// Rust (tokio)
let tools = client.list_tools().await?;
```

```go
// Go (goroutines)
tools, err := client.ListTools(ctx)
```

```python
# Python (asyncio)
tools = await client.list_tools()
```

```typescript
// JavaScript (Promises)
const tools = await client.listTools();
```

## توليد الشيفرة من المخطط

ولّد الروابط من مخطط ZAP:

```bash
# Clone the schema
git clone https://github.com/zap-proto/zap
cd zap/schema

# Generate for your language
capnp compile -o rust zap.capnp
capnp compile -o go zap.capnp
capnp compile -o c++ zap.capnp
```

راجع صفحات كل لغة لتعليمات توليد الشيفرة بالتفصيل.
