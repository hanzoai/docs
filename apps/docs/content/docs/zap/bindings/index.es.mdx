## Patrones comunes

### Creación del cliente

Todos los enlaces siguen un patrón parecido:

```rust
// Rust
let client = Zap::connect("zap://localhost:9000").await?;
```

```go
// Go
client, err := zap.Connect(ctx, "zap://localhost:9000")
```

```python
# Python
client = await Zap.connect("zap://localhost:9000")
```

```typescript
// JavaScript
const client = await Zap.connect('zap://localhost:9000');
```

### Manejo de errores

Cada enlace usa el manejo de errores propio del lenguaje:

- **Rust**: `Result<T, Error>` con el operador `?`
- **Go**: Varios valores de retorno `(result, error)`
- **Python**: Excepciones con contexto async
- **JavaScript**: Promesas con try/catch o `.catch()`

### Async/Await

La mayoría de los enlaces admiten operaciones async:

```rust
// Rust (tokio)
let tools = client.list_tools().await?;
```

```go
// Go (goroutines)
tools, err := client.ListTools(ctx)
```

```python
# Python (asyncio)
tools = await client.list_tools()
```

```typescript
// JavaScript (Promises)
const tools = await client.listTools();
```

## Generación de código a partir del esquema

Genera enlaces a partir del esquema de ZAP:

```bash
# Clone the schema
git clone https://github.com/zap-proto/zap
cd zap/schema

# Generate for your language
capnp compile -o rust zap.capnp
capnp compile -o go zap.capnp
capnp compile -o c++ zap.capnp
```

Consulta las páginas de cada lenguaje para las instrucciones detalladas de generación de código.
