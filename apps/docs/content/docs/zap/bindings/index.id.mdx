## Pola umum

### Pembuatan klien

Semua pengikatan mengikuti pola yang serupa:

```rust
// Rust
let client = Zap::connect("zap://localhost:9000").await?;
```

```go
// Go
client, err := zap.Connect(ctx, "zap://localhost:9000")
```

```python
# Python
client = await Zap.connect("zap://localhost:9000")
```

```typescript
// JavaScript
const client = await Zap.connect('zap://localhost:9000');
```

### Penanganan kesalahan

Setiap pengikatan memakai penanganan kesalahan yang idiomatis bagi bahasanya:

- **Rust**: `Result<T, Error>` dengan operator `?`
- **Go**: Beberapa nilai kembalian `(result, error)`
- **Python**: Eksepsi dengan konteks async
- **JavaScript**: Promise dengan try/catch atau `.catch()`

### Async/Await

Sebagian besar pengikatan mendukung operasi async:

```rust
// Rust (tokio)
let tools = client.list_tools().await?;
```

```go
// Go (goroutines)
tools, err := client.ListTools(ctx)
```

```python
# Python (asyncio)
tools = await client.list_tools()
```

```typescript
// JavaScript (Promises)
const tools = await client.listTools();
```

## Pembuatan kode dari skema

Hasilkan pengikatan dari skema ZAP:

```bash
# Clone the schema
git clone https://github.com/zap-proto/zap
cd zap/schema

# Generate for your language
capnp compile -o rust zap.capnp
capnp compile -o go zap.capnp
capnp compile -o c++ zap.capnp
```

Lihat halaman tiap bahasa untuk petunjuk pembuatan kode yang terperinci.
