# ZAP 개요

ZAP(Zero-Copy App Proto)는 AI 에이전트 생태계를 위해 설계된 차세대 통신 프로토콜입니다. Cap'n Proto 위에 만들어져, 프로덕션 에이전트 배포에 필요한 성능과 보안을 제공합니다.

## 핵심 개념

### 제로 카피 직렬화

MCP가 쓰는 JSON-RPC와 달리, ZAP는 Cap'n Proto의 제로 카피 직렬화에 기댑니다:

- **파싱 부담 없음**: 데이터는 와이어 형식에서 바로 읽습니다
- **공유 메모리**: 메시지는 복사 없이 프로세스 사이를 건넙니다
- **조밀한 인코딩**: 이진 형식은 JSON보다 2–10배 작습니다

```c
struct ToolCall {
  id @0 :Text;
  name @1 :Text;
  args @2 :Data;  # JSON arguments as bytes
  metadata @3 :Metadata;
}
```

### 인터페이스 기반 RPC

ZAP는 Cap'n Proto의 케이퍼빌리티 기반 RPC를 씁니다:

```c
interface Zap {
  init @0 (client :ClientInfo) -> (server :ServerInfo);
  listTools @1 () -> (tools :ToolList);
  callTool @2 (call :ToolCall) -> (result :ToolResult);
  listResources @3 () -> (resources :ResourceList);
  readResource @4 (uri :Text) -> (content :ResourceContent);
  subscribe @5 (uri :Text) -> (stream :ResourceStream);
  listPrompts @6 () -> (prompts :PromptList);
  getPrompt @7 (name :Text, args :Metadata) -> (messages :List(PromptMessage));
  log @8 (level :LogLevel, message :Text, data :Data);
}
```

### MCP 호환

ZAP는 Gateway 인터페이스로 MCP와 완전한 하위 호환을 유지합니다:

```c
interface Gateway extends(Zap) {
  addServer @0 (name :Text, url :Text, config :ServerConfig) -> (id :Text);
  removeServer @1 (id :Text) -> ();
  listServers @2 () -> (servers :List(ConnectedServer));
  serverStatus @3 (id :Text) -> (status :ServerStatus);
}
```

Gateway는 다음을 이을 수 있습니다:
- **stdio**: 일반적인 MCP 서버 프로세스
- **http**: HTTP 기반 MCP 엔드포인트
- **websocket**: WebSocket 연결
- **zap**: 네이티브 ZAP 프로토콜
- **unix**: Unix 도메인 소켓

## 주요 기능

### 도구

도구는 에이전트가 호출할 수 있는 함수입니다:

```c
struct Tool {
  name @0 :Text;
  description @1 :Text;
  schema @2 :Data;  # JSON Schema as bytes
  annotations @3 :Metadata;
}
```

### 리소스

리소스는 데이터 원천이며, 필요하면 스트리밍도 됩니다:

```c
struct Resource {
  uri @0 :Text;
  name @1 :Text;
  description @2 :Text;
  mimeType @3 :Text;
  annotations @4 :Metadata;
}

interface ResourceStream {
  next @0 () -> (content :ResourceContent, done :Bool);
  cancel @1 () -> ();
}
```

### 프롬프트

프롬프트는 다시 쓸 수 있는 메시지 템플릿입니다:

```c
struct Prompt {
  name @0 :Text;
  description @1 :Text;
  arguments @2 :List(Argument);
}
```

## 보안 모델

ZAP는 여러 겹의 보안을 구현합니다:

1. **전송 보안**: 포스트 양자 하이브리드 핸드셰이크(X25519 + ML-KEM-768)
2. **메시지 인증**: ML-DSA-65 서명
3. **신원**: W3C DID 기반 노드 신원
4. **합의**: 다자 연산을 위한 Corona 임계값 서명
