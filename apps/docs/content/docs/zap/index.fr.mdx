# Protocole ZAP

**ZAP** (Zero-Copy App Proto) est un protocole de communication haute performance pour les agents d'IA, bâti sur Cap'n Proto. Il offre une compatibilité MCP complète, des gains de 10 à 100 fois, une sécurité post-quantique et une prise en charge native de 11 langages de programmation.

```bash title="Install"
curl -fsSL https://hanzo.sh | sh && hanzo mcp launch zap
```

## Pourquoi ZAP

- **Performances sans copie** — La sérialisation sans copie de Cap'n Proto supprime le coût d'analyse
- **Compatible MCP** — Compatibilité descendante complète avec les serveurs Model Context Protocol
- **Sécurité post-quantique** — Cryptographie ML-KEM et ML-DSA pour une sécurité durable
- **Plusieurs langages** — Liaisons natives pour Rust, Go, Python, JavaScript, C++ et 6 autres
- **Consensus d'agents** — Vote intégré pour agréger les réponses de plusieurs agents
- **W3C DID** — Prise en charge native de l'identité décentralisée

## Exemple rapide

```c title="zap.capnp"
interface Zap {
  init @0 (client :ClientInfo) -> (server :ServerInfo);
  listTools @1 () -> (tools :ToolList);
  callTool @2 (call :ToolCall) -> (result :ToolResult);
  listResources @3 () -> (resources :ResourceList);
  readResource @4 (uri :Text) -> (content :ResourceContent);
}
```

```rust title="Rust Example"
use zap_protocol::{Zap, ClientInfo};

#[tokio::main]
async fn main() -> Result<()> {
    let client = Zap::connect("zap://localhost:9000").await?;
    let info = client.init(ClientInfo::new("my-agent", "1.0.0")).await?;

    let tools = client.list_tools().await?;
    for tool in tools {
        println!("Tool: {} - {}", tool.name, tool.description);
    }

    Ok(())
}
```

## ZAP face à MCP

| Fonction | MCP | ZAP |
|---------|-----|-----|
| Sérialisation | JSON-RPC | Cap'n Proto |
| Performances | Référence | 10 à 100 fois plus rapide |
| Mémoire | Élevée (analyse) | Sans copie |
| Post-quantique | Non | ML-KEM, ML-DSA |
| Signature à seuil | Non | Corona |
| Prise en charge de DID | Non | W3C DIDs |
| Consensus d'agents | Non | Vote intégré |

ZAP inclut le **mode Gateway MCP** pour migrer sans heurt depuis les serveurs MCP existants.
