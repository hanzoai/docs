# MCP

모델 컨텍스트 프로토콜 서버 하나, 도구 표면 하나. **`hanzo-mcp`**를 Claude Code(또는 Cursor, Claude Desktop, 아무 MCP 클라이언트)에 더하면 Hanzo의 모든 기능이 하나의 연결로 나타납니다 — 도구마다 선을 잇지 않습니다.

> 호스팅된 MCP 서버를 찾으시나요. **[클라우드 MCP](/docs/mcp-tools)**는 설치할 것이 없는 URL이고, 그 모든 도구는 [도구 목록](/docs/mcp-tools/all-tools)에 열거되어 있습니다. 이 페이지는 편집기 옆에서 도는 서버입니다.

```bash title="Add the Hanzo MCP to Claude Code"
claude mcp add hanzo -- npx -y @hanzo/mcp serve
```

그 명령 하나가 표면 전체를 엽니다.

- **통합 도구 13개** — `fs`, `exec`, `code`, `git`, `fetch`, `workspace`, `ui`, 그리고 선택인 `think`, `memory`, `hanzo`, `plan`, `tasks`, `mode`. 기능마다 동작으로 라우팅되는 도구 하나(HIP-0300)라서, 클라이언트는 겹치는 이름 수백 개 대신 작고 안정된 집합을 봅니다.
- **클라우드 서비스** — `hanzo` 도구가 플랫폼으로 네이티브하게 라우팅합니다. IAM(신원), Commerce, Storage, 그리고 `api.hanzo.ai/v1`의 AI API. 토큰으로 인증됩니다.
- **당신의 커넥터** — GitHub, Slack, Google, Discord, X 등. 콘솔에서 연결하면 같은 연결로 나타납니다.

같은 표면이 세 가지로 나갑니다 — TypeScript(`@hanzo/mcp`), Python(PyPI의 `hanzo-mcp`), Rust(`hanzo-mcp::brain`) — 일대일로 비추며, MCP 전송 **stdio**와 **streamable-http** 위입니다.

## 클라이언트 설정

```json title="Claude Desktop / Cursor — mcp config"
{
  "mcpServers": {
    "hanzo": {
      "command": "npx",
      "args": ["-y", "@hanzo/mcp", "serve"]
    }
  }
}
```

한 번 로그인하면(`hanzo auth login`) 클라우드 도구 `hanzo`와 커넥터가 스스로 인증됩니다. 로컬 도구(`fs`, `exec`, `git`, …)는 계정 없이 동작합니다.

## 도구 색인

플랫폼이 드러낼 수 있는 모든 도구는 `GET api.hanzo.ai/v1/tools`에 색인됩니다(인증). 오늘은 다섯 출처의 **1,468개 도구**입니다 — 통합 서버는 위의 동작 라우팅 표면으로 그것들을 내놓습니다.

| 출처 | 무엇인가 |
|--------|-----------|
| `builtin` | 핵심 로컬 도구(fs, exec, git, code, …) |
| `skill` | 포장된 기술 |
| `connector` | 연결된 클라우드 연동(GitHub, Slack, Google, Discord, X, …) |
| `agent` | 에이전트 진입점 |
| `function` | 사용자가 정의한 함수 |

## 서비스로서의 MCP

통합 서버 너머로 Hanzo는 아무 MCP 서버든 당신을 위해 **호스팅**할 수 있습니다 — 아무 npx, uvx, 또는 사용자 패키지에서 배포하고, 즉시 확장하며, 관리할 인프라는 없습니다.

```bash title="Launch an MCP server"
hanzo mcp launch npx @modelcontextprotocol/server-filesystem
```

## 핵심 기능

- **아무 MCP 서버** — 파일 시스템, Git, SQL, KV, Slack, GitHub, Notion 등
- **한 번의 클릭 배포** — 명령 하나로 아무 MCP 서버나 띄웁니다
- **자동 확장** — 0에서 수천 인스턴스까지 자동
- **유휴 비용 $0** — 쓴 만큼만. 유휴 요금은 없습니다
- **안전한 샌드박스** — 세밀한 권한의 격리 컨테이너
- **15곳 넘는 지역** — 세계에서 가장 낮은 지연을 위한 엣지 배포

## 띄우는 방법

### NPX 패키지

```bash
hanzo mcp launch npx @modelcontextprotocol/server-filesystem
hanzo mcp launch npx @modelcontextprotocol/server-github
hanzo mcp launch npx @modelcontextprotocol/server-slack
```

### UVX / Python

```bash
hanzo mcp launch uvx mcp-server-sqlite
hanzo mcp launch uvx mcp-server-postgres
```

### 사용자 서버

```bash
hanzo mcp launch git://github.com/you/mcp-server
hanzo mcp launch docker://your-org/mcp-custom:latest
```

## 구성

설정 파일 하나로 여러 서버를 배포합니다.

```yaml title="mcp-config.yaml"
version: "1"
servers:
  filesystem:
    package: "@modelcontextprotocol/server-filesystem"
    runtime: npx
    args: ["/workspace"]

  database:
    package: "mcp-server-postgres"
    runtime: uvx
    env:
      DATABASE_URL: "${secrets.DATABASE_URL}"

  github:
    package: "@modelcontextprotocol/server-github"
    runtime: npx
    env:
      GITHUB_TOKEN: "${secrets.GITHUB_TOKEN}"

  custom:
    image: "your-org/mcp-custom:latest"
    runtime: docker
    replicas: 3
```

```bash
hanzo mcp deploy
```
