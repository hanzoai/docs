**หลังหน้านี้คุณมีข้อมูลรับรองที่ใช้งานได้ และหนึ่งสายที่ตอบกลับมา**

Hanzo คือคลาวด์หนึ่งหลังกุญแจหนึ่ง ความสามารถทุกอย่าง — การอนุมาน ตัวตน
ที่เก็บ เงิน เอเจนต์ — ตอบที่ `https://api.hanzo.ai` และ CLI
SDK กับเครื่องมือ MCP ถูกสร้างจากคำอธิบายเดียวกัน ไม่มีอะไรต้อง
ต่อแยกตามบริการ: เอากุญแจครั้งเดียว แล้วทุกอย่างอยู่ในมือ

## 1. ติดตั้ง

<Tabs items={['npm', 'Script', 'Homebrew', 'จากซอร์ส']}>
<Tab value="npm">
```bash

```

`hanzo` คือ CLI และไคลเอนต์ในการติดตั้งครั้งเดียว
</Tab>
<Tab value="Script">
```bash
curl -fsSL https://hanzo.sh | sh
```

ติดตั้งที่ `~/.local/bin` `https://hanzo.sh/cli` ติดตั้งเฉพาะ CLI
</Tab>
<Tab value="Homebrew">
```bash
brew install hanzoai/tap/hanzo
```
</Tab>
<Tab value="จากซอร์ส">
```bash
git clone https://github.com/hanzoai/cli && cd cli && cargo install --path .
```
</Tab>
</Tabs>

```bash
hanzo version
```

## 2. เข้าสู่ระบบ

```bash
hanzo auth login
```

นั่นเปิดเบราว์เซอร์ไปที่ [hanzo.id](https://hanzo.id) ผู้ให้บริการตัวตน
ของ Hanzo และเก็บข้อมูลรับรองไว้ในเครื่อง `hanzo auth show` พิมพ์
ว่าคุณเป็นใคร `hanzo auth list` แสดงทุกตัวตนบนเครื่องนี้ และ
`hanzo auth use` สลับระหว่างพวกมัน

บนเซิร์ฟเวอร์ ออกกุญแจแทนการให้คนเข้าสู่ระบบ: **console.hanzo.ai →
กุญแจ API** กุญแจลับคือ *คุณ* จึงอยู่บนเซิร์ฟเวอร์ ไม่เคย
อยู่ในเบราว์เซอร์ — [การยืนยันตัวตน](/docs/api-keys) คือกฎทั้งหมด

```bash
export HANZO_API_KEY=sk-...
```

## 3. แสดงรายการโมเดล

แคตตาล็อกโมเดลที่เกตเวย์ให้บริการอยู่ตอนนี้ เป็นการอ่าน ต้องการแค่
กุญแจ และเป็นการทำงานเดียวกันบนทั้งสี่พื้นผิว

<Tabs items={['CLI', 'SDK', 'HTTP', 'MCP']}>

ทั้งหมดถูกสร้างจากคำอธิบาย API เดียวกัน ดังนั้นชื่อเมธอด
ตรงกันข้ามภาษา [C++](/docs/sdks/cpp) คือตัวที่ยัง
กำลังมาถึง
</Tab>
<Tab value="HTTP">
```bash
curl https://api.hanzo.ai/v1/models \
  -H "Authorization: Bearer $HANZO_API_KEY"
```
</Tab>
<Tab value="MCP">
```bash
curl -X POST https://api.hanzo.ai/v1/mcp \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

จุดปลายเดียว เครื่องมือหนึ่งต่อความสามารถ `tools/call` ตั้งชื่อความสามารถและ
การทำงาน `describe` อธิบายอินพุตของการทำงานใดก็ได้
</Tab>
</Tabs>

นั่นคือ API เดียวที่มองจากสี่ที่ และแท็บข้างบนคือความต่าง
ทั้งหมด เลือกอันที่คุณจะเขียน

- **[CLI](/docs/cli)** — แต่ละความสามารถเป็นกลุ่มคำสั่ง หน้าละหนึ่ง
- **[SDK](/docs/sdks)** — Python, TypeScript, Go, Rust, C++, Swift และ Kotlin
  สร้างจากคำอธิบายเดียวกับ CLI และเครื่องมือ
- **[MCP](/docs/mcp)** — จุดปลายหนึ่งที่เอเจนต์เชื่อมต่อ [เครื่องมือ](/docs/mcp-tools)
  ถูกระบุหนึ่งรายการต่อความสามารถ

HTTP ไม่ต้องมีหน้า: คือ `https://api.hanzo.ai` และกุญแจที่คุณเพิ่งส่งออก

## 4. ส่งการเติมข้อความ

นี่คือก้าวแรกที่ใช้เครดิต ทุกอย่างข้างบนรันได้ฟรี

```bash
hanzo chat completions --model zen-1 --messages '[{"role":"user","content":"hello"}]'
```

แล้วอ่านว่ามันใช้ไปเท่าไร:

```bash
hanzo billing balance
hanzo usage summary
```

[เครดิตและการเรียกเก็บ](/docs/credits) อธิบายว่าเครดิตคืออะไรและเกิดอะไรที่
ศูนย์ [ราคา](/docs/pricing) คืออัตราของแต่ละรุ่นและเครื่องมือ

## 5. รันคลาวด์ในเครื่อง

ไบนารีเดียวกับที่ให้บริการ `api.hanzo.ai` รันบนเครื่องคุณ:

```bash
hanzo up cloud
```

`hanzo up` เปล่า ๆ คือสิ่งเดียวกัน — `cloud` เป็นค่าเริ่มต้น ตั้งชื่อบริการหนึ่งเพื่อ
รันมันลำพัง: `hanzo up iam`, `hanzo up kms`, `hanzo up gateway`, `hanzo up
storage`, `hanzo up pubsub` ดู[รันของคุณเอง](/docs/network) ว่าหมายถึงอะไร
และต้องการอะไร
