## 1. Boot Your Local AI Operating System (10 Minutes)

Install the unified `hanzo` CLI, Dev coding agent, MCP server, and local model engine:

```bash
curl -fsSL https://hanzo.sh | sh
hanzo version
hanzo auth login
```

### Canonical CLI Lifecycle (3-Layer Model)

Hanzo separates the **local runtime** (microVM or native runtime, `k3s`, `containerd`, `hanzod`) from **platform & app workloads** (Hanzo Cloud, Engine, and your apps), so you can rebuild and iterate on apps in seconds without restarting Kubernetes:

```bash
hanzo start                 # boot local runtime (VM, k3s, containerd)
hanzo up                    # start Hanzo Cloud & configured local workloads
hanzo ps                    # inspect Runtime, k3s, Cloud, hanzod & sandboxes
hanzo doctor                # diagnose local runtime, ports & credentials
hanzo down                  # stop Cloud & apps while keeping k3s + image cache warm
hanzo stop                  # gracefully stop the local runtime and reclaim resources
```

### Fast Loopback Mode (Zero Kubernetes Required)

To run the single static Cloud binary ([`hanzoai/cloud`](https://github.com/hanzoai/cloud)) and local open-weight model inference ([`hanzoai/engine`](https://github.com/hanzoai/engine)) directly on localhost:

```bash
# Terminal 1 — OSS Cloud core (encrypted SQLite /v1/base, /v1/tasks, /v1/kms, /mcp)
git clone https://github.com/hanzoai/cloud.git && cd cloud
make dev

# Terminal 2 — Local open-weight LLM & embeddings on :1234 (includes built-in /ui chat)
hanzo pull zen-nano
hanzo engine serve zen-nano -- --host 127.0.0.1 -p 1234 --no-advertise

# Terminal 3 — Verify both services answer cleanly
curl -sS http://127.0.0.1:9090/healthz
curl -sS http://127.0.0.1:1234/v1/models
curl -sS -X POST http://127.0.0.1:8080/v1/base/collections/notes \
  -H "Content-Type: application/json" \
  -d '{"doc":{"title":"local-stack-ready"}}'
```

See [Self-Hosting & Air-Gapped](/docs/self-hosting) to add local OIDC identity ([`hanzoai/iam`](https://github.com/hanzoai/iam)) or deploy offline.

## 2. Run the Core Apps You Live In Every Day

Connect your local Cloud (`:8080`) and Engine (`:1234`) to the full open-source client and agent suite:

### Hanzo Desktop & Hanzo Dev Desktop
- **Install prebuilt desktop apps** (macOS, Windows, Linux): **[hanzo.ai/download](https://hanzo.ai/download)** — see [Desktop](/docs/apps/desktop) to point **Settings → Environments & Machines → Cloud API Endpoint** at `http://127.0.0.1:8080`.
- **Build standalone Hanzo Dev Desktop from source** ([`hanzoai/dev`](https://github.com/hanzoai/dev)):
  ```bash
  git clone https://github.com/hanzoai/dev.git && cd dev
  pnpm install
  pnpm run build:desktop
  ```

### Hanzo Mobile (iOS & Android)
Install the signed Android APK directly, deploy over USB with ADB or Xcode, or sideload from Linux — see **[Mobile](/docs/apps/mobile)** and [`hanzoai/mobile`](https://github.com/hanzoai/mobile).

### Hanzo Bot (24/7 Autonomous Agents Across Your Channels)
Run always-on agents connected to Slack, Discord, Telegram, WhatsApp, and iMessage — backed by your local Engine and Cloud:

```bash
npm install -g @hanzo/bot
hanzo-bot onboard --install-daemon
```

Source: [`hanzoai/bot`](https://github.com/hanzoai/bot).

### Hanzo Chat & Hanzo Team
```bash
# Multi-model AI chat web app wired to your local engine
git clone https://github.com/hanzoai/chat.git && cd chat
pnpm install
VITE_HANZO_API=http://127.0.0.1:1234 pnpm dev

# Shared workspace for humans, bots, and agents
git clone https://github.com/hanzoai/team.git && cd team
pnpm install && pnpm dev
```

### Wire Your Coding Agents (MCP, Browser Extension & Progressive Skills)
Give Claude Code, Codex, Cursor, Windsurf, Gemini CLI, Antigravity, or Hanzo Dev full access to your local stack and 1,477+ skills without bloating context:

```bash
# 1. Load Tier-0 progressive instructions (< 8 KB — never dumps all skills up front)
curl -fsSL https://hanzoskills.com/CLAUDE.md >> ~/.claude/CLAUDE.md

# 2. Attach Hanzo MCP (13 HIP-0300 unified tools over stdio)
claude mcp add --scope user hanzo -- npx -y hanzo mcp   # or: codex mcp add hanzo -- npx -y hanzo mcp

# 3. Install the Hanzo Browser Extension for live tab inspection & automation
mkdir -p ~/.hanzo/browser-extension && cd ~/.hanzo/browser-extension
URL=$(curl -fsSL https://api.github.com/repos/hanzoai/extension/releases/latest \
  | grep -oE 'https://[^"]*hanzo-ai-chrome[^"]*\.zip' | head -1)
curl -fsSL "$URL" -o ext.zip && unzip -oq ext.zip && rm ext.zip
```

Load `~/.hanzo/browser-extension` in Chrome/Brave/Arc/Edge via `chrome://extensions` → **Developer mode** → **Load unpacked**. See [Skills, MCP & Desktop](/docs/skills) for every agent's native config.

## 4. Build Your First Custom App Into the `@hanzo/app` Siderail

Every Hanzo app is a **100% static client-side App Mod (`@hanzo/mod`)** that mounts directly into the [`@hanzo/app`](https://github.com/hanzoai/app) host shell — inheriting the left siderail, authenticated IAM session, model picker, keyboard shortcuts, and `/v1` platform APIs with zero backend boilerplate.

### Step 1: Export a `Mod` Descriptor

```tsx title="src/mods/growth-hq/index.tsx"
import type { Mod } from '@hanzo/mod';
import { Rocket } from 'lucide-react';
import { GrowthHqPane } from './Pane';
import { GrowthHqBar } from './Bar';

export const growthHqMod: Mod = {
  id: 'growth-hq',
  title: 'Growth HQ',
  icon: Rocket,
  path: '/growth-hq',
  Pane: GrowthHqPane,
  Bar: GrowthHqBar,
  capabilities: ['web', 'mcp'],
};

export default growthHqMod;
```

### Step 2: Connect IAM, AI & Tools Inside Your Pane

```tsx title="src/mods/growth-hq/Pane.tsx"
import { useState } from 'react';
import { useIam } from '@hanzo/iam/react';
import { useAi } from '@hanzo/ai/react';
import { Button, YStack, Text } from '@hanzo/ui';

export function GrowthHqPane() {
  const { org } = useIam();
  const { chat } = useAi();
  const [plan, setPlan] = useState<string>('');

  const draftLaunch = async () => {
    const res = await chat({
      model: 'enso',
      messages: [
        {
          role: 'user',
          content: 'Draft a 7-day product launch checklist with social posts, landing page copy, and email outreach.',
        },
      ],
      tools: ['builtin:exec', 'builtin:fs'],
    });
    setPlan(String(res?.choices?.[0]?.message?.content ?? 'Done'));
  };

  return (
    <YStack flex={1} p="$4" gap="$3">
      <Text fontSize="$5" fontWeight="600">
        Growth HQ — {org?.name ?? 'Local Workspace'}
      </Text>
      <Button onPress={draftLaunch}>Generate Launch Plan</Button>
      {plan ? <Text>{plan}</Text> : null}
    </YStack>
  );
}
```

### Step 3: Mount Into the Siderail & Pair With Plugins or Skills

1. Register `growthHqMod` in your `@hanzo/app` shell so its icon (`Rocket`) and route (`/growth-hq`) appear in the left siderail alongside Chat, Dev, Studio, and Team.
2. Run against your local Cloud (`hanzo up` or `make dev` in `hanzoai/cloud`) and test live tool calls.
3. Add an **in-process TypeScript plugin** for external SaaS connectors and a repo-local **`.hanzo/skills/<name>/SKILL.md`** so your agents can operate your custom app autonomously.

Full architecture, plugin contract, and marketplace publishing steps live in **[Building Apps & Mods](/docs/apps/mods)**.

## 6. Automate Tasks, Fix Bugs, Test Everything & Earn Bounties

Use the Hanzo CLI harness and Kata to automate work across any repository:

```bash
hanzo dev                                              # native coding agent
hanzo --claude "add unit tests for edge cases"         # Claude Code + Hanzo MCP
hanzo --codex "reproduce and fix the test race"        # Codex + Hanzo MCP
kata run --suite tests/unit                            # closed-loop test repair (hanzoai/kata)
```

### Pull Request Checklist
1. Branch cleanly from `main` in `github.com/hanzoai/<repo>` and keep PRs small and focused.
2. Run the repo's full tests & linters (`go test -race ./...`, `cargo test --locked && cargo clippy --all-targets -- -D warnings`, `pnpm test`, or `pytest`) and paste the output into your PR description.
3. Fix any unclear setup steps in `README.md`, `Makefile`, or `hanzoai/docs` as you go.
4. Link your issue (`Closes #<number>`) so reviews and rewards track automatically.
