## 소개

Fumapress는 Hanzo Docs로 Markdown 파일을 보여 줍니다. 스킬 파일과 노트를 읽을 때 유용합니다.

명령은 프로젝트 디렉터리에서 실행합니다.

```npm
npx @hanzo/docs-press dir/to/content
```

### 구성

다른 구성이 필요하면 로컬에 설치할 수 있습니다.

```npm
npm install @hanzo/docs-press -D
```

그런 다음 구성 파일을 초기화합니다.

```npm
npx @hanzo/docs-press init
```
