## 簡介

Fumapress 讓你用 Hanzo Docs 查看 Markdown 檔案，適合閱讀技能檔案和筆記。

在專案目錄下執行這條指令。

```npm
npx @hanzo/docs-press dir/to/content
```

### 設定

如果需要其他設定，可以在本機安裝：

```npm
npm install @hanzo/docs-press -D
```

然後初始化設定檔：

```npm
npx @hanzo/docs-press init
```
