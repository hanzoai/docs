## Giới thiệu

Fumapress cho phép xem tệp Markdown với Hanzo Docs. Nó hữu ích để đọc tệp skill và ghi chú.

Chạy lệnh trong thư mục dự án của bạn.

```npm
npx @hanzo/docs-press dir/to/content
```

### Cấu hình

Với cấu hình khác, bạn có thể cài cục bộ:

```npm
npm install @hanzo/docs-press -D
```

Rồi khởi tạo tệp cấu hình:

```npm
npx @hanzo/docs-press init
```
