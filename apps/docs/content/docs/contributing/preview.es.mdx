## Introducción

Fumapress permite ver archivos Markdown con Hanzo Docs. Sirve para leer archivos de skills y notas.

Ejecuta el comando dentro del directorio de tu proyecto.

```npm
npx @hanzo/docs-press dir/to/content
```

### Configuraciones

Para otras configuraciones, puedes instalarlo en local:

```npm
npm install @hanzo/docs-press -D
```

Luego inicializa el archivo de configuración:

```npm
npx @hanzo/docs-press init
```
