## مقدمة

يتيح Fumapress عرض ملفات Markdown مع Hanzo Docs، وهو مفيد لقراءة ملفات المهارات والملاحظات.

شغّل الأمر داخل دليل مشروعك.

```npm
npx @hanzo/docs-press dir/to/content
```

### الضبط

لضبط آخر، يمكنك تثبيته محليًا:

```npm
npm install @hanzo/docs-press -D
```

ثم هيّئ ملف الضبط:

```npm
npx @hanzo/docs-press init
```
