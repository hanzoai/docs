## Введение

Fumapress показывает файлы Markdown в Hanzo Docs. Он удобен для чтения файлов skills и заметок.

Запустите команду в каталоге проекта.

```npm
npx @hanzo/docs-press dir/to/content
```

### Конфигурации

Для других настроек можно установить его локально:

```npm
npm install @hanzo/docs-press -D
```

Затем инициализируйте файл конфигурации:

```npm
npx @hanzo/docs-press init
```
