## Pengantar

Fumapress memungkinkan Anda melihat berkas Markdown dengan Hanzo Docs. Berguna untuk membaca berkas skill dan catatan.

Jalankan perintah di dalam direktori proyek Anda.

```npm
npx @hanzo/docs-press dir/to/content
```

### Konfigurasi

Untuk konfigurasi lain, Anda dapat memasangnya secara lokal:

```npm
npm install @hanzo/docs-press -D
```

Lalu inisialisasi berkas konfigurasi:

```npm
npx @hanzo/docs-press init
```
