## Giriş

Fumapress, Markdown dosyalarını Hanzo Docs ile görmenizi sağlar. Skill dosyalarını ve notları okumak için kullanışlıdır.

Komutu proje dizininizin altında çalıştırın.

```npm
npx @hanzo/docs-press dir/to/content
```

### Yapılandırmalar

Başka yapılandırmalar için yerelde kurabilirsiniz:

```npm
npm install @hanzo/docs-press -D
```

Ardından yapılandırma dosyasını başlatın:

```npm
npx @hanzo/docs-press init
```
