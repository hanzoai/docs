## はじめに

Fumapress は Hanzo Docs で Markdown ファイルを表示します。スキルのファイルやメモを読むのに役立ちます。

コマンドはプロジェクトのディレクトリで実行します。

```npm
npx @hanzo/docs-press dir/to/content
```

### 設定

ほかの設定にするには、ローカルにインストールできます。

```npm
npm install @hanzo/docs-press -D
```

それから設定ファイルを初期化します。

```npm
npx @hanzo/docs-press init
```
