## परिचय

Fumapress से Hanzo Docs के साथ Markdown फ़ाइलें देखी जा सकती हैं। यह skills फ़ाइलें और नोट पढ़ने में उपयोगी है।

कमांड अपनी परियोजना निर्देशिका में चलाएँ।

```npm
npx @hanzo/docs-press dir/to/content
```

### कॉन्फ़िगरेशन

अन्य कॉन्फ़िगरेशन के लिए इसे स्थानीय रूप से इंस्टॉल कर सकते हैं:

```npm
npm install @hanzo/docs-press -D
```

फिर कॉन्फ़िग फ़ाइल आरंभ करें:

```npm
npx @hanzo/docs-press init
```
