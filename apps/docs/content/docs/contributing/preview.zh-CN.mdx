## 简介

Fumapress 让你用 Hanzo Docs 查看 Markdown 文件，适合阅读技能文件和笔记。

在项目目录下运行这条命令。

```npm
npx @hanzo/docs-press dir/to/content
```

### 配置

如果需要其他配置，可以在本地安装：

```npm
npm install @hanzo/docs-press -D
```

然后初始化配置文件：

```npm
npx @hanzo/docs-press init
```
