## Introdução

O Fumapress permite ver arquivos Markdown com o Hanzo Docs. Ele serve para ler arquivos de skills e anotações.

Execute o comando dentro do diretório do seu projeto.

```npm
npx @hanzo/docs-press dir/to/content
```

### Configurações

Para outras configurações, você pode instalá-lo localmente:

```npm
npm install @hanzo/docs-press -D
```

Depois, inicialize o arquivo de configuração:

```npm
npx @hanzo/docs-press init
```
