## บทนำ

Fumapress ให้ดูไฟล์ Markdown ด้วย Hanzo Docs มีประโยชน์สำหรับอ่านไฟล์สกิลและโน้ต

รันคำสั่งภายใต้ไดเรกทอรีโครงการของคุณ

```npm
npx @hanzo/docs-press dir/to/content
```

### การกำหนดค่า

สำหรับการกำหนดค่าอื่น คุณติดตั้งในเครื่องได้:

```npm
npm install @hanzo/docs-press -D
```

จากนั้นเริ่มไฟล์กำหนดค่า:

```npm
npx @hanzo/docs-press init
```
