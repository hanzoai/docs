## Einführung

Fumapress zeigt Markdown-Dateien mit Hanzo Docs an. Es eignet sich zum Lesen von Skill-Dateien und Notizen.

Führen Sie den Befehl im Projektverzeichnis aus.

```npm
npx @hanzo/docs-press dir/to/content
```

### Konfigurationen

Für weitere Konfigurationen können Sie es lokal installieren:

```npm
npm install @hanzo/docs-press -D
```

Initialisieren Sie dann die Konfigurationsdatei:

```npm
npx @hanzo/docs-press init
```
