## Introduction

Fumapress permet d'afficher des fichiers Markdown avec Hanzo Docs. Il sert à lire des fichiers de skills et des notes.

Lancez la commande dans le répertoire de votre projet.

```npm
npx @hanzo/docs-press dir/to/content
```

### Configurations

Pour d'autres configurations, vous pouvez l'installer localement :

```npm
npm install @hanzo/docs-press -D
```

Puis initialisez le fichier de configuration :

```npm
npx @hanzo/docs-press init
```
