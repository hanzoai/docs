## Introduzione

Fumapress permette di vedere i file Markdown con Hanzo Docs. È utile per leggere file di skill e note.

Esegui il comando nella directory del progetto.

```npm
npx @hanzo/docs-press dir/to/content
```

### Configurazioni

Per altre configurazioni puoi installarlo in locale:

```npm
npm install @hanzo/docs-press -D
```

Poi inizializza il file di configurazione:

```npm
npx @hanzo/docs-press init
```
