Cada modelo abaixo é alcançado com uma chave em um endereço. Passe o `id` como
`model` e o resto da requisição é o mesmo, qualquer um que você escolha.

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"<id from below>","messages":[{"role":"user","content":"Hello"}]}'
```

A tabela é buscada de [`/v1/models`](/docs/openapi/ai) no navegador quando
a página carrega, então é o catálogo que o gateway serve agora, não
uma cópia escrita quando a página foi construída.

## O que uma tarifa significa

As tarifas são por milhão de tokens, entrada e saída com preço separado, e são
as mesmas se você chama da CLI, de um SDK, de HTTP ou de uma ferramenta MCP — o preço
é uma propriedade do modelo, não da superfície pela qual você chega.

[Preços](/docs/pricing) explica como o uso vira uma conta. [Créditos](/docs/credits)
cobre o que acontece quando o saldo acaba.
