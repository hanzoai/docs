# Console-Einrichtung

Verbinden Sie Ihre Konten einmal in der Konsole, und dieselbe einheitliche
Nutzung folgt Ihnen in der `dev`-CLI, in Hanzo Desktop, auf hanzo.app und
hanzo.chat.

## Konten verbinden

<Steps>
<Step>
### KI-Konten öffnen

Melden Sie sich bei [console.hanzo.ai](https://console.hanzo.ai) an und öffnen
Sie den Bereich **KI-Konten** (`/ai-accounts`).
</Step>
<Step>
### Ein Konto hinzufügen

Wählen Sie auf der Registerkarte **Konten** einen Anbieter — Hanzo oder einen
der anderen im Verzeichnis — und schließen Sie den geführten
Kontoverbindungsablauf ab. Er verwendet Ihre vorhandene Anmeldung wieder
(OAuth, Browsersitzung oder API-Schlüssel); es werden keine Passwörter
gespeichert.
</Step>
<Step>
### Für jedes Konto wiederholen

Verknüpfen Sie so viele Konten, wie Sie möchten, einschließlich GPU, Cloud und
Integrationen (Zahlungen, E-Commerce, Marketing, Analytik). Jedes verbundene
Konto erscheint im einheitlichen Dashboard.
</Step>
</Steps>

## Was das einheitliche Dashboard zeigt

Für jedes verbundene Konto, in einer Ansicht:

- **Ratenlimits** und Zeit bis zur Rücksetzung jedes Fensters
- **Guthaben** und verbleibendes Saldo
- **Ausgaben** bis heute
- **Quelle**, aus der jede Zahl gelesen wurde (OAuth, Websitzung, CLI oder API-Token)

Das Dashboard liest über denselben Kern [`@hanzo/usage`](/docs/usage/quickstart),
den CLI und Desktop-Apps nutzen, deshalb stimmen die Zahlen überall überein.
