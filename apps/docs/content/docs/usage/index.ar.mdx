# استخدام Hanzo

**استخدام Hanzo** هو الموصّل الشامل للذكاء الاصطناعي ومستوى الاستخدام. اربط
حسابات مزوّدي الذكاء الاصطناعي مرة واحدة، ثم اطّلع على الاستخدام الموحّد — حدود
المعدّل وإعادة الضبط والأرصدة والإنفاق — في كل مكان يعمل فيه Hanzo: واجهة `dev`
CLI وHanzo Desktop وhanzo.app وhanzo.chat و[console.hanzo.ai](https://console.hanzo.ai).

## القصّة

1. **اربط مرة واحدة.** اربط Hanzo ومزوّدي الذكاء الاصطناعي الآخرين الذين تدفع
   لهم أصلًا — السجل قابل للتوسعة — إضافة إلى حسابات GPU والسحابة والتكامل
   (المدفوعات والتجارة الإلكترونية والتسويق والتحليلات)، باستخدام جلسات الدخول
   التي لديك أصلًا. لا تُخزَّن كلمات المرور.
2. **اطّلع على الاستخدام الموحّد.** عرض واحد لكل حساب: الحدود وإعادة الضبط
   والأرصدة والإنفاق، بشكل أصيل في كل سطح من سطوح Hanzo.
3. **أضف مؤسستك.** يمكنك اختياريًا مشاركة جلسات الدخول المتحقَّق منها على مستوى
   المؤسسة وتوجيه استخدام الذكاء الاصطناعي عبر الواجهة الخلفية لـ Hanzo للحصول
   على عرض شامل وتحليلات وتقارير لكل عضو. تُطبَّق رسوم بنسبة 1% على الاستخدام
   الموجَّه.
4. **ادفع لمطوّري الذكاء الاصطناعي مفتوح المصدر.** Hanzo سحابة مبنية أصلًا
   للذكاء الاصطناعي ومصمَّمة لإعادة الإنفاق إلى منظومة الذكاء الاصطناعي مفتوح
   المصدر التي تعمل عليها.

## كيف يعمل

المحرك هو [`@hanzo/usage`](/docs/usage/quickstart) — نواة TypeScript من دون
واجهة، بترخيص MIT. كل مزوّد واصف يحمل خط أنابيب مرتّبًا من استراتيجيات الجلب
(`oauth` → `web` → `cli` → `apiToken` → `localProbe`) تعيد استخدام جلسات دخولك
الحالية — ملفات رموز OAuth الخاصة بواجهة CLI وجلسات المتصفح ومفاتيح API. تتراجع
الاستراتيجيات حسب ترتيب الأولوية ولا تطلب كلمات المرور أبدًا. تحرّك النواة نفسها
تطبيق شريط قوائم macOS وواجهة CLI وتطبيقات سطح المكتب والويب ووحدة التحكم.
