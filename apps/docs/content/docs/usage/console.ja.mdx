# コンソールの初期設定

コンソールでアカウントを一度接続すれば、同じ統合された利用状況が `dev` CLI、
Hanzo Desktop、hanzo.app、hanzo.chat に付いてきます。

## アカウントを接続する

<Steps>
<Step>
### AI アカウントを開く

[console.hanzo.ai](https://console.hanzo.ai) にサインインし、
**AI アカウント**（`/ai-accounts`）を開きます。
</Step>
<Step>
### アカウントを追加する

**アカウント**タブでプロバイダーを選びます。Hanzo でも、レジストリにある他の
どれでも構いません。案内付きのアカウント接続を完了してください。既存のログイン
（OAuth、ブラウザーセッション、または API キー）を再利用します。パスワードは
保存されません。
</Step>
<Step>
### すべてのアカウントで繰り返す

GPU、クラウド、連携プロバイダー（決済、電子商取引、マーケティング、分析）を含め、
好きなだけアカウントを結びます。接続したアカウントは統合ダッシュボードに現れます。
</Step>
</Steps>

## 統合ダッシュボードに表示されるもの

接続済みの各アカウントについて、一つの画面で:

- 各ウィンドウの**レート制限**とリセットまでの時間
- **クレジット**と残りの残高
- 現在までの**支出**
- 各数値が読み取られた**取得元**（OAuth、ウェブセッション、CLI、または API トークン）

ダッシュボードは、CLI とデスクトップアプリが使うのと同じ
[`@hanzo/usage`](/docs/usage/quickstart) コアを通して読むため、数値はどこでも一致します。
