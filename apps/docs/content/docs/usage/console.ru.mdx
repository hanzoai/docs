# Подключение в консоли

Подключите учётные записи один раз в консоли, и то же единое использование
следует за вами в CLI `dev`, Hanzo Desktop, hanzo.app и hanzo.chat.

## Подключите учётные записи

<Steps>
<Step>
### Откройте учётные записи ИИ

Войдите на [console.hanzo.ai](https://console.hanzo.ai) и откройте раздел
**Учётные записи ИИ** (`/ai-accounts`).
</Step>
<Step>
### Добавьте учётную запись

На вкладке **Учётные записи** выберите поставщика — Hanzo или любого другого из
реестра — и пройдите управляемое подключение учётной записи. Оно использует ваш
существующий вход (OAuth, сеанс браузера или ключ API); пароли не сохраняются.
</Step>
<Step>
### Повторите для каждой учётной записи

Привяжите сколько угодно учётных записей, включая GPU, облако и интеграции
(платежи, электронная коммерция, маркетинг, аналитика). Каждая подключённая
учётная запись появляется на единой панели.
</Step>
</Steps>

## Что показывает единая панель

Для каждой подключённой учётной записи, в одном представлении:

- **Лимиты частоты** и время до сброса каждого окна
- **Кредиты** и остаток баланса
- **Расходы** на текущий момент
- **Источник**, из которого прочитана каждая цифра (OAuth, веб-сеанс, CLI или токен API)

Панель читает через то же ядро [`@hanzo/usage`](/docs/usage/quickstart), что CLI
и настольные приложения, поэтому цифры совпадают везде.
