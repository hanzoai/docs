# Uso do Hanzo

**Uso do Hanzo** é o conector universal de IA e o plano de uso. Vincule suas
contas de provedores de IA uma vez e depois veja o uso unificado — limites de
taxa, redefinições, créditos e gasto — em todo lugar onde o Hanzo roda: a CLI
`dev`, o Hanzo Desktop, hanzo.app, hanzo.chat e
[console.hanzo.ai](https://console.hanzo.ai).

## A história

1. **Conecte uma vez.** Vincule o Hanzo, os outros provedores de IA que você já
   paga — o registro é extensível — além de contas de GPU, nuvem e integração
   (pagamentos, comércio eletrônico, marketing, análise), usando os logins que
   você já tem. Nenhuma senha é armazenada.
2. **Veja o uso unificado.** Uma visão de cada conta: limites, redefinições,
   créditos e gasto, nativa em cada superfície do Hanzo.
3. **Adicione sua organização.** Opcionalmente, compartilhe logins verificados
   em toda a organização e encaminhe o uso de IA pelo backend do Hanzo para uma
   visão abrangente, análises e relatórios por membro. Uma taxa de 1% incide
   sobre o uso encaminhado.
4. **Pague desenvolvedores de IA de código aberto.** O Hanzo é uma nuvem nativa
   de IA, projetada para devolver o gasto ao ecossistema de IA de código aberto
   sobre o qual ela roda.

## Como funciona

O motor é [`@hanzo/usage`](/docs/usage/quickstart) — um núcleo TypeScript sem
interface, sob licença MIT. Cada provedor é um descritor com um pipeline
ordenado de estratégias de leitura (`oauth` → `web` → `cli` → `apiToken` →
`localProbe`) que reutilizam seus logins existentes — arquivos de token OAuth da
CLI, sessões do navegador, chaves de API. As estratégias recuam na ordem de
prioridade e nunca pedem senhas. O mesmo núcleo move o app da barra de menus do
macOS, a CLI, os apps de desktop e web, e o console.
