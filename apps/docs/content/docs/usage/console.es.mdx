# Incorporación en la consola

Conecta tus cuentas una sola vez en la consola y el mismo uso unificado te sigue
en la CLI `dev`, Hanzo Desktop, hanzo.app y hanzo.chat.

## Conecta tus cuentas

<Steps>
<Step>
### Abre Cuentas de IA

Inicia sesión en [console.hanzo.ai](https://console.hanzo.ai) y abre la
sección **Cuentas de IA** (`/ai-accounts`).
</Step>
<Step>
### Añade una cuenta

En la pestaña **Cuentas**, elige un proveedor — Hanzo, o cualquiera de los demás
del registro — y completa el flujo guiado de conexión de cuenta. Reutiliza tu
inicio de sesión existente (OAuth, sesión del navegador o clave de API); no se
almacenan contraseñas.
</Step>
<Step>
### Repite con cada cuenta

Vincula tantas cuentas como quieras, incluidas las de GPU, nube e integraciones
(pagos, comercio electrónico, marketing, analítica). Cada cuenta conectada
aparece en el panel unificado.
</Step>
</Steps>

## Qué muestra el panel unificado

Para cada cuenta conectada, en una sola vista:

- **Límites de tasa** y tiempo hasta el reinicio de cada ventana
- **Créditos** y saldo restante
- **Gasto** hasta la fecha
- **Origen** del que se leyó cada cifra (OAuth, sesión web, CLI o token de API)

El panel lee a través del mismo núcleo [`@hanzo/usage`](/docs/usage/quickstart)
que usan la CLI y las apps de escritorio, así que las cifras coinciden en todas
partes.
