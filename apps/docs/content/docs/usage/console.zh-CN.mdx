# 控制台入门

在控制台里连接一次账户，同一套统一用量就会跟着你走到 `dev` CLI、Hanzo Desktop、
hanzo.app 和 hanzo.chat。

## 连接你的账户

<Steps>
<Step>
### 打开 AI 账户

登录 [console.hanzo.ai](https://console.hanzo.ai)，打开 **AI 账户**
部分（`/ai-accounts`）。
</Step>
<Step>
### 添加一个账户

在 **账户** 选项卡中选择一个提供商 — Hanzo，或注册表中的任何其他提供商 —
并完成引导式账户连接流程。它会复用你已有的登录（OAuth、浏览器会话或 API 密钥）；
不存储密码。
</Step>
<Step>
### 对每个账户重复

连接任意多个账户，包括 GPU、云和集成提供商（支付、电商、营销、分析）。每个已连接
的账户都会出现在统一仪表板中。
</Step>
</Steps>

## 统一仪表板显示什么

对每个已连接的账户，在同一个视图里：

- 每个窗口的**速率限制**和距离重置的时间
- **额度**和剩余余额
- 至今的**支出**
- 每个数字读取自的**来源**（OAuth、网页会话、CLI 或 API 令牌）

仪表板通过 CLI 和桌面应用所用的同一个 [`@hanzo/usage`](/docs/usage/quickstart)
核心读取，因此数字在各处都一致。
