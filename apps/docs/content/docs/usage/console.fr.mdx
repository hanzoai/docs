# Intégration à la console

Connectez vos comptes une seule fois dans la console, et le même usage unifié
vous suit dans la CLI `dev`, Hanzo Desktop, hanzo.app et hanzo.chat.

## Connectez vos comptes

<Steps>
<Step>
### Ouvrez Comptes d'IA

Connectez-vous à [console.hanzo.ai](https://console.hanzo.ai) et ouvrez la
section **Comptes d'IA** (`/ai-accounts`).
</Step>
<Step>
### Ajoutez un compte

Dans l'onglet **Comptes**, choisissez un fournisseur — Hanzo, ou n'importe quel
autre du registre — et terminez le parcours guidé de connexion de compte. Il
réutilise votre connexion existante (OAuth, session du navigateur ou clé d'API) ;
aucun mot de passe n'est stocké.
</Step>
<Step>
### Répétez pour chaque compte

Liez autant de comptes que vous le souhaitez, y compris GPU, cloud et
intégrations (paiements, commerce, marketing, analytique). Chaque compte
connecté apparaît dans le tableau de bord unifié.
</Step>
</Steps>

## Ce que montre le tableau de bord unifié

Pour chaque compte connecté, dans une seule vue :

- Les **limites de débit** et le délai avant réinitialisation de chaque fenêtre
- Les **crédits** et le solde restant
- Les **dépenses** à ce jour
- La **source** de lecture de chaque chiffre (OAuth, session web, CLI ou jeton d'API)

Le tableau de bord lit via le même noyau [`@hanzo/usage`](/docs/usage/quickstart)
que la CLI et les applications de bureau, donc les chiffres correspondent partout.
