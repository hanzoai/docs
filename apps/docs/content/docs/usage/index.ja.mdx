# Hanzo の利用状況

**Hanzo の利用状況**は、普遍的な AI コネクターであり利用面です。AI プロバイダーの
アカウントを一度結び、統合された利用状況 — レート制限、リセット、クレジット、
支出 — を、Hanzo が動くあらゆる場所で見られます。`dev` CLI、Hanzo Desktop、
hanzo.app、hanzo.chat、そして [console.hanzo.ai](https://console.hanzo.ai) です。

## 筋書き

1. **一度つなぐ。** Hanzo と、すでに支払っている他の AI プロバイダー — レジストリは
   拡張できます — に加え、GPU、クラウド、連携アカウント（決済、電子商取引、
   マーケティング、分析）を、すでにあるログインで結びます。パスワードは保存しません。
2. **統合された利用状況を見る。** すべてのアカウントを一つの画面で。上限、リセット、
   クレジット、支出が、Hanzo のあらゆる画面に最初からあります。
3. **組織を加える。** 任意で、検証済みログインを組織全体に共有し、AI の利用を
   Hanzo のバックエンド経由でルーティングすると、包括的なビュー、分析、メンバー
   ごとの報告が得られます。ルーティングされた利用には 1% の手数料がかかります。
4. **オープンソースの AI 開発者に支払う。** Hanzo は AI ネイティブなクラウドで、
   自分が動いているオープンソースの AI エコシステムへ支出を戻すように設計されています。

## 仕組み

エンジンは [`@hanzo/usage`](/docs/usage/quickstart) です。画面を持たない
TypeScript コアで、MIT ライセンスです。各プロバイダーは、取得戦略の順序付き
パイプライン（`oauth` → `web` → `cli` → `apiToken` → `localProbe`）を持つ記述子で、
既存のログイン — CLI の OAuth トークンファイル、ブラウザーセッション、API キー —
を再利用します。戦略は優先順にフォールバックし、パスワードを尋ねることはありません。
同じコアが macOS のメニューバーアプリ、CLI、デスクトップとウェブのアプリ、そして
コンソールを動かします。
