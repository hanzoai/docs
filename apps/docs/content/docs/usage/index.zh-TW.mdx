# Hanzo 用量

**Hanzo 用量**是通用的 AI 連接器與用量平面。把 AI 供應商帳戶連接一次，然後在
Hanzo 執行的每一處查看統一用量 — 速率限制、重設、額度與支出：`dev` CLI、
Hanzo Desktop、hanzo.app、hanzo.chat，以及
[console.hanzo.ai](https://console.hanzo.ai)。

## 故事

1. **連接一次。** 連接 Hanzo，以及你已經在付費的其他 AI 供應商 — 登錄表可以擴充 —
   再加上 GPU、雲端與整合帳戶（付款、電商、行銷、分析），使用你既有的登入。不儲存密碼。
2. **查看統一用量。** 每個帳戶一個檢視：限額、重設、額度與支出，原生存在於 Hanzo
   的每一個表面。
3. **加入你的組織。** 可以選擇在整個組織內共用已驗證的登入，並把 AI 用量經由 Hanzo
   的後端路由，以取得完整檢視、分析與依成員報告。被路由的用量收取 1% 的費用。
4. **向開源 AI 開發者付費。** Hanzo 是為 AI 而生的雲端，設計目的是把支出送回它所執行
   其上的開源 AI 生態。

## 運作方式

引擎是 [`@hanzo/usage`](/docs/usage/quickstart) — 一個無介面的 TypeScript 核心，
採用 MIT 授權。每個供應商是一個描述元，帶有有序的取得策略管線
（`oauth` → `web` → `cli` → `apiToken` → `localProbe`），沿用你既有的登入 —
CLI 的 OAuth 權杖檔案、瀏覽器工作階段、API 金鑰。策略依優先順序回退，而且從不索取密碼。
同一個核心驅動 macOS 選單列應用程式、CLI、桌面與網頁應用程式，以及主控台。
