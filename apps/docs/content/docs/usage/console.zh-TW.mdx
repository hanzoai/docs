# 主控台入門

在主控台裡連接一次帳戶，同一套統一用量就會跟著你走到 `dev` CLI、Hanzo Desktop、
hanzo.app 與 hanzo.chat。

## 連接你的帳戶

<Steps>
<Step>
### 開啟 AI 帳戶

登入 [console.hanzo.ai](https://console.hanzo.ai)，開啟 **AI 帳戶**
區段（`/ai-accounts`）。
</Step>
<Step>
### 新增一個帳戶

在 **帳戶** 索引標籤中選擇一個供應商 — Hanzo，或登錄表中的任何其他供應商 —
並完成引導式帳戶連接流程。它會沿用你既有的登入（OAuth、瀏覽器工作階段或 API 金鑰）；
不儲存密碼。
</Step>
<Step>
### 對每個帳戶重複

連接任意多個帳戶，包括 GPU、雲端與整合供應商（付款、電商、行銷、分析）。每個已連接
的帳戶都會出現在統一儀表板中。
</Step>
</Steps>

## 統一儀表板顯示什麼

對每個已連接的帳戶，在同一個檢視裡：

- 每個視窗的**速率限制**與距離重設的時間
- **額度**與剩餘餘額
- 至今的**支出**
- 每個數字讀取自的**來源**（OAuth、網頁工作階段、CLI 或 API 權杖）

儀表板透過 CLI 與桌面應用程式所用的同一個 [`@hanzo/usage`](/docs/usage/quickstart)
核心讀取，因此數字在各處都一致。
