# Uso de Hanzo

**Uso de Hanzo** es el conector universal de IA y el plano de uso. Vincula tus
cuentas de proveedores de IA una sola vez y luego consulta el uso unificado —
límites de tasa, restablecimientos, créditos y gasto — en todos los lugares
donde corre Hanzo: la CLI `dev`, Hanzo Desktop, hanzo.app, hanzo.chat y
[console.hanzo.ai](https://console.hanzo.ai).

## La historia

1. **Conecta una vez.** Vincula Hanzo, los demás proveedores de IA que ya pagas
   — el registro es extensible — además de cuentas de GPU, nube e integraciones
   (pagos, comercio electrónico, marketing, analítica), con los inicios de
   sesión que ya tienes. No se almacenan contraseñas.
2. **Consulta el uso unificado.** Una vista de cada cuenta: límites,
   restablecimientos, créditos y gasto, nativa en cada superficie de Hanzo.
3. **Añade tu organización.** Opcionalmente comparte inicios de sesión
   verificados en toda la organización y enruta el uso de IA a través del
   backend de Hanzo para obtener una vista integral, analítica e informes por
   miembro. Se aplica una tarifa del 1 % al uso enrutado.
4. **Paga a los desarrolladores de IA de código abierto.** Hanzo es una nube
   nativa de IA diseñada para devolver el gasto al ecosistema de IA de código
   abierto sobre el que se ejecuta.

## Cómo funciona

El motor es [`@hanzo/usage`](/docs/usage/quickstart): un núcleo TypeScript sin
interfaz, con licencia MIT. Cada proveedor es un descriptor con una canalización
ordenada de estrategias de obtención (`oauth` → `web` → `cli` → `apiToken` →
`localProbe`) que reutilizan tus inicios de sesión existentes: archivos de
tokens OAuth de la CLI, sesiones del navegador y claves de API. Las estrategias
recurren en orden de prioridad y nunca piden contraseñas. El mismo núcleo
impulsa la app de la barra de menús de macOS, la CLI, las apps de escritorio y
web, y la consola.
