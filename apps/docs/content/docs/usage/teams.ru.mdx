# Команды и организации

Индивидуальный учёт использования бесплатен и выполняется локально. Добавьте
организацию, чтобы совместно пользоваться доступом и получить полную
маршрутизируемую картину использования ИИ по всей команде.

## Общий доступ к входам

Пригласите организацию и откройте проверенные входы к поставщикам для всей
организации. Участники пользуются общими учётными записями и никогда не видят
исходные учётные данные: подключения проверяются один раз и становятся
доступны команде в пределах вашей организации.

## Проверенная маршрутизация через Hanzo

При желании направляйте использование ИИ через серверную часть Hanzo.
Маршрутизируемый трафик измеряется централизованно и даёт организации:

- **Полную картину** каждого запроса по всем участникам и поставщикам
- **Аналитику** расходов, лимитов и загрузки во времени
- **Отчёты по участникам**: использование в разрезе человека и учётной записи

## Цены

Индивидуальный учёт использования бесплатен. Маршрутизация через Hanzo
облагается **комиссией 1% с маршрутизируемого использования** — это единственная
плата за общеорганизационный слой маршрутизации, общего доступа и аналитики.
Расходы поставщиков по-прежнему выставляет каждый поставщик.

## Зачем направлять трафик через Hanzo

Hanzo — универсальный коннектор и слой управления интеграциями для ИИ, а также
облако, изначально созданное для ИИ и для выплат разработчикам ИИ с открытым
исходным кодом. Маршрутизация использования через Hanzo финансирует эту
экосистему и одновременно даёт организации единую проверенную систему учёта
расходов на ИИ.
