# कंसोल ऑनबोर्डिंग

कंसोल में अपने खाते एक बार जोड़ें, और वही एकीकृत उपयोग `dev` CLI, Hanzo Desktop,
hanzo.app और hanzo.chat पर आपके साथ रहता है।

## अपने खाते जोड़ें

<Steps>
<Step>
### AI खाते खोलें

[console.hanzo.ai](https://console.hanzo.ai) पर साइन इन करें और
**AI खाते** अनुभाग (`/ai-accounts`) खोलें।
</Step>
<Step>
### एक खाता जोड़ें

**खाते** टैब पर एक प्रदाता चुनें — Hanzo, या रजिस्ट्री में से कोई अन्य — और
निर्देशित खाता-जोड़ने का प्रवाह पूरा करें। यह आपके मौजूदा लॉगिन का पुन: उपयोग
करता है (OAuth, ब्राउज़र सत्र, या API कुंजी); कोई पासवर्ड संग्रहीत नहीं होता।
</Step>
<Step>
### हर खाते के लिए दोहराएँ

जितने चाहें उतने खाते जोड़ें, जिनमें GPU, क्लाउड और इंटीग्रेशन प्रदाता शामिल हैं
(भुगतान, ई-कॉमर्स, मार्केटिंग, विश्लेषण)। हर जुड़ा खाता एकीकृत डैशबोर्ड में दिखता है।
</Step>
</Steps>

## एकीकृत डैशबोर्ड क्या दिखाता है

हर जुड़े खाते के लिए, एक ही दृश्य में:

- हर विंडो के **दर सीमा** और रीसेट तक का समय
- **क्रेडिट** और शेष राशि
- आज तक का **खर्च**
- **स्रोत** जिससे प्रत्येक आँकड़ा पढ़ा गया (OAuth, वेब सत्र, CLI, या API टोकन)

डैशबोर्ड उसी [`@hanzo/usage`](/docs/usage/quickstart) कोर के माध्यम से पढ़ता है
जिसका उपयोग CLI और डेस्कटॉप ऐप करते हैं, इसलिए संख्याएँ हर जगह मेल खाती हैं।
