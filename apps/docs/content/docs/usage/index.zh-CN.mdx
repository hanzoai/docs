# Hanzo 用量

**Hanzo 用量**是通用的 AI 连接器与用量平面。把 AI 提供商账户连接一次，然后在
Hanzo 运行的每一处查看统一用量 — 速率限制、重置、额度和支出：`dev` CLI、
Hanzo Desktop、hanzo.app、hanzo.chat，以及
[console.hanzo.ai](https://console.hanzo.ai)。

## 故事

1. **连接一次。** 连接 Hanzo，以及你已经在付费的其他 AI 提供商 — 注册表可以扩展 —
   再加上 GPU、云和集成账户（支付、电商、营销、分析），使用你已有的登录。不存储密码。
2. **查看统一用量。** 每个账户一个视图：限额、重置、额度和支出，原生存在于 Hanzo
   的每一个表面。
3. **加入你的组织。** 可以选择在整个组织内共享已验证的登录，并把 AI 用量经由 Hanzo
   的后端路由，以获得全面视图、分析和按成员报告。被路由的用量收取 1% 的费用。
4. **向开源 AI 开发者付费。** Hanzo 是为 AI 而生的云，设计目的是把支出送回它所运行
   其上的开源 AI 生态。

## 工作方式

引擎是 [`@hanzo/usage`](/docs/usage/quickstart) — 一个无界面的 TypeScript 核心，
采用 MIT 许可。每个提供商是一个描述符，带有有序的获取策略流水线
（`oauth` → `web` → `cli` → `apiToken` → `localProbe`），复用你已有的登录 —
CLI 的 OAuth 令牌文件、浏览器会话、API 密钥。策略按优先级回退，并且从不索要密码。
同一个核心驱动 macOS 菜单栏应用、CLI、桌面与网页应用，以及控制台。
