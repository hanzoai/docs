# 콘솔 온보딩

콘솔에서 계정을 한 번 연결하면 같은 통합 사용량이 `dev` CLI, Hanzo Desktop,
hanzo.app, hanzo.chat까지 따라옵니다.

## 계정 연결

<Steps>
<Step>
### AI 계정 열기

[console.hanzo.ai](https://console.hanzo.ai)에 로그인하고 **AI 계정**
(`/ai-accounts`) 섹션을 엽니다.
</Step>
<Step>
### 계정 추가

**계정** 탭에서 공급자를 고릅니다. Hanzo이거나 레지스트리의 다른 공급자여도
됩니다. 안내형 계정 연결 흐름을 마칩니다. 이미 있는 로그인(OAuth, 브라우저
세션 또는 API 키)을 다시 쓰며, 비밀번호는 저장하지 않습니다.
</Step>
<Step>
### 모든 계정에 반복

GPU, 클라우드, 통합 공급자(결제, 전자상거래, 마케팅, 분석)를 포함해 원하는 만큼
계정을 연결합니다. 연결된 각 계정은 통합 대시보드에 나타납니다.
</Step>
</Steps>

## 통합 대시보드가 보여주는 것

연결된 각 계정에 대해, 한 화면에서:

- 각 구간의 **속도 제한**과 초기화까지 남은 시간
- **크레딧**과 남은 잔액
- 현재까지의 **지출**
- 각 수치가 읽힌 **출처**(OAuth, 웹 세션, CLI 또는 API 토큰)

대시보드는 CLI와 데스크톱 앱이 쓰는 것과 같은 [`@hanzo/usage`](/docs/usage/quickstart)
코어를 통해 읽으므로, 숫자는 어디서나 일치합니다.
