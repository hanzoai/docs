# Использование Hanzo

**Использование Hanzo** — универсальный коннектор ИИ и плоскость использования.
Один раз привяжите учётные записи поставщиков ИИ, а затем смотрите единое
использование — лимиты частоты, сбросы, кредиты и расходы — везде, где работает
Hanzo: в CLI `dev`, Hanzo Desktop, hanzo.app, hanzo.chat и
[console.hanzo.ai](https://console.hanzo.ai).

## Сюжет

1. **Подключите один раз.** Привяжите Hanzo, других поставщиков ИИ, которым вы
   уже платите — реестр расширяем — плюс учётные записи GPU, облака и интеграций
   (платежи, электронная коммерция, маркетинг, аналитика), используя входы,
   которые у вас уже есть. Пароли не сохраняются.
2. **Смотрите единое использование.** Одно представление по каждой учётной
   записи: лимиты, сбросы, кредиты и расходы, встроенное в каждую поверхность
   Hanzo.
3. **Добавьте организацию.** По желанию откройте проверенные входы на всю
   организацию и направьте использование ИИ через серверную часть Hanzo, чтобы
   получить полную картину, аналитику и отчёты по участникам. На
   маршрутизируемое использование начисляется комиссия 1%.
4. **Платите разработчикам ИИ с открытым кодом.** Hanzo — облако, изначально
   созданное для ИИ и устроенное так, чтобы возвращать расходы в экосистему
   открытого ИИ, на которой оно работает.

## Как это устроено

Движок — [`@hanzo/usage`](/docs/usage/quickstart), ядро на TypeScript без
интерфейса, под лицензией MIT. Каждый поставщик — это описатель с упорядоченным
конвейером стратегий чтения (`oauth` → `web` → `cli` → `apiToken` →
`localProbe`), которые повторно используют ваши существующие входы: файлы
токенов OAuth CLI, сеансы браузера, ключи API. Стратегии отступают по порядку
приоритета и никогда не просят пароль. То же ядро приводит в движение приложение
строки меню macOS, CLI, настольные и веб-приложения и консоль.
