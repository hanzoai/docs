# Utilizzo Hanzo

**Utilizzo Hanzo** è il connettore universale di IA e il piano di utilizzo.
Collega una sola volta gli account dei fornitori di IA, poi consulta l'utilizzo
unificato — limiti di frequenza, ripristini, crediti e spesa — ovunque giri
Hanzo: la CLI `dev`, Hanzo Desktop, hanzo.app, hanzo.chat e
[console.hanzo.ai](https://console.hanzo.ai).

## La storia

1. **Connetti una volta.** Collega Hanzo, gli altri fornitori di IA che già
   paghi — il registro è estendibile — più gli account GPU, cloud e di
   integrazione (pagamenti, commercio elettronico, marketing, analitica), con
   gli accessi che hai già. Nessuna password viene memorizzata.
2. **Vedi l'utilizzo unificato.** Una vista su ogni account: limiti, ripristini,
   crediti e spesa, nativa su ogni superficie Hanzo.
3. **Aggiungi la tua organizzazione.** Condividi facoltativamente gli accessi
   verificati in tutta l'organizzazione e instrada l'uso dell'IA attraverso il
   backend di Hanzo per una vista completa, analisi e report per membro. All'uso
   instradato si applica una commissione dell'1%.
4. **Paga gli sviluppatori di IA open source.** Hanzo è un cloud nativo dell'IA
   progettato per restituire la spesa all'ecosistema di IA open source su cui
   gira.

## Come funziona

Il motore è [`@hanzo/usage`](/docs/usage/quickstart) — un nucleo TypeScript senza
interfaccia, con licenza MIT. Ogni fornitore è un descrittore con una pipeline
ordinata di strategie di lettura (`oauth` → `web` → `cli` → `apiToken` →
`localProbe`) che riusano gli accessi esistenti — file di token OAuth della CLI,
sessioni del browser, chiavi API. Le strategie ripiegano in ordine di priorità
e non chiedono mai password. Lo stesso nucleo muove l'app della barra dei menu
di macOS, la CLI, le app desktop e web, e la console.
