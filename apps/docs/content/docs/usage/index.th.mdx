# การใช้งาน Hanzo

**การใช้งาน Hanzo** คือตัวเชื่อม AI สากลและระนาบการใช้งาน เชื่อมบัญชีผู้ให้บริการ
AI ครั้งเดียว แล้วดูการใช้งานแบบรวม — ขีดจำกัดอัตรา การรีเซ็ต เครดิต และค่าใช้จ่าย
— ทุกที่ที่ Hanzo ทำงาน: CLI `dev`, Hanzo Desktop, hanzo.app, hanzo.chat และ
[console.hanzo.ai](https://console.hanzo.ai)

## เรื่องราว

1. **เชื่อมต่อครั้งเดียว** เชื่อม Hanzo ผู้ให้บริการ AI อื่นที่คุณจ่ายอยู่แล้ว —
   รีจิสทรีขยายได้ — รวมถึงบัญชี GPU, คลาวด์ และการเชื่อมต่อ (การชำระเงิน,
   อีคอมเมิร์ซ, การตลาด, การวิเคราะห์) โดยใช้การเข้าสู่ระบบที่คุณมีอยู่แล้ว
   ไม่มีการเก็บรหัสผ่าน
2. **ดูการใช้งานแบบรวม** มุมมองเดียวทุกบัญชี: ขีดจำกัด การรีเซ็ต เครดิต
   และค่าใช้จ่าย เป็นของแท้ในทุกพื้นผิวของ Hanzo
3. **เพิ่มองค์กรของคุณ** เลือกแชร์การเข้าสู่ระบบที่ยืนยันแล้วทั่วทั้งองค์กร และ
   กำหนดเส้นทางการใช้งาน AI ผ่านแบ็กเอนด์ของ Hanzo เพื่อมุมมองที่ครอบคลุม
   การวิเคราะห์ และรายงานรายสมาชิก มีค่าธรรมเนียม 1% สำหรับการใช้งานที่ถูกกำหนดเส้นทาง
4. **จ่ายให้นักพัฒนา AI โอเพนซอร์ส** Hanzo เป็นคลาวด์ที่เกิดมาเพื่อ AI ซึ่งออกแบบ
   ให้ส่งค่าใช้จ่ายกลับสู่ระบบนิเวศ AI โอเพนซอร์สที่มันทำงานอยู่

## มันทำงานอย่างไร

เครื่องยนต์คือ [`@hanzo/usage`](/docs/usage/quickstart) — แกน TypeScript ที่ไม่มี
ส่วนติดต่อผู้ใช้ ภายใต้สัญญาอนุญาต MIT ผู้ให้บริการแต่ละรายเป็นตัวอธิบายที่มี
ลำดับกลยุทธ์การดึง (`oauth` → `web` → `cli` → `apiToken` → `localProbe`) ซึ่งใช้
การเข้าสู่ระบบที่มีอยู่แล้วซ้ำ — ไฟล์โทเคน OAuth ของ CLI, เซสชันเบราว์เซอร์, คีย์ API
กลยุทธ์ถอยตามลำดับความสำคัญ และไม่เคยขอรหัสผ่าน แกนเดียวกันขับแอปแถบเมนู macOS,
CLI, แอปเดสก์ท็อปและเว็บ และคอนโซล
