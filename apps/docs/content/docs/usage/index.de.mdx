# Hanzo-Nutzung

**Hanzo-Nutzung** ist der universelle KI-Konnektor und die Nutzungsebene.
Verknüpfen Sie Ihre KI-Anbieterkonten einmal und sehen Sie danach die
einheitliche Nutzung — Ratenlimits, Rücksetzungen, Guthaben und Ausgaben —
überall, wo Hanzo läuft: in der `dev`-CLI, in Hanzo Desktop, auf hanzo.app,
hanzo.chat und [console.hanzo.ai](https://console.hanzo.ai).

## Die Geschichte

1. **Einmal verbinden.** Verknüpfen Sie Hanzo, die anderen KI-Anbieter, die Sie
   bereits bezahlen — das Verzeichnis ist erweiterbar — sowie GPU-, Cloud- und
   Integrationskonten (Zahlungen, E-Commerce, Marketing, Analytik) mit den
   Anmeldungen, die Sie schon haben. Es werden keine Passwörter gespeichert.
2. **Einheitliche Nutzung sehen.** Eine Ansicht über jedes Konto: Limits,
   Rücksetzungen, Guthaben und Ausgaben, nativ auf jeder Hanzo-Oberfläche.
3. **Ihre Organisation hinzufügen.** Teilen Sie optional verifizierte
   Anmeldungen organisationsweit und leiten Sie die KI-Nutzung über das Backend
   von Hanzo, für eine umfassende Sicht, Auswertungen und Berichte pro Mitglied.
   Auf weitergeleitete Nutzung fällt eine Gebühr von 1 % an.
4. **Open-Source-KI-Entwickler bezahlen.** Hanzo ist eine KI-native Cloud, die
   Ausgaben an das Open-Source-KI-Ökosystem zurückführt, auf dem sie läuft.

## So funktioniert es

Die Engine ist [`@hanzo/usage`](/docs/usage/quickstart) — ein TypeScript-Kern
ohne Oberfläche, unter der MIT-Lizenz. Jeder Anbieter ist ein Deskriptor mit
einer geordneten Pipeline von Abrufstrategien (`oauth` → `web` → `cli` →
`apiToken` → `localProbe`), die Ihre vorhandenen Anmeldungen wiederverwenden —
OAuth-Tokendateien der CLI, Browsersitzungen, API-Schlüssel. Die Strategien
fallen in Prioritätsreihenfolge zurück und fragen nie nach Passwörtern. Derselbe
Kern treibt die macOS-Menüleisten-App, die CLI, die Desktop- und Web-Apps und
die Konsole an.
