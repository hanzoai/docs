# إعداد وحدة التحكم

اربط حساباتك مرة واحدة في وحدة التحكم، فيتبعك الاستخدام الموحّد نفسه في واجهة
`dev` CLI وHanzo Desktop وhanzo.app وhanzo.chat.

## اربط حساباتك

<Steps>
<Step>
### افتح حسابات الذكاء الاصطناعي

سجّل الدخول إلى [console.hanzo.ai](https://console.hanzo.ai) وافتح قسم
**حسابات الذكاء الاصطناعي** (`/ai-accounts`).
</Step>
<Step>
### أضف حسابًا

في علامة التبويب **الحسابات**، اختر مزوّدًا — Hanzo أو أي مزوّد آخر في السجل —
وأتمم مسار ربط الحساب الموجَّه. يعيد استخدام تسجيل دخولك الحالي (OAuth أو جلسة
المتصفح أو مفتاح API)؛ لا تُخزَّن كلمات المرور.
</Step>
<Step>
### كرّر لكل حساب

اربط ما تشاء من الحسابات، بما فيها GPU والسحابة ومزوّدو التكامل (المدفوعات
والتجارة الإلكترونية والتسويق والتحليلات). يظهر كل حساب مرتبط في اللوحة الموحّدة.
</Step>
</Steps>

## ماذا تعرض اللوحة الموحّدة

لكل حساب مرتبط، في عرض واحد:

- **حدود المعدّل** والوقت المتبقي حتى إعادة الضبط لكل نافذة
- **الأرصدة** والرصيد المتبقي
- **الإنفاق** حتى الآن
- **المصدر** الذي قُرئ منه كل رقم (OAuth أو جلسة ويب أو CLI أو رمز API)

تقرأ اللوحة عبر نواة [`@hanzo/usage`](/docs/usage/quickstart) نفسها التي تستخدمها
واجهة CLI وتطبيقات سطح المكتب، لذلك تتطابق الأرقام في كل مكان.
