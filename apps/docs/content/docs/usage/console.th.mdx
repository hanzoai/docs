# การเริ่มต้นใช้งานคอนโซล

เชื่อมต่อบัญชีของคุณครั้งเดียวในคอนโซล แล้วการใช้งานแบบรวมเดียวกันจะติดตามคุณไป
ใน CLI `dev`, Hanzo Desktop, hanzo.app และ hanzo.chat

## เชื่อมต่อบัญชีของคุณ

<Steps>
<Step>
### เปิดบัญชี AI

ลงชื่อเข้าใช้ [console.hanzo.ai](https://console.hanzo.ai) แล้วเปิดส่วน
**บัญชี AI** (`/ai-accounts`)
</Step>
<Step>
### เพิ่มบัญชี

ในแท็บ **บัญชี** เลือกผู้ให้บริการ — Hanzo หรือรายอื่นในรีจิสทรี — แล้วทำขั้นตอน
เชื่อมต่อบัญชีแบบมีคำแนะนำให้ครบ ขั้นตอนนี้ใช้การเข้าสู่ระบบที่คุณมีอยู่แล้ว
(OAuth, เซสชันเบราว์เซอร์ หรือคีย์ API) ไม่มีการเก็บรหัสผ่าน
</Step>
<Step>
### ทำซ้ำสำหรับทุกบัญชี

เชื่อมบัญชีได้มากเท่าที่ต้องการ รวมถึง GPU, คลาวด์ และผู้ให้บริการเชื่อมต่อ
(การชำระเงิน, อีคอมเมิร์ซ, การตลาด, การวิเคราะห์) ทุกบัญชีที่เชื่อมแล้วจะปรากฏ
ในแดชบอร์ดแบบรวม
</Step>
</Steps>

## แดชบอร์ดแบบรวมแสดงอะไร

สำหรับทุกบัญชีที่เชื่อมแล้ว ในมุมมองเดียว:

- **ขีดจำกัดอัตรา** และเวลาจนกว่าจะรีเซ็ตของแต่ละหน้าต่าง
- **เครดิต** และยอดคงเหลือ
- **ค่าใช้จ่าย**จนถึงปัจจุบัน
- **แหล่งที่มา**ที่อ่านตัวเลขแต่ละค่า (OAuth, เซสชันเว็บ, CLI หรือโทเคน API)

แดชบอร์ดอ่านผ่านแกน [`@hanzo/usage`](/docs/usage/quickstart) เดียวกันกับที่ CLI
และแอปเดสก์ท็อปใช้ ดังนั้นตัวเลขจึงตรงกันทุกที่
