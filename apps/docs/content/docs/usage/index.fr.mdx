# Utilisation Hanzo

**Utilisation Hanzo** est le connecteur universel d'IA et le plan d'usage.
Liez une seule fois vos comptes de fournisseurs d'IA, puis consultez l'usage
unifié — limites de débit, réinitialisations, crédits et dépenses — partout où
Hanzo s'exécute : la CLI `dev`, Hanzo Desktop, hanzo.app, hanzo.chat et
[console.hanzo.ai](https://console.hanzo.ai).

## Le récit

1. **Connectez une fois.** Liez Hanzo, les autres fournisseurs d'IA que vous
   payez déjà — le registre est extensible — ainsi que les comptes GPU, cloud
   et d'intégration (paiements, commerce, marketing, analytique), avec les
   connexions que vous avez déjà. Aucun mot de passe n'est stocké.
2. **Voyez l'usage unifié.** Une vue de chaque compte : limites,
   réinitialisations, crédits et dépenses, native sur chaque surface Hanzo.
3. **Ajoutez votre organisation.** Partagez éventuellement des connexions
   vérifiées à l'échelle de l'organisation et acheminez l'usage de l'IA via le
   backend de Hanzo pour une vue complète, des analyses et des rapports par
   membre. Des frais de 1 % s'appliquent à l'usage acheminé.
4. **Rémunérez les développeurs d'IA open source.** Hanzo est un cloud natif de
   l'IA conçu pour renvoyer les dépenses vers l'écosystème d'IA open source sur
   lequel il s'exécute.

## Comment ça marche

Le moteur est [`@hanzo/usage`](/docs/usage/quickstart) — un noyau TypeScript
sans interface, sous licence MIT. Chaque fournisseur est un descripteur avec un
pipeline ordonné de stratégies de lecture (`oauth` → `web` → `cli` → `apiToken` →
`localProbe`) qui réutilisent vos connexions existantes — fichiers de jetons
OAuth de la CLI, sessions du navigateur, clés d'API. Les stratégies se
replacent dans l'ordre de priorité et ne demandent jamais de mots de passe. Le
même noyau anime l'app de la barre de menus macOS, la CLI, les apps de bureau
et web, et la console.
