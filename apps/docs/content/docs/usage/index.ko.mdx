# Hanzo 사용량

**Hanzo 사용량**은 범용 AI 커넥터이자 사용량 평면입니다. AI 공급자 계정을 한 번
연결한 뒤, 통합 사용량 — 속도 제한, 초기화, 크레딧, 지출 — 을 Hanzo가 실행되는
모든 곳에서 봅니다. `dev` CLI, Hanzo Desktop, hanzo.app, hanzo.chat, 그리고
[console.hanzo.ai](https://console.hanzo.ai)입니다.

## 이야기

1. **한 번 연결합니다.** Hanzo와 이미 비용을 내는 다른 AI 공급자 — 레지스트리는
   확장할 수 있습니다 — 그리고 GPU, 클라우드, 통합 계정(결제, 전자상거래, 마케팅,
   분석)을 이미 있는 로그인으로 연결합니다. 비밀번호는 저장하지 않습니다.
2. **통합 사용량을 봅니다.** 모든 계정을 한 화면에서. 한도, 초기화, 크레딧, 지출이
   Hanzo의 모든 표면에 기본으로 있습니다.
3. **조직을 더합니다.** 선택적으로 검증된 로그인을 조직 전체에 공유하고, AI
   사용량을 Hanzo 백엔드를 통해 라우팅하면 포괄적인 보기, 분석, 구성원별 보고를
   얻습니다. 라우팅된 사용량에는 1% 수수료가 붙습니다.
4. **오픈 소스 AI 개발자에게 지급합니다.** Hanzo는 AI 네이티브 클라우드이며,
   자신이 올라간 오픈 소스 AI 생태계로 지출을 되돌리도록 설계되었습니다.

## 동작 방식

엔진은 [`@hanzo/usage`](/docs/usage/quickstart)입니다. 화면이 없는 TypeScript
코어이며 MIT 라이선스입니다. 각 공급자는 가져오기 전략의 순서 있는 파이프라인
(`oauth` → `web` → `cli` → `apiToken` → `localProbe`)을 가진 기술자이며, 기존
로그인 — CLI OAuth 토큰 파일, 브라우저 세션, API 키 — 을 다시 씁니다. 전략은
우선순위대로 물러서며 비밀번호를 묻지 않습니다. 같은 코어가 macOS 메뉴 막대 앱,
CLI, 데스크톱과 웹 앱, 그리고 콘솔을 움직입니다.
