**بعد هذه الصفحة يمكنك تعريف وكيل، ومشاهدته يعمل، وتوجيهه أثناء
تشغيله.**

## اسمان

**الوكيل** تعريف: نموذج، وتوجيه نظام، ومجموعة من أسماء الأدوات.
**الجلسة** تشغيل حي — الصف الذي تعلّق عليه كل واجهة نشاطها،
سواء كانت الواجهة CLI أو وحدة التحكم أو الدردشة أو بوتًا.

```bash
curl -X POST https://api.hanzo.ai/v1/agents \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"triage","model":"zen-1","instructions":"Triage inbound issues.","tools":["search"]}'
```

```bash
hanzo agents list
```

الاسم فريد في مؤسستك ويطابق
`^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$`. النموذج الذي تسمّيه يُفحص مقابل
فهرس البوابة المخدوم **عند التعريف** — الخطأ المطبعي يُرفض الآن
لا عند الثالثة فجرًا في أول تشغيل. الوكيل الذي يعمل باستمرار يجب أن يحمل
جدول cron من خمسة حقول، ويُحتسب ضمن سقف لكل مؤسسة.

## التدفق الواحد شجرة واحدة

```bash
curl -X POST https://api.hanzo.ai/v1/agents/sessions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"agent":"triage"}'
```

الجلسة التي تحمل `parentSessionId` تصير **وكيلًا فرعيًا** لتلك الجلسة
وترث جذرها. لذا تفرّع عشرة وكلاء فرعيين ليس عشر تشغيلات غير مترابطة —
بل شجرة واحدة، و`/v1/agents/sessions/{id}/tree` يُرجع الرسم كله في
قراءة واحدة، وكل عقدة تحمل عدد أحداثها.

السرد يُرجع **جلسات الجذر فقط** ما لم تطلب النزول. الحالة واحدة
من `running` أو `paused` أو `done` أو `error`.

## توجيه جلسة قيد التشغيل

أربعة أوامر، كلها تحت `/v1/agents/sessions/{id}`: `message` و`pause`
و`resume` و`stop`.

<Callout>
**الأمر نية، لا تغيير حالة.** لا شيء في ذلك الاستدعاء يكتب
حالة الجلسة. `200` يعني أن الأمر سُجّل بشكل دائم وسُلّم —
والوكيل يقرر متى يتصرف بناءً عليه.
</Callout>

هذا ما يجعل التوجيه يعمل عبر الآلات. جلسة `hanzo code` بدأت
على حاسوبك المحمول تستهلك الأوامر التي نشرتها لوحة المعلومات، باستطلاع
`/v1/agents/sessions/{id}/control` — أوامر أحدث من مؤشر، الأقدم أولًا،
ولا تُعاد تسليمها بعد تطبيقها.

رفضان يستحقان المعرفة: الجلسة **المنتهية** ترفض كل أمر بـ
`409`، والمعرّف الذي يخص مستأجرًا آخر هو `404` — لا مؤسسة توجّه
وكلاء أخرى، والـ 404 لا يؤكّد أن المعرّف موجود.

`stop` هو الاستثناء الذي يلغي فعلًا بدل أن يشير.

## المشاهدة

```
GET /v1/agents/sessions/stream
```

أحداث يرسلها الخادم: إطارات `session` وإطارات `event`، تُضيَّق بـ `?root=`.
النطاق هو المؤسسة ويفشل مغلقًا — الناقل يصفّي حسب المستأجر قبل التوزيع. المشترك
الذي يتأخر أكثر من 256 إطارًا يُسقط بدل أن يُسمح له بإيقاف
التدفق، ويصل `: ping` كل 25 ثانية حتى تظهر الوصلة الميتة.

الأدوار تُسجَّل عند `/v1/agents/sessions/{id}/events` — رسالة، استدعاء أداة،
توليد، سجل، حالة، تحكم — وكل واحد يجيب بـ `seq` رتيب. لا يضيع
شيء، فيمكن إعادة تشغيل الجولة بعد انتهائها.

## ما يصل إليه الوكيل

- **الأدوات** — [الأدوات](/docs/openapi/tools) هي مستوى الأدوات لكل مستأجر الذي
  يستدعي الوكيل عبره.
- **الحوسبة** — إيجار [صندوق رمل](/docs/concepts/sandboxes).
- **المعرفة** — [الذاكرة](/docs/concepts/memory).
- **النماذج** — [ai](/docs/openapi/ai)، مستوى الاستدلال.
