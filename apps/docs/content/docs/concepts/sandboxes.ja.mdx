## 一つの原基

サンドボックスは、実行時の境界の下にあるポッドだ。道具鎖はすでに中にあり、
自分のファイルシステムを持ち、それを終わらせる **リース** がある。オブジェクトは一つ、寿命は
一つ — 使い捨てる Python の実行と、数時間のコーディングセッションは、境界が違うだけの
同じものだ。

```bash
curl -X POST https://api.hanzo.ai/v1/sandbox/lease \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"class":"exec"}'
```

```bash
hanzo sandboxes list
```

ほかの操作はすべて、その呼び出しが返すサンドボックスに対して働く。

## 四つの級

閉じた集合だ。空は `exec` を意味する。

| 級 | 何か | 作業ディレクトリ | 生きる期間 |
|---|---|---|---|
| `exec` | 使い捨て。何も残さない | `/mnt/data` | 秒から分 |
| `dev` | コーディング。プロジェクトのディスクが付く | `/work` | 時間 |
| `desktop` | `dev` に画面を足したもの | `/work` | 時間 |
| `android` | `desktop` に、その画面上の電話を足したもの | `/work` | 時間 |

`exec` 以外の級はすべてプロジェクトを **要する**。そしてプロジェクトは **同時に一つの生きた
サンドボックス** しか持たない — すでに一つあるプロジェクトへの二度目のリースは、
黙って二台目の機械を渡すのではなく、名前で拒否される。

実行時を *頼む* ことはできる（`gvisor` か `kata-fc`）。決めるのは所有者で、
答えは実際に何を得たか教える。

## 終わらせる動詞は二つで、違いは大事だ

<Callout>
**`stop` は仕事を終わらせる。`end` は資源を終わらせる。** おかしくなった実行は
`stop` のあとでも読める。だから動詞が二つある。
</Callout>

その先では `ttlSec` がリースを限り、刈り取り役が毎分走る。期限切れのリースを終わらせ、
一時間を超えて遊んでいるサンドボックスを眠らせる。**プールは
ない** — サンドボックスはリースのために作られ、終わりに消される。名前は
二度と使われないので、古い id が他人の機械に届くことはない。

## ポッドにできること

あなたにできることではない。資格情報はポッドに届かない。リースには一つ、
短命のトークンが渡される。あなたの身元とのトークン交換で得て、
`hanzo-sandbox` クライアントとして振る舞い、リースと一緒に切れ、更新トークンはない。
ポッドは自分のクラスタ資格情報を持たない。

隔離は物理的だ。サンドボックスのストアは組織につき一つのファイルだ。

## exec: セッション *が* サンドボックスだ

[exec](/docs/openapi/exec) は一回の呼び出しでプログラム全体を走らせる。言語は十三 —
`py`、`js`、`ts`、`bash`、`r`、`php`、`go`、`rs`、`c`、`cpp`、
`java`、`d`、`f90`。

```bash
curl -X POST https://api.hanzo.ai/v1/exec \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"language":"py","code":"print(6*7)"}'
```

自分のストアも自分の寿命も持たない — 返すセッション id *が*
サンドボックス id だ。ゼロでない終了はエラー状態ではなく、**stderr 付きの `200`** だ。
呼び出しは成功し、プログラムは失敗した。それは別の事実だ。実行のあいだファイルシステムを
保つには、同じ `session_id` を再び渡す。

## エージェントと出会う場所

`POST /v1/sandbox/run` は名前付きセッションへ語り、その出力は
そのセッションの生きたログへ追記される — [エージェント](/docs/concepts/agents) のセッションストリームが
すでに見ているログだ。それが両者の継ぎ目だ。サンドボックスが仕事をし、
セッションがその記録だ。
