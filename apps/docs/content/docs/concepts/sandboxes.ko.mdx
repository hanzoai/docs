**이 페이지 다음에는 신뢰할 수 없는 코드를 돌리고, 그것이 돈을 그만 쓰는 순간을 정확히 알 수 있다.**

## 하나의 원형

샌드박스는 실행 시간 경계 아래의 파드다. 도구 사슬이 이미 안에 있고,
자기 파일 시스템이 있으며, 그것을 끝내는 **임대**가 있다. 객체는 하나, 수명은
하나다 — 일회용 파이썬 실행과 몇 시간의 코딩 세션은 경계만 다른
같은 것이다.

```bash
curl -X POST https://api.hanzo.ai/v1/sandbox/lease \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"class":"exec"}'
```

```bash
hanzo sandboxes list
```

다른 모든 연산은 그 호출이 돌려주는 샌드박스에 작용한다.

## 네 등급

닫힌 집합이다. 비어 있으면 `exec`다.

| 등급 | 무엇인가 | 작업 디렉터리 | 사는 기간 |
|---|---|---|---|
| `exec` | 일회용. 아무것도 남기지 않는다 | `/mnt/data` | 초에서 분 |
| `dev` | 코딩. 프로젝트 디스크가 붙는다 | `/work` | 시간 |
| `desktop` | `dev`에 화면을 더한 것 | `/work` | 시간 |
| `android` | `desktop`에 그 화면 위의 전화를 더한 것 | `/work` | 시간 |

`exec`를 뺀 모든 등급은 프로젝트를 **요구**한다. 그리고 프로젝트는 **한 번에 살아있는
샌드박스 하나**만 가진다 — 이미 하나 있는 프로젝트에 대한 두 번째 임대는
말없이 두 번째 기계를 주지 않고, 이름으로 거절된다.

실행 시간을 *청할* 수는 있다 (`gvisor` 또는 `kata-fc`). 정하는 것은 소유자고,
답은 실제로 무엇을 받았는지 말한다.

## 끝내는 동사는 둘이고, 차이가 중요하다

<Callout>
**`stop`은 일을 끝낸다. `end`는 자원을 끝낸다.** 잘못된 실행은
`stop` 뒤에도 읽을 수 있다. 동사가 둘인 이유가 전부 그것이다.
</Callout>

그 너머로 `ttlSec`가 임대를 한정하고, 거두는 이가 매분 돈다. 만료된 임대를 끝내고,
한 시간 넘게 놀고 있는 샌드박스를 재운다. **풀은
없다** — 샌드박스는 임대를 위해 만들어지고 끝에 지워진다. 이름은
다시 쓰이지 않으므로, 낡은 id가 남의 기계에 닿는 일은 없다.

## 파드가 할 수 있는 것

네가 할 수 있는 것이 아니다. 자격 증명은 파드에 닿지 않는다. 임대에는 하나,
짧은 수명의 토큰이 건네진다. 네 신원과 토큰을 교환해 얻고,
`hanzo-sandbox` 클라이언트로 행동하며, 임대와 함께 만료되고, 갱신 토큰은 없다.
파드는 자기 클러스터 자격 증명을 지니지 않는다.

격리는 물리적이다. 샌드박스 저장소는 조직당 파일 하나다.

## exec: 세션 *이* 샌드박스다

[exec](/docs/openapi/exec)는 한 번의 호출로 프로그램 전체를 돌린다. 언어는 열셋 —
`py`, `js`, `ts`, `bash`, `r`, `php`, `go`, `rs`, `c`, `cpp`,
`java`, `d`, `f90`.

```bash
curl -X POST https://api.hanzo.ai/v1/exec \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"language":"py","code":"print(6*7)"}'
```

자기 저장소도 자기 수명도 없다 — 돌려주는 세션 id *가*
샌드박스 id다. 영이 아닌 종료는 오류 상태가 아니라 **stderr가 있는 `200`**이다.
호출은 성공했고, 프로그램은 실패했다. 그건 다른 사실이다. 실행 사이에 파일 시스템을
지키려면 같은 `session_id`를 다시 넘긴다.

## 에이전트와 만나는 곳

`POST /v1/sandbox/run`은 이름 붙은 세션으로 이야기하고, 그 출력은
그 세션의 살아있는 로그에 붙는다 — [에이전트](/docs/concepts/agents) 세션 스트림이
이미 보고 있는 로그다. 둘 사이의 이음매가 그것이다. 샌드박스가 일을 하고,
세션이 그 기록이다.
