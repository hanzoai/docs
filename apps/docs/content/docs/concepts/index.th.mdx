## ประโยคเดียว

**คำขอ** พกข้อมูลประจำตัว ขอบแปลงข้อมูลนั้นเป็น
**องค์กร** — ขอบเขตการเช่าที่ทุกที่เก็บถูกแยกออกจากกัน ภายในองค์กรคุณ
สร้าง **โปรเจกต์** ซึ่งกำหนดขอบเขตของงาน โค้ดรันใน **แซนด์บ็อกซ์** ซึ่งคือ
สัญญาเช่า **เอเจนต์** คือนิยามบวก **เซสชัน** ที่บังคับทิศทางและ
เล่นซ้ำได้ สิ่งที่มันใช้จ่ายได้คือ **งบประมาณ** ซึ่งตรวจก่อนทุกการเรียก สิ่งที่มัน
รู้มาจาก **ความจำ** สิ่งที่เดินโดยคุณไม่ต้องสั่งคือ **เวิร์กโฟลว์**

สิ่งอื่นทั้งหมดใน API คือหนึ่งในเจ็ดนี้ พร้อมงานที่เฉพาะเจาะจง
