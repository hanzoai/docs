## La phrase unique

Une **requête** porte un justificatif. La périphérie transforme ce justificatif en une
**organisation** — la frontière de location sur laquelle chaque magasin est isolé. Dans une organisation vous
créez des **projets**, qui délimitent le travail. Le code s'exécute dans un **bac à sable**, qui est un
bail. Un **agent** est une définition plus une **session** que l'on peut piloter et
rejouer. Ce qu'il peut dépenser est son **budget**, vérifié avant chaque appel. Ce qu'il
sait vient de la **mémoire**. Ce qui tourne sans que vous le demandiez est un **flux de travail**.

Tout le reste de l'API est l'une de ces sept idées, avec un rôle précis.
