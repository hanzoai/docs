## 一句話

一次 **請求** 攜帶一份憑證。邊緣把這份憑證變成一個
**組織** — 每個儲存都按這個租戶邊界隔離。在組織裡你
建立 **專案**，用來劃定工作範圍。程式碼在 **沙箱** 裡執行，沙箱是一份
租約。一個 **代理** 是定義加上一個可以被駕駛、可以被重播的 **工作階段**。它可以花的是
**預算**，每次呼叫前都會檢查。它知道的來自 **記憶**。不用你開口就會跑的是
**工作流程**。

API 裡的其他一切，都是這七個想法裡的一個，帶著一件具體的事。
