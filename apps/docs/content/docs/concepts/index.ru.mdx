## Одно предложение

**Запрос** несёт учётные данные. Край превращает их в
**организацию** — границу аренды, по которой изолировано каждое хранилище. Внутри организации вы
создаёте **проекты**, которые ограничивают работу. Код выполняется в **песочнице**, а это
аренда. **Агент** — это определение плюс **сессия**, которую можно направлять и
воспроизводить. Сколько он может потратить — его **бюджет**, проверяемый перед каждым вызовом. То, что он
знает, приходит из **памяти**. То, что выполняется без вашего запроса, — **рабочий процесс**.

Всё остальное в API — одна из этих семи идей с конкретной работой.
