**หลังจากหน้านี้ คุณกำหนดเอเจนต์ได้ ดูมันทำงาน และบังคับมันขณะ
ที่มันรัน**

## คำนามสองคำ

**เอเจนต์** คือคำจำกัดความ: โมเดลหนึ่ง ข้อความระบบหนึ่ง และชุดชื่อเครื่องมือ
**เซสชัน** คือการรันที่ยังมีชีวิต — แถวที่ทุกพื้นผิวแขวนกิจกรรมของตน
ไม่ว่าพื้นผิวนั้นจะเป็น CLI คอนโซล แชท หรือบอต

```bash
curl -X POST https://api.hanzo.ai/v1/agents \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"triage","model":"zen-1","instructions":"Triage inbound issues.","tools":["search"]}'
```

```bash
hanzo agents list
```

ชื่อไม่ซ้ำในองค์กรของคุณ และตรงกับ
`^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$` โมเดลที่คุณตั้งชื่อถูกตรวจกับ
แคตตาล็อกที่เกตเวย์ให้บริการ **ตอนนิยาม** — พิมพ์ผิดถูกปฏิเสธตอนนี้
ไม่ใช่ตี 3 ของการรันแรก เอเจนต์ที่รันต่อเนื่องต้องถือ
ตาราง cron ห้าช่อง และนับเข้าเพดานต่อองค์กร

## หนึ่งโฟลว์คือหนึ่งต้นไม้

```bash
curl -X POST https://api.hanzo.ai/v1/agents/sessions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"agent":"triage"}'
```

เซสชันที่ถือ `parentSessionId` กลายเป็น **เอเจนต์ย่อย** ของเซสชันนั้น
และสืบทอดรากของมัน ดังนั้นพัดของเอเจนต์ย่อยสิบตัวไม่ใช่การรันที่ไม่เกี่ยวข้องสิบครั้ง —
มันคือหนึ่งต้นไม้ และ `/v1/agents/sessions/{id}/tree` คืนกราฟทั้งก้อนใน
การอ่านครั้งเดียว แต่ละโหนดถือจำนวนเหตุการณ์ของตน

การแสดงรายการคืน **เฉพาะเซสชันราก** เว้นแต่คุณขอให้ลงไป สถานะเป็นหนึ่งใน
`running`, `paused`, `done`, `error`

## บังคับเซสชันที่กำลังรัน

สี่คำสั่ง ทั้งหมดอยู่ใต้ `/v1/agents/sessions/{id}`: `message`, `pause`,
`resume`, `stop`

<Callout>
**คำสั่งคือเจตนา ไม่ใช่การเปลี่ยนสถานะ** ไม่มีอะไรในการเรียกนั้นเขียน
สถานะของเซสชัน `200` หมายความว่าคำสั่งถูกบันทึกอย่างคงทนและส่งถึง —
เอเจนต์ตัดสินใจเองว่าจะทำตามเมื่อใด
</Callout>

นี่คือสิ่งที่ทำให้การบังคับทำงานข้ามเครื่อง เซสชัน `hanzo code` ที่เริ่ม
บนแล็ปท็อปของคุณกินคำสั่งที่แดชบอร์ดโพสต์ โดยสำรวจ
`/v1/agents/sessions/{id}/control` — คำสั่งที่ใหม่กว่าเคอร์เซอร์ เก่าที่สุดก่อน
ไม่ส่งซ้ำเมื่อนำไปใช้แล้ว

การปฏิเสธสองอย่างที่ควรรู้: เซสชันที่ **จบแล้ว** ปฏิเสธทุกคำสั่งด้วย
`409` และ id ที่เป็นของผู้เช่ารายอื่นคือ `404` — ไม่มีองค์กรใดบังคับ
เอเจนต์ของอีกองค์กร และ 404 ไม่ยืนยันว่า id มีอยู่

`stop` คือข้อยกเว้นที่ยกเลิกจริง ไม่ใช่แค่ส่งสัญญาณ

## การเฝ้าดู

```
GET /v1/agents/sessions/stream
```

เหตุการณ์ที่เซิร์ฟเวอร์ส่ง: เฟรม `session` และเฟรม `event` แคบลงด้วย `?root=`
มันอยู่ในขอบเขตองค์กรและล้มแบบปิด — บัสกรองตามผู้เช่าก่อนกระจาย ผู้สมัครรับ
ที่ตามหลังเกิน 256 เฟรมถูกทิ้ง แทนที่จะปล่อยให้หน่วง
สตรีม และ `: ping` มาทุก 25 วินาที เพื่อให้การเชื่อมต่อที่ตาย
มองเห็น

รอบถูกบันทึกที่ `/v1/agents/sessions/{id}/events` — ข้อความ การเรียกเครื่องมือ
การเกิด บันทึก สถานะ การควบคุม — แต่ละอันตอบด้วย `seq` ที่เพิ่มขึ้นทางเดียว ไม่มีอะไร
หาย ดังนั้นการรันเล่นซ้ำได้หลังจากจบ
