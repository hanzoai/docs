**“โปรเจกต์” ตั้งชื่อสองสิ่ง** *โปรเจกต์ไซต์* คือสิ่งที่คุณปรับใช้ *โปรเจกต์ IAM*
คือขอบเขตภายในองค์กร ที่อยู่ต่างกัน วงจรชีวิตต่างกัน และเจ้าของต่างกัน

## โปรเจกต์ไซต์ — ที่ที่ไซต์อาศัย

แฮนเดิลที่บิลด์ถูกปรับใช้และให้บริการอยู่ใต้แฮนเดิลนั้น

```bash
curl -X POST https://api.hanzo.ai/v1/projects \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"slug":"acme-marketing"}'
```

```bash
hanzo projects list
```

**slug** คือส่วนที่รับน้ำหนัก มันกลายเป็นช่วงคีย์ของที่เก็บอ็อบเจ็กต์
โฮสต์สาธารณะ `<slug>.hanzo.app` และแฮนเดิลที่ทุกการเรียกถัดไปชี้ไป
มันตรงกับ `^[a-z0-9]([a-z0-9-]{0,38}[a-z0-9])?$` ป้ายที่สงวนไว้ถูกปฏิเสธ
และไม่ซ้ำ **ต่อองค์กร** — slug เดียวกันในองค์กรของคนอื่นไม่เกี่ยวกับคุณ
ชื่อโฮสต์สาธารณะในทางกลับกันไม่ซ้ำทั้งโลก
และเป็นของผู้ที่มาก่อน

การสร้างหนึ่งรายการยังจัดเตรียมพื้นที่ข้อมูลและที่เก็บ git มาตรฐาน ทั้งสองอย่าง
ทำเท่าที่ทำได้ มันตอบ `201` ในสถานะ `draft`

วงจรชีวิตของมันคือ **รุ่นที่เผยแพร่** ไม่ใช่สภาพแวดล้อม:

```
POST /v1/projects/{slug}/deploy
GET  /v1/projects/{slug}/releases
POST /v1/projects/{slug}/releases/{release}/activate
```

ทุกการปรับใช้คือรุ่นที่เผยแพร่ และรุ่นใดก็ทำให้ใช้งานจริงอีกครั้งได้ ดังนั้นการย้อนกลับ
คือการดำเนินการเดียวกับการเดินหน้า ชื่อโฮสต์ที่กำหนดเองถูกตรวจที่
`/v1/projects/{slug}/domains/{host}/verify`

การเผยแพร่สู่สาธารณะฟรี `visibility: private` คือฟีเจอร์ที่ต้องจ่าย

## โปรเจกต์ IAM — ขอบเขตภายในองค์กร

ขอบเขตที่คนเลือกเมื่องานแยกตามผลิตภัณฑ์หรือลูกค้า
ไม่ใช่ตามทีม มันถูกสร้างและลบ **เฉพาะ** ที่ `/v1/iam/projects`
และติดไปกับคำขอในฐานะ `X-Project-Id` ที่ผ่านการตรวจแล้ว

```
GET /v1/iam/projects
```

คุณไม่สร้างมันที่อื่น `/v1/platform/projects` เป็น *ภาพฉาย* —
โปรเจกต์บวกกับสิ่งที่ระนาบคอนเทนเนอร์วางไว้ข้างใต้ — และมัน
บอกอย่างตรงไปตรงมา แอปพลิเคชันอาศัยอยู่ข้างใต้:

```
/v1/platform/projects/{project}/apps/{app}
/v1/platform/projects/{project}/apps/{app}/env
/v1/platform/projects/{project}/apps/{app}/preview
```

คีย์ API ถูกจำกัดขอบเขตให้โปรเจกต์ IAM เดียวได้ ซึ่งเป็นวิธีปกติที่จะกัน
คีย์ก่อนโปรดักชันไม่ให้แตะข้อมูลโปรดักชัน

## แยกให้ออก

| | โปรเจกต์ไซต์ | โปรเจกต์ IAM |
|---|---|---|
| **มันคืออะไร** | ไซต์ที่ปรับใช้แล้ว | ขอบเขตภายในองค์กร |
| **สร้างที่** | `/v1/projects` | `/v1/iam/projects` |
| **จำได้จาก** | slug ที่ไม่ซ้ำต่อองค์กร | id ที่ถือไปเป็น `X-Project-Id` |
| **กำหนดรุ่นด้วย** | รุ่นที่เผยแพร่ | ไม่มีอะไร — มันเป็นเส้นแบ่ง |
| **ความสามารถ** | [โปรเจกต์](/docs/openapi/projects) | [iam](/docs/openapi/iam) |

กฎง่าย ๆ: **ถ้าคุณกำลังปรับใช้ไบต์ มันคือโปรเจกต์ไซต์ ถ้าคุณกำลัง
จำกัดสิทธิ์ มันคือโปรเจกต์ IAM**
