**بعد هذه الصفحة يمكنك حدّ ما ينفقه وكيل، وقراءة ما أنفقه، و
تمييز رفض الميزانية من فشل النموذج.**

## ما هي الميزانية

كل استدعاء نموذج وكل استدعاء أداة مسعّر يقوم به وكيل **يُسعَّر قبل أن
يُصنع** — حد أعلى لما قد يكلّفه الاستدعاء — ويُفحص هذا السعر،
بهذا الترتيب، مقابل أربعة أشياء:

1. **رصيد مؤسستك** — هل يمكن دفعه أصلًا
2. **سقف فترة الوكيل** — `cap_micro_usd` ناقص ما أنفقته هذه الفترة
3. **سقف المهمة** — `max_task_micro_usd` ناقص ما أنفقه هذا التشغيل
4. **ميزانية الجلسة** — `budget_micro_usd` ناقص ما أنفقته هذه الجلسة

أي واحد منها يرفض الاستدعاء. لا علم ولا التفاف: التشغيل لا يبلغ
نموذجًا إلا عبر البوابة.

## المال ميكرو دولار صحيح

كل مبلغ عدد صحيح من الميكرو دولار، في حقل لاحقته
`_micro_usd`. **1,000,000 دولار واحد**، لذا `11902000` هو 11.902 $ و`250` هو
جزء من أربعين من السنت. يكلّف الاستدعاء كسور سنت؛ وسقف محفوظ بالسنتات
لا يرى واحدًا.

## إعلان ميزانية

الحقول الثلاثة مطلوبة حين تعرّف وكيلًا.

```bash
curl -X POST https://api.hanzo.ai/v1/agent \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "triage",
    "model": "zen-1",
    "instructions": "Triage inbound issues.",
    "cap_micro_usd": 20000000,
    "max_task_micro_usd": 500000,
    "period": "month"
  }'
```

يجوز لهذا الوكيل أن ينفق **20 $ في الشهر**، ولا يجوز لتشغيل واحد منه أن ينفق أكثر
من **0.50 $**.

- يجب أن يكون `cap_micro_usd` موجبًا. سقف صفر يعني لا حد ولا
  سجل، وهي الحالة التي توجد الميزانية لإزالتها.
- يجب أن يكون `max_task_micro_usd` موجبًا ولا يجوز أن يتجاوز السقف.
- `period` هو `day` أو `week` أو `month`.

الفترات **محاذاة للتقويم بتوقيت UTC**: `month` يعني الشهر، لا ثلاثين
يومًا من أول استدعاء، و`week` يبدأ الاثنين. النافذة تدور عند
أول استدعاء بعد انقلابها، و`consumed_micro_usd` يعود إلى صفر.

## قراءة ما أنفقه

```
GET /v1/agent/{ref}/spend
```

```json
{
  "cap_micro_usd": 20000000,
  "max_task_micro_usd": 500000,
  "period": "month",
  "consumed_micro_usd": 11902000,
  "remaining_micro_usd": 8098000,
  "by_component": { "model": 11431000, "computer": 402000, "tool": 69000 }
}
```

`by_component` يقسم الإنفاق ثلاثًا: **model** كل إكمال اشتراه
الوكيل، **computer** زمن التشغيل الذي أقام فيه، **tool** استدعاء
أداة مسعّر. المكوّن بلا إنفاق **غائب، لا صفر**.

## كيف يبدو الرفض

الخرق يجيب `402` بالرمز `budget_exceeded`:

```json
{
  "error": {
    "code": "budget_exceeded",
    "message": "task budget exceeded: this call would cost up to 620000 micro-USD and 118000 remain",
    "event": "budget.exceeded",
    "scope": "task",
    "component": "model",
    "quote_micro_usd": 620000,
    "remaining_micro_usd": 118000
  }
}
```

`scope` يسمّي أي سقف رفض — `agent` أو `task` أو `session` — حتى تعرف
هل ترفع الشهر أو التشغيل أو هذه الجلسة وحدها.

<Callout>
**يُخبَر الوكيل داخل النطاق.** تحت جلسة تُلحَق الحمولة نفسها بتدفق
أحداث الجلسة كحدث حالة من `budget`، فيقرأ الوكيل
رفضه وهو ما زال يعمل ويستطيع أن يختم — يكتب ما لديه،
ويقول لماذا توقف — بدل أن ينهار على استدعاء فاشل.
</Callout>

`budget_exceeded` ليس فشل نموذج. الاستدعاء الذي فشل فيه النموذج يُعاد؛ والاستدعاء
الذي رفضته الميزانية لا يُعاد، لأن إعادته ترفضه مرة أخرى.

## الأسعار حدود عليا، والتسوية هي الفعلي

يخطئ السعر كبيرًا عمدًا: التوجيه كما سيُرسل، زائد أكبر
إكمال تسمح به الطلبية — `max_tokens`، أو 4,096 حين لا تسمّي الطلبية
أيًا — بسعر استدلال المنصة.

حين وقع الاستدعاء، ما **أبلغت عنه البوابة فعلًا** يُسوَّى
مقابل كل حصيلة فُحص السعر عليها، والفرق يعود
إلى السقف. الاستدعاء الذي فشل لا يُسوَّى أبدًا، فلا يُفوتر أبدًا ويعود
هامشه.

لهذا يمكن رفض وكيل وهامشه يبدو كافيًا: البوابة
تقارن سقف الاستدعاء التالي، لا كلفته المرجّحة.

## ميزانية الجلسة الخاصة

يجوز لجلسة أن تحمل سقفًا خاصًا بها، تحت سقف الوكيل:

```bash
curl -X POST https://api.hanzo.ai/v1/agent/sessions/$ID/budget \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"budget_micro_usd": 2000000}'
```

الجلسة التي تبلغ ميزانيتها **تُوقف مؤقتًا، لا تفشل** — يستأنف العمل
لحظة ترفع السقف أو تزيله. ثلاث قواعد:

- البديل يجب أن يكون **أكبر بصرامة** مما استهلكته الجلسة
- **الإزالة باتجاه واحد**: `{"budget_micro_usd": null}` يرفع السقف
  نهائيًا، ولا يمكن إعطاء تلك الجلسة واحدًا مرة أخرى
- الجلسة **التي أُنشئت بلا** ميزانية لا يمكن إعطاؤها واحدة لاحقًا

كل واحدة من هذه ترفض بـ `409` بدل أن تفعل شيئًا آخر بهدوء.

## وكيل عُرّف قبل وجود الميزانيات

يحمل سقف صفر و**ليس محدودًا** — إنفاقه ما زال يُحصى و
يُقرأ عند `/spend`، والتحديث يعطيه سقفًا. رفض كل وكيل عُرّف
قبل شحن الميزة يكون انقطاعًا، لا سياسة.
