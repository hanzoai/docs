**この七ページのあと、API の残りは自分で説明できます。**

クラウドには能力がたくさんあります。考えは多くありません。七つで、
組み合わさっています。一度読めば、まだ開いたことのない能力も
名前とアドレスから意味が通ります。

## 一文で

**リクエスト**は資格情報を運びます。エッジはその資格情報を
**組織**に変えます。すべてのストアが隔離されるテナンシー境界です。組織の中で
仕事の範囲を切る **プロジェクト** を作ります。コードは **サンドボックス** で動き、それは
リースです。**エージェント**は定義に、操縦も再生もできる **セッション** を足したものです。使ってよい額は
**予算**で、呼び出しの前に毎回検査されます。知っていることは **メモリ** から来ます。頼まなくても動くものは
**ワークフロー**です。

API のほかのすべては、この七つのどれかに具体的な仕事が付いたものです。
