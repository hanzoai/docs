## 一句话

一次 **请求** 携带一份凭证。边缘把这份凭证变成一个
**组织** — 每个存储都按这个租户边界隔离。在组织里你
创建 **项目**，用来划定工作范围。代码在 **沙箱** 里运行，沙箱是一份
租约。一个 **智能体** 是定义加上一个可以被驾驶、可以被回放的 **会话**。它可以花的是
**预算**，每次调用前都会检查。它知道的来自 **记忆**。不用你开口就会跑的是
**工作流**。

API 里的其他一切，都是这七个想法里的一个，带着一件具体的事。
