<Callout type="warn">
**«مشروع» يسمّي شيئين.** *مشروع الموقع* شيء تنشره. *مشروع IAM* نطاق داخل مؤسسة.
لهما عنوانان مختلفان، ودورتان حياتيتان مختلفتان، ومالكان مختلفان. المواصفات
تبقيهما منفصلين؛ وينبغي لك أن تفعل المثل.

## مشروع الموقع — حيث يعيش الموقع

مُعرّف تُنشَر تحته بنية وتُقدَّم.

```bash
curl -X POST https://api.hanzo.ai/v1/projects \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"slug":"acme-marketing"}'
```

```bash
hanzo projects list
```

**slug** هو الجزء الحامل. يصير مقطع مفتاح مخزن الكائنات،
والمضيف العام `<slug>.hanzo.app`، والمُعرّف الذي يتوجّه إليه كل استدعاء لاحق.
يطابق `^[a-z0-9]([a-z0-9-]{0,38}[a-z0-9])?$`، والتسميات المحجوزة تُرفض،
وهو فريد **لكل مؤسسة** — الـ slug نفسه في مؤسسة شخص آخر لا يعنيك.
اسم المضيف العام، في المقابل، فريد على مستوى العالم
ويذهب إلى من يصل أولًا.

إنشاء واحد يوفّر أيضًا مساحة بيانات ومستودع git معياريًا، وكلاهما بأفضل جهد.
يجيب `201` في حالة `draft`.

دورة حياته هي **الإصدارات**، لا البيئات:

```
POST /v1/projects/{slug}/deploy
GET  /v1/projects/{slug}/releases
POST /v1/projects/{slug}/releases/{release}/activate
```

كل نشر هو إصدار، وأي إصدار يمكن جعله حيًا من جديد، لذا الرجوع إلى الخلف
هو العملية نفسها كالتقدّم إلى الأمام. أسماء المضيف المخصّصة تُتحقَّق عند
`/v1/projects/{slug}/domains/{host}/verify`.

النشر علنًا مجاني؛ `visibility: private` هي الميزة المدفوعة.

## مشروع IAM — نطاق داخل مؤسسة

النطاق الذي يختاره الناس حين ينفصل عملهم حسب المنتج أو العميل لا حسب الفريق.
يُنشأ ويُحذف **فقط** عند `/v1/iam/projects`،
ويركب على الطلب بوصفه `X-Project-Id` المُتحقَّق منه.

```
GET /v1/iam/projects
```

لا تنشئ واحدًا في أي مكان آخر. `/v1/platform/projects` *إسقاط* —
المشروع زائد ما وضعته طبقة الحاويات تحته — وهو يقول ذلك صراحة.
التطبيقات تعيش تحته:

```
/v1/platform/projects/{project}/apps/{app}
/v1/platform/projects/{project}/apps/{app}/env
/v1/platform/projects/{project}/apps/{app}/preview
```

يمكن حصر مفتاح API في مشروع IAM واحد، وهي الطريقة المعتادة لمنع
مفتاح ما قبل الإنتاج من لمس بيانات الإنتاج.

## التمييز بينهما

| | مشروع الموقع | مشروع IAM |
|---|---|---|
| **ما هو** | موقع منشور | نطاق داخل مؤسسة |
| **يُنشأ عند** | `/v1/projects` | `/v1/iam/projects` |
| **يُعرَّف بـ** | slug فريد لكل مؤسسة | معرّف يُحمَل كـ `X-Project-Id` |
| **يُنسَخ بـ** | إصدارات | لا شيء — إنه حد |
| **القدرة** | [المشاريع](/docs/openapi/projects) | [iam](/docs/openapi/iam) |

قاعدة عملية: **إذا كنت تنشر بايتات، فهو مشروع موقع. إذا كنت
تحصر الأذونات، فهو مشروع IAM.**
