## Der eine Satz

Eine **Anfrage** trägt einen Berechtigungsnachweis. Der Rand macht daraus eine
**Organisation** — die Mandantengrenze, an der jeder Speicher isoliert ist. In einer Organisation legen Sie
**Projekte** an, die Arbeit eingrenzen. Code läuft in einer **Sandbox**, und die ist ein
Mietverhältnis. Ein **Agent** ist eine Definition plus eine **Sitzung**, die gelenkt und
erneut abgespielt werden kann. Was er ausgeben darf, ist sein **Budget**, geprüft vor jedem Aufruf. Was er
weiß, kommt aus dem **Speicher**. Was ohne Ihre Aufforderung läuft, ist ein **Ablauf**.

Alles andere in der API ist eine dieser sieben Ideen mit einer konkreten Aufgabe.
