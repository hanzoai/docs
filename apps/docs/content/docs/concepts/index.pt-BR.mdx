## A frase única

Uma **solicitação** carrega uma credencial. A borda transforma essa credencial numa
**organização** — a fronteira de locação sobre a qual cada armazenamento fica isolado. Dentro de uma organização você
cria **projetos**, que delimitam o trabalho. O código roda numa **sandbox**, que é um
arrendamento. Um **agente** é uma definição mais uma **sessão** que pode ser conduzida e
reproduzida. O que ele pode gastar é o **orçamento**, conferido antes de cada chamada. O que ele
sabe vem da **memória**. O que roda sem você pedir é um **fluxo de trabalho**.

Todo o resto da API é uma dessas sete, com uma função específica.
