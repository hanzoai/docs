**Bu sayfadan sonra çalışan bir kimliğiniz ve yanıt vermiş bir çağrınız olur.**

Hanzo, tek anahtarın ardındaki tek buluttur. Her yetenek — çıkarım, kimlik,
depolama, para, aracılar — `https://api.hanzo.ai` adresinde yanıt verir; CLI,
SDK’lar ve MCP araçları aynı açıklamadan üretilir. Hizmet başına bağlayacak
bir şey yoktur: anahtarı bir kez alın, her şeye erişin.

## 1. Kurun

<Tabs items={['npm', 'Script', 'Homebrew', 'Kaynaktan']}>
<Tab value="npm">
```bash
npm i -g hanzo
```

`hanzo` tek kurulumda hem CLI hem istemcidir.
</Tab>
<Tab value="Script">
```bash
curl -fsSL https://hanzo.sh | sh
```

`~/.local/bin` içine kurulur. `https://hanzo.sh/cli` yalnız CLI’yi kurar.
</Tab>
<Tab value="Homebrew">
```bash
brew install hanzoai/tap/hanzo
```
</Tab>
<Tab value="Kaynaktan">
```bash
git clone https://github.com/hanzoai/cli && cd cli && cargo install --path .
```
</Tab>
</Tabs>

```bash
hanzo version
```

## 2. Oturum açın

```bash
hanzo auth login
```

Bu, Hanzo’nun kimlik sağlayıcısı [hanzo.id](https://hanzo.id) üzerinde bir tarayıcı
açar ve kimliği yerelde saklar. `hanzo auth show` kim olduğunuzu yazar;
`hanzo auth list` bu makinedeki her kimliği gösterir ve
`hanzo auth use` aralarında geçiş yapar.

Bir sunucuda kişi oturumu açmak yerine anahtar üretin: **console.hanzo.ai →
API anahtarları**. Gizli anahtar *sizsiniz*, bu yüzden sunucuda durur, asla
bir tarayıcıda değil — [Kimlik doğrulama](/docs/api-keys) kuralın tamamıdır.

```bash
export HANZO_API_KEY=sk-...
```

## 3. Modelleri listeleyin

Ağ geçidinin şu an sunduğu modellerin kataloğu. Bir okumadır, yalnızca
anahtar ister ve dört yüzeyde de aynı işlemdir.

<Tabs items={['CLI', 'SDK', 'HTTP', 'MCP']}>
<Tab value="CLI">
```bash
hanzo models list
```
</Tab>
<Tab value="SDK">
<Tabs items={['.ts', '.py', '.go', '.rs', '.swift', '.kt']}>
<Tab value=".ts">
```bash
npm i hanzo
```

Hepsi API’nin aynı açıklamasından üretildiği için yöntem adları
diller arasında hizalanır. [C++](/docs/sdks/cpp) hâlâ yerine
oturanıdır.
</Tab>
<Tab value="HTTP">
```bash
curl https://api.hanzo.ai/v1/models \
  -H "Authorization: Bearer $HANZO_API_KEY"
```
</Tab>
<Tab value="MCP">
```bash
curl -X POST https://api.hanzo.ai/v1/mcp \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

Bir uç nokta, yetenek başına bir araç. `tools/call` yeteneği ve
işlemi adlandırır; `describe` herhangi bir işlemin girdisini açıklar.
</Tab>
</Tabs>

Bunlar dört yerden görülen tek API’dir ve yukarıdaki sekmeler bütün
farktır. Yazacağınızı seçin:

- **[CLI](/docs/cli)** — her yetenek bir komut grubu, her biri için bir sayfa.
- **[SDK’lar](/docs/sdks)** — Python, TypeScript, Go, Rust, C++, Swift ve Kotlin,
  CLI ve araçlarla aynı açıklamadan üretilir.
- **[MCP](/docs/mcp)** — bir aracının bağlandığı tek uç nokta; [araçlar](/docs/mcp-tools)
  yetenek başına bir tane listelenir.

HTTP’nin sayfaya ihtiyacı yok: `https://api.hanzo.ai` ve az önce dışa aktardığınız anahtar.

## 4. Bir tamamlama gönderin

Kredi düşüren ilk adım budur; yukarıdaki her şey ücretsiz çalışır.

```bash
hanzo chat completions --model zen-1 --messages '[{"role":"user","content":"hello"}]'
```

Sonra ne kadar düştüğünü okuyun:

```bash
hanzo billing balance
hanzo usage summary
```

[Krediler ve faturalama](/docs/credits) kredinin ne olduğunu ve sıfırda ne olduğunu anlatır;
[Fiyatlar](/docs/pricing) her model ve aracın tarifesidir.

## 5. Bulutu yerelde çalıştırın

`api.hanzo.ai`’yi sunan aynı ikili sizin makinenizde çalışır:

```bash
hanzo up cloud
```

Yalın `hanzo up` aynı şeydir — `cloud` varsayılandır. Tek başına çalıştırmak için bir hizmet adlandırın:
`hanzo up iam`, `hanzo up kms`, `hanzo up gateway`, `hanzo up
storage`, `hanzo up pubsub`. Bunun ne anlama geldiği ve ne gerektirdiği için [Kendiniz çalıştırın](/docs/network) sayfasına bakın.
