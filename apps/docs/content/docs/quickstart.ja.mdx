**このページのあとには、動く認証情報と、返事の来た呼び出しがひとつあります。**

Hanzo はひとつの鍵の向こうにあるひとつのクラウドです。推論、アイデンティティ、
ストレージ、お金、エージェント — どれも `https://api.hanzo.ai` で答え、CLI と
SDK と MCP ツールは同じ記述から生成されます。サービスごとに配線する
ものはありません。鍵を一度取れば、すべてに届きます。

## 1. インストール

<Tabs items={['npm', 'Script', 'Homebrew', 'ソースから']}>
<Tab value="npm">
```bash
npm i -g hanzo
```

`hanzo` は CLI とクライアントが一度のインストールに入っています。
</Tab>
<Tab value="Script">
```bash
curl -fsSL https://hanzo.sh | sh
```

`~/.local/bin` に入ります。`https://hanzo.sh/cli` は CLI だけを入れます。
</Tab>
<Tab value="Homebrew">
```bash
brew install hanzoai/tap/hanzo
```
</Tab>
<Tab value="ソースから">
```bash
git clone https://github.com/hanzoai/cli && cd cli && cargo install --path .
```
</Tab>
</Tabs>

```bash
hanzo version
```

## 2. ログイン

```bash
hanzo auth login
```

ブラウザが [hanzo.id](https://hanzo.id)、Hanzo のアイデンティティ
プロバイダに開き、できた認証情報をローカルに保存します。`hanzo auth show` は
あなたが誰かを表示し、`hanzo auth list` はこのマシンのすべてのアイデンティティを示し、
`hanzo auth use` はそれらを切り替えます。

サーバでは人をログインさせず、鍵を発行します。**console.hanzo.ai →
API キー**。秘密鍵は*あなた*なので、サーバに置き、ブラウザには
決して置きません — [認証](/docs/api-keys) がルールのすべてです。

```bash
export HANZO_API_KEY=sk-...
```

ゲートウェイが今提供しているモデルのカタログです。読み取りで、必要なのは
鍵だけで、四つの面で同じ操作です。

どれも API の同じ記述から生成されるので、メソッド名は
言語をまたいで揃います。[C++](/docs/sdks/cpp) は、まだ着地している
途中のものです。
</Tab>
<Tab value="HTTP">
```bash
curl https://api.hanzo.ai/v1/models \
  -H "Authorization: Bearer $HANZO_API_KEY"
```
</Tab>
<Tab value="MCP">
```bash
curl -X POST https://api.hanzo.ai/v1/mcp \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

エンドポイントはひとつ、能力ごとにツールがひとつ。`tools/call` は能力と
操作を名付け、`describe` はどの操作の入力も説明します。
</Tab>
</Tabs>

ひとつの API を四つの場所から見ているだけで、上のタブがその
違いのすべてです。書くものを選んでください。

- **[CLI](/docs/cli)** — 能力ごとにコマンドグループ、ページはひとつずつ。
- **[SDK](/docs/sdks)** — Python、TypeScript、Go、Rust、C++、Swift、Kotlin。
  CLI とツールと同じ記述から生成されます。
- **[MCP](/docs/mcp)** — エージェントが接続するエンドポイントがひとつ。[ツール](/docs/mcp-tools)は
  能力ごとにひとつ載っています。

HTTP にページは要りません。`https://api.hanzo.ai` と、いま書き出した鍵です。

## 4. 補完を送る

ここがクレジットを使う最初の一歩です。ここより上は無料で実行できます。

```bash
hanzo chat completions --model zen-1 --messages '[{"role":"user","content":"hello"}]'
```

それから、いくら使ったかを読みます。

```bash
hanzo billing balance
hanzo usage summary
```

[クレジットと請求](/docs/credits)はクレジットとは何か、ゼロで何が起きるかを説明します。
[料金](/docs/pricing)はモデルとツールごとのレートです。

## 5. クラウドをローカルで動かす

`api.hanzo.ai` を配っているのと同じバイナリが、あなたのマシンで動きます。

```bash
hanzo up cloud
```

ただの `hanzo up` も同じです — `cloud` が既定です。サービスをひとつ名指しして
それだけ動かすこともできます。`hanzo up iam`、`hanzo up kms`、`hanzo up gateway`、`hanzo up
storage`、`hanzo up pubsub`。意味と必要なものは[自分で動かす](/docs/network)を見てください。
