下のどのモデルも、一つの住所で一つの鍵から届く。`id` を
`model` として渡せば、どれを選んでもリクエストの残りは同じだ。

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"<id from below>","messages":[{"role":"user","content":"Hello"}]}'
```

このページを開くと、ブラウザが [`/v1/models`](/docs/openapi/ai) から表を取る。だからこれは
ページを書いたときの写しではなく、ゲートウェイが今出している一覧だ。

## 料金が意味すること

料金は百万トークンあたりで、入力と出力は別料金。CLI、SDK、HTTP、MCP ツールの
どこから呼んでも同じだ — 価格はモデルの性質であって、届く面の性質ではない。

[料金](/docs/pricing)は利用が請求になる仕組みを説明する。[クレジット](/docs/credits)は
残高が尽きたときに何が起きるかを扱う。
