# คอนโซล

คอนโซล Hanzo คือพื้นผิวควบคุมแบบรวมของ Hanzo Cloud -- แอปที่คุณกำลังดูอยู่ มันรวมทุกผลิตภัณฑ์คลาวด์ไว้ที่เดียว: ตัวตน, คีย์, ความลับ, โมเดล, การเรียกเก็บเงิน, การทำให้ใช้งานได้ และแดชบอร์ด ทั้งหมดอยู่ในขอบเขตขององค์กรคุณ

## แอปเดียวสำหรับทุกผลิตภัณฑ์

คอนโซลเรนเดอร์จากแคตตาล็อกผลิตภัณฑ์เดียว ดังนั้นทุกบริการของ Hanzo Cloud เข้าถึงได้จากแถบนำทาง ภาพรวม และพาเล็ตคำสั่งเดียวกัน แต่ละผลิตภัณฑ์เป็นโมดูลในตัว -- ไม่ใช่ลิงก์ออกไปข้างนอก -- และอิง API `/v1` จริง:

- **AI** -- โมเดล, สนามทดลอง, ผู้ให้บริการ, embeddings
- **ความปลอดภัย** -- [IAM](/docs/openapi/iam), [KMS](/docs/openapi/kms), [Authz](/docs/openapi/authz), [MPC](/docs/openapi), [Zero Trust](/docs/openapi/network)
- **สังเกตการณ์** -- [แดชบอร์ด](/docs/openapi/o11y), ค่าใช้จ่าย, [การเรียกเก็บเงิน](/docs/openapi/billing), สถานะ
- **ทำให้ใช้งานได้** -- โปรเจกต์, สภาพแวดล้อม, ฟังก์ชัน, คลัสเตอร์

## การลงชื่อเข้าใช้และขอบเขต

คอนโซลลงชื่อเข้าใช้ผ่าน Hanzo IAM ที่ [hanzo.id](https://hanzo.id) ในฐานะแอปพลิเคชัน `hanzo-cloud` เซสชันของคุณอยู่ในขอบเขตของ**องค์กร** และผู้ดูแลระบบส่วนกลางสามารถสลับขอบเขตไปยังองค์กรใดก็ได้ ข้อมูลถูกกำหนดขอบเขตใหม่ในที่ขณะที่อัตลักษณ์แบรนด์คงเดิม ดู [IAM](/docs/openapi/iam) และ[องค์กร](/docs/openapi/iam)

## มันถูกส่งมอบอย่างไร

คอนโซลเป็นแอปหน้าเดียวที่ฝัง (`go:embed`) ตรงเข้าไปในไบนารีของ Hanzo Cloud และให้บริการที่ `console.hanzo.ai` เป็นไคลเอนต์ล้วนบนแบ็กเอนด์ `/v1` แบบรวม -- ไม่มีฐานข้อมูลของตัวเอง ทุกมุมมองเป็นข้อมูลจริงจาก API ของบริการ

```bash
# The console calls the same API you can call directly, with the same key
curl https://api.hanzo.ai/v1/models \
  -H "Authorization: Bearer sk-..."
```

## ที่เกี่ยวข้อง

- [IAM](/docs/openapi/iam) -- ตัวตนและขอบเขตองค์กรเบื้องหลังทุกมุมมองของคอนโซล
- [คีย์ API](/docs/api-keys) -- สร้างคีย์จากคอนโซลสำหรับ API
- [แดชบอร์ด](/docs/openapi/o11y) -- พื้นผิวการวิเคราะห์และความสามารถในการสังเกต
- [การเรียกเก็บเงิน](/docs/openapi/billing) -- ยอดคงเหลือ การใช้งาน และใบแจ้งหนี้
- [API](/docs/openapi) -- พื้นผิว `/v1` เดียวกันที่คอนโซลเรนเดอร์
