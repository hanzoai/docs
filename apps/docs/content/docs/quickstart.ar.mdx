**بعد هذه الصفحة لديك اعتماد يعمل واستدعاء أجاب.**

Hanzo سحابة واحدة خلف مفتاح واحد. كل قدرة — استدلال وهوية
وتخزين ومال ووكلاء — تجيب على `https://api.hanzo.ai`، وواجهة سطر الأوامر و
SDK وأدوات MCP تُولَّد من الوصف نفسه. لا شيء توصله لكل خدمة:
مفتاح واحد مرة واحدة ويصبح كل شيء في المتناول.

## 1. التثبيت

<Tabs items={['npm', 'Script', 'Homebrew', 'من المصدر']}>
<Tab value="npm">
```bash
npm i -g hanzo
```

`hanzo` هي واجهة سطر الأوامر والعميل في تثبيت واحد.
</Tab>
<Tab value="Script">
```bash
curl -fsSL https://hanzo.sh | sh
```

يُثبَّت في `~/.local/bin`. `https://hanzo.sh/cli` يثبّت الواجهة وحدها.
</Tab>
<Tab value="Homebrew">
```bash
brew install hanzoai/tap/hanzo
```
</Tab>
<Tab value="من المصدر">
```bash
git clone https://github.com/hanzoai/cli && cd cli && cargo install --path .
```
</Tab>
</Tabs>

```bash
hanzo version
```

## 2. تسجيل الدخول

```bash
hanzo auth login
```

يفتح ذلك متصفحًا على [hanzo.id](https://hanzo.id)، مزوّد هوية
Hanzo، ويخزن الاعتماد محليًا. `hanzo auth show` يطبع
من أنت؛ `hanzo auth list` يعرض كل هوية على هذا الجهاز و
`hanzo auth use` ينتقل بينها.

على خادم، اصنع مفتاحًا بدل تسجيل دخول شخص: **console.hanzo.ai →
مفاتيح API**. المفتاح السري هو *أنت*، فيبقى على خادم ولا يدخل
متصفحًا أبدًا — [المصادقة](/docs/api-keys) هي القاعدة كلها.

```bash
export HANZO_API_KEY=sk-...
```

## 3. اسرد النماذج

فهرس النماذج التي تخدمها البوابة الآن. إنها قراءة، لا تحتاج
سوى المفتاح، وهي العملية نفسها على الأسطح الأربعة.

كلها مولَّدة من وصف API نفسه، فتتطابق أسماء
الأساليب عبر اللغات. [C++](/docs/sdks/cpp) هو الذي ما زال
في الطريق.
</Tab>
<Tab value="HTTP">
```bash
curl https://api.hanzo.ai/v1/models \
  -H "Authorization: Bearer $HANZO_API_KEY"
```
</Tab>
<Tab value="MCP">
```bash
curl -X POST https://api.hanzo.ai/v1/mcp \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

نقطة نهاية واحدة وأداة لكل قدرة. `tools/call` يسمي القدرة و
العملية؛ `describe` يشرح دخل أي عملية.
</Tab>
</Tabs>

هذه API واحدة من أربعة مواضع، والألسنة أعلاه هي
الفرق كله. اختر ما ستكتب به:

- **[CLI](/docs/cli)** — كل قدرة مجموعة أوامر، وصفحة لكل واحدة.
- **[SDKs](/docs/sdks)** — Python وTypeScript وGo وRust وC++ وSwift وKotlin،
  مولَّدة من الوصف نفسه الذي تُبنى منه الواجهة والأدوات.
- **[MCP](/docs/mcp)** — نقطة نهاية يتصل بها وكيل؛ [الأدوات](/docs/mcp-tools)
  مدرجة واحدة لكل قدرة.

HTTP لا يحتاج صفحة: هو `https://api.hanzo.ai` والمفتاح الذي صدّرته للتو.

## 4. أرسل إكمالًا

هذه أول خطوة تسحب رصيدًا؛ كل ما فوقها يعمل مجانًا.

```bash
hanzo chat completions --model zen-1 --messages '[{"role":"user","content":"hello"}]'
```

ثم اقرأ ما سحبته:

```bash
hanzo billing balance
hanzo usage summary
```

[الأرصدة والفوترة](/docs/credits) تشرح ما هو الرصيد وما يحدث عند
الصفر؛ [الأسعار](/docs/pricing) هي تعرفة كل نموذج وأداة.

## 5. شغّل السحابة محليًا

الثنائي نفسه الذي يخدم `api.hanzo.ai` يعمل على جهازك:

```bash
hanzo up cloud
```

`hanzo up` وحده هو الشيء نفسه — `cloud` هو الافتراضي. سمِّ خدمة لتشغّلها
وحدها: `hanzo up iam` و`hanzo up kms` و`hanzo up gateway` و`hanzo up
storage` و`hanzo up pubsub`. انظر [شغّل نسختك](/docs/network) لتعرف ماذا
يعني ذلك وماذا يحتاج.
