नीचे हर मॉडल एक पते पर एक कुंजी से पहुँच में है. `id` को
`model` की तरह भेजें और अनुरोध का बाकी हिस्सा वही रहता है, चाहे आप कोई भी चुनें.

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"<id from below>","messages":[{"role":"user","content":"Hello"}]}'
```

पृष्ठ लोड होने पर तालिका आपके ब्राउज़र में [`/v1/models`](/docs/openapi/ai) से आती है, इसलिए यह
वह सूची है जो गेटवे अभी दे रहा है, न कि पृष्ठ बनते समय लिखी प्रतिलिपि.

## दर का मतलब

दरें प्रति दस लाख टोकन हैं, इनपुट और आउटपुट अलग दाम के, और CLI, SDK, HTTP या MCP
उपकरण से कॉल करने पर एक जैसी — कीमत मॉडल का गुण है, उस सतह का नहीं जिससे आप पहुँचते हैं.

[मूल्य](/docs/pricing) बताता है उपयोग बिल कैसे बनता है. [क्रेडिट](/docs/credits)
बताता है शेष खत्म होने पर क्या होता है.
