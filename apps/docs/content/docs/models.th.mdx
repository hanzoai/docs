โมเดลทุกรายการด้านล่างถึงได้ด้วยกุญแจเดียวบนที่อยู่เดียว ส่ง `id` เป็น
`model` แล้วที่เหลือของคำขอเหมือนกันไม่ว่าคุณจะเลือกอันไหน

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"<id from below>","messages":[{"role":"user","content":"Hello"}]}'
```

ตารางถูกดึงจาก [`/v1/models`](/docs/openapi/ai) ในเบราว์เซอร์เมื่อ
หน้านี้โหลด ดังนั้นมันคือแคตตาล็อกที่เกตเวย์ให้บริการตอนนี้ ไม่ใช่

## อัตราหมายถึงอะไร

อัตราคิดต่อล้านโทเคน อินพุตและเอาต์พุตคิดราคาแยก และเท่ากัน
ไม่ว่าคุณเรียกจาก CLI, SDK, HTTP หรือเครื่องมือ MCP — ราคาเป็นคุณสมบัติของโมเดล
ไม่ใช่ของพื้นผิวที่คุณใช้เข้าถึง
