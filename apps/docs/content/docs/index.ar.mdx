<ProviderStrip />

## المنصة حسب المجال

لكل قدرة اسم واحد ومسار واحد — `/v1/<name>` — وتعيش في
مجال واحد بالضبط. لا شيء مكرر، فلا شيء غامض.

## خذها معك

السحابة أعلاه وتلك التي تشغّلها بنفسك هما [البرنامج
نفسه](/docs/network) — الثنائي نفسه والعقد نفسه ومسارات `/v1` نفسها. أحضر
وحدة GPU أو Kubernetes، أو عدّن على أي جهاز.

```bash
curl -fsSL https://hanzo.sh | sh
```

<Callout type="info">
هذه **V8 · Open Edition**، محددة في [HIP-0127](https://hips.hanzo.ai):
عقد واحد وربطات كثيرة وعملاء رفيعون وسلك — لا FFI أبدًا — بين
اللغات. انظر [فلسفة الهندسة](/docs/architecture/philosophy) لتعرف *السبب*.
</Callout>
