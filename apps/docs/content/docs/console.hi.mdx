# कंसोल

Hanzo कंसोल, Hanzo Cloud की एकीकृत नियंत्रण सतह है -- वही ऐप जिसे आप देख रहे हैं। यह हर क्लाउड उत्पाद को एक जगह लाता है: पहचान, कुंजियाँ, रहस्य, मॉडल, बिलिंग, परिनियोजन और डैशबोर्ड, सब आपके संगठन के दायरे में।

## हर उत्पाद के लिए एक ऐप

कंसोल एक ही उत्पाद कैटलॉग से रेंडर होता है, इसलिए हर Hanzo Cloud सेवा उसी नेविगेशन, अवलोकन और कमांड पैलेट से पहुँच में है। हर उत्पाद एक मूल मॉड्यूल है -- बाहर की कड़ी नहीं -- वास्तविक `/v1` API पर आधारित:

- **AI** -- मॉडल, प्लेग्राउंड, प्रदाता, embeddings
- **सुरक्षा** -- [IAM](/docs/openapi/iam), [KMS](/docs/openapi/kms), [Authz](/docs/openapi/authz), [MPC](/docs/openapi), [Zero Trust](/docs/openapi/network)
- **अवलोकन** -- [डैशबोर्ड](/docs/openapi/o11y), लागत, [बिलिंग](/docs/openapi/billing), स्थिति
- **परिनियोजन** -- प्रोजेक्ट, वातावरण, फ़ंक्शन, क्लस्टर

## साइन-इन और दायरा

कंसोल [hanzo.id](https://hanzo.id) पर Hanzo IAM के माध्यम से `hanzo-cloud` अनुप्रयोग के रूप में साइन इन करता है। आपका सत्र एक **संगठन** के दायरे में है, और एक वैश्विक व्यवस्थापक दायरा किसी भी संगठन पर बदल सकता है; ब्रांड पहचान स्थिर रहती है जबकि डेटा उसी जगह नए दायरे में आ जाता है। देखें [IAM](/docs/openapi/iam) और [संगठन](/docs/openapi/iam)।

## यह कैसे पहुँचता है

कंसोल एक एकल-पृष्ठ ऐप है जो (`go:embed`) सीधे Hanzo Cloud बाइनरी में एम्बेड है और `console.hanzo.ai` पर परोसा जाता है। यह एकीकृत `/v1` बैकएंड पर एक शुद्ध क्लाइंट है -- इसका अपना डेटाबेस नहीं है; हर दृश्य किसी सेवा API का वास्तविक डेटा है।

```bash
# The console calls the same API you can call directly, with the same key
curl https://api.hanzo.ai/v1/models \
  -H "Authorization: Bearer sk-..."
```

## संबंधित

- [IAM](/docs/openapi/iam) -- हर कंसोल दृश्य के पीछे पहचान और संगठन का दायरा
- [API कुंजियाँ](/docs/api-keys) -- API के लिए कंसोल से कुंजियाँ बनाएँ
- [डैशबोर्ड](/docs/openapi/o11y) -- विश्लेषण और अवलोकनीयता की सतहें
- [बिलिंग](/docs/openapi/billing) -- शेष, उपयोग और चालान
- [API](/docs/openapi) -- वही `/v1` सतह जिसे कंसोल रेंडर करता है
